DSHA 0.1.5-rc1 正式版，由贡献者 @ym2025szz 维护并发布，感谢原作者 @qiannianhuanxiang 和其他贡献者。与 GitHub Latest 使用相同的已验收 APK，版本码 116。
新版 dsh 0.1.5-rc.1：支持 DeepSeek-V41-Flash，保留 V4 模型选项；图片、文本附件和读取工具已完成实际调用。
文件与移动体验：Markdown、HTML、PDF、图片、代码和长文本预览，滚动与代码复制；标签关闭“×”在右侧居中，完善键盘避让、回车换行、提示、图片草稿和阅读位置恢复。
启动与安装：拆分 Ubuntu / dsh 离线包，复用未变化网页脚本，修复首次原生扩展缓存失败。Android 16 同机启动至鉴权 3.43～3.66 秒，完整冷环境验证约 19.3 秒。
覆盖更新：相同 Ubuntu 基础环境只更新受管运行时，个人目录、会话、配置和第三方插件保持原位；基础环境变更先保护数据再重建。取消按启动次数自动备份和启动时全目录扫描，保留手动备份与回退恢复。
错误与维护：启动阶段、实际插件错误、退出码和日志下载；60 秒后继续等待，独立安全启动；核验 Web PID，维护前回收终端及后台任务。
延续预览版能力：双版本、插件安装／导入／导出／启停／更新／回退、后台 APK 下载与校验、无线 ADB、Shizuku、局域网和 PTY，并完善设备命令白名单。
与上次已发布 rc1.4 预览版相比，dsh 从 0.1.2-rc.1 升至 0.1.5-rc.1，标准 APK 约缩小 17.3%，兼容 APK 约缩小 12.7%。
升级前先保留手动备份。此前已发布 v1.2 预览版基础环境为 9，升到本版 10 需要保护数据并重建；本地 alpha.2 的同基础环境局部更新实测约 7.45 秒。
本轮 Android 16 验证模型、附件、工具、WebView／Gecko、文件预览、启动、更新、终端、插件及备份；两版各 330 项单测无失败。Android 6/7、真实 16 KB 页内核仍需实机补充，不代表所有机型均已验证。
