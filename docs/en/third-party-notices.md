# Third-party component notices

This is the English translation of the notice generated by `python tools/generate-third-party-notices.py` from the current locks and actual assets. DSHA-owned code is MIT-licensed. Each bundled third-party component follows its own license; the APK-level license does not convert it to MIT.

## DSH and npm dependencies

- `@deepseek-ai/dsh` is **0.2.1-rc.2**. Complete versions, origins, and integrity values are in `tools/dsh-runtime/package-lock.json`; original package license files remain in the runtime archive.
- Office entry point `@deepseek-ai/libreoffice-kit` **0.1.5**, WASM **0.1.5**: upstream NOTICE, licenses, sources, and prebuilt explanations are retained. DSHA font-path adaptation is in `assets/office-fonts-patch.json`.
- pnpm **10.34.5** (MIT) and certifi **2026.7.22** (MPL-2.0): `tools/runtime-tools.lock.json` pins versions and original-package digests. The CA configuration does not disable TLS verification.
- Inspect license directories and actual dependencies together with archive members. Optional dependencies for other platforms in a lockfile are not necessarily included in the arm64 APK.
- core-js **3.50.0** (MIT), original package `https://registry.npmjs.org/core-js/-/core-js-3.50.0.tgz`; full license at `assets/web-integration/core-js.LICENSE`.
- sharp **0.35.5** is Apache-2.0. The arm64 libvips package **1.3.4** declares LGPL-3.0-or-later, sourced from the original locked npm package and https://github.com/lovell/sharp-libvips . Its README describes embedded dependencies and source retrieval; check these against the actual binary rather than extending one libvips license to all embedded libraries.
- `@ubjs/core` / `@ubjs/node` **0.31.0-3** are MPL-2.0, from https://github.com/jhugman/uniffi-bindgen-react-native . The `@trycua/cua-driver` **0.28.0** wrapper is MIT, while its Linux arm64 native package declares **MIT AND MPL-2.0**, from https://github.com/trycua/cua . Check native-package declarations separately from the wrapper.
- Full MPL-2.0, LGPL-3.0, and GPL-3.0 texts are supplied in `assets/licenses`; exact text origins and digests are recorded in `docs/audits/build156/third-party-license-sources.json`. A generic license text does not establish a binary original's provenance or redistribution rights.

- proroot v1.2.8 uses an upstream proprietary license. DSHA distributes original upstream binaries without claiming rebuildable/auditable source or arbitrary redistribution after modification. See bundled notices for license and provenance. Container root does not imply Android root permission.
