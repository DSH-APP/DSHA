## Changes

- New package `dsh.android.client` installs alongside old `com.dsh.client`. Data, OS grants and local credentials are independent; use backup export/restore to migrate. Simultaneous services may still compete for shared device ports.
- Experimental virtual display, global confirmation policy, task notifications and device capability controls. Virtual display requires an authorized ADB / Root / Shizuku channel. Allow-all bypasses DSHA confirmation only; it grants no Android permission or system sandbox.
- Bundled DSH 0.2.1-rc.2 and mobile UI 3.2.1; default proot, optional proroot, unchanged Ubuntu base10.
- Fixes cover runtime launch/dependency links, plugin state/provenance/management blocking, LAN/login, preview acknowledgement, directory picking and background restoration. Keyboard handoff, sidebar/preset waiting layout and single-tap conversation selection are updated. PiP is off by default and opt-in.
- One-tap backup and password-free export; destructive reinstall is removed. External workspace maintenance detaches private references and retains external contents, with original backup scope/integrity checks.
