# rc1.4 原生 UI 排版优化验收

此页保留 9 月 7 日排版验收。其后同版本增加功能修复，当前安装包与摘要见[最新功能验收](functional-audit-rc1.4.md)；本页 APK 已归档到 `release/history/rc1.4-before-functional-audit-20260908`。

按“紧凑但不要过于紧凑”的偏好完成排版重整。版本名仍为 rc1.4 / rc1.4low，版本码仍为 113，保留右上角日夜切换，不恢复设置主题卡片。

## 已实现

- 主界面和子页使用统一标题栏，子页返回放在顶部；清除重复的正文标题和返回按钮。切换根导航时清理旧子页栈，返回、主题切换及未保存输入保留经过实测。
- 页面边距统一为 16dp；卡片、按钮和标签的圆角层级统一；正文保持 15sp，主按钮至少 48dp，工具操作至少 44dp。
- 设置页统一图标、文字与行高，将后台运行设置单独分组；缩短重复说明，避免孤字换行。
- 配置按显示与运行、安全与备份、设备能力分组，保存按钮固定在本页底部；长标签改为短标题和必要说明，大字体仍能自适应。
- 插件页集中来源输入和解析操作，进度靠近表单；管理页先显示搜索筛选，导入/导出和帮助采用较轻的层级。解析前收起键盘，让进度与结果可见。
- 更新页按版本/通道、状态/操作、版本说明分组；仅显示当前可用的下载或安装操作，检查与浏览发布页按主次展示。
- 诊断页分为环境检查、问题反馈、报告；备份页分为备份恢复、工作区、共享和环境维护，危险操作独立放在下方。
- 启动内容可整体滚动，日志仍使用剩余空间；终端输入框和工具操作补齐触摸尺寸。

设计依据与验收目标见 [排版计划](ui-layout-plan-rc1.4.md)。

## 验证

- Android 13 / Redmi M2012K10C 上使用原生控件渲染，覆盖 16 个页面/状态、6 种宽高/字体组合及日夜模式，共 192 组布局。宽度包括 320/360/392dp，字号倍率 1.0/1.3，并覆盖 320×400dp 短视口。
- 完整矩阵检查 3,924 项文字状态，最低对比度约 5.25:1；没有发现文字裁切、同级操作重叠或实际操作区域小于 44dp。
- 最后的设置副标题、插件间距与更新展示调整另完成 84 组定向复核，1,908 项文字状态通过，最低约 5.55:1。
- 实际打开设置→配置，检查统一标题及返回；切换日夜后保留子页和未保存的端口输入，返回后真实配置未变化。
- 110 项 Java 测试通过，标准/兼容 Release 与两版 Lint 通过，既有 Android 验收代码编译通过。发布包检查确认不包含调试排版页面或 Instrumentation 入口。

截图使用独立示例状态，不执行模型请求、安装、恢复或设备授权。原生控件在指定逻辑视口中渲染，不将模拟宽度称作另一台实机。无障碍大字体和旧 Android 的完整设备矩阵仍有覆盖限制。

本地预览位于 `app/build/layout-evidence/index.html`，包含 128 张原生页面截图，可切换页面、主题和字体尺寸。调试代码仅在 `app/src/debug`；本轮没有再次安装额外测试包。
