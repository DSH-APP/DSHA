# rc1.3 实现与验收清单

> 历史记录：本文对应文中日期、版本与当时实际执行的范围；旧命令、证书规则、数据策略和“当前产物”不作为本轮构建或验收入口。现行流程见[接手指南](接手指南.md)、[CONTRIBUTING](../CONTRIBUTING.md)与[本轮约束](audits/build154/POLICY.md)。原字节及摘要保存在[历史文档清单](audits/build154/history-document-sources.json)。


本轮按用户要求实现此前建议中的更新、网页安装、诊断反馈及插件恢复功能，不扩展作者投稿或开发模板。

## 必须交付

- [x] 更新通道：稳定 / 预览，预览包默认预览；按 versionCode 和 standard / low 匹配，无降级误报。
- [x] APK 更新：展示说明、进度、取消和失败重试，校验 SHA-256、包名、版本和签名后交给系统安装器。
- [x] 网站与 App 共用由 APK 实际元数据生成的发布清单，网站下载同步至 rc1.3。
- [x] 网页安装：HTTPS App Link / dsha 链接入口、实际包信息确认、安装登记与重启提示；未安装 App 时可下载 APK。
- [x] 诊断：版本、系统、内核、环境和失败步骤；复制及导出脱敏报告，不读取对话或导出 API Key / token。
- [x] 已知故障提供证书/npm 修复、备用文件选择器等对应操作。
- [x] 插件显示已装 / 可更新版本，安装前展示兼容范围。
- [x] 插件更新失败保留现有实体，保留每个插件唯一上一版，支持回退。
- [x] 第三方插件导致启动问题时可安全启动，支持恢复此前启用状态并保留用户数据。
- [x] 两版签名一致、versionCode 112，环境版本仍为 9；四个交付文件位于 release。
- [x] 针对性单测、构建 / Lint、两种内核及相关功能真机验收、网站页面和线上接口核验。

文件名：`dsha-1.2.0-rc1.3.apk`、`dsha-1.2.0-rc1.3low.apk`，各附 `.apk.sha256`。
证据及验证限制见[验收记录](release-rc1.3-2026-09-07.md)。正式签名 App Link 的系统自动关联尚未作安装后真机验证；已完成域名/包声明核对及自定义 scheme 实际流程。Android 6—12、Android 17、16 KB 真机覆盖仍待补充。
