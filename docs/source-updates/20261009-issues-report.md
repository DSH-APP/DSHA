## ADB 离线依赖准备

`AdbWheelPaths` 先绑定 Android 提供的实际 app/files 根，解析所选数据布局与合法 guest 数据链接，再交给原 NOFOLLOW 文件系统写入。缓存只能落在当前应用的所选数据或运行根；Python 安装目标只能落在所选 rootfs。越界链接、循环、应用根替换和数据布局变化仍拒绝。

离线归档与每个 wheel 在发布前核对 APK 内 lock 的 SHA-256，复制后读回核对。现有修改版和额外文件保留。注入/安装失败后，只有当下 Python 依赖实际导入成功才继续准备密钥和包装器；缓存目录存在不能代替导入结果，进程退出未确认也不能当作通过。错误显示目标与 `CACHE_MISSING`、`CACHE_EMPTY` 或实际条目状态，避免空缓存被描述成已保留完整依赖。

报告没有宿主各级父链的 lstat 结果，所以本轮修复了源码中可确认的 Android 别名和数据链接缺口，没有断言原设备具体是哪一级触发 `PARENT_LINK`。受管脚本的签名与归属门禁保留。

## 网页附件选择

WebView 与 Low Gecko 的通用附件入口直接使用 `ACTION_OPEN_DOCUMENT`、`CATEGORY_OPENABLE`。空 accept 使用 `*/*`，MIME 限制、多选与只读 URI 授权保留；图片专用请求继续保留图片过滤。文档入口无法启动时才回退 `GET_CONTENT`。取消排空、页面代次核对、ClipData 顺序和 content URI 复制门禁保持。

选择器抽屉中的云盘、文件管理等来源由该 ROM 已注册的 DocumentsProvider 决定。没有为了增加候选强行指定某个系统包，也没有新增 `window.DSHA.pickFile` 桥；移动插件仍可使用原 file input 回调。

## 图片草稿暂存

`dsh-app-integration` 更新为 1.2.2。新 lease 带页实例标识与时间戳，每 30 秒刷新；停止心跳超过 120 秒才可回收。不同页面编辑同一 session 时继续互相保护，正常离页释放占用，BFCache 返回重新登记。被占用阻止的保存可在占用释放后重试。

无页身份的旧记录（包括只有 `at` 的现场热修格式）不能安全自动判死。界面会显示“恢复草稿暂存”：先保留原图并关闭其他 DSH 页面，确认后重新核对原值，仅移除本次确认的旧/未知 lease。IndexedDB、已存图片 Blob 与修订号不清理；确认期间出现新的活跃页面会阻止恢复。容量、配额、存储权限、引用冲突和数据库错误分别提示，不显示任意异常中的路径或令牌。普通 TXT 附件不再误触图片草稿保存警告。

受管 `client.js` 内容一致时继续跳过写入。内容不同、需要恢复签名内置版本时，先把现场原件按 SHA-256 去重保留到应用私有 `files/runtime-overlay-edits/`，读回核对完成后再替换；原件不自动删除。现场热修不会被无声丢弃，但不会因此绕过签名受管证明自动启用任意改版脚本。正式草稿修复已经写入随包源码，不再依赖每次重启后的临时热修。
