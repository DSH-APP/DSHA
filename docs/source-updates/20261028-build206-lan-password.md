# build206 局域网密码访问修订

日期：2026-10-28。本文记录基于 build206 的源码修订及验证边界；实际构建、测试和发布结果以本轮独立回执为准。版本码仍为 206，原包名和版本名称不变。

## 局域网访问

- 配置页设置局域网密码并确认后，监听器才具备启动条件。启动页展示和复制的是不含凭据的局域网地址；浏览器访问时使用 HTTP Basic 验证，用户名为 `dsha`，密码为用户设置的值。密码长度为 8–128 个字符，本机保存加盐派生校验值，不将该校验值纳入备份导出。
- Basic 验证仅用于安全 GET 请求建立当前会话；普通代理请求依赖会话 Cookie。请求处理校验实际监听地址和端口对应的 Host、Origin 与 Fetch Metadata，WebSocket 也要求匹配的 Origin。登录尝试按来源限速并限制记录数量。旧 `?token=` 链接不再作为授权入口，已有使用者需设置密码并重新登录。
- 重设密码会停用原监听并撤销当前会话，保存后按当前开关状态重新提交监听请求；提交不代表异步绑定已成功，启动页展示实际状态。关闭局域网访问、运行代次退休和重新启动同样受现有会话及代次围栏约束，旧运行的回调不能为新运行发放会话。
- 局域网使用明文 HTTP：Basic 凭据、会话和传输内容可被网络中的观察者获取，只应在可信网络和可信设备上使用。同网连通还取决于路由、防火墙及客户端隔离。
- 监听线程对运行时网络异常做收尾并报告异常类型，避免异常直接逃逸线程；这不是所有设备网络故障都已解决的证明。
