# Sunset 合并与虚拟屏启动参数修复

本次源码以 `e3b3fdd9166b4c2c8868dcc196a23266be23704e` 为基线，合并 Sunset-3090-Q 的 `5d694b65f5ceca9ccbd3d854a2b1efbacd53c159`。该分支相对基线新增 45 个提交，包含终端、v5 界面和移动插件更新。源码版本为 `0.2.1-rc.3-20261027.1149-dsh0.2.1-rc.3` / build204；正式包身份配置保持 `dsh.android.client` 和既有 E7E3 发布证书。

合并保留手机控制、本机与局域网访问，继续撤除电脑连接。移动插件升级到 3.2.2，同时保留十语言和原生安全区补丁。正式及独立应急 DSH 仍为 rc.3，其固定归档均为 `36c3c40e14a665f30531f31678f1b384ee6ed152d5114b7509998af03089baeb`；当前生产构建配方的 87 项输入与该归档的记录一致。两套运行根仍相互独立。

虚拟屏 MCP 的 `android_vscreen_launch` 接受调用方可选的 `generation`。提供时先检查当前 `coreInstance` 和显示代次，再向既有 App 桥只发送 `coreInstance`、`package`。状态预检与启动并非原子操作，App 执行时不校验这次可选代次；不能将预检描述为严格的代次围栏。tap、node 等操作仍保留原始 `generation`。无法确认启动是否执行时，MCP 返回未知结果并禁止自动重放；rc.3 SDK 在取消调用时可能先抛出 `AbortError` 而丢弃服务器回执，因此仍须观察实际状态。`/app/help` 的十语示例已同步现有桥参数。

终端合并中还修复了当前会话保护提示、后台简易会话的侧栏状态刷新，以及创建中的会话与“结束全部”之间的确认边界。新终端和主页文案补入十语言目录；窄屏和 RTL 的实际呈现仍需设备验收。

本轮 Standard Debug 定向单元测试共 219 项，0 失败、0 错误；1 项真实 POSIX shell 测试因 Windows 宿主条件跳过。最初的终端确认回调测试因未等待 Robolectric 主线程失败，修正测试时序后重跑通过，原结果保留。Standard Debug Lint 为 0 错误、357 条警告；首轮发现调试验收代码使用高版本 Android API，改用兼容写法后重跑通过。

虚拟屏实际 MCP 注册、参数和本机回环请求、原生桥帮助示例、终端和主页十语字典、移动网页安全区、语言补丁链、活动采样和插件状态等宿主检查通过。移动网页浏览器检查首轮缺少固定 React 夹具；准备并核验夹具后单项复跑通过，不能称为一次连续全绿。固定上游移动插件 218 个文件通过大小和摘要核验。

本轮没有构建、安装或发布 build204 APK，也没有进行手机验收。此前分支的设备和发布记录只适用于其各自版本，不能转记为本次合并的设备结果。
