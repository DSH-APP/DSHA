# ADR 0002：现行威胁模型与控制适用范围

状态：源码边界复核。此记录说明现行实现和用户选择，不是法律结论、独立安全认证或全设备测试证明。开放正式插件、依赖脚本与终端的决定来自 [ADR 0001](0001-build154-boundaries.md)；对应说明见[中文安全模型](../security-model.md)与[英文安全模型](../security-model.en.md)。

## 资产与主体

资产包括 API Key/Keystore 密文、桥 token、LAN token、对话/附件/项目、插件源码与依赖、配置、备份、短信、屏幕内容、共享存储和受管运行资产。主体包括用户、原生应用、同 UID 的 guest/Node/第三方插件、内嵌页、独立应急进程、同机其他应用、LAN 客户端、模型服务和下载/更新源。

用户配置外部模型后，请求内容和附件可能发送到该服务。模型服务与下载源不是本机授权权威；归档、插件和外部页面不能通过自述健康、格式或来源建立本机能力许可。

## 威胁、控制与限制

| 威胁与入口 | 现行控制 | 控制性质及限制 |
|---|---|---|
| 其他普通 App 访问私有文件 | Android UID 与私有目录 | 系统隔离措施；同 UID 的 guest、插件与终端共享权限，proot 不隔离恶意代码。 |
| 同机 App 连接 loopback 桥 | 当前 X-Token、有限路由、能力和代次检查；不开放 CORS | 鉴权措施；本机 TCP 可被其他 App 连接，同 UID 代码可能读取本机凭据。 |
| LAN 窃听或令牌泄露 | 独立启用、鉴权、连接/流预算、令牌脱敏 | 鉴权与可用性措施；LAN HTTP 明文，未建立 TLS 或受信配对。 |
| 插件/安装脚本执行不可信代码 | 包格式、路径、实际摘要、依赖锁与目录证明；宿主事务 | 内容与恢复措施；正式生命周期脚本/pnpmfile 开放、自动提交启用，不声称恶意插件沙箱。 |
| 受管设备命令误写系统/媒体 | 原生与特权执行侧解析相同命令策略、核对目标；保护共享根、DCIM/Pictures/Android 私有媒体目录 | 防误操作及受管入口限制；不约束用户已授权的同 UID 任意代码，不用确认伪造设备身份。 |
| 短信泄露 | 默认关闭的可撤销独立授权；仅当前 Android 用户的严格 content query；拒绝 provider 写入和 telephony 私有树读取 | 敏感能力措施；不能从备份恢复许可，不能代替系统真实权限。 |
| 旧页面/回调越权录音与读屏 | 当前来源、实际端口、页面、运行代次/授权修订及工具检查；拒绝摄像头/屏幕音频 | 能力措施；敏感窗口分类仍是启发式，不能保证识别所有私人页面。 |
| 屏幕/日志对外传播 | 按请求读取；普通截图可存私有 Pictures/DSHA，MCP 可返回图像；已知秘密脱敏、默认报告不附原始输出 | 数据最小化措施；截图不是完全不落盘，正则不能识别任意秘密，分享需要用户选择。 |
| 不可信归档覆盖配置/授权 | 完整认证/摘要后预检，范围/记录双向核验，私有编号槽位、链接边界和隔离 | 完整性与路径措施；归档不会启用机器状态/设备授权，历史未知原件保留。 |
| 应急聊天任意改正式数据 | 独立根/HOME/workspace，五工具；原生确认绑定候选、源摘要和数据代次，再取得既有停止屏障 | 受控修复措施；HTTP 不能确认写入，正式终端开放不解除该边界。 |
| PID 复用或未知 guest 被误杀/丢现场 | 出生身份、会话、退出证据；未确认退出保留锁和现场 | 防误操作与事务措施；不按裸 PID/端口/名称强杀，系统拒读不推导已退出。 |
| 更新源描述伪造版本 | HTTPS/重定向限制、完整 APK SHA、包名/版本/flavor/安装签名检查 | 来源和安装措施；清单无独立签名，服务器受损仍可错误描述官方发布。 |

## 验证范围

源码/宿主测试证明实际检查逻辑和限定输入行为；不证明 Android OEM/Root/Shizuku、真实 FUSE、16 KiB 页、长期后台、Keystore 或模型服务矩阵。Linux tmpfs 的原子发布回归不等于持久磁盘同步及掉电恢复。当前通过项和缺口按本轮逐项台账及最终产物回执记录。

未明确的外部源码授权与无可信原件的历史摘要保持未知，不以此 ADR 编造依据。后续修改授权、协议或恢复边界时更新本记录，并对实际入口而不是文案做相应回归。
