# Core current-source review

The eighteen source IDs are reviewed in `review-core.json`. Final Android Gradle, APK/ELF/signature and release source-byte gates belong to root integration. This lane did not use a phone, ADB, an audit/debug APK, Gradle, upload, version changes, or release signing.

HarnessController is an application entry facade. WebLifecycleController uses the exact application HarnessSessionState, lifecycle and queue. StartupPipeline, StartupEnvironmentActions, WebOutputSession, WebReadyTasks and WebProcessSession execute the real preparation, output, post-auth work, exact launcher/bridge lease and exit steps. LanAuthBridge exchanges a captured generation/address/port without holding the lifecycle monitor across HTTP. HostConfigService owns native configuration transactions. No second Web state owner was added.

RuntimeHostPorts is an application-owned instance. DshaApp owns controller, backup/install/plugin repositories and the foreground service reference; an old service destroy cannot detach a replacement. Plugin revision/invalidation belongs to that application's repository. Five unnecessary backup/core dependencies were removed; the twenty remaining Android job/service, native Settings/Targets and maintenance coordination facts are individually explained in `architecture-backup-core-dispositions.json`. The boundary baseline cannot reintroduce the removed edges and does not claim a zero backup/core import graph.

DiagnosticHistory now caps actual UTF-8 bytes and preserves complete lines with atomic previous-record recovery. StartupDiagnostics runs through injected clock/filesystem/event ports in real tests, parses process events with strict duplicate-key/type checks, preserves ordinary optional-dependency logs as related evidence, and bounds persisted issues while keeping fresh in-memory details. Old-generation issues cannot write current diagnostic events.

BackupTask's formerly live guest backup creation now calls the native v5 Downloads exporter. Its four historical integer scopes map to application/sessions/settings/plugins; credentials are excluded by default. BackupManager's creation adapters use current host snapshots and real v5 tar/gzip exports. Historical import, encrypted-original authentication and interrupted transaction reading remain available.

Stopping uses immutable WebStopDiagnostic codes/raw arguments, including inspection and force evidence. WebProcessManager and WebRecordedStop contain no UiText. Core WebStopCoordinator retains all sources as typed facts; WebStopText and the application-injected host display port render current language. The old string/detail accessors are compatibility seams, not algorithm authorities. Explicit force escalation requires the same native candidate/owner generation after an unconfirmed ordinary stop, and never replaces guest/owned-launcher exit confirmation.

The core i18n contribution contains 44 complete messages and 38 stop-display messages. Dynamic file names, commands, module IDs and unknown error details remain parameters. Root UI merge/generation and the final receipts determine the current catalog/test counts.

Local behavioral evidence is the fresh current-source SDK/JVM receipt at `app/build/audit-build156/core-jvm/receipt.json`, source ownership checks in `tools/test-core-boundaries.py`, and pinned token-preserving GJF receipts under `app/build/java-format/`. One Windows real-symlink test is an explicit host capability assumption; portable LINK refusal and unchanged target checks still execute. This is not Android/FUSE or full device-matrix evidence.
