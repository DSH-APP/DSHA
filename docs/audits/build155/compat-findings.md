Implemented in this source pass: Low no longer decides from a Chrome user-agent cutoff. It selects Gecko for explicit preference, Android before API 26, or an unavailable WebView provider. WebView construction failure, missing page capabilities, invalid capability check result, and a crashed renderer use the current verified local service and generation before a one-time Low switch; ordinary HTTP/network errors stay visible as such. The real capability expression was evaluated in a host VM with required APIs present and deliberately missing. Browser execution on physical devices is still unknown.

The two web test entry points now use `tools/fixtures/web-state/web-state-fixture.html` through test-only Gradle asset source sets. The androidTest one-file upload assertion consumes the shared fixture's JSON response. The obsolete model-entry smoke branch and Gecko model event assertion are removed. Guest DNS takes active Android `LinkProperties` servers only when the file has no user nameserver; an unavailable network adds none, and managed lines can be replaced without altering user search/options. Root discovery is inspection only, restricted to root-owned, non-group/world-writable candidates in known locations. Default error export omits raw runtime/plugin/history bodies and keeps bounded state/count fields.

Follow-up regression caught before final gate: an empty transient `LinkProperties` result initially removed the last managed DNS block. The resolver now preserves a previously valid block until a new valid numeric device address arrives, while an explicit user `nameserver` removes the managed block and takes priority. IPv4 octets and IPv6 hextets/compression are parsed locally; malformed values such as `a`, `10.0.0.999` and `:::` are rejected without hostname resolution. Eight direct JUnit cases pass, including this regression. Both modified Java files pass the pinned 1.22.0 formatter check after a two-file format write.
