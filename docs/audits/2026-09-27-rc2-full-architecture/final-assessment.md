## 架构定性与“屎味”来源

DSHA 是**防御性较强的模块化 Android 单体宿主 + 应用私有 Ubuntu/Node/DSH 运行时 + 多语言、多内核设备桥**。它不是只有一个巨大类的无分层项目：纯 Java `util/`、独立应急运行根、PID 出生身份核验、事务日志/摘要、v5 先认证后恢复预检、系统/用户插件分层和正式双 flavor 门禁，都是明确的核心亮点。

技术债的主要来源是边界被长期演进拉宽：Android Java 与 guest Python/Node/Shell、WebView/Gecko、proot/proroot、Root/Shizuku/ADB、历史数据代次和锁定上游补丁同时存在。必要复杂性变成“屎味”，发生在**同一能力出现多个入口但授权不共用**、**历史必须保留却拿历史总数限制下一次操作**、**事务终态与敏感暂存清理不统一**、**受管资产/插件声明变了但旧证明继续沿用**、**生成器输入与 Gradle 声明漂移**、以及**长驻页面资源随 Activity 而非文件引用生命周期增长**。封存报告逐项给出了代码调用链和反证，不凭类的行数推断作者意图。
