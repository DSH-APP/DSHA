## DSH 0.1.6-alpha.1

官方 [发布说明](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.1.6-alpha.1) 对应完整锁定包。主包之外额外内置 19 个官方组件，覆盖 Browser Use 三种后端、Computer Use 的 MCP/原生提供方、Auto review、Team、Python PTC 和 SSH。未裁剪上游 Web 终端、归档会话、MCP 资源、Headless、文件预览、Trajectory、输入菜单、重连、图片/Files API、Node PTC 与其他修复。

- 默认提供 Android Computer Use 适配器，使用官方 computer-use 注册和 MCP 管线，通过现有 DSHA 鉴权桥及确认机制执行读屏/点击/输入/按键/滑动/截屏。
- Auto review 选项通过官方模块挂载；不自动为会话选择 Auto review。
- 额外提供方需要按上游要求配置。Browser Use 需要 Chromium 或已配置的调试端点；Stagehand 的原生模型需单独配置；Cua Driver 需要受支持的桌面环境/权限。同一 computer-use 或 browser-use 组合只启用一个提供方。
- Android 提供方需要无障碍授权；系统截图接口需要 Android 11+。保留上游 Cua Driver 不代表其桌面原生后端可以无条件操作 Android 窗口。
- 可选插件失败保留诊断，但不再触发整个原生启动失败；关键入口失败继续进入恢复。

升级时保留个人数据与自定义地址。手工配置旧官方 API 根地址的用户应按上游说明移除覆盖或改为 Messages 地址；自定义插件中的旧 PTC/workflow 名称及 `agent/session-start` 需按上游迁移说明适配。新运行时回退仍受真实数据兼容证据与试运行约束。
