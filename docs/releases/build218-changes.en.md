# DSHA 0.2.1-rc.3-20261031.1800-dsh0.2.1-rc.5 / build218

- Rebuilds first-run onboarding as four steps (welcome → purpose → grants → done), replacing the three-page ViewPager2 flow and the separate preparation page. `welcomed == false` still enters onboarding only, and Main and startup recovery keep checking the same contract.
- First deployment now runs as an app-level background maintenance task with progress shown by the deployment capsule on the onboarding page and in the Main top bar instead of a full-screen wait. The screen stays on during deployment, and the done page plus one Web start appear only after success. If the in-onboarding deployment is killed in the background, onboarding returns to its previous step (`welcomed` is written only when leaving onboarding for Main).
- Over-the-top updates go back to the full-screen runtime maintenance page in the new layout (stage bar, stage list and bottom actions), instead of a limited Main with a dialog. When the disk holds an unfinished maintenance transaction or an unclosed isolated trial, the maintenance page, the panel and auto-start switch to "recover interrupted maintenance" first (verify the old trial process has exited, then close the site) rather than starting an update that is bound to fail with `TRIAL_RECOVERY_REQUIRED`. Auto-start still tries the same candidate only once; the limited Main is entered only when the user explicitly chooses "Enter limited interface", and it writes no readiness marker, so terminal, Web and plugin execution still pass the environment gates.
- Adds grant cards for seven device capabilities plus ADB, recommended by purpose and skippable. Notification permission is requested on tap for Android 13+; battery optimization is checked read-only without requesting an exemption; Stellar Manager (`roro.stellar.manager`) is recognized and opened; accessibility copy now matches the real system-list name.
- Tablets at ≥600dp use two columns, phone landscape compresses the header and footer, and content scrolls at 1.3× font. versionCode is raised to 218; the DSHA revision stays 0.2.1-rc.3 and the bundled DSH is 0.2.1-rc.5; this round was not verified by an on-device overwrite install, and build/acceptance scope follows this CI run and the Release receipt.
