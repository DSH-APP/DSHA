# DSHA 0.2.1-rc.3-20261102.0400-dsh0.2.1-rc.5 / build258

- Экран загрузки при запуске и переход с иконки сразу в Web: в «Настройки → Конфигурация запуска» или в новом встроенном плагине dsh-launch-target (сведения о плагинах Web) можно выбрать, что открывает иконка приложения — главный экран или Web (по умолчанию главный экран). При выборе Web сначала показывается экран загрузки, а Web открывается, когда среда готова; возврат назад из Web ведёт на домашний экран.
- Обслуживание, восстановление запуска и ожидающие ссылки на плагины по-прежнему сначала открывают главный экран, а возврат из уведомления или карточки задачи никогда не ведёт сразу в Web. Выбор хранится только на этом устройстве и не попадает в резервные копии.
- Объём проверки: только локальные целевые модульные тесты и проверки исходников; аварийный DSH и этот пакет на устройство не устанавливались. versionCode повышен до 258 (на основе build257). Ревизия DSHA остаётся 0.2.1-rc.3, встроенный DSH — 0.2.1-rc.5.
