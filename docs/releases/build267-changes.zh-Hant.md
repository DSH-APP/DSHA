# DSHA 0.2.1-rc.3-20261102.0830-dsh0.2.1-rc.5 / build267

- 實驗性：切到行動數據後容器無外網的爭取性修復。以前容器的 DNS 只在啟動時寫入當時網路的位址，從 WiFi 切到行動數據後這個位址就無法使用，所有網域解析逾時，回到 WiFi 才恢復。現在切換網路後會自動重新整理容器的 DNS；解析仍失敗時，會經 Android 系統解析器再解析一次（只解析，不會重送請求，也不注入公共 DNS）。新增唯讀診斷 /app/net。
- 這是實驗性修復，不保證在所有機型、系統、電信業者、VPN 或私人 DNS 組合下都有效；如果切換網路後仍無外網，請回報 /app/net 的輸出。
- 驗證範圍：僅本機單元測試與原始碼門禁；未做切換網路的實機驗證。版本碼提升為 267（基於 build266）；DSHA 修訂號維持 0.2.1-rc.3，內建 DSH 為 0.2.1-rc.5。
