## 实现范围

- **平板形态判定**：按当前窗口 dp 重新判定，不按机型名称。极简模式宽度 ≥ 840dp 且内联后终端仍保留 ≥ 480dp 时，用户打开会话后显示约 240–296dp 的内联侧栏，终端同时保留并可输入；窄窗仍为抽屉（宽 336dp 上限，至少保留 32dp 遮罩/返回手势区）。工作台 ≥ 840dp 常驻内联，低于断点用抽屉。
- **旋转/分屏/折叠**：侧栏“已打开”意图随 Activity 保存；抽屉与内联切换时继续显示同一面板，不重建会话。可用高度 < 560dp 隐藏副标题和次要说明，< 480dp 把底部动作改为三列两行。
- **深色 UI**：侧栏与顶栏改为与终端一致的深色语义色；选中会话高亮、运行状态点、紧凑会话行（选择/重命名/结束图标，触控目标 48dp）、分组空态、主按钮与分组标题层级对齐设计稿。极简内联时悬浮球隐藏，用侧栏关闭按钮或返回键收起，避免 RTL/左吸边叠面板。
- **入口与可达性**：极简/窄工作台仍由悬浮球或顶栏“菜单”打开；工作台宽屏顶栏新增“设置/说明”。抽屉打开时同时隔离背景可访问性树、后代焦点并暂停悬浮球聚焦，关闭后恢复；实际 Activity 焦点移到侧栏关闭按钮。
- **结束全部**：侧栏底部新增“结束全部”，确认框列出 PTY/简易数量并说明这不是返回页面。宿主逐项复用 owner 的关闭与核验，不遍历裸 PID：先按本轮 ID 快照发起，再按 owner 中实际剩余标签显示“已关闭/正在结束/未确认”，未确认会话保留可逐个核验；不会调用维护用 fail-fast closeAll，也不停止 Web 或其他业务。请求在 owner 的单线程关闭队列中串行执行，每个会话最长等待 5 秒，界面持续显示进度；看门狗只收尾显示，不假装关闭成功。
- **未改变**：PTY/JNI 内核、会话身份/编号、关闭核验合同、运行保护、维护屏障、正式包身份和包内运行归档；未升级 Termux 依赖。
