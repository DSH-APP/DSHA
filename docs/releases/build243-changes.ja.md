# DSHA 0.2.1-rc.3-20261101.0450-dsh0.2.1-rc.5 / build243

- スマートフォン縦向きの修正：狭い画面では起動ページの「停止 / 再起動」をメインボタンの下に等幅の枠付きボタン 2 つとして表示。Web 復元確認の長い説明はサブタイトルへ移し、大見出しは短い状態のみ表示。3 本の準備状況レール（実行環境 / ワークスペース / ポート）は元のデザインのまま。
- 実行環境メンテナンス画面にメンテナンス記録のログ枠を埋め込まなくなりました。失敗理由は説明枠に含まれ、完全な記録は下部の記録表示から開けます。幅広画面で説明がない場合、段階カードが行全体を使います。
- 「アプリごとに設定」の空のバッジを表示しなくなりました。言語グリッドの列数は幅と文字サイズの倍率で決まり、大きな文字の端末では 2 列になります。フローティングバーの最大行数 1–6 は 1 行に均等配置。
- スマートフォンの下部ナビを、内容の上に重ねる不透明なフローティングカプセルに変更。ページ下部にカプセル分の余白を確保し、最終行はカプセルの上までスクロールできます。タブレットは従来どおり左レールです。
- スマートフォンの歓迎ページでは 6 枠のチェックを 1 行の要約にまとめ、タップでアーキテクチャ・容量・WebView を表示。タブレットは従来どおり全枠表示。
- 初回案内の「導入前チェック」にウェブカーネルと対応判定を追加。Android 10 以下または非 arm64 は導入不可。鴻蒙 / 荣耀の独自 WebView は高リスクとし、先に System WebView の更新を案内。メンテ失敗ページと自己診断は同じ端末要約を使い、サポート向けにコピーできる。ネット送信はしない。
- 案内の権限バーは推奨項目のみ表示し、「全 x / 7」の空の点を混ぜなくなりました。デバイスコマンドは Stellar（Shizuku 互換レイヤー経由）のみを推奨し、未インストール時はメインボタンで GitHub Release を開きます。既存の Shizuku も引き続き使えます。Root と ADB は設定画面のみ。電池最適化はこのアプリのシステム「アプリ情報」を開き（ColorOS では「電池使用量」をタップ）、免除を自動申請しません。
- Shizuku/Root の状態文の揺れで権限ページ全体を再描画しなくなり、ユーザー補助の 1.5 秒未満の切断は接続済みのまま表示してカードのちらつきを抑えます。完了ページの「権限」は案内の 6 項目のみを表示し、Root を外して「x / 6 有効」と数えます。
- 検証範囲：OnePlus PJD110（360dp 縦向き）1 台にテストパッケージを上書きインストールして確認。結果は本ビルドの検証記録に従います。他の端末では未検証。
