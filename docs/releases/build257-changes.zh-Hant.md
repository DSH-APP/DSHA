# DSHA 0.2.1-rc.3-20261102.0200-dsh0.2.1-rc.5 / build257

- proroot 檔案鎖修正：proroot 引擎的執行庫把所有 fcntl 失敗都回報成「權限不足」（EPERM），檔案被其他行程鎖住時也一樣，Gradle 等依賴跨行程檔案鎖的工具因此出錯。相容層現在回傳正確的錯誤碼，鎖被占用時得到「稍後重試」。預設的 proot 引擎不受影響。
- 驗證範圍：測試包在一台 Android 16 平板上選用 proroot 核對了鎖探針與 Web 對話；正式包未在實機安裝。版本碼提升為 257（基於 build256）；DSHA 修訂號維持 0.2.1-rc.3，內建 DSH 為 0.2.1-rc.5。
