# DSHA 0.2.1-rc.3-20261024.0645-dsh0.2.1-rc.3 / build195

- 新增手机与电脑工作台入口，电脑连接可在不启动本地 Ubuntu 的情况下使用。
- 新增扫码配对、可信电脑管理、连接路径状态及独立远程网页会话。
- 新增可展开的悬浮助手，支持会话输入、系统语音输入、暂停、继续和停止手机控制任务。
- 手机控制区分本地与电脑来源，切换、暂停、断线和授权撤销会废弃旧操作许可。
- 电脑连接采用端到端加密流传输，支持直连与配置的中继服务；电脑 DSH 的对话和文件保留在电脑。
- 插件运行约定整理为一份参考文档，区分当前接口、建议扩展与实际权限边界。

本轮仅 Standard 软件构建与宿主集成验证。未进行真机验收；系统无障碍、悬浮窗、摄像头、语音识别和后台行为仍受设备实际能力及授权影响。
