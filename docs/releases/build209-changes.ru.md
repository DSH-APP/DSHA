# DSHA 0.2.1-rc.3-20261029.1845-dsh0.2.1-rc.3 / build209

- Название приложения изменено на DSH-A-Su (Sunset Mod), applicationId — на io.github.sunsetrne.dsha. Пакет устанавливается параллельно с оригиналом dsh.android.client, данные полностью разделены, старые данные не перезаписываются.
- Подпись выпуска создана заново: исторический сертификат E7E3 больше не используется, вместо него — собственный сертификат Mod. verifyPublishCertificate теперь проверяет новый сертификат и новое имя пакета; ожидаемый хеш записан в ci/release-identity.json.
- Вариант «Остров» (上島) вошёл в обычный пакет: отдельная сборка и собственное имя пакета больше не выпускаются.
- Отказ от Android 10 и ниже: совместимая ветка low / GeckoView удалена, минимум — Android 11 (API 30), только arm64-v8a.
- Объявление службы доступности общее для всех вариантов: находится в main manifest, не ограничивает packageNames и не перекрывается flavor. Метка и описание обновлены до «DSH-A-Su управление экраном» и сокращены.
- Сохранены десять языков: zh, zh-Hant, en, ru, ja, ko, ar, pt, la, fr.
- Короткие подписи интерфейса для fr, pt, ru, ar и la дополнительно сокращены, чтобы занимать меньше места.
- Исправлен повреждённый текст «Далее» в латинской локали (la).
- Фиксированные входные данные сборки переведены на предрелизные Release-ресурсы публичного репозитория с закреплением SHA-256; полный набор входных данных можно восстановить напрямую из публичного репозитория (см. [документ о фиксированных входных данных сборки](../../docs/fixed-build-inputs.md)).
- Инструменты выпуска и проверки CI, связанные с именем пакета и сертификатом, обновлены синхронно; результаты сборки и проверок — по подтверждениям в репозитории.
