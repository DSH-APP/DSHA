# DSHA 0.2.1-rc.3-20261102.0800-dsh0.2.1-rc.5 / build266

- 懸浮助手重構：改為可拖動的小膠囊加對話卡片，展開、收合或切換工作階段都不會再取消進行中的對話；可以直接在視窗內打字，AI 正在操作手機時會原地等你送出，再把這則訊息插進目前輪次接著做。點 ✕ 隱藏後改由通知繼續回覆。
- 防誤觸：停止工作需要二次確認，拖動只認狀態列；位置會記住，並限制在螢幕內。
- 手機操作確認新增「本輪允許此應用程式」，同一輪內不再反覆確認同一個應用程式；敏感應用程式每 5 次仍會再確認一次。
- 驗證範圍：實機核對了展開不取消對話、新卡片日夜、本輪授權與啟動確認；視窗內輸入鍵盤銜接、通知回覆與上島回覆未實機核對。版本碼提升為 266（基於 build265）；DSHA 修訂號維持 0.2.1-rc.3，內建 DSH 為 0.2.1-rc.5。
