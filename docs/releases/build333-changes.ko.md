# DSHA 0.2.1-rc.5-20261106.1830-dsh0.2.2-rc.1 / build333

- 앱 간 파일 접근(SAF, PR #3, review `5797594537` APPROVE, merge `9cc91f5e`): 설정 → 기기 기능 권한 → 시스템 권한에 "앱 간 파일 접근"이 추가됩니다. 사용자가 시스템 문서 선택기로 폴더를 승인하면 DSHA는 읽기/쓰기 권한을 영구 보존하고(최대 8개 트리), 권한 페이지에서 관리하며 읽기 전용 탐색과 텍스트 미리보기를 제공합니다. 새 `/app/saf/*` 브리지 엔드포인트(trees / ls / stat / read / write / push / pull / mkdir / rm; read 호출당 256 KiB, write 16 KiB, push/pull 32 MiB, 목록 500개, `rm`은 2단계 일회용 토큰)를 추가하고 브리지 프로토콜은 버전 3을 유지합니다(순수 추가). 보안 경계: 승인부의 짧은 id만 인정하고 쓰기/삭제는 해당 트리가 쓰기 가능해야 하며, 컨테이너 경로는 `BridgePathPolicy`를 재사용(자격 증명 영역은 읽기/쓰기 불가), 로컬 파일은 `O_NOFOLLOW` + dev/ino + `/proc/self/fd` 실제 경로 재확인으로 열고 하드 링크와 `.l2s` 실체를 거부합니다. 내장 `dsh-device-shell-guide` 프롬프트와 `/app/help`에 진입 문구를 한 줄씩 추가합니다. 해당 PR에서 관리 입력으로 runtime descriptor를 다시 계산하며(runtimeId `04b24571`), 고정 입력은 재구성하지 않습니다.
- 설정 → 체험에 "백그라운드에서 숨기기" 스위치 추가(`73896284`, ADB 키프얼라이브 보조): 기본 꺼짐, 기기 로컬 설정이며 백업 허용 목록에 들어가지 않습니다. 켜면 이 앱의 모든 유효한 작업을 최근 작업에서 제거하고, 끄면 복원하여 기존 "메인 카드 하나만" 규칙으로 다시 분류합니다. 앱 재시작이나 프로세스 종료 후 다시 열면 설정을 다시 읽어 적용하고, 실패 시 `RECENTS_HIDE_APPLY`를 진단 로그에 기록하고 다음 실행에서 재시도합니다. 최근 작업 가시성에만 영향을 주며 `DeviceBridgeService`, 상주 알림, 포그라운드 서비스, 중지 의미는 바꾸지 않고 키프얼라이브를 약속하지 않습니다(Doze, 제조사 절전, 강제 중지 방지 없음).
- 기기 기능 권한 페이지 UI 일관성 수정(`8509ae0a`): 상태 알약을 `PluginFlowRow` 안에서 가변으로(`wrap_content` + 최소 너비 56dp, 자리가 없으면 줄바꿈, 사등분 압축 없음), 상태 줄의 12dp 들여쓰기를 제거하고 두 줄을 허용하며 제목/상태 글자 크기를 `device_grants.xml`(12sp)로 옮깁니다. 나머지 9개 언어의 "꺼짐" 상태 단어는 기존 "닫힘" 번역을 재사용하고(중국어는 关闭 / 關閉 유지), 요약 상태·화면 인식·클립보드 단계 세 곳에 적용하며 "닫기 버튼" 문자열은 바꾸지 않습니다. 요약 바는 `shell_bg` + 하단 1dp `shell_line`으로 평탄화하고 하단 16dp 모서리, 강한 테두리, 2dp 그림자를 제거하며, 짧은 화면(`screenHeightDp ≤ 480`)에서는 요약 바를 스크롤 영역으로 옮기고 일반 높이에서는 고정과 점프 링크를 유지합니다.
