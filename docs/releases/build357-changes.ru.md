# DSHA 0.2.2-20261111.0200-dsh0.2.2-rc.1 / build357

- Исправление раскладки build355 (T143 v3, `d3c07b4f8`): в официальной сборке build355 фактически была первая раскладка T143 (одна карточка с двумя элементами рядом и старые отступы страницы настроек); эта сборка переключает её на v3, которую пользователь подтвердил на предпросмотре build353 `.debug`. Изменяются только два файла раскладки — `app/src/main/res/layout/fragment_settings.xml` и `plugin_list_footer.xml` — без Java, без строковых ключей и без изменения кликов.

- Локальные записи страницы плагинов становятся двумя отдельными карточками: внешний `pluginLocalCard` больше не несёт `ShellCard` и служит только горизонтальным контейнером; «Импорт пакета плагина» и «Экспорт плагинов» (`btnImport` / `btnExport`) получают собственную скруглённую поверхность `ShellCard`, фон нажатия `?attr/selectableItemBackground`, `clickable` / `focusable` и отступы `shell_row_min_height`, по 6dp с каждой стороны образуют промежуток 12dp. Подзаголовки и стрелки справа остаются удалёнными; id, строковые ключи и семантика нажатий не меняются.
- Управляемая среда выполнения не изменилась: правка ограничена двумя файлами раскладки слоя app и не входит во входы `runtime-descriptor`; объединённое дерево проверяет через `tools/prepare-runtime-descriptor.py --check`, что **`8e54085c`** не меняется (205 входов).
