## 实现范围

- 终端悬浮球从 `☰` 改为设计稿的 `>_`，仍为页面内 52dp 可拖动吸边菜单球；不申请系统悬浮窗权限。
- 悬浮球和工作台顶栏“菜单”不再打开 AlertDialog 菜单，而是打开会话侧栏：
  - 极简模式与窄工作台使用左侧抽屉；
  - 工作台窗口达到 840dp 时，同一侧栏内联常驻。
- 侧栏包含 PTY/简易分组、新建、会话切换、重命名、结束核验、返回主界面、显示设置、键盘、粘贴、回到输入和说明。

- 打开抽屉时把终端内容和工具栏从可访问性树隐藏，关闭后恢复；抽屉开合状态随 Activity 保存，但不会恢复或重放会话。
