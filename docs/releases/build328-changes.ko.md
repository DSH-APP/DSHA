# DSHA 0.2.1-rc.5-20261106.0010-dsh0.2.2-rc.1 / build328

- 0.2.2 환경에서 `gh`가 "managed GitHub CLI is unavailable"로 실패하는 문제를 수정했습니다. 공식 GitHub CLI v2.103.3(linux-arm64)을 12번째 고정 입력 `gh-cli.tar.gz`로 관리 자산에 추가하고, 설치 시 고정된 멤버만 추출하고 SHA-256을 다시 검증한 뒤 `/opt/gh/bin/gh`에 원자적으로 게시합니다. 전체 트리 재구성 시에도 관리 자산으로 주입되며 사용자의 수동 설치에 의존하지 않습니다.
- 바이너리가 없거나 손상된 경우 gh 래퍼가 고정 URL과 고정 다이제스트로 자동 부트스트랩하며, 어느 단계든 실패하면 fail-closed로 중단하고 복사 가능한 복구 명령을 출력합니다. 실제로는 없으면서 "bundled"라고 주장하던 오해의 문구를 제거했습니다.
- `util/MaintenanceToolPaths` 명시적 계약과 재구성 전 유계 사전 검사를 추가했습니다. `/opt`는 사용자 도구 디렉터리로 보존하고, `/usr/local/bin`은 시스템 트리라 보존하지 않으며, `usr/local/share/dsha`는 관리 자산으로 주입합니다. `/opt` 항목이 10만 개를 넘으면 이전 트리를 옮기기 전에 재구성을 거부합니다.
- 검증 범위: 호스트 테스트, contracts 전체 그룹, 소스/디스크립터/서드파티 고지 게이트. 이 기기에서 실제 기기 검증은 하지 않았습니다. 버전 코드를 328로 올립니다(build327 기준). 번들 gh 아카이브로 APK가 약 13.0 MiB 증가합니다.
