# DSHA 0.2.1-rc.3-20261029.1500-dsh0.2.1-rc.3 / build207

- Rootコマンドの3段階インターセプトを追加しました。厳格（既定、許可リストのみ）、緩和（任意のコマンドを許可するが、フォーマット・書き込み・再起動・データ消去などの不可逆操作はブロック）、完全緩和（コマンド内容を検査しない）。設定 → デバイス権限で切り替えられます。
- 緩和と完全緩和は Root チャネルにのみ適用されます。Shizuku/ADB の汎用実行器は厳格のままで、SMS 読み取りは3段階すべてでネイティブ認可が必要です。
- Root の生コマンドは特権プロセスで実行され、タイムアウト、256 KiB の出力切り詰め、実行 ID の検証を維持します。厳格モードではストレージルートと第1階層ディレクトリの再帰削除もブロックします。
- 本パッケージは SunsetRNE テスト ID（E7E3 ではない）で固定テスト署名を使用します。検証範囲は本機へのインストールと Root 3段階の動作に限られ、すべての ROM／機種は対象外です。
