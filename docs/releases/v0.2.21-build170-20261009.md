# build170：问题报告修复、本地 APK 与真机验收

本地正式包版本 `0.2.21-20261009.0750-dsh0.2.0-rc.2` / **170**，日期 2026-10-09。按用户要求打包 Standard 与 Low，使用 `com.dsh.client`、历史 E7E3 证书、非调试构建覆盖验收。APK 仅交付本地，不上传、不发布 Release。

本轮修复 ADB 依赖的 Android 私有路径/guest 数据链接解析、离线归档与逐 wheel 摘要、注入失败后的实际导入复核和准确缓存状态；附件直接进入系统文档选择器，保留图片过滤、多选与取消；图片草稿增加页身份、心跳和过期回收，旧引用提供确认恢复，TXT 不再触发图片草稿误报警。`dsh-app-integration` 为 1.2.2，现场改版 client 原件在替换前按摘要留存在私有目录。

真机验收发现首次准备的 Python 父目录尚不存在，原检查仍会报 `PARENT_LINK_OR_MISSING`。build170 修复该路径：只接受已核验私有根中尚未创建的后缀，由原 NOFOLLOW 发布器逐级创建，现有链接与非目录仍拒绝。增加一个真实临时目录回归，两版各 **45** 项关联 JUnit 全通过，Release Lint 无 Error/Fatal，最终增量构建与检查 59.25 秒。草稿 31 项真实 Chromium/IndexedDB 检查沿用同字节源码证据，没有跑全量历史矩阵。

Android13 真机上实际完成了低版原生冷准备：补齐 15 个 wheel，校验并安装 15 个，`KEY_GEN_OK`、`SETUP_DONE` 与 `ADB_OFFLINE_READY` 均出现，PARENT_LINK 未再复现。无线调试关闭时“验证已有连接”可先准备离线依赖，并明确说明连接未验证；联网发现、握手与配对仍保留权限门禁。本机没有 Wi-Fi，因此未把离线准备称为无线配对成功，原 vivo Android16 设备也未复验。

本轮实际验证了 WebView 和 Gecko 的文档选择、两份 44B/47B 文本文件回传、图片过滤，以及草稿保存/关闭页面/重新进入后的恢复。WebView 的旧锁恢复确认和取消均通过，Gecko 使用校验有效的 192×192 PNG 恢复及显示通过。初次沿用的 68B 测试 PNG 自身 IDAT CRC 不正确，Gecko 显示失败属于素材问题，已换有效图确认。上传与草稿功能源码在修复 ADB 时逐字节不变；最终两个签名 APK 再完成覆盖、READY 和对应网页内核启动确认。来源文件 SHA 在设备核对，但没有对网页回传/恢复 Blob 做全文 SHA 读回，未发送聊天或调用模型。

用户对话、插件、配置和 API 凭据保留；只清理五份自有下载目录素材、测试草稿与自有终端。ADB 开关、系统无线调试值和浏览器内核偏好恢复到原状态，手机最终安装 Standard170，Web 正常停止，状态 READY。新生成的未配对 ADB 密钥保留供正常功能使用。

DSH 仍为 0.2.0-rc.2，Ubuntu 基础环境仍为 10，内置移动 UI 仍为 3.0.5 / 上游固定提交 `9b16223e6c5ee8209c25034b24fb790990967b3f`。原生库与大型归档对照 build167 APK 字节相同；运行时身份为 `5d6f6c4920a7fd08c6a18548d8533cef3ccf415c27b3722d707217c9639ea4b3`。完整冷安装 30 秒目标、Android6/7、16KiB 真机及原生 SAF 最终保存没有在本轮扩大声明。
