# DSHA 0.2.1-rc.5-20261109.0300-dsh0.2.2-rc.1 / build345

- Settings and device-grant slimming (`0d0b9d359`): the Settings page drops its top banner and the subtitles of six entries, hides the always-visible notes for the overlay / hidden background / version update / self-check / about rows, and moves theme and language state to trailing values; the power-saving row loses the dynamic subtitle and keeps a constant height. The device-grant page collapses the long device-channel and global-confirmation explanations by default, merges the duplicated Root note, removes the page banner and several always-visible explainers, and turns channel / system-permission / sensitive-capability / virtual-screen state into same-line `ShellStatusPill` pills with short external-device states (off / unbound / bound / unverified). Switches keep the Material capsule shape, and the off-track first becomes near-white with a thin outline (later replaced by the `trackTint` scheme in `90609c2c4`).
- Manage file access fix (`ad9b93849`): after the previous commit moved state into a same-line pill, `DisclosureCard` could only insert details after the summary in a vertical parent, while the pill's parent had become a horizontal row, so tapping "Manage file access" could not expand (reproduced on device and in unit tests). The layout adds a `config_all_files_line` row and inserts the detail container after it; `DeviceGrantsLayoutTest` / `GrantsAccordionTest` follow the new contract and the CI Source checks are fixed; `DeviceGrantsLayoutTest` / `DeviceGrantsScreenModeTest` / `GrantsAccordionTest` all pass.
- Disclosure second-expand crash (`f94a95a14`): collapse only cleared the detail container, leaving the action button attached to the old `FlowRow`; the next expand reused the same button in a new `FlowRow` and threw `IllegalStateException: The specified child already has a parent`. Collapse and release now detach the action view first, with a fallback detach before rendering; reopening during the collapse animation follows the new state. Two regression cases cover expand→collapse→expand and changing the description while expanded.
- Manage file access opens the system page; switch track (`90609c2c4`): Manage file access returns to opening the system "All files access" page from the whole row or the state pill (consistent with other system-permission rows) instead of a disclosure, and the trailing arrow is visible again. The previous switch used `android:track` for a custom white track, but `MaterialSwitch` ignores it: the default tint painted the track the same colour as the card, leaving only a dot when off. It now uses the style `trackTint=@color/switch_track_fill` (`shell_surface` near-white when off, theme accent when on), keeps the Material `trackDecoration` outline, removes the dead drawable and adds a track-tint assertion so it cannot regress to the same colour.
- Data & backup / GitHub login slimming (`f6274ab55`): the hero expanded area used to hold the complete detail while the summary took the first sentence, so a NEVER default-expanded card repeated the whole section; the expanded area now holds only the content after the first sentence, NEVER no longer expands by default, and the old backup receipt is no longer stacked on top (which contradicted "no backup exported yet"). GitHub login shortens scope / credential / source / online-check long values to short words (not recorded / not saved / hosts.yml · not written / signed in), moves line wrapping into the expanded explanation, and folds the duplicated "record not saved" into the credential row.
- GitHub login guide dialog (`aec0ad5e9`): the dialog becomes custom content, showing the command in a monospace, long-press-selectable box, with copy buttons for the command and the authorization link; the bottom keeps the one-tap "Open terminal" action and adds a neutral "Copy command" button. Copy is bilingual via `UiText.choose`; TLS/CA failure hints get their own line instead of a long merged paragraph.
- Version and scope: versionCode raised to 345 (based on the released build344 / `e49f3b337`); the DSHA revision stays `0.2.1-rc.5` with bundled DSH `0.2.2-rc.1`. This is a pure UI fix and slimming build: no managed input changes and no run-root script changes; runtimeId stays `f65796a2`, fixed inputs remain frozen at the locked 20261105e, and the bundled `dsh-web-mobile` stays upstream 3.3.1 and default-enabled.
