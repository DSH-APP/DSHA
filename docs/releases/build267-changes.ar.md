# DSHA 0.2.1-rc.3-20261102.0830-dsh0.2.1-rc.5 / build267

- تجريبي: إصلاح بأفضل جهد لانقطاع الإنترنت عن الحاوية بعد التحويل إلى بيانات الجوال. كان DNS الحاوية يُكتب عند الإقلاع فقط بعناوين الشبكة الحالية، فإذا انتقلت من Wi-Fi إلى بيانات الجوال لم تعد هذه العناوين متاحة وانتهت مهلة كل عمليات التحليل حتى عودة Wi-Fi. صار DNS الحاوية يُحدَّث تلقائيًا بعد تغيّر الشبكة؛ وإذا ظل التحليل يفشل يُعاد مرة واحدة عبر محلل نظام Android (تحليل فقط، دون إعادة إرسال الطلبات أو حقن DNS عام). أُضيف التشخيص للقراءة فقط /app/net.
- هذا الإصلاح تجريبي ولا يُضمن لكل تركيبات الجهاز والنظام والمشغّل وVPN وDNS الخاص؛ وإذا بقيت الحاوية دون إنترنت بعد تغيير الشبكة فأرسل مخرجات /app/net.
- نطاق التحقق: اختبارات وحدات وفحوص مصدر محلية فقط؛ لم يُختبر تبديل الشبكة على جهاز. رُفع versionCode إلى 267 (مبني على build266). تبقى مراجعة DSHA ‏0.2.1-rc.3 وDSH المضمّن ‏0.2.1-rc.5.
