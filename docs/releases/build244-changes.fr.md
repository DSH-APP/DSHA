# DSHA 0.2.1-rc.3-20261101.0910-dsh0.2.1-rc.5 / build244

- Corrige l’échec permanent de « Récupérer la maintenance interrompue » : les anciennes versions écrivaient de façon atomique l’enregistrement d’achèvement des plugins dans le dossier des transactions de plugins, et une écriture interrompue laissait des fichiers comme `.previous` ou `.tmp-*`. Ensuite chaque vérification signalait `PLUGIN_JOURNAL_ID`, la récupération restait bloquée sur « Arrêt du Web », les autres réparations étaient refusées avec `REPAIR_RECOVER_PENDING_FIRST` et le Web ne démarrait pas.
- L’enregistrement d’achèvement est désormais stocké hors du dossier des transactions. Les anciens restes et toute autre entrée non reconnue de ce dossier sont conservés tels quels ; ils ne bloquent plus la maintenance et ne sont jamais rejoués comme opérations de plugin. Les appareils déjà bloqués devraient passer la vérification après une installation par-dessus.
- Cette version met à jour le script de transactions de plugins : l’installation par-dessus remplace donc les fichiers gérés via le flux normal de mise à jour de l’environnement géré ; les données personnelles restent en place.
- Portée de la vérification : les tests unitaires locaux (1689 cas dans les paquets backup et util) et les régressions Python des transactions de plugins passent ; pas encore vérifié sur un appareil ayant rencontré le problème. versionCode passe à 244. La révision DSHA reste 0.2.1-rc.3 et le DSH intégré reste 0.2.1-rc.5.
