- إصلاحات الهاتف بالوضع الرأسي: على الشاشات الضيقة أصبح «إيقاف / إعادة تشغيل» في صفحة التشغيل زرين متساويين بإطار أسفل الزر الرئيسي؛ ونُقلت ملاحظات استعادة Web الطويلة إلى العنوان الفرعي ليعرض العنوان الكبير حالة قصيرة فقط. تبقى مسارات الجاهزية الثلاثة (بيئة التشغيل / مساحة العمل / المنفذ) بتصميمها الأصلي.
- لم تعد صفحة صيانة بيئة التشغيل تضمّن مربع سجل الصيانة؛ إذ يتضمن مربع الإخفاق السبب، ويُفتح السجل الكامل من زر عرض السجل في الأسفل. وعلى الشاشات العريضة تملأ بطاقة المراحل الصف عند عدم وجود ملاحظة.
- لم يعد «تخصيص حسب التطبيق» يعرض شارة فارغة؛ ويُحدَّد عدد أعمدة شبكة اللغات بحسب العرض ومقياس الخط فتصبح عمودين في الهواتف ذات الخط الكبير؛ وتتقاسم خيارات أقصى عدد أسطر 1–6 للشريط العائم صفاً واحداً بالتساوي.
- أصبحت ملاحة أسفل الهاتف كبسولة عائمة غير شفافة فوق المحتوى؛ ويُترك أسفل الصفحة ارتفاع الكبسولة حتى يمكن تمرير آخر سطر فوقها. تبقى الأجهزة اللوحية بالشريط الأيسر.
- في الهاتف تُطوى فحوصات الترحيب الست في سطر ملخص واحد؛ الضغط يعرض المعمارية والمساحة وWebView. الأجهزة اللوحية تُظهر الشبكة كاملة كما هي.
- يضيف فحص ما قبل النشر نواة الويب وخلاصة الدعم: لا يمكن النشر على Android 10 أو أقدم أو غير arm64؛ يُعلَّم HarmonyOS / WebView الخاص بـ Honor-Huawei كخطر مرتفع مع تنبيه لتحديث System WebView أولاً. صفحة فشل الصيانة والتشخيص يعيدان استخدام الملخص المحلي ويمكن نسخُه للدعم. لا يُرفع شيء عبر الشبكة.
- يعرض شريط الأذونات في الإعداد الأولي العناصر الموصى بها فقط، دون صف النقاط الفارغة «الكل x / 7». توصي قناة الأوامر بـ Stellar فقط (عبر طبقة توافق Shizuku)؛ وعند عدم تثبيت مدير يفتح الزر الرئيسي GitHub Release، ويظل Shizuku المثبت قابلًا للاستخدام. يبقى Root وADB في الإعدادات فقط. يفتح مدخل تحسين البطارية صفحة النظام «معلومات التطبيق» (في ColorOS اضغط «استخدام البطارية»)، ولا يطلب DSHA أي استثناء.
- لم يعد الاستطلاع الدوري يعيد رسم صفحة الأذونات كلها عند تذبذب نص حالة Shizuku/Root، وتبقى إمكانية الوصول متصلة خلال الانقطاعات الأقصر من 1.5 ثانية، مما يقلل وميض البطاقات. تعرض صفحة الإنهاء أذونات الإعداد الست فقط دون Root، وتعدّها «مفعّل x / 6».
