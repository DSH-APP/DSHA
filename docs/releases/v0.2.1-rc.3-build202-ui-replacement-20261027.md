## 1. 本批范围

### 1.1 v5 页面组件层

- 新增 `res/values/shell_page.xml`：页面标题 / 说明、分组标签、卡片、行、输入、开关、主次 / 危险按钮、分段控件的统一样式与尺寸。
- 新增 `bg_shell_card` / `bg_shell_input` / `bg_shell_danger` / `bg_shell_segment` 与 `shell_segment_text`，全部引用 `shell_*` token。
- `values/colors.xml` 与 `values-night/colors.xml` 的通用层级色对齐 v5：画布、卡片、凹槽、文字、描边、状态色。旧页面（文件、备份、技能、任务、恢复等）随通用色自动进入 v5 画布，不再出现白色底 + 灰色卡片两套视觉。
- `CardPage` 改为 v5 页面骨架，并新增 compact 模式供底部弹层使用；`UiNavigation.addHeader` 只保留返回键，避免顶栏标题与页面大标题重复。

### 1.2 已替换页面

- 设置：三组卡片（运行环境 / 使用体验 / 支持），包含语言、悬浮条、省电、更新、自检、关于。
- 插件：页面标题、市场 / 已安装分段、社区入口、链接安装、筛选 / 排序、本地导入导出与插件卡片。
- 运行配置、安装与环境、设备能力授权、数据与备份、更新、自检与诊断、欢迎 / 首启、关于对话框、环境恢复页。
- 文件 / 备份 / 技能 / 任务 / 存储等 CardPage 内页自动获得 v5 标题、卡片与按钮。

### 1.3 终端

- 修复侧栏「新建会话」「结束会话」「回到输入」第一次点按只获得焦点、第二次才触发的问题：移除菜单控件不必要的 `focusableInTouchMode`，并让「回到输入」在收起侧栏后立即恢复终端输入焦点。
- 按用户要求移除终端侧栏的「系统 / 白天 / 黑夜」主题分段开关；终端外观仍跟随应用主题与系统，切换由 AppCompat 重建 Activity，会话由进程级 owner 保持。
- 保留点击「终端」直接拉起独立全屏 `TerminalActivity`、返回只关闭页面不结束会话、结束进程逐个核验等既有语义。
