- إضافة ثلاثة أوضاع لاعتراض أوامر root: الصارم (افتراضي، القائمة المسموحة فقط)، والمتساهل (أي أمر مع حظر العمليات غير القابلة للتراجع مثل التهيئة أو التفليش أو إعادة التشغيل أو مسح بيانات التطبيقات)، والكامل (دون فحص محتوى الأوامر)؛ ويمكن التبديل من الإعدادات ← أذونات الجهاز.
