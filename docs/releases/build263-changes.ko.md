# DSHA 0.2.1-rc.3-20261102.0630-dsh0.2.1-rc.5 / build263

- 터미널 탭을 닫아도 더 이상 멈추지 않습니다. 이전에는 마지막 터미널 탭을 닫으면 화면이 터미널 세션이 완전히 끝날 때까지 기다려 5초를 넘겨 「앱이 응답하지 않음」이 뜰 수 있었고, 이때 「앱 닫기」를 고르면 DSH도 함께 종료되었습니다. 이제 종료를 기다리는 동안 화면이 막히지 않아 DSH가 함께 종료되지 않습니다.
- 검증 범위: 사용자가 테스트 패키지 실기기에서 터미널 탭을 닫아도 응답 없음이 되지 않고 DSH 연결이 유지됨을 확인했습니다. 로컬 단위 테스트와 소스 게이트를 통과했습니다. versionCode를 263으로 올렸습니다(build262 기반). DSHA 리비전은 0.2.1-rc.3, 내장 DSH는 0.2.1-rc.5로 유지됩니다.
