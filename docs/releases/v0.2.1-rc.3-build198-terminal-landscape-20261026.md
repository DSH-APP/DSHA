## 1. 用户反馈与核验结论

用户提供两张平板截图：竖屏抽屉为白底三向态侧栏，结构和配色符合上一批设计；横屏内联侧栏中，底部摘要、三向态开关、六个动作和脚注合计约占侧栏高度的一半，挤占了会话列表。逐项核对后确认：

- 横屏底栏仍是两列三行；在截图所示的可视高度里，六个 48dp 动作 + 主题轨道 + 摘要 + 脚注合计约占侧栏高度一半。
- 摘要「1 个会话 · PTY 1 / 简易 0」在横屏被挤成两行，进一步增加高度。
- 横屏仍显示副标题与「返回只关闭页面…」脚注，这两项在低高度本可让位给会话列表。
- 侧栏宽度约 25% 窗口（约 240–296dp），三列动作需要更短的可见标签；两列三行则继续浪费高度。

结论：不是颜色或图标问题，是**横屏底栏的行数、字号、间距与摘要换行**问题。

## 2. 本次改了什么

| 范围 | 行为 |
|---|---|
| 横屏判定 | 新增纯逻辑 `TerminalWorkspacePolicy.shortLandscape(widthDp, heightDp)`：宽度 > 高度且高度 < 1000dp。竖屏、接近方形和超大窗口不触发；不是按机型或物理像素猜测 |
| 动作网格 | 横屏由两列三行改为**三列两行**；六个动作仍全部可达，不折叠、不删除 |
| 动作尺寸 | 横屏动作按钮 44dp 高、10.5sp、单行省略号、图标 15dp、内边距与图标间距收紧；仍高于 43.5dp 布局审计下限 |
| 短标签 | 横屏显示「主界面 / 显示 / 键盘 / 说明 / 粘贴 / 输入」，完整名称保留在 `contentDescription`（无障碍不缩水） |
| 摘要 | 摘要强制单行省略，不再两行换行；「结束全部」字号与高度收紧 |
| 主题开关 | 横屏轨道内边距与外边距收紧，三段 44dp 高、10sp；选中态/无障碍描述不变 |
| 头部 | 横屏隐藏副标题与「PTY / 简易」提示，新建按钮 44dp，标题字号略降，头部内边距收紧 |
| 脚注 | 横屏隐藏「返回只关闭页面 · 结束进程单独核验」脚注，把高度留给会话列表；竖屏仍显示 |
| 恢复 | 旋转回竖屏或窗口高度 ≥1000dp 时恢复两列三行、完整标签、脚注与副标题 |

按 dp 预算，横屏底栏从三行 48dp 动作改为两行 44dp 动作，并收紧主题、摘要与头部，预计减少约 110–130dp 高度；截图未提供设备 density，无法精确反推当前 dp，最终以真机旋转为准。
