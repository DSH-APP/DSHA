# DSHA 0.2.1-rc.5-20261109.0900-dsh0.2.2-rc.1 / build347

- اختيار مجلدات SAF يوجّه الآن صراحةً إلى منتقي الملفات النظامي (`479302313`): أُضيف `ui/SystemDocumentPicker` الذي يضبط نية اختيار الشجرة صراحةً على `com.android.documentsui` / `com.google.android.documentsui`، ويعود إلى التحليل الافتراضي عندما يكون غير مُصدَّر أو معطّلًا أو غير موجود محليًا. وإذا استبدلت الشركة المصنّعة معالج الإجراء الافتراضي، تشرح الصفحة أولًا أن بطاقات SD / أقراص USB قد لا تظهر، ثم تقدّم ثلاثة مداخل: منتقي الملفات النظامي / معلومات التطبيق الذي استولى على الافتراضي (مسح «الفتح الافتراضي») / المتابعة بالافتراضي. وُحّدت أماكن اختيار الشجرة الثلاثة (صفحة الأذونات، ومجلد النسخ الاحتياطي بنقرة واحدة في مساحة العمل، ومصدر النسخ الاحتياطي للمشروع في البيانات الأصلية)، وأُضيف إلى البيان `<queries>` للحزمتين النظاميتين و`OPEN_DOCUMENT_TREE`؛ ويغطي `SystemDocumentPickerTest` بسبع حالات فرض المدخل النظامي والتعرف على استيلاء الشركة المصنّعة والتراجع.
- كبسولات حالة قنوات الجهاز لم تعد تدفع الأزرار والمفاتيح خارج الشاشة (`cfad29009`): أصبحت صفوف Root / Shizuku / ADB / الجهاز الخارجي «عمود عنوان + كبسولة حالة» بتوزيع الأوزان؛ تُقاس أزرار التحقق / الاقتران والمفاتيح أولًا بعرضها الخاص، وينكسر النص الطويل داخل العمود الأيسر؛ أُضيف `ShellChannelStatusPill` (بحد أقصى 6 أسطر، دون اختصار، تباعد 2dp)، ودُمجت حالة الجهاز الخارجي في العمود الأيسر؛ وأُضيفت إلى `DeviceGrantsLayoutTest` حالات انحدار للحالة الطويلة / الصينية الإنجليزية / خط 1.3× تبقى فيها الأزرار بعرضها وداخل الصفحة.
