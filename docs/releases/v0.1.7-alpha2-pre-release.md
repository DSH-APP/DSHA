# DSHA v0.1.7-alpha2 · Pre-release

由贡献者 [@ym2025szz](https://github.com/ym2025szz) 发布，感谢原作者 [@qiannianhuanxiang](https://github.com/qiannianhuanxiang) 和其他贡献者。

这是一个 **GitHub Pre-release**，不是稳定版。DSH 最近从 0.1.6/早期接口升级到 0.1.7-alpha.2，Session V4、Agent 预设、插件管理和部分 Web API 都发生了变化。已有用户请先导出重要数据并保存备份密码，再谨慎覆盖更新；旧版自建 `.agent-presets/<id>/agent.cordis.yml` 目录型预设可能需要按上游新的 `@deepseek-ai/dsh-agent-preset` 注册方式迁移，详见 [上游说明](https://github.com/deepseek-ai/deepseek-harness/discussions/7545)。

## 本版内容

- **实验性虚拟屏（仅 Standard）**：Android 11/API 30+，通过 ADB、Shizuku 或 Root 创建独立 VirtualDisplay；支持应用内预览、可选悬浮预览、应用选择与启动、触控、滑动、本机键盘输入、AI 点击/按键和无障碍控件树。输入动作绑定最近帧 `frameSeq`，旧帧会被拒绝。该能力仍在实验阶段，可能受厂商 ROM、授权状态和无障碍服务影响。
- **Low 版暂不支持虚拟屏**：兼容版保留原有兼容内核与设备功能，虚拟屏入口和核心均关闭。
- 修复 PiP 中 WebView/Gecko 流式文字和字体闪烁，进入 PiP 时保持内容渲染，真正离开预览页后再暂停。
- 统一“数据与备份”页面的自动备份、存储空间卡片；优化 Language 弹窗首帧布局和插件面板标题避让。
- 内置 `dsh-web-mobile` 3.0.1 同步上游最新修复，保留 DSHA 的鉴权和请求校验。
- 内置 DSH `0.1.7-alpha.2`、Ubuntu 基础环境 10；版本码 145；两版沿用 E7E3 正式签名。
