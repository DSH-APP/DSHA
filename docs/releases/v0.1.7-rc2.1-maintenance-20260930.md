# DSHA 0.1.7-rc2.1 维护修订（2026-09-30）

本次修订沿用版本码 148、包名 `com.dsh.client` 和 E7E3 历史发布证书，覆盖以下问题：

- 应急 DSH 增加受管 `repair-cli-dependencies` 提案，仍通过 `dsha_propose → 原生确认 → dsha_result`，只恢复签名 APK 的依赖树并运行已有隔离试运行。
- `QueueDock` 的插话箭头不再由 `running=false` 禁用；空闲状态交给宿主 `followup` 唤醒新回合，移动端不依赖 hover tooltip。
- 手动/救援导出不再强制输入密码。密码为空时输出 DSHADATA v5 完整性归档；密码不为空时保持 AEAD。自动备份仍由宿主生成随机密码，避免自动副本变成明文。
- 无障碍服务补上 `onUnbind` 清理；ADB 成功探活后，仅在系统设置仍保留用户启用项且具备 ADB 授予的 `WRITE_SECURE_SETTINGS` 时请求一次重新绑定。
