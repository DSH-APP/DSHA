# DSHA 0.2.1-rc.3-20261101.2330-dsh0.2.1-rc.5 / build256

- 데이터 및 백업 하위 페이지 재구성: 복원은 연속된 대화상자 대신 페이지 안의 4단계 마법사(파일 선택, 범위와 옵션, 사전 검사, 복원 확인)로 바뀌었습니다. 확인 버튼은 한 번 누르면 잠기며 화면을 돌려도 이어서 진행됩니다.
- 사용자 지정 내보내기는 다섯 가지 범위 중 하나를 고르는 방식이 되었고, API 키를 포함하면 내보낸 파일이 암호화되지 않는다고 알려 줍니다. 복구 및 유지 관리 도구는 용도별로 묶었으며 각 동작은 여전히 확인을 거칩니다.
- 저장 공간 페이지에 전체 사용량과 분류별 분포를 표시하고, 보관 사본은 백업 사본·이전 환경·플러그인 등으로 걸러 볼 수 있습니다(선택한 항목은 유지). 저장 안내는 제목을 눌러 펼치는 Q&A로 바꿨습니다.
- build255는 업데이트 설명 테스트 하나가 본문 문구와 맞지 않아 빌드와 배포가 실패했기 때문에 따로 배포하지 않았습니다. 해당 유지 관리 화면 버튼 변경은 이번 빌드에 포함되며 테스트도 고쳤습니다.
- 검증 범위: 로컬 빌드와 관련 단위 테스트만 했습니다. 실기기 설치는 확인하지 않았고 UI 테스트와 Lint는 CI에 맡깁니다. versionCode를 256으로 올렸습니다(build255 기반). DSHA 리비전은 0.2.1-rc.3, 내장 DSH는 0.2.1-rc.5로 유지됩니다.
