# DSHA 0.2.1-rc.5-20261109.0900-dsh0.2.2-rc.1 / build347

- Выбор папок SAF теперь явно направляется в системный выбор файлов (`479302313`): новый `ui/SystemDocumentPicker` задаёт компонент `com.android.documentsui` / `com.google.android.documentsui` для intent выбора дерева, а при отсутствии, отключении или неэкспортированности откатывается к обычному разрешению. Если OEM подменил обработчик по умолчанию, приложение сначала объясняет, что карты SD / USB-накопители могут быть не видны, и предлагает три входа: системный выбор файлов / сведения о перехватившем приложении (сбросить «по умолчанию») / продолжить с текущим. Все три места выбора дерева (страница разрешений, каталог резервной копии рабочей области и источник резервной копии проекта) унифицированы; в манифест добавлены `<queries>` для двух системных пакетов и `OPEN_DOCUMENT_TREE`; `SystemDocumentPickerTest` из 7 случаев покрывает принудительный системный вход, определение перехвата OEM и откат.
- Пульсы статуса каналов устройства больше не вытесняют кнопки и переключатели (`cfad29009`): четыре строки Root / Shizuku / ADB / внешнее устройство стали «левой колонкой заголовка + пульсом статуса» с весовым перераспределением; кнопки проверки / сопряжения и переключатели измеряются первыми, длинный статус переносится внутри левой колонки; добавлен `ShellChannelStatusPill` (не более 6 строк, без многоточия, межстрочный интервал 2dp), статус внешнего устройства перенесён в левую колонку; `DeviceGrantsLayoutTest` дополнен регрессиями для длинного статуса / китайского и английского / шрифта 1,3× — действия сохраняют ширину и остаются на экране.
- «Скрыть из недавних» получил защиту содержимого и экспериментальный строгий режим (`76b3a44a6`): RecentTasks в Android 13+ сохраняет «последнюю видимую задачу», поэтому при свайпе из приложения сразу в недавние текущая карточка остаётся у системы, и публичный API не может убрать только её, не завершив UI. Новый `ui/RecentsPrivacyGuard` (жизненный цикл уровня Application) при включённом переключателе все экраны отключают содержимое скриншота в недавних (API 33+); экспериментальный строгий режим (по умолчанию выключен) завершает задачу UI через 700 мс после ухода всего приложения в фон, но не срабатывает, пока идёт выбор результата (SAF), в режиме «картинка в картинке», в многооконном режиме и при повороте; сбои пишутся в диагностический журнал без падения и повторов; `BrowserTasks` после применения перечитывает список задач и флаги root Intent, и пустой список или несовпадение флага теперь считаются сбоем (`RECENTS_HIDE_APPLY` / `RECENTS_HIDE_VERIFY`), а не ложным успехом; в настройках добавлена подстрока строгого режима (скрыта при выключенном родительском переключателе) и десятизычные строки `m9500`–`m9502`.
- Обновление управляемой среды: изменения `DshaApp` / `ConfigStore` пересчитывают `runtimeId` в `28dc573a`; fixed-inputs остаются зафиксированными на 20261105e; встроенный `dsh-web-mobile` остаётся на upstream 3.3.1 и включён по умолчанию.
- Версия и область: versionCode повышен до 347 (на базе выпущенного build346 / `86f91ba0a`); редакция DSHA остаётся `0.2.1-rc.5`, встроенный DSH `0.2.2-rc.1`. Пакет не меняет белый список команд устройства и не ослабляет защиту при выполнении.
- **Не проверено / не принято**: на OnePlus C16 — пусто ли содержимое текущей карточки при свайпе из приложения в недавние, исчезает ли карточка после Home, исчезает ли она в строгом режиме при работающих dsh Web / терминале / ADB keep-alive; вход в системный выбор файлов и фактическое разрешение дерева при перехвате OEM; визуальная приёмка четырёх строк каналов при день-ночь / коротком экране / шрифте 1,3× / RTL; фактический результат перечитывания `BrowserTasks` на новых ROM. **build347 ещё не проверен на устройстве**: приёмка — первая успешная установка поверх 346→347, целостность данных, READY, обновление управляемой среды и поведение трёх функций выше; приёмка на устройстве официальных пакетов build344–build347 ждёт пользователя.
- Область проверки: идентичность выпуска и предполётные проверки, весь набор host contracts, descriptor `28dc573a` / источники управляемой среды, уведомления третьих сторон, встроенные плагины, пути учётных данных, semver, host manifest, гигиена исходников, UI i18n, `generate-changelog --check`, ссылки документации, форматирование всего дерева Java, `git diff --check`, `test-vscreen-help`, `test-diagnostic-feedback`; полный `:app:testStandardDebugUnitTest` (10 базовых сбоев aarch64 Robolectric записаны как есть) и `:app:lintStandardRelease`; подписанный assemble локально не выполняется (нет release keystore).
