# DSHA 0.1.5-rc2 修订与验收

本次将 dsh 更新到 **0.1.5-rc.2**，APK 版本码为 **121**，Ubuntu 基础环境保持 **10**。交付文件为 `release/dsha-0.1.5-rc2.apk` 与 `release/dsha-0.1.5-rc2low.apk`，各自附带 SHA-256 文件。既有 rc1.1 等历史安装包保留。

## 本轮调整

- **同步上游 rc2**：更新锁文件和 Linux arm64 离线运行时。上游改进反馈确认弹窗、交付文件卡片、对话间距和文件图标，详见[官方发布说明](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.1.5-rc.2)。普通更新仅替换受管运行时，个人目录、会话、配置和第三方插件保持原位。
- **Agent 预设位置**：恢复会话顶部原有右侧位置，保留标准、PTC、极简和创造四项真实切换。侧栏按钮下移，与预设控件对齐；英文模式名称允许弹性收缩，菜单和辅助功能名称保留完整文案。
- **多终端**：PTY 和简易终端均支持新建、选择与单独关闭，各自保留输出、工作目录和环境变量。简易终端还保留输入草稿与光标。关闭失败时保留会话；关闭全部标签后显示空状态，不自动重新打开。维护仍回收所有终端并核验后台进程。
- **中英文切换**：设置页增加语言选项，默认中文。原生布局、菜单、应用提示和两种网页内核同步语言。界面重建保留终端和 Web 服务；用户的聊天、文件、命令和输入内容保持原文。
- **保留已修复能力**：旧 WebView 的 Iterator/PDF Worker 兼容、独立日志滚动、安装页顶部定位、备份 API Key 归属、Shizuku/Root/ADB 及文件共享改进继续保留。

## 适配验证

已针对 rc2 的真实 npm 内容逐项核验网页拼接、回车行为、会话交互、预设切换、语言服务、PDF 页面/Worker 与文件协议的补丁锚点。Tooltip 的前端文件名及压缩变量发生变化；核对变量重命名后函数行为一致，并更新对应补丁与入口缓存标记。

已完成的检查：

- Android 13 / Redmi M2012K10C / arm64，使用非调试插桩包。多终端 **56 项**检查通过：三个 PTY 与两个简易终端的独立进程、cwd/export、单独关闭、语言切换、草稿与光标保留。
- 原生语言设置 **57 项**检查通过：实际点击设置中的语言选项，检查六个真实原生页面的英文控件，再返回中文；不改用户输入或历史内容。
- 英文原生布局 **2,094 项**文字状态检查通过，覆盖日夜、320×640 / 320×400 dp 和 1.0 / 1.3 倍字体，最低对比度约 **5.25:1**。修正插件数量栏被压缩和短屏按钮换行问题；子页返回、主题切换及未保存输入保留正常。
- 标准版 WebView 116 已实际切换四种预设，逐项核对 Host 返回值和会话投影；原会话保留。英文预设菜单和原生语言桥正常，用户的中文对话保持原文。
- 最终预设样式在 WebView 116 的竖屏和横屏验证通过：中文宽 98px、英文约 135px，按钮与左侧入口的中心均为 32px；英文重载后保持所选语言。菜单锚点不再误套用弹出菜单宽度或小屏后台任务样式。
- 兼容版 Gecko 143 从原生英文设置完成真实启动，实际触摸可展开四项英文菜单，顶部完整模式名称与侧栏入口对齐；英文文件面板内的 PDF 预览实际渲染通过并截图核对。
  - 此项依据实际触摸与截图验收。人工验收脚本的五分钟等待窗口已超时，结束标记晚于窗口写入，因此脚本返回失败；不计作自动化检查通过。
- 独立 cache 冷环境完整解压、离线工具安装和首次加载验证通过，约 **28.32 秒**；现有用户 Ubuntu 未重建。
- 两版各 **354 项单测：353 通过、1 跳过、0 失败**，Lint 无错误。rc2 对应的 Tooltip 8 项、语言桥 3 项、预设切换 5 项、会话交互 6 项、ES 兼容 10 项及 PDF 精确补丁检查通过。
- 正式签名、版本号、arm64 架构、16 KiB ZIP 对齐及关键适配资源已核验；APK 不包含插桩入口。测试机安装签名与发布签名不同，设备副本沿用测试机原签名保留数据，正式交付使用既有发布证书。

本轮未使用 Android 6/7 实机或真实 16 KiB 页内核。兼容版保持 minSdk 23；两版的 Ubuntu 基础包和宿主原生库保持不变。全部交互验收未发送模型请求。
