# DSHA 0.1.6-alpha2.1 · build 142

本地候选记录，日期：2026-09-21。标准版版本名为 `0.1.6-alpha2.1`，兼容版为 `0.1.6-alpha2.1low`，版本码 142，包名 `com.dsh.client`。内置 DSH 仍为 `0.1.6-alpha.2`，Ubuntu 基础环境仍为 10，受管运行时身份保持不变。

## 本轮改动

- PiP 进入/退出过渡期间保持 WebView/Gecko 内容活动，避免 `onPause/onStop` 提前清理刷新率或暂停渲染造成流式文字闪烁。
- 数据与备份页的自动备份、存储空间入口改为固定 XML 卡片，统一图标、内边距、分隔线和文字基线。
- `DshaDialogBuilder` 改为显示后一次性测量窗口，Language 选择在弹窗退出后的下一帧触发语言重建。
- 当前 `dsh-web-mobile 3.0.0` 基于上游提交 `af20948`，保留 DSHA 会话抽屉/预设修复与本地删除接口鉴权；同步上游后台任务/子代理芯片、文件入口、文件面板手势和输入区布局修复。
- 新增 Android 11/API 30+ 独立虚拟屏：独立 `app_process` 核心、VirtualDisplay/ImageReader 最新帧预览、ADB/Shizuku/Root 启动通道、3090 认证端点和 `dsh-tool-vscreen` 工具。预览改为紧凑窗口，支持大小调节、单指实时触控、双指缩放、本机键盘输入和无障碍控件树/输入框操作；无悬浮窗权限也可用。
- 自定义服务商增加受校验的请求头名称/值列表，支持 `x-opencode-session` 等网关要求；请求头不会进入 API Key 或公共导出。
