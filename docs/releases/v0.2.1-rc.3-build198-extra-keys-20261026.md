## 1. 本次改了什么

| 范围 | 行为 |
|---|---|
| 手机默认 | 7+7，仿 Termux：`Esc / - HOME ↑ END PgUp` + `Tab Ctrl Alt ← ↓ → PgDn`；窄屏不再挤 8 列 |
| 平板默认 | 8+8：`Esc Tab Ctrl Alt ← ↓ → ↑` + `^C ^D ^Z HOME END \| / -` |
| 自定义 | 显示设置 →「快捷按键布局」，或长按附加键区域/单个按键；手机、平板两套草稿分别保存 |
| 编辑操作 | 从 27 个动作目录增删、替换、左移/右移、移除、恢复当前布局默认；每行最多 10 个；空行保存后隐藏 |
| 渲染 | 单行、8–13sp 自动缩字、固定 48dp 行高；超过可用宽度横向滚动，不再折行或裁掉 `HOME` 等标签 |
| 修饰键 | `Ctrl/Alt` 仍是一次性修饰键；选中态使用按键底色 + 描边，下一次按键后清除 |
| 刷新边界 | 保存只重建当前 PTY 的附加键视图，不新建/切换会话，不发送输入；简易模式没有附加键 |

持久化沿用 `deepseekharness`：`term_extra_keys_phone`、`term_extra_keys_tablet`，格式为 `ACTION,ACTION|ACTION,...`；损坏或空值回退默认。模型与单测在 [TerminalExtraKeys.java](../../app/src/main/java/com/deepseekharness/app/util/TerminalExtraKeys.java)、[TerminalExtraKeysTest.java](../../app/src/test/java/com/deepseekharness/app/util/TerminalExtraKeysTest.java)；编辑面板在 [ExtraKeysDialog.java](../../app/src/main/java/com/deepseekharness/app/ui/ExtraKeysDialog.java)。

同一轮的 HTML 设计更新（侧栏三向态、图标化、单行会话、2×2 填充动作）见 [终端原型](../design/terminal-20261025/preview.html)、[验证记录](../design/terminal-20261025/validation.md) 与 [原生化方案](../design/terminal-20261025/native-terminal-theme-plan.md)。原生化主题本身尚未落地，等用户确认。
