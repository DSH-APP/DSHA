# DSHA 0.2.1-rc.3-20261101.0053-dsh0.2.1-rc.5 / build220

- 携帯タスクの右下フローティング操作ウィンドウと画面認証の競合を修正しました。状態ウィンドウを展開すると画面操作は一時停止し、古い認証を取り消します。その後に届く `turn/end` または `/app/ui/task-end` が一時停止中の操作ウィンドウを無条件で閉じることはありません。
- ユーザーが展開して一時停止した同じタスクは接続を維持します。明示的な「続行」では画面を再観察し、「停止」ではタスクを回収します。古い認証や結果不明の操作を自動承認・再実行することはありません。通常の完了時は従来どおりウィンドウとサービスを終了します。
- クリーンアップ時にメインスレッドでタスク所有者と一時停止状態を再確認します。展開後の保持、明示停止、通常完了の Android 回帰テストを追加し、デバイス操作ガイドを更新しました。
- モバイル ScreenSense の認識/操作性能評価と段階的リファクタリング案を追加しました。OCR、コンパクトプロトコル、遅延予算は設計評価であり、このビルドの実装機能ではありません。
- versionCode を 220 に引き上げました。DSHA リビジョンは 0.2.1-rc.3、内蔵 DSH は 0.2.1-rc.5 のままです。完全なビルド、テスト、署名、実機検証の範囲は CI / Release の記録に従います。
