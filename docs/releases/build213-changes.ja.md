# DSHA 0.2.1-rc.3-20261030.1900-dsh0.2.1-rc.5 / build213

- 内蔵 DSH を上流の dsh-v0.2.1-rc.5 に更新：会話の thinking 表示が上流の更新に追随します。ランタイムアーカイブは rc.5 で再構築し（127,674,426 B、SHA-256 `91aa4685721ce569e32953295dc6b01b63fe2ac5e1eac8173440656896acdcb2`）、パッチチェーンと 31 の data/storage 読み取りパッケージを確認済みです。証拠は [rc.5 データ読み取り証拠](../runtime-data-compatibility-rc5.md) にあります。
- ターミナルに DSH CLI 入口を追加：ワークスペース上部バーのボタンと「新規セッション」選択器から、固定の起動バナー付き PTY セッションを直接開けます（dsh バージョンを事前確認し、対話型 TUI がないこと、headless の認証情報/権限の違い、ターミナルで Web を起動しないことを説明します）。セッション種別は追加せず、セッション終了・実行保護・メンテナンスバリアの意味は変わりません。
- 端末のセッションドロワーは、スマートフォン縦向き/狭いウィンドウ（< 600dp）で最大幅を 336dp から 224dp（約 1/3 減）に狭め、タブレット/広いウィンドウ（≥ 600dp）は 336dp を維持します。スクリム/戻るジェスチャー領域は引き続き最低 32dp を確保し、インラインサイドバーの幅は変わりません。
- 224dp のドロワーでは、セッション行が既存の狭ウィンドウ規則でステータスを縦積みにし、下部アクションは 2 列を維持します。低いウィンドウ/横向きの圧縮規則は変わりません。
- versionCode を 213 に引き上げました。DSHA のリビジョンは 0.2.1-rc.3 のまま、内蔵 DSH のサフィックスは 0.2.1-rc.5 です。ビルドと検証の範囲は本 run と Release の記録に従います。
