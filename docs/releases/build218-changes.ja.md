# DSHA 0.2.1-rc.3-20261031.1800-dsh0.2.1-rc.5 / build218

- 初回ガイドを 4 ステップ（ようこそ → 用途 → 権限 → 完了）に再構成し、従来の 3 ページ ViewPager2 と独立した準備ページを置き換えました。`welcomed == false` のときは引き続きガイドのみを開き、Main と起動リカバリも同じ契約を検証します。
- 初回デプロイはアプリ全体のバックグラウンド保守タスクになり、進捗はガイド画面と Main 上部バーのデプロイカプセルに表示されます。全画面で待たせることはなく、デプロイ中は画面を点灯したままにし、成功後に完了画面と 1 回の Web 起動を行います。ガイド内のデプロイがバックグラウンドで終了した場合はガイドの元のステップに戻ります（`welcomed` はガイドを離れて Main に入るときだけ書き込まれます）。
- 上書き更新は、新レイアウトの全画面「実行環境メンテナンス」ページ（ステージバー + ステージ一覧 + 下部操作）に戻り、制限付き Main とダイアログでの表示は行いません。ディスク上に未完了の保守トランザクションまたは未クローズの隔離トライアル現場がある場合は、保守ページ・パネル・自動開始が先に「中断した保守の復元」（古いトライアルプロセスの終了を確認して現場を閉じる）へ切り替え、`TRIAL_RECOVERY_REQUIRED` で必ず失敗する更新を開始しません。自動開始は従来どおり「同じ候補を 1 回だけ」試し、制限付き Main はユーザーが保守ページで「制限付きメイン画面に入る」を明示的に選んだときだけ表示され、準備完了マーカーは書きません。ターミナル・Web・プラグイン実行は引き続き環境ゲートを通過します。
- 権限カード（7 種類の端末機能 + ADB、用途別の推奨とスキップ可）を追加しました。通知権限は Android 13+ でタップ時に要求し、バッテリー最適化は読み取り専用で確認して免除は申請しません。Stellar マネージャー（`roro.stellar.manager`）を認識して起動でき、アクセシビリティ設定の文言は実際のシステム一覧名に統一しました。
