# DSHA 0.2.1-rc.5-20261106.1830-dsh0.2.2-rc.1 / build333

- الوصول إلى الملفات بين التطبيقات (SAF، PR #3، review `5797594537` APPROVE، merge `9cc91f5e`): يضاف إلى «الإعدادات ← أذونات قدرات الجهاز ← أذونات النظام» عنصر «الوصول إلى الملفات بين التطبيقات». بعد أن يمنح المستخدم مجلدًا عبر منتقي المستندات في النظام، يحتفظ DSHA بصلاحية القراءة/الكتابة (حتى 8 أشجار)؛ وتدير صفحة الأذونات هذه الأشجار وتوفر تصفحًا للقراءة فقط مع معاينة نصية. نقاط نهاية جسر جديدة `/app/saf/*` (trees / ls / stat / read / write / push / pull / mkdir / rm؛ read بمقدار 256 KiB لكل نداء، write 16 KiB، push/pull 32 MiB، القوائم 500 عنصر؛ ويستخدم `rm` رمزًا لمرة واحدة من مرحلتين)، ويبقى بروتوكول الجسر بالإصدار 3 (إضافي فقط). حدود الأمان: تُقبل فقط معرّفات سجل الأذونات القصيرة، وتتطلب الكتابة والحذف أن تكون الشجرة قابلة للكتابة، وتعيد مسارات الحاوية استخدام `BridgePathPolicy` (مناطق بيانات الاعتماد غير قابلة للقراءة أو الكتابة)، وتُفتح الملفات المحلية بـ `O_NOFOLLOW` + dev/ino + إعادة التحقق من المسار الحقيقي عبر `/proc/self/fd`، مع رفض الروابط الصلبة وكيانات `.l2s`. يضاف إلى موجه `dsh-device-shell-guide` المدمج وإلى `/app/help` سطر إرشادي واحد للوصول. تعيد المدخلات المُدارة حساب runtime descriptor في هذا PR (runtimeId `04b24571`)؛ ولا تُعاد المدخلات الثابتة بناؤها.
- يضيف «الإعدادات ← التجربة» مفتاح «إخفاء في الخلفية» (`73896284`، مساعد للإبقاء على ADB): مغلق افتراضيًا، وتفضيل محلي على الجهاز لا يدخل قائمة النسخ الاحتياطي. عند تشغيله تُزال جميع مهام هذا التطبيق الصالحة من المهام الأخيرة؛ وعند إيقافه تُستعاد وتُعاد تصنيفها وفق قاعدة «بطاقة رئيسية واحدة» الحالية. بعد إعادة تشغيل التطبيق أو إعادة فتحه بعد قتل العملية تُقرأ التفضيلات وتُطبق من جديد، ومع الفشل يُكتب `RECENTS_HIDE_APPLY` في سجل التشخيص وتُعاد المحاولة عند الفتح التالي. يؤثر فقط في ظهور المهام الأخيرة: لا يغيّر `DeviceBridgeService` ولا الإشعار الدائم ولا خدمة المقدمة ولا دلالة الإيقاف، ولا يعد وعدًا بالإبقاء (لا حماية من Doze أو توفير طاقة الشركة المصنعة أو الإيقاف القسري).
- إصلاح اتساق واجهة صفحة أذونات قدرات الجهاز (`8509ae0a`): أصبحت كبسولات الحالة تتكيف داخل `PluginFlowRow` (`wrap_content` بعرض أدنى 56dp؛ تنتقل إلى سطر جديد بدل ضغطها إلى أرباع)، ويُزال إزاحة 12dp عن سطر الحالة ويُسمح بسطرين، وتُنقل أحجام العنوان والحالة إلى `device_grants.xml` (12sp). تعيد كلمة الحالة «مغلق» في اللغات التسع الأخرى استخدام ترجمة «مغلق» الجاهزة (والصينية تحتفظ 关闭 / 關閉) عبر حالة الملخص والتعرف على الشاشة ودرجات الحافظة، دون تغيير نص «زر الإغلاق». تُسطَّح شريط الملخص إلى `shell_bg` + `shell_line` سفلي 1dp، مع إزالة زوايا 16dp السفلية والحد القوي والظل 2dp؛ وعلى الشاشات القصيرة (`screenHeightDp ≤ 480`) ينتقل الشريط إلى منطقة التمرير، بينما يبقى مثبتًا في الارتفاعات العادية مع روابط الانتقال.
- نطاق التحقق: مجموعة contracts الكاملة للمضيف، وفحص تنسيق الشجرة كاملة (JDK 17)، و`generate-changelog --check`، وفحوص روابط الوثائق ونظافة المصدر، وبوابات `test-release-*`، والاختبارات الوحدوية الموجَّهة (صفحة التحديث، وفئات SAF الخمس مع التوجيه، و`TaskNavigationPolicy`، و`BrowserTasks`، و`ConfigStore` إخفاء الخلفية، وتخطيط الأذونات). **لم تُجرَّ أي من الميزتين الجديدتين على جهاز فعلي**: تحتوي مجموعة `androidTest` على خطأ تجميع قائم مسبقًا (`RecoveryInstrumentation` تستدعي `HarnessService.refreshPowerMode()` دون `Context`)، ويبقى السلوك الفعلي في المهام الأخيرة والقطع بمستوى البكسل في صفحة الأذونات (خط 1.3×، شاشات قصيرة، RTL) بحاجة إلى تحقق على جهاز فعلي. يُرفع رمز الإصدار إلى 333 (أساس build332)؛ وتبقى مراجعة DSHA 0.2.1-rc.5، وDSH المضمَّن 0.2.2-rc.1، وruntimeId `04b24571` (تغييرات الإصدار والوثائق لا تغيّر المدخلات المُدارة).
