# DSHA 0.2.1-rc.3-20261030.0214-dsh0.2.1-rc.3 / build210

- تمت مزامنة dsh-web-mobile المدمج مع أحدث محتوى المنبع (main @ 04dcd19، الإصدار ما زال 3.2.2): ملف لمس الأجهزة اللوحية، ومدخل تنزيل الملفات، وإعدادات سريعة في الدرج، مع إعادة محاذاة التصحيحات المحلية إلى المنبع الجديد.
- أُصلحت إخفاقات كاذبة في تحقق إصدار الإنتاج: aapt2 الحديث يطبع الحد الأدنى لواجهة API باسم minSdkVersion، فلم يعد التطبيق يُرفض كعدم تطابق minSdk.
- عاد لاحقة versionName لبناء الاختبار إلى -SunsetTest، فتعرفت صفحة التحديث على هوية الاختبار مجددًا.
- أصبحت شروط سير عمل الإصدار تستخدم اسم المستودع الحالي وmain، فلا يُتخطى التنفيذ بعد إعادة التسمية.
- اكتملت بوابات المصدر: دخلت نصوص الشبكة المحلية كتالوج اللغات العشر، وأضيفت سمات الوصول لمدخل اللغة وقائمة DNS، وبلغ تباين النص الخافت وحالة الضغط 4.5:1.
- قُسّم واجهة HarnessController: نُقلت قراءة الأصول المضمنة إلى PackagedAssets، ولم يعد النسخ الاحتياطي بنقرة واحدة يعتمد على إعدادات core مباشرة.
- نجحت جميع اختبارات الانحدار المضيفة الـ14؛ ونتائج البناء والإصدار وفق إيصالات المستودع.
