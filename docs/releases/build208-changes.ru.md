# DSHA 0.2.1-rc.3-20261029.0741-dsh0.2.1-rc.3 / build208

- - Исправлено определение собственных накладных окон DSHA (панель статуса, ассистент, подтверждение) как заслоняющих цель: незарегистрированные не получающие фокус собственные окна исключаются целиком по идентификатору пакета и больше не дают TARGET_WINDOW_OCCLUDED. - - Сохранены dsh-web-mobile 3.2.2, DSH rc.3, локальный доступ и доступ по LAN, а также десять языков. Проверка на телефоне остаётся приостановленной.
