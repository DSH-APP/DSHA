# DSHA 0.2.1-rc.3-20261102.0830-dsh0.2.1-rc.5 / build267

- 실험적: 모바일 데이터로 바꾸면 컨테이너가 인터넷에 연결되지 않는 문제에 대한 임시 수정입니다. 이전에는 컨테이너의 DNS가 시작할 때의 네트워크 주소로만 기록되어, Wi-Fi에서 모바일 데이터로 바꾸면 그 주소에 닿지 않아 Wi-Fi로 돌아갈 때까지 모든 이름 확인이 시간 초과되었습니다. 이제 네트워크가 바뀌면 컨테이너 DNS를 자동으로 새로 고치고, 그래도 실패하면 Android 시스템 확인자로 한 번 더 확인합니다(확인만 하며 요청을 다시 보내거나 공용 DNS를 넣지 않습니다). 읽기 전용 진단 /app/net을 추가했습니다.
- 이 수정은 실험적이며 모든 기기·시스템·통신사·VPN·비공개 DNS 조합에서 효과를 보장하지 않습니다. 네트워크를 바꾼 뒤에도 인터넷이 안 되면 /app/net 출력을 알려 주세요.
- 검증 범위: 로컬 단위 테스트와 소스 게이트만 했습니다. 네트워크 전환은 실기기에서 확인하지 않았습니다. versionCode를 267로 올렸습니다(build266 기반). DSHA 리비전은 0.2.1-rc.3, 내장 DSH는 0.2.1-rc.5로 유지됩니다.
