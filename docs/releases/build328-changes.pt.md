# DSHA 0.2.1-rc.5-20261106.0010-dsh0.2.2-rc.1 / build328

- Corrige a falha do `gh` no ambiente 0.2.2 com a mensagem "managed GitHub CLI is unavailable": o GitHub CLI oficial v2.103.3 (linux-arm64) passa a ser o 12º insumo fixo `gh-cli.tar.gz` dos ativos gerenciados; na instalação apenas o membro fixado é extraído, o SHA-256 é verificado novamente e o binário é publicado atomicamente em `/opt/gh/bin/gh`; na reconstrução da árvore inteira ele é injetado como ativo gerenciado, sem depender de instalação manual.
- Quando o binário está ausente ou corrompido, o wrapper do gh faz o bootstrap pela URL fixa e pelo digest fixo, falha de forma fail-closed em qualquer etapa e imprime um comando de recuperação pronto para copiar; o texto enganoso que afirmava estar "bundled" foi removido.
- Adiciona o contrato explícito `util/MaintenanceToolPaths` e uma pré-checagem limitada antes da reconstrução: `/opt` é preservado como diretório de ferramentas do usuário, `/usr/local/bin` pertence à árvore do sistema e não é preservado, e `usr/local/share/dsha` é injetado como ativo gerenciado; com mais de 100.000 entradas em `/opt`, a reconstrução é recusada antes de mover a árvore antiga.
- Escopo de verificação: testes de host, grupo completo de contracts e verificações de fonte/descritor/avisos de terceiros; não houve validação em dispositivo neste ambiente. Eleva o versionCode para 328 (base build327); o APK cresce cerca de 13,0 MiB por causa do arquivo gh embutido.
