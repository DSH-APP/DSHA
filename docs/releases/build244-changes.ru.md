# DSHA 0.2.1-rc.3-20261101.0910-dsh0.2.1-rc.5 / build244

- Исправлен вечный сбой «Восстановить прерванное обслуживание»: старые сборки атомарно записывали отметку о завершении плагинов прямо в каталог транзакций плагинов, и прерванная запись оставляла файлы вроде `.previous` или `.tmp-*`. После этого каждая проверка сообщала `PLUGIN_JOURNAL_ID`, восстановление зависало на «Остановка Web», другие исправления отклонялись с `REPAIR_RECOVER_PENDING_FIRST`, а Web не запускался.
- Отметка о завершении теперь хранится вне каталога транзакций. Старые остатки и другие нераспознанные записи в этом каталоге сохраняются как есть, больше не блокируют обслуживание и никогда не воспроизводятся как операции плагинов. Устройства, уже попавшие в эту ситуацию, должны пройти проверку после установки поверх.
- Эта сборка обновляет скрипт транзакций плагинов, поэтому установка поверх заменяет управляемые файлы через обычное обновление управляемой среды; личные данные остаются на месте.
- Объём проверки: локальные модульные тесты (1689 случаев в пакетах backup и util) и Python-регрессии транзакций плагинов пройдены; на устройстве с этой проблемой ещё не проверено. versionCode повышен до 244. Ревизия DSHA остаётся 0.2.1-rc.3, встроенный DSH — 0.2.1-rc.5.
