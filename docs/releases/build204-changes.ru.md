# DSHA 0.2.1-rc.3-20261027.1149-dsh0.2.1-rc.3 / build204

- Интерфейс: оформление страниц v5 из интерактивного прототипа теперь охватывает настройки, плагины, параметры запуска, установку и окружение, разрешения устройства, данные и резервные копии, обновления, диагностику, приветствие/первый запуск, «о приложении» и восстановление окружения; заголовки, группы, карточки, поля ввода и кнопки приведены к одному масштабу 26sp и единой светлой/ночной палитре.
- Терминал: «Новый сеанс», «Завершить сеанс» и «Вернуться к вводу» срабатывают с первого нажатия; переключатель «Система / Светлая / Тёмная» удалён из боковой панели, терминал следует теме приложения и не пересоздаёт сеансы и не повторяет команды.
- Доработка: на странице сопряжения ADB убран дублирующий заголовок, страница подтверждения установки по ссылке приведена к масштабу 26sp, страница обслуживания окружения (распаковка) переведена на карточки и кнопки v5.
- Объединены улучшения управления плагинами из Sunset-3090-Q: меньше повторных обновлений, сохранено подтверждённое состояние операций.
- Исправлена постоянная приостановка чтения экрана после изменения общих подтверждений. Явные запреты, паузы пользователя и разрешения Android сохраняются.
- Удалены рабочие пространства ПК, сопряжение по QR, коннекторы ПК и ретрансляторы. Управление телефоном и локальный доступ сохранены.
- Устранено повторное применение верхней безопасной области. Строка состояния, десять языков и системный язык сохранены.
- Запуск приложения на виртуальном экране принимает необязательный generation и предварительно проверяет состояние; нативный запрос запуска содержит только coreInstance и package. Такая проверка состояния не является атомарной проверкой поколения.
- В объединённом исходном коде встроены dsh-web-mobile 3.2.2 и DSH rc.3. Проверка на телефоне остаётся приостановленной; результаты других веток и пакетов не подтверждают эту сборку.
