### 4.2 rc.5 设置弹层字体行

「设置 → 通用设置 → 更多字体设置」展开后：

| 行 | 标题 | 说明 | 输入框 |
|---|---|---|---|
| 正文字体 | `[80,1824,1340,1912]` | `[80,1928,1340,2072]`（整宽、两行） | `[112,2120,1308,2216]`（独占下一行） |
| 代码字体 | `[80,2360,1340,2452]` | `[80,2464,1340,2612]`（整宽） | `[112,2656,1308,2756]`（独占下一行） |
| 代码字号 | `[80,2900,740,2988]` + stepper | 原布局 | 未受影响 |

说明列宽 1260px（不再被压成 1 字/行），输入框宽 1196px = 299dp；弹层不再被纵向撑高。

「终端字体」行位于可视区下方。WebView 内容的无障碍滚动返回 `NODE_SCROLL_REGION_UNAVAILABLE`，

该行与已实测两行共用同一补丁规则；无头 Chromium + 真实 rc.5 前端已实测三个字体行均为
`flex-wrap:wrap`、文字列/控件各 328px、无横向溢出（见[移动 Web 适配补丁](web-mobile-patches.md)）。
