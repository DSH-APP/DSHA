## 2. 本批做了什么

### 2.1 用户要求与落点

用户要求：把 `DSHA-UI-v5-完整分享包-20261026.zip` 的交互设计**尝试性编译**进应用，同时**保留点击即拉起全屏终端的功能设计和部分优化设计**。经确认，本批采用「原生试点整合 + 可装 APK」，并把 `Sunset-zhongdua-G` 的全屏终端与主要优化合入 `Sunset-3090-Q`（build201 基线）。

### 2.2 分支与输入

- 切到 `Sunset-3090-Q` 并快进到远端 `4452c9d`（build201），保留 build201 的 `dsh-web-mobile` 3.2.2、固定输入锁和本分支 CI 范围。
- 合并 `Sunset-zhongdua-G`（终端系列 `02f80ab`…`8d7e4b6`）为 merge commit `6a0cf18`。17 个冲突按「版本/插件/固定输入以 build201 为准，终端与十语资源取合入分支」收口；测试包后缀统一 `.SunsetRNE`。
- 恢复固定输入 ZIP（`ci/sunset-inputs.lock.json`，asset 672547073，SHA `1d1d47b2…`）的 `dsh-runtime.bin` 与 recovery 归档，回到 `d77261bf…` / `b9fe8a04…`，并重生成 runtime-descriptor（提交态 runtimeId `c1fb8b4d…`）。
- 移除与本分支 3.2.2 插件不兼容的旧移动 locale 补丁脚本（`tools/mobile-locales.*` 及其测试）；`dsh-web-mobile` 仍由 build201 的 3.2.2 源与既有补丁工具生成。
- `app/libs/dsha-connect.aar` 作为固定编译输入保留、不提交。

### 2.3 原生外壳（v5 试点）

- 新增 `shell_*` 日夜两套 token（17 色 ×2、导航/左栏尺寸、`Widget.DSHA.ShellNavLabel`）。
- 手机：顶栏品牌块 + DSHA/页面语境两行 + 主题/关于；底部改为悬浮胶囊导航（12dp 边距、22dp 圆角、1dp 描边、44dp 命中、10sp 标签、选中浅蓝）。

- 现有导航语义未改：终端仍是动作（不替换主容器、返回保留来源页）、重复点选保留页面、`open_web/open_plugins/open_terminal` 意图与门禁不变。
- 对应文件：`MainActivity.java`、`activity_main.xml`、`layout-sw600dp/activity_main.xml`、`ui/ShellRail.java`、`values/shell_ui.xml`、`values-night/shell_ui.xml`、`bg_shell_nav/brand/rail/rail_item`、`color/shell_nav_item_tint` 等。

### 2.4 启动主页（v5 维护/主页试点）

- 重排 `fragment_launch.xml`：语境 → 大标题 → 说明 → 2dp 活动条 → 主操作 → 三格真实状态（运行环境 / 工作台 / 本机端口）→ 快捷行（打开本机终端、运行环境、访问地址、电脑工作区）→ 日志面板。
- 新增 `ShellActivityTrack`：RUNNING 横扫光带 / SETTLED / ERROR / IDLE；帧回调推进，无无限 `ValueAnimator`；系统关闭动画、不可见或 detach 时静态。
- `LaunchFragment` 仅用真实状态映射文案（启动/停止/进入/核对/就绪/待确认/需恢复/重启暂停），不伪造阶段进度；保留启动/停止/进入/局域网/日志下载/每秒刷新/自动进入/门禁全部原逻辑。
- 日志：新增复制（`SensitiveClipboard`，提示可能含本机地址）、跟随/暂停跟随/查看最新；导出沿用既有 `DiagnosticActivity.downloadLogs`。
- 快捷行「打开本机终端」调用 `MainActivity.openTerminal()`（终端门禁与全屏宿主不变）；「运行环境」复用既有恢复/环境维护入口。

### 2.5 终端保留（点击即拉起全屏终端）

- 合入独立全屏 `TerminalActivity`（同 task、非导出、专属 Insets/Back）与 `TerminalRuntimeService`、`TerminalRuntimeProtection`、`TerminalSessionOwner` 增强。

- 保留优化：三向态侧栏与图标化、手机 7+7 / 平板 8+8 附加键自定义、横屏三列两行压缩、单行会话、宽屏内联/窄屏抽屉、结束全部核验。
- 终端内核、PTY/JNI、运行资产摘要与生产数据格式未改。

## 4. 与原型的有意差异 / 未做

- 原型是离线 HTML 演示，不是 APK；本批只原生实现外壳与启动主页的信息层级。**未**照搬原型的 16 个主视图。
- 设置、插件、文件、备份、诊断等子页仍沿用现有原生实现；原型中的模拟环境/终端/插件数据未接入。
- 原型终端是页内模拟终端；本批按要求保留独立全屏原生终端，两者不是同一形态。
- 启动页未实现原型的分阶段 phase 列表：仓库规则要求不伪造就绪或阶段进度，本批只表达真实状态。
- 新增 `UiText.choose` 文案未进 `tools/i18n/messages.json`，非 zh/en 语言回落英文；UI 语言目录与移动插件语言包未在本批重译。
- 平板左栏 `LOCAL FIRST` 用横向小字近似原型的竖排；手机选中态沿用 Material 默认 active indicator，不是覆盖整项的圆角块。
- APK 比 build201 约大 127 MB：正式运行时按 npm lock 重建（`36c3…`），独立应急运行时仍为固定输入（`d772…`），两者字节不同，不再共用包内字节，因此 recovery 运行时单独入包。这是固定输入与当前源码混用的预期结果，不是恢复功能变化。
- 未做真机：Android 16 平板上的顶栏/胶囊/左栏实际渲染、点击、旋转、字体缩放、TalkBack、终端手势与 IME 均未验收；截图不能替代。
