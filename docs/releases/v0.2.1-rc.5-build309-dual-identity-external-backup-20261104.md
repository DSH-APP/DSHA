## 2. 改动

- 发布身份（c12bf11f）：`-Pdsha.identity=mod|upstream`（默认 mod，未知值配置失败）；包名、显示名、测试后缀、默认 key alias 与 `verifyPublishCertificate` 证书均取自身份文件；`ci/release-identity.json` 为 Mod 兼容入口，`tools/release-identity.py --check` 强制与 mod 一致并拒绝两套身份共享包名、证书、alias、测试后缀、tag 前缀或仓库。`release-upstream.yml` 只在 `ym2025szz/DSHA-prerelase` 私有仓库 `codex/prerelease-190` 运行，本仓库不保存 E7E3 密钥；`test-package.yml` 增加 identity 输入，测试证书须与两个正式证书都不同。
- 外接设备（9956ac80）：`ExternalDeviceHost` 在确认前捕获目标序列号、产品、指纹与各代次，权限变化后未派发步骤以 `EXTERNAL_AUTHORITY_CHANGED_BEFORE_DISPATCH` 拒绝；`RootShell.writeExternalRequest` 派发前再核对。`wm` 仅 size / density 查询，`logcat` 仅只读参数，规划与派发共用 `diagnosticReadRejection`；授权页外接开关保存失败时回滚。
- 备份读取（cd39ecc4）：read / currentSnapshot 以 O_NONBLOCK 打开，list / syncDirectory 加 O_DIRECTORY；`AndroidDeviceFiles` 的 O_DIRECTORY 由 asm-generic 的 0x10000（arm64 上为 O_DIRECT）改为 aarch64 的 040000。主机测试 `tools/test-backup-read-nonblock.py` 用真实 FIFO 替换做正反对照。
- 备份诊断（d726ecb3）：`BackupFailureDiagnostic` 按阶段写 failure.json（不含消息与路径）；`BackupTemporaryFiles` 让清理失败作为 suppressed 附在原始错误上。
