# DSHA 0.2.1-rc.3-20261027.1312-dsh0.2.1-rc.3 / build205

- 端末への貼り付けは容量制限のある FIFO 入力キューに順番に入り、括弧付き貼り付けは一件として送られます。キューが満杯になると後続入力を停止して確認を求め、未送信の内容は自動再試行しません。
- 仮想画面の起動結果が不明な場合、許可された診断コードを保持します。診断はリモート側の終了を証明せず、不明結果の保護も解除しません。
- スマートフォン操作を、直近に成功した画面観察の対象に結び付けます。対象の変更や新しい観察の開始後は新たな観察が必要で、古い観察では操作許可を復元できません。
- 端末の DNS が利用可能な場合、旧版の既定 DNS 設定とバイト単位で完全一致するものだけを端末 DNS に移行します。利用者が変更した設定と、端末 DNS を利用できない場合の旧設定は保持します。
- セッションとワークスペースのストリーム復旧、ダウンロードの探査、圧縮応答の回帰テストを拡充しました。これらは実機や実サーバー再起動の検証を意味しません。
- dsh-web-mobile 3.2.2、DSH rc.3、ローカル・LAN 接続と10言語を維持します。実機検証は引き続き一時停止中です。
