# DSHA 0.2.1-rc.5-20261106.1830-dsh0.2.2-rc.1 / build333

- アプリ間ファイルアクセス（SAF、PR #3、review `5797594537` APPROVE、merge `9cc91f5e`）：設定 → デバイス機能の権限 → システム権限に「アプリ間ファイルアクセス」を追加。ユーザーがシステムのドキュメント選択画面でフォルダを許可すると、DSHA は読み取り/書き込み権限を永続化し（最大 8 ツリー）、権限ページで管理と読み取り専用の閲覧・テキストプレビューができます。`/app/saf/*` ブリッジ端点を追加（trees / ls / stat / read / write / push / pull / mkdir / rm。read は 1 回 256 KiB、write 16 KiB、push/pull 32 MiB、一覧 500 件、`rm` は 2 段階のワンタイムトークン）。ブリッジプロトコルはバージョン 3 のまま（追加のみ）。安全境界：許可簿の短い id のみを受け付け、書き込み/削除はそのツリーが書き込み可能であることを要求。コンテナパスは `BridgePathPolicy` を再利用（認証情報領域は読み書き不可）。ローカルファイルは `O_NOFOLLOW` + dev/ino + `/proc/self/fd` の実パス照合で開き、ハードリンクと `.l2s` 実体を拒否します。組み込みの `dsh-device-shell-guide` プロンプトと `/app/help` に入口の一文を追加。PR 内で管理対象入力により runtime descriptor を再計算（runtimeId `04b24571`）、固定入力は再構築しません。
- 設定 → 体験に「バックグラウンドで隠す」スイッチを追加（`73896284`、ADB キープアライブの補助）：既定はオフ、端末ローカルの設定でバックアップ許可リストには入りません。オンにすると本アプリの有効なタスクをすべて最近のタスクから外し、オフにすると復元して既存の「メインカード 1 枚のみ」ルールで再分類します。アプリ再起動やプロセス終了後の再起動では設定を読み直して適用し、失敗時は `RECENTS_HIDE_APPLY` を診断ログに書き、次回起動時に再試行します。最近のタスクの可視性だけに影響し、`DeviceBridgeService`、常駐通知、フォアグラウンドサービス、停止セマンティクスは変更しません。キープアライブの約束ではなく（Doze、メーカー省電力、強制停止は防ぎません）。
- デバイス機能の権限ページの UI 一貫性修正（`8509ae0a`）：状態ピルを `PluginFlowRow` 内で可変に（`wrap_content` と最小幅 56dp、収まらない場合は折り返し、四等分の圧縮はしない）、状態行の 12dp インデントを削除して 2 行を許容し、タイトル/状態の文字サイズを `device_grants.xml`（12sp）へ移動。他の 9 言語の「オフ」状態語は既存の「閉じられています」訳（中国語は 关闭 / 關閉 を維持）を再利用し、概要状態・画面認識・クリップボード段の 3 箇所に適用、「閉じるボタン」の文字列は変更しません。概要バーは `shell_bg` + 下端 1dp の `shell_line` に平坦化し、下端 16dp の角丸・強い枠線・2dp の影を削除。短い画面（`screenHeightDp ≤ 480`）では概要バーをスクロール領域へ移し、通常の高さでは固定のままジャンプリンクを保持します。
