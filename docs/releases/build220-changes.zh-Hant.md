# DSHA 0.2.1-rc.3-20261101.0053-dsh0.2.1-rc.5 / build220

- 修正手機任務右下角浮動控制窗與識屏授權的競態：使用者展開狀態窗後，螢幕控制會立即暫停並撤銷舊授權；之後到達的 `turn/end` 與 `/app/ui/task-end` 不再無條件關閉暫停控制窗。

- 清理路徑會在主執行緒再次核對任務歸屬與暫停狀態，補上展開暫停保留、明確停止回收與正常完成回收的 Android 回歸測試；同步更新裝置操作指南。
- 補充手機端 ScreenSense 識屏/操作層效能評估與分階段重構方案；OCR、緊湊協定與延遲預算仍是設計評估，不是本版已落地能力。
- 版本碼提升為 220；DSHA 修訂號維持 0.2.1-rc.3，內建 DSH 為 0.2.1-rc.5。完整建置、單元測試、簽名與真機驗收範圍以本版 CI / Release 回執為準。
