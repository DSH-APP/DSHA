# DSHA v0.1.5-rc2 正式版

由贡献者 [@ym2025szz](https://github.com/ym2025szz) 维护并发布，感谢原作者 [@qiannianhuanxiang](https://github.com/qiannianhuanxiang) 和所有贡献者。

本次将已验收的 **构建 129** 发布为正式 Release，并显式设为 **Latest**。保留 APK 名称 **0.1.5-rc2 / 0.1.5-rc2low**、原发布签名及包名；上游 dsh 为 **0.1.5-rc.2**，Ubuntu 基础环境仍为 **10**。名称中的 rc2 对应随包运行时与既有安装包命名，本次 GitHub 发布不标记为预发布。

## 本次正式版的变化

### 统一界面与中英文

- 卡片、按钮、输入框、底栏、权限卡片及日夜主题统一；应用内确认、选择、插件、恢复、下载等弹窗使用同一套样式，短屏和大字体下正文可滚动，底部操作可见。
- 页面切换使用短淡入淡出与小幅位移，并尊重系统关闭动画设置。安装检查日志能独立上下滚动；诊断报告放入限高滚动框。关于弹窗使用仓库/QQ群信息卡片和独立关闭按钮。
- 默认中文，可选择 English。原生页面、应用提示、动态状态与 WebView/Gecko 的实际语言服务同步；修复切回中文后仍保留英文插件检测结果等问题。
- 语言切换只重建界面，终端与 Web 继续运行。聊天、文件名、命令、用户输入和第三方原始错误不做自动替换。

### 多终端、插件与平板

- PTY 和简易终端各自支持新建、切换与关闭标签，保留独立进程、输出、工作目录和输入草稿；跨切页、旋转及语言切换保持状态。
- 显示编号复用最小空缺：关闭所有终端后，新建仍为“终端 1”。内部会话 ID 继续递增，关闭失败保留标签，过期回调不会关闭新会话。
- 插件管理的排序和检查更新按钮统一加框；支持名称升序/降序、已启用优先和可更新优先，名称排序处理大小写、数字与中文拼音。
- 内置 dsh-web-mobile 为 **2.4.1-dsha.2**。四种 Agent 预设由 Host 确认后应用；已有内容的会话保留，并通过同工作区新会话应用所选预设。
- 平板触屏宽屏下预设与文件夹入口靠右，去掉默认黑框，保留键盘焦点提示；文件夹按钮实际打开文件面板。

### 文件、浏览内核与网络

- **#64 多文件选择**：修复系统多选结果在 ClipData 中被丢弃的问题。WebView 与 Gecko 共用解析，保留文件顺序与名称，仍只接收用户选择的 content URI，并保留数量/大小限制。
- **旧 WebView / PDF**：在应用模块加载前补齐 Iterator、Promise、URL、集合和二进制等接口，PDF Worker 单独注入；修正旧 Chromium 的文件资源协议解析。兼容脚本生成避免单行拼接破坏字符串换行。
- 提前补齐缺失的 AbortSignal.any/timeout 和随机 UUID，保留原生实现、取消原因与监听清理；保留实际插件错误用于诊断。
- **#63 DNS**：默认仅在双栈解析返回 EAI_AGAIN/EAI_FAIL 时尝试一次 IPv4；另提供 IPv4 兼容和原生模式。保留用户 DNS 配置，不降级显式 IPv6、不重放 HTTP 请求、不更改 TLS 验证。

### 启动、升级与设备能力

- 首选端口冲突时保留配置，尝试可用备用端口或由 dsh 分配端口；鉴权、保活和局域网使用实际端口。慢鉴权 60 秒只提示，不强行结束启动。
- 明确的配置/插件故障进入原生恢复页，保留最近脱敏记录；提供健康配置、修复前快照和独立安全启动。快照仅处理固定配置文件，不恢复按启动次数整库备份。
- 修复旧平板升级时误遍历宿主路径映射与模拟硬链接，先保护、再恢复并逐文件核验；真实文件权限异常仍会中止操作并保留原环境。
- 设备能力集中授权；Root、Shizuku、ADB 各自核验，命令执行结果未知时不切换通道重放。
- Shizuku 按 API 权限所属管理器识别改包名版本，用户点击授权时可通过标准 REQUEST_BINDER 恢复连接。严格核对回调来源、服务描述符和请求时效，再交给受保护的 Provider 握手，仍由管理器授权。

## 验证范围

最终两版各 **383 项 JUnit：382 通过、1 跳过、0 失败**，Release Lint 无错误；发布签名、SHA-256、arm64、最低 API、16 KiB ZIP 对齐与无插桩入口均已核验。

- Android 13 / WebView 116：缺失接口恢复、真实页面及重载、实际 PDF.js 模块 Worker 冷启动，共 **30 项检查通过**。
- 标准 WebView 与兼容 Gecko：真实文件选择 Activity 回调返回两个文件，逐项核对名称、顺序和字节，并检查取消、空结果、去重、非法来源及数量上限。
- 标准 API 13.1.5 / 兼容 API 12.2.0：Shizuku Binder 断连恢复、保留现有授权、UserService 绑定与 id 均通过，实际使用 Shizuku 通道返回 uid=2000(shell)。
- 此系列修订另已验证中英文日夜/短屏/大字体界面、多终端、DNS 故障注入、插件排序、日志滚动、Android 17 平板升级与宽屏顶栏；对应记录见构建 121–129 文档。

**兼容边界**：最终轮次未使用 Android 6/7 实机、真实 16 KiB 页内核或实际 thedjchi 改版安装实例。thedjchi 适配依据其公开标准协议实现，不等同于所有改版均已实测；本次未重新进行模型推理往返测试。
