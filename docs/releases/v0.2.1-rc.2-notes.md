# DSHA v0.2.1-rc.2 · build190 正式版

发布：2026-10-23。由贡献者 [@ym2025szz](https://github.com/ym2025szz) 直接发布到 [DSH-APP/DSHA](https://github.com/DSH-APP/DSHA/releases/tag/v0.2.1-rc.2)，不创建 PR。感谢原作者与其他贡献者。此页是当前发布说明；下方链接中较早的“仅私有交付/公开暂停”仅描述当时状态，本次用户授权覆盖该限制。旧版 Release、标签与 v1.1.10 及更早介绍保留。

## 本版变化

- 包名改为 `dsh.android.client`，可与旧 `com.dsh.client` 共存。数据、Android 授权和本机凭据独立，迁移使用备份导出/恢复；两套服务同时运行仍可能发生共享设备端口冲突。
- 实验性虚拟屏、全局确认策略、任务通知和设备能力入口；虚拟屏需要有效 ADB / Root / Shizuku 能力。全局允许只免除 DSHA 确认，不赋予系统能力，也不构成安全沙箱。
- 内置 DSH 0.2.1-rc.2、移动 UI 3.2.1；默认 proot、可选 proroot，Ubuntu 基础环境仍为10。
- 修复运行时入口与依赖链接、插件状态/来源与管理阻塞、局域网/登录、预览确认、工作区选择和后台恢复等路径；键盘衔接、侧栏与预设等待布局优化，会话单击切换。画中画默认关闭，由用户主动启用。
- 一键备份与无需密码的导出；移除彻底重装，维护只断开外置工作区的私有引用，不清理外置内容。备份范围与原格式校验保留。

## 安装、迁移与源代码

从 [Release](https://github.com/DSH-APP/DSHA/releases/tag/v0.2.1-rc.2) 下载 APK 及对应 `.sha256`，[校验步骤](../download-verification.md)。旧包与新包数据不自动共享；先在旧包导出，再在新包恢复。首次解压完成进入主页，后台启动 Web，就绪后在 Web UI 配置模型。后续同包覆盖前先正常停止 DSH，保留备份。

Release 的 **`DSHA-0.2.1-rc.2-20261022.2100-source.zip`** 包含该公开提交的全部跟踪源码、中文/英文文档及11个固定离线构建输入（其中2个与源码同名且字节相同，去重后只存一份）。GitHub 自动生成的 Source code ZIP 不包含被 Git 忽略的大型离线包。签名私钥、模型密钥、用户数据和未脱敏设备资料不进入源码归档；签名构建需自行提供凭据。输入包 SHA-256 `417f5b022a99baaa611bb3a68695f29df5e23fc529efd76d5e55b069d8829e18`，695627776字节。构建见 [BUILD](../../BUILD.md)；归档摘要随 Release 提供。

## 验证范围与已知限制

继承精确2100包的所选软件检查：Standard/Low各44类332项关联JUnit零失败/错误/跳过，17项宿主、7项APK门禁通过；Lint零错误，警告248/161保留。不是全历史检查一次连续通过。实际 Android13 正常停止覆盖后，58个受检查用户文件在首启前逐字节相同；proot/proroot后端、网页、旧会话和立即息屏启动有记录。

插件真实启停确认约3.10–3.39秒，页面三轮约1.41–2.47秒，不能证明普遍整页提速。PR119既有实现保留并补22项布局/策略回归；较早1817像素记录仍有3帧局部标题异常，不能据此宣称全部PiP问题消失。自然Doze、其他ROM、全设备矩阵、新长时/功耗/温度对照与2100真实模型调用未完整复验。Root递归READ子链接缺口仍存在；权限护栏不是系统沙箱。详细范围见[本轮交付证据](v0.2.1-rc.2-build190-ui-performance-20261022.md)、[性能分析](../ui-performance-20261022.md)和[安全模型](../security-model.md)。
