# DSHA v0.1.5-rc1 正式版

由贡献者 [@ym2025szz](https://github.com/ym2025szz) 维护并发布，感谢原作者 [@qiannianhuanxiang](https://github.com/qiannianhuanxiang) 和其他贡献者。

本次将经过真机验收的 `0.1.5-rc1` 作为正式 Release 发布并设为 **Latest**。沿用已验收 APK 的文件名和版本号，包内上游 dsh 为 `0.1.5-rc.1`；版本码 **116**，Ubuntu 基础环境版本 **10**。

## 正式版更新

- **新版 dsh 与模型**：从此前已发布预览版的 `0.1.2-rc.1` 升级到 `0.1.5-rc.1`，提供 DeepSeek-V41-Flash，保留 V4 Flash、Pro 和 Vision 实验模型。已完成新 Flash 的真实文字、图片、文本附件和读取工具调用。
- **文件与对话体验**：保留新版右栏引导、Markdown、HTML、PDF、图片、代码和长文本预览，支持滚动和代码复制；标签关闭“×”位于右侧垂直中心。修复输入法和系统栏遮挡、提示残留，普通回车换行，点击发送按钮或 Ctrl / ⌘ + Enter 发送。延续预览版的附件、文件保存、图片草稿和阅读位置恢复。
- **启动与安装**：拆分 Ubuntu 和 dsh 离线包，复用未变化的网页拼接结果；保留 curl/git/证书与首次安装完整校验。修复首次原生扩展缓存悬空导致找不到内置组件的问题。Android 16 同机连续六次启动至鉴权为 **3.43～3.66 秒**，冷环境解压及完整验证约 **19.3 秒**。
- **覆盖升级与备份**：同一 Ubuntu 基础环境只事务更新 dsh、内置插件和受管工具，个人目录、会话、配置和第三方插件保持原位；基础环境变化时先备份并校验，再重建、恢复，失败保留回退路径。删除按启动次数自动备份及普通启动的全目录扫描，保留手动备份。补齐旧配置类型和旧会话迁移兼容，缺少插件依赖时保留源码并报告缺失项。
- **运行与恢复**：启动页记录实际阶段、耗时、插件错误和退出码，失败日志可下载；超过 60 秒继续等待。安全启动使用独立基础配置，保留原 profile；proroot 在满足退出条件时可尝试一次 proot。停止与维护统一核验 Web PID 身份，维护前回收 PTY、普通终端及其后台进程。
- **插件、更新与设备入口**：汇总此前预览版的插件链接安装、导入导出、检测、启停、更新、回退及诊断修复；延续后台 APK 下载、取消与续传、签名和包信息校验。设备命令使用白名单保护系统与关键进程，保留无线 ADB、Shizuku 备用通道、局域网访问和容器终端。

| v1.2.0-rc1.2 | 双版本、插件安装与删除、浏览内核与体积优化 | 保留双内核与插件能力；新增官方文件预览适配和更小的独立运行时包 |
| v1.2.0-rc1.3 | 更新通道、网页插件入口、诊断、回退与安全启动 | 保留这些入口；强化实际插件错误、失败输出和独立安全配置 |

相对最新已发布预览版 **v1.2.0-rc1.4**，标准 APK 从 **212.87 MiB** 降至 **176.06 MiB**（约减少 **17.3%**），兼容 APK 从 **289.69 MiB** 降至 **252.82 MiB**（约减少 **12.7%**）。保留完整离线 Ubuntu、Node、Python 和 dsh；不同设备上的启动耗时不能直接横向比较。

两版共用 `com.dsh.client`、历史签名和应用数据，不能并排安装。升级前保留重要数据的手动备份，再覆盖安装对应版本。

- 已发布 v1.2 预览版使用基础环境版本 9；更新到本版的基础环境 10 时，会先保护数据再重建，不适用下述局部更新耗时。
- 使用相同基础环境 10 的本地 alpha 测试包可局部更新；alpha.2 → 本版真机实测约 **7.45 秒**，前后数据摘要一致。
- 已安装本次同名本地修订包的用户与此 Release 使用相同 APK，无需重复下载。此次正式发布没有重新签名或更换验收包。
- 1.1.10 及更早版本的历史 Release、资产和说明保持原样。本轮未重新验证这些旧架构版本的全部直接升级路径。

## 验证范围

本轮在 **Android 16 / Xiaomi 2410DPN6CC / arm64** 实测覆盖更新、冷安装、首次原生模块加载、连续启动和重启、安全启动、两种浏览内核、文件预览、模型往返、附件、工具调用、终端维护、插件管理及备份恢复。

两版各 **330 项 JUnit：329 通过、1 跳过，无失败**；Release Lint 无错误。两包的签名、SHA-256、ZIP 16 KB 对齐、离线包摘要、依赖完整性和 ELF 静态检查通过。最终标准版已覆盖安装；详细证据与限制见[验收记录](https://github.com/DSH-APP/DSHA/blob/v0.1.5-rc1/docs/releases/v0.1.5-rc1.md)。

Android 6/7 和真实 16 KB 页内核仍缺本轮实机覆盖；兼容包可构建、可验签及同机 Gecko 测试通过，不等于所有机型均已验证。
