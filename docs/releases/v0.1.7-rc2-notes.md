# DSHA v0.1.7-rc2 正式版

由贡献者 [@SunsetRNE](https://github.com/SunsetRNE) 维护并发布，感谢原作者 [@qiannianhuanxiang](https://github.com/qiannianhuanxiang) 和其他贡献者。

本次以 **正式 Release / Latest** 发布已验收的 build 147，保留 `0.1.7-rc2` 安装包名称、原包名和 E7E3 历史签名。内置 DSH 为 `0.1.7-rc.2`，Ubuntu 基础环境为 10；GitHub 不标记为预发布。

## 简短更新说明

- **DSH 与移动端更新**：alpha.2 升至 rc.2，加入定时任务、快捷键、进行中会话启用新工具等上游改进，修复部分长对话和插件设置问题；移动插件更新为 3.0.3。
- **插件下载提速**：修复重复加锁导致的安装卡死；新增自动、npm 官方源、npmmirror 选择，更新检查最多三路并发，锁定版本复用缓存，失败有限回退。
- **独立应急与麦克风**：正式环境不可用时可使用独立应急 DSH；修复写入仍需原生确认。WebView、Gecko 和应急页面按网页请求申请录音权限。
- **稳定性与数据保护**：收敛维护和终端状态，完善插件事务、文件访问和授权撤销；修复旧 Web PID 复用、应急请求扩展错误及旧系统安装退出状态误报（[#79](https://github.com/DSH-APP/DSHA/issues/79)），补齐后台 LAN 服务及监听恢复（[#80](https://github.com/DSH-APP/DSHA/issues/80)）。

## 升级与验证范围

两版共享 `com.dsh.client` 和数据，使用同签名 APK 覆盖安装，不能并排安装。升级前导出重要数据并保存备份密码；本机自动副本不保证卸载后存续。相同 Ubuntu 基础版本按受管组件更新。独立应急环境按需解压，需额外约 0.8 GiB 空间。

最终包两版各 807 项单测（806 通过、1 项既有跳过），Release Lint、APK/ELF/签名、插件与应急门禁通过；Android 13 真机各完成 11 项非破坏性验收，包含后台及息屏 LAN 请求。未扩写为 Android 6/7/8、原 issue 平板、长期 Doze、16 KiB 真机或全部外部模型服务验证完成。固定延迟夹具的六插件查询中位耗时约 921→318 ms，仅说明并发减少串行等待，不代表实际网络吞吐增幅。

详细证据见[插件及 #79/#80 验收](v0.1.7-rc2-plugin-network-issues79-80.md)。仓库主页保留 1.1.10 及更早的历史介绍，当前功能和验证范围以上文为准。
