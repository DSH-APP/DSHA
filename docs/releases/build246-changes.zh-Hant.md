# DSHA 0.2.1-rc.3-20261101.1600-dsh0.2.1-rc.5 / build246

- 修正懸浮助手視窗未與輸入法隔離：收起後的懸浮助手貼在螢幕底部，先前在其他應用中點輸入框彈出鍵盤時，它會隨鍵盤整體上彈，擋住輸入區附近內容。
- 懸浮助手從不接收文字輸入（編輯在獨立的助手頁面進行），現在它的視窗只避讓系統列，不再回應其他應用的輸入法；讀屏時登記的懸浮助手排除區也不再隨鍵盤開合變化。
- 驗證範圍：僅本機/CI 單元測試；**未在實機測試**。本修正可能在部分系統或 ROM 上不生效（懸浮助手仍隨鍵盤上彈），需要使用者後續回饋確認。版本碼提升為 246；DSHA 修訂號保持 0.2.1-rc.3，內建 DSH 為 0.2.1-rc.5。
