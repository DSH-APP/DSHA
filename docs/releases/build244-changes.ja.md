# DSHA 0.2.1-rc.3-20261101.0910-dsh0.2.1-rc.5 / build244

- 「中断したメンテナンスを復旧」が永久に失敗する問題を修正：旧ビルドはプラグイン完了記録をプラグイントランザクションのディレクトリ内にアトミック書き込みしており、書き込みが中断されると `.previous` や `.tmp-*` などのファイルが残りました。以後すべての検査が `PLUGIN_JOURNAL_ID` を報告し、復旧は「Web を停止中」で止まり、他の修復は `REPAIR_RECOVER_PENDING_FIRST` で拒否され、Web が起動できませんでした。
- 完了記録はトランザクションディレクトリの外に保存するようになりました。旧い残留ファイルやそのディレクトリ内の認識できない項目はそのまま保持し、メンテナンスを妨げず、プラグイン操作として再実行もしません。すでにこの状態の端末は上書きインストール後に検査を通過する見込みです。
- 本ビルドはプラグイントランザクションスクリプトを更新するため、上書きインストールでは通常の管理ランタイム更新で管理ファイルを置き換えます。個人データはそのまま残ります。
- 検証範囲：ローカル単体テスト（backup と util パッケージの 1689 件）とプラグイントランザクションの Python 回帰テストに合格。この問題が起きた端末での実機確認はまだです。versionCode を 244 に引き上げ。DSHA リビジョンは 0.2.1-rc.3、同梱 DSH は 0.2.1-rc.5 のまま。
