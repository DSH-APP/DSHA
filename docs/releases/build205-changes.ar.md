# DSHA 0.2.1-rc.3-20261027.1312-dsh0.2.1-rc.3 / build205

- يستخدم اللصق في الطرفية طابور إدخال محدوداً بترتيب FIFO، ويُرسل اللصق المحاط بعلامات كعنصر واحد. عند امتلاء الطابور يتوقف الإدخال اللاحق لحين التأكيد؛ ولا يُعاد إرسال المحتوى غير المرسل تلقائياً.
- عند عدم معرفة نتيجة بدء الشاشة الافتراضية، تُحفظ رموز التشخيص المسموح بها. لا يثبت التشخيص خروج العملية البعيدة ولا يزيل حاجز النتيجة المجهولة.
- ترتبط إجراءات التحكم في الهاتف بهدف أحدث قراءة ناجحة للشاشة. يتطلب تغير الهدف أو بدء قراءة جديدة ملاحظة حديثة؛ ولا تعيد القراءة القديمة إذن التنفيذ.
- عند توفر DNS الجهاز، لا يُنقل إلى DNS الجهاز إلا إعداد DNS الافتراضي القديم المطابق تماماً على مستوى البايتات. تُحفظ إعدادات المستخدم المعدلة والإعدادات القديمة عند عدم توفر DNS الجهاز.
- توسيع اختبارات الانحدار لاستعادة تدفقات الجلسة ومساحة العمل، وفحص التنزيل، والاستجابات المضغوطة. لا تثبت هذه الاختبارات قبول الهاتف أو إعادة تشغيل خادم فعلي.
- الإبقاء على dsh-web-mobile 3.2.2 وDSH rc.3 والوصول المحلي وعبر الشبكة المحلية واللغات العشر. يظل اختبار قبول الهاتف متوقفاً.
