# DSHA 0.1.5-rc2 · 构建 123 界面修订

删除配置页空备份卡片，统一操作文字对齐与同类框的颜色，并完成中英文、日夜及大字体排版验收。版本码 **123**；dsh 保持 **0.1.5-rc.2**，Ubuntu 基础环境保持 **10**，两版文件名保持不变。

## 本次修订

- 删除配置页只显示“备份”标题、没有内容或操作的遗留卡片。
- 语言选项设置横向与纵向居中，统一按钮及操作标签的居中和字体边距；同时修正悬浮条入口、维护提示和终端标签的对齐。标题、说明段落和输入内容保留各自的阅读布局。
- 旧 `bg_polished_card`、`bg_polished_primary` 及主按钮文字状态改为引用共同资源。普通卡片不再混用渐变，主按钮不再另用硬编码蓝色或白字。补齐 Material 容器颜色，使用应用的灰蓝主题。
- 欢迎第一页在短屏、大字体下可以滚动查看完整文字。
- 悬浮条设置弹窗按实际标题和底部按钮高度分配中间滚动区域，避免英文标题换行后超高；调整按钮左右留白，避免 Preview 单词被拆行。

## 验收结果

使用 Android 13 / Redmi M2012K10C / arm64 **非调试插桩包**验收；正式包不包含测试入口。

- 中文：**2,790 个文字状态、552 处居中、90 项颜色像素检查**通过。
- 英文：最终复验同样 **2,790 / 552 / 90** 全部通过，包含短按钮单词拆行检查。
- 覆盖 23 个页面/显示状态，含启动、设置、配置、数据与备份、安装、插件市场与管理、更新状态、诊断、插件导入、两种终端、设备授权、ADB、环境提取及欢迎页；覆盖日夜、320×640 / 320×400 dp、1.0 / 1.3 倍字体。
- 中文设备页面与悬浮条弹窗补充复核 **1,896 个文字状态**通过，增加 360×720 和 392×760 dp；预览、取消不保存，确认保存只写测试专用偏好。
- 未发现文字裁切、溢出、操作重叠或过小触摸区域；最低文字对比度约 **5.06:1**。真实子页返回、主题切换及未保存输入保留通过。
- 已逐张查看关键截图，确认语言选项居中、同类框颜色统一、英文 Preview 完整显示、欢迎页滚动后末尾说明可见。
- 两版各 **360 项单测：359 通过、1 跳过、0 失败**；Lint 无错误。版本号、历史发布签名、arm64、16 KiB ZIP 对齐和无调试入口已核验；Ubuntu 基础包及宿主原生库保持不变。

本轮未使用 Android 6/7 实机或真实 16 KiB 页内核。测试机副本沿用其原签名保留数据，正式交付使用既有发布证书。布局检查使用独立显示样例，不发送模型请求。

已有恢复模式、多终端、语言切换和 Agent 预设功能继续保留；恢复功能验收见[构建 122 记录](v0.1.5-rc2-build122.md)。
