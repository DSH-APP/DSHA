# DSHA 0.2.1-rc.3-20261026.2115-dsh0.2.1-rc.3 / build202

- 인터페이스 시험: v5 인터랙션 프로토타입의 셸을 네이티브로 구현했습니다. 헤더의 브랜드와 페이지 맥락, 휴대폰의 떠 있는 캡슐 내비게이션, 태블릿의 왼쪽 내비게이션 레일, 정보 계층이 재구성된 시작 홈과 활동 표시줄, 로그 복사·따라가기·내보내기를 제공합니다. 플러그인과 설정은 기존의 실제 기능을 그대로 사용하며, 프로토타입의 모의 데이터는 연결하지 않았습니다.
- 터미널: Sunset-zhongdua-G의 전체 화면 터미널 호스트와 세션 보호를 합쳤습니다. "터미널"을 누르면 독립된 전체 화면 TerminalActivity가 열리고, 뒤로 가기는 페이지만 닫으며 세션은 끝내지 않습니다. 테마 사이드바, 휴대폰 7+7 / 태블릿 8+8 추가 키, 가로 화면 3열 압축도 이 빌드에 포함됩니다.
- 내장 dsh-web-mobile은 3.2.2, 내장 DSH는 rc.3을 유지합니다. versionCode는 202로 올라갑니다. 테스트 식별자는 dsh.android.client.SunsetRNE이며 로컬 테스트 인증서를 사용하고 E7E3 정식 패키지가 아닙니다.
- 경계: 이번 배치는 인터페이스와 터미널 통합 시험입니다. 실기기 설치, TalkBack, 글꼴 확대, 회전 전체 검증은 하지 않았습니다. 플러그인/설정 하위 페이지와 일부 프로토타입 화면(파일, 백업, 진단)은 기존 구현을 그대로 사용합니다.
