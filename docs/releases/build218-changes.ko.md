# DSHA 0.2.1-rc.3-20261031.1800-dsh0.2.1-rc.5 / build218

- 첫 실행 안내를 4단계(환영 → 용도 → 권한 → 완료)로 재구성하고 기존 3페이지 ViewPager2와 별도 준비 페이지를 대체했습니다. `welcomed == false`이면 여전히 안내만 열리며 Main과 시작 복구 화면은 같은 계약을 계속 검증합니다.
- 첫 배포는 앱 수준 백그라운드 유지보수 작업으로 실행되고, 진행 상황은 안내 화면과 Main 상단 바의 배포 캡슐에 표시됩니다. 전체 화면으로 기다리지 않으며 배포 중에는 화면을 켜 두고, 성공한 뒤에만 완료 화면과 Web 1회 시작으로 넘어갑니다. 가이드 내 배포가 백그라운드에서 종료되면 가이드의 원래 단계로 돌아갑니다(`welcomed`는 가이드를 떠나 Main으로 들어갈 때만 기록됩니다).
- 덮어쓰기 업데이트는 새 레이아웃의 전체 화면 실행 환경 유지보수 페이지(단계 막대 + 단계 목록 + 하단 작업)로 돌아가며, 제한된 Main과 대화상자로 표시하지 않습니다. 디스크에 미완료 유지보수 트랜잭션이나 닫히지 않은 격리 시험 현장이 있으면 유지보수 페이지·패널·자동 시작이 먼저 '중단된 유지보수 복구'(이전 시험 프로세스 종료 확인 후 현장 닫기)로 전환하고, `TRIAL_RECOVERY_REQUIRED`로 반드시 실패할 업데이트를 시작하지 않습니다. 자동 시작은 여전히 '같은 후보를 한 번만' 시도하며, 제한된 Main은 사용자가 유지보수 페이지에서 '제한된 메인 화면으로 들어가기'를 명시적으로 선택할 때만 표시되고 준비 완료 표시를 쓰지 않습니다. 터미널·Web·플러그인 실행은 계속 환경 게이트를 통과해야 합니다.
- 권한 카드(7가지 기기 기능 + ADB, 용도별 추천과 건너뛰기 가능)를 추가했습니다. 알림 권한은 Android 13+에서 탭 시 요청하고, 배터리 최적화는 읽기 전용으로 확인하며 예외를 요청하지 않습니다. Stellar 관리자(`roro.stellar.manager`)를 인식해 열 수 있고, 접근성 설정 문구는 실제 시스템 목록 이름으로 통일했습니다.
- 태블릿 600dp 이상은 2열, 휴대폰 가로 화면은 머리말과 바닥글을 압축하며 본문은 1.3배 글꼴에서도 스크롤됩니다. versionCode는 218로, DSHA 개정은 0.2.1-rc.3, 내장 DSH는 0.2.1-rc.5로 유지됩니다. 이번 라운드는 실제 기기 덮어쓰기 설치 검증을 하지 않았고 빌드·수용 범위는 이번 CI run과 Release 영수증을 따릅니다.
