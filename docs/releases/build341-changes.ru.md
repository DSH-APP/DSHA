- Новый компонент раскрытия `DisclosureCard` заменяет лист ⓘ (T120, `1dae32177`): сводка остаётся в исходном TextView, шеврон в конце строки раскрывает её; в свёрнутом виде скрытые дочерние представления не создаются, а объяснение / действия создаются только при раскрытии; состояние раскрытия хранится у хоста в Bundle, поэтому поворот / обновление / смена языка его не теряют; аномальные и ослабленные состояния могут быть раскрыты по умолчанию; `UiMotion` получает затухание сворачивания и поворот шеврона с единой кривой и статическим запасным вариантом при отключённых системных анимациях. Три точки входа (обычная сводка, вертикальный контейнер после горизонтального ряда, после выбранного соседнего представления); юнит-тесты покрывают ленивое создание, раскрытие по умолчанию, восстановление состояния, постоянный показ последствий, отложенное создание действий и макет при шрифте 1,3×.
- Перенос раскрытий на четырёх частых экранах и страницах данных / настроек (T120, `72daa4429` / `1f8a6002d`): экран запуска сводит проверку восстановления / причину неопределённости к одной строке (аномалии раскрываются полностью) и переносит версии runtime и dsh в свёртку «Техническая информация» внизу страницы; экран настроек убирает последний InfoHint и добавляет «Техническую информацию» в строку версии подвала; разрешения устройства делают пояснение постоянной строкой, убирают ⓘ из заголовка, превращают описания групп каналов / экрана в свёртки внутри меток (при ослаблении root раскрыто по умолчанию), «Доступ ко всем файлам» становится карточкой раскрытия (свёрнуто = состояние + одна строка последствий, раскрыто = полный охват и «Перейти в настройки системы», несут m0546 / x1970284 / m0393), в раскрытие канала помещена x1970572, из карточки глобального подтверждения убран ⓘ, а в раскрытие помещена uiv5a010 (после включения раскрыто по умолчанию с одной строкой последствий), способ подтверждения экрана становится свёрткой (в свёрнутом виде сохраняется последствие безопасности, «Разрешить всё» раскрыто по умолчанию); страница данных / резервных копий сворачивает карточки состояния рабочей области до сводки + последствий, раскрывая пути сохранения / детали нативных задач, и переносит четыре длинных объяснения со страниц сохранённых копий, результата экспорта и настроек.
