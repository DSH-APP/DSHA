## 四项需求的实现

1. 最近任务集中显示主页卡片，浏览器继续保留独立任务及现有页面实例，用于全屏/PiP/隐藏切换。主页根返回桌面，重进复用主页任务；页面内返回先处理内部导航。移除创建额外任务的标志，通知入口使用同一导航规则。
2. 访问地址页持续显示局域网状态，区分关闭、等待认证、无可分享地址和发现受限，提供主动开启、权限与刷新入口。实际私有Wi-Fi/以太网IPv4地址按当前端口、监听和运行代次生成；复制时重新核验。不会把移动网络/VPN地址伪装成局域网链接，也不会在打开地址页时静默开启监听。
3. 手机控制成为当前对话的工具能力，撤去独立工作区入口。用户明确要求操作手机时，模型通过 `android_control begin/finish` 绑定真实会话与活动turn，显示原生任务界面；不会另建隐形模型会话。观察前同步移除自有悬浮窗口，保持原生确认和当前目标/画面/节点校验。finish释放手机任务而不取消模型回复；明确Stop/Pause继续生效。旧电脑普通对话兼容保留，新手机任务能力需配套新helper。
4. 跟随系统按BCP47语言、区域与繁体脚本匹配内置语言，并可手动选择简体中文、繁体中文、英语、俄语、日语、韩语、阿拉伯语、葡萄牙语、拉丁语、法语。原生4706项×10、DSH网页2932项×10、移动插件52项×10及本版说明均纳入生成和占位符检查；阿拉伯语支持RTL。内置主对话提示随当前选择适配，保留用户自定义提示和明确的语言要求，不翻译历史消息或用户内容。

已读取并审阅PR189的实际内容，选择性采用语言适配思路并扩展为十语；不将此记为原PR的原样合并。远程网页不能覆盖本机语言选择。自动标题使用官方rc3独立的“按消息语言”提示，不经过主对话提示组装；不能把主对话的动态语言证据扩写成所有独立模型任务均强制跟随界面。

## 真机发现并修复的额外问题

- 恢复的prepare页面与已经完成的入口检查不一致时，旧同根导航早退会保留错误页面。现在同时比较准备模式；匹配的健康实例和待进入网页意图继续保留。
- Settings等其他应用在前台时，旧Activity确认可能留在浏览器后面。当前精确绑定的本机任务改用原生确认窗口；窗口移除后仍校验原目标。无回答/撤销/超时与明确拒绝分开处理，旧窗口按钮不能确认新请求。
- 只读枚举到IME曾触发全局pause并取消模型；现移除此观察副作用，原几何裁剪、坐标遮挡规则不变。旧poll成功/失败回包受控制器、lease/revision、turn/task围栏约束，不能修改或取消后继任务；后台I/O在锁外。
- 恢复权限后系统重建进程，旧Launch被压在CREATED、同根导航又保留它，造成只有工具栏和底栏。新条件排除仍受入口门禁控制的旧页面，创建可见状态页；未知业务页不恢复，正常Stop可用，未知guest的原退出和启动屏障没有放宽。新增三项真实Fragment/View回归覆盖匹配普通Launch、匹配prepare和未知业务页。
