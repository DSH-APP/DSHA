# DSHA 0.2.1-rc.3-20261102.1030-dsh0.2.1-rc.5 / build271

- Экспериментально: новая возможность «Внешнее устройство», по умолчанию выключена. После отдельного включения в группе каналов в «Настройки → Разрешения устройства» можно управлять другим телефоном по USB или беспроводной отладке и после подтверждения устанавливать на него APK, APKS, XAPK или модули; каждая установка требует подтверждения.
- Прошивка ограничена предварительной проверкой только для чтения и пробным прогоном без записи; возможность требует разрешённого root и не наследует ADB и глобальные разрешения этого телефона.
- Это экспериментальная функция, не проверенная с подключённым устройством, и она может не работать.
- Объём проверки: только локальные модульные тесты и проверки исходников; на устройстве не проверялось. versionCode повышен до 271 (на основе build270). Ревизия DSHA остаётся 0.2.1-rc.3, встроенный DSH — 0.2.1-rc.5.
