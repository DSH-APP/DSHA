## 九、真机待验（build336 发布前，需用户 / 主会话）

1. 覆盖安装（build335 → build336，升级前插件默认禁用）：主界面不白屏、侧栏只有一个设置入口、
   footer 设置入口不重复，`dsh-web-mobile` **默认启用**（插件页开关为开）；
2. 插件页关闭 → 重启 Web 恢复默认界面；再打开 → 重启后竖屏壳生效，跨 Web 重启保持；
3. 竖屏核对：顶栏开关不被裁、文件键可见、页签不叠字、文件面板标签条不被顶栏盖住、设置弹层为
   官方全屏；文件面板的原生「保存到 / 分享 / 下载记录」可用；切到 ru/ja/ko 等语言时移动壳
   标签为对应语言；
4. 已知回归（C 接受）：手机快捷键弹层无搜索、设置字体族行可能被压窄、深色主题按压遮罩会亮闪；
   会话行单击/抽屉关闭按上游行为，需真机确认无回退；
5. 任一项失败：回退 `builtin-plugins.json` 的一行改动（恢复 `defaultDisabled: true`）并重跑
   注册表 / 描述符生成器；插件字节与上游同步可以保留。
