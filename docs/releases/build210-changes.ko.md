# DSHA 0.2.1-rc.3-20261030.0214-dsh0.2.1-rc.3 / build210

- 내장 dsh-web-mobile을 업스트림 최신 내용으로 동기화(main @ 04dcd19, 버전은 3.2.2 유지): 태블릿 터치 프로필, 파일 다운로드 진입점, 드로어 빠른 설정을 추가하고 로컬 패치를 새 업스트림에 맞췄습니다.
- 정식 패키지 배포 검증의 오탐을 수정: 새 aapt2가 최소 API를 minSdkVersion으로 출력해 더 이상 minSdk 불일치로 거부되지 않습니다.
- 테스트 빌드 versionName 접미사를 -SunsetTest로 되돌려 업데이트 페이지가 테스트 신원을 다시 인식합니다.
- 배포 워크플로의 저장소/브랜치 조건을 현재 저장소 이름과 main으로 바꿔 이름 변경 후에도 건너뛰지 않습니다.
- 소스 게이트 보강: LAN 문구를 10개 언어 카탈로그에 추가하고 언어 항목과 DNS 선택에 접근성 속성을 부여했으며, 흐린 안내 문구와 눌림 상태 대비를 4.5:1로 맞췄습니다.
- HarnessController 파사드 분리: 패키지 자산 읽기를 PackagedAssets로 옮겨 원클릭 백업이 core 설정에 직접 의존하지 않습니다.
- 호스트 회귀 14건이 모두 통과했습니다. 빌드와 배포 결과는 저장소 기록을 따릅니다.
