# DSHA 0.2.1-rc.5-20261109.0700-dsh0.2.2-rc.1 / build346

- Жёсткое взаимоисключение «экран всегда включён» и энергосбережения (`d540dfe9d`): добавлена чистая логика `util/PowerModePolicy`; оба режима по умолчанию выключены, включение любого принудительно выключает другой и синхронизирует сохранение, службу и флаг окна, а выключение одного и повторное включение не затрагивают другой; страница настроек использует защиту от рекурсии программного `setChecked` и показывает двуязычный тост при принудительном выключении другой стороны; при запуске историческое состояние «оба включены» нормализуется в «экран включён, энергосбережение выключено» и записывается без уведомления. `PowerModePolicyTest` / `ConfigStorePowerModeTest` покрывают значения по умолчанию, независимость и ветку запуска.
- История активности физического экрана M1 (`19d928f3c`): добавлены `ScreenActivityFeed` (кольцевой буфер в памяти примерно 120 с / 64 события), `ScreenActivityEvent` / `ScreenActivityPolicy` / `ScreenActivityQuery` и `ScreenActivityRecorder`; запись идёт только во время задачи телефона — смена цели, нажатия / прокрутка пользователя, изменения содержимого и действия ассистента; task-end, пауза, отключение или переподключение службы доступности немедленно очищают историю; ничего не пишется на диск, в резервные копии или диагностику; для чувствительных приложений остаётся только смена цели, для поля пароля — только «уже введено», события IME и собственных оверлеев отбрасываются.
- Ответы и инструмент: каждый JSON-ответ `/app/ui/*` теперь несёт `recentActivity` (не более 3 событий после предыдущего ответа); добавлен `GET /app/ui/history?since=<seq>&limit=20` (по умолчанию 20, максимум 100, `since` продолжается из `nextSince`; M1 не возвращает изображения, `frames` — пустой массив); встроенный `dsh-computer-use-android` получает инструмент `android_history`, `/app/help` синхронизирован. В конфигурацию доступности добавлены `typeViewClicked|typeViewScrolled`; исполнитель действий явно записывает `ASSISTANT_ACTION` и разделяет user / assistant окном диспетчеризации 1,5 с; семантика защиты при выполнении (сверка цели, TTL учётных данных, политика подтверждений) не меняется.
- Обновление управляемой среды: изменения `DshaAccessibilityService` / `HttpShellService` / `screen/ScreenActionExecutor` / нового `screen/ScreenActivityRecorder` / конфигурации доступности и встроенного плагина `server.cjs` пересчитывают `runtime-descriptor` в `7b1ca97d`; fixed-inputs остаются зафиксированными на 20261105e; встроенный `dsh-web-mobile` остаётся на upstream 3.3.1 и включён по умолчанию.
