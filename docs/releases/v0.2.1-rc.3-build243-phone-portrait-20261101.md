## 2. 本版内容

逐条说明见 [build243 更新说明](build243-changes.zh.md)。主要包括：

- 启动页窄屏「停止 / 重启」改为两枚等宽描边按钮，长说明移到副标题；三段就绪轨道保留原设计与 `READY` 文案，并恢复各自的描边卡片。
- 手机底部导航改为叠在内容上的不透明悬浮胶囊；页底按胶囊高度留余量。平板仍为左侧导航。
- 维护页删除内嵌「本次维护记录」日志框；空标签、语言网格列数、悬浮条行数选项的窄屏修正。
- 新增纯逻辑 `util/DeviceSupportReport`（配单测）与采样 `ui/DeviceSupportProbe`：引导「部署前检查」增加网页内核与支持结论，硬拦截 Android 10 及以下 / 非 arm64，鸿蒙与荣耀/华为自研 WebView 只提示高风险；维护失败页与自检复用同一摘要，可「复制给支持」，不联网上报。手机欢迎页把检查格收成一行摘要，详情弹窗内格子同行等高。
- 引导授权：进度条只算推荐项；设备通道只推荐 Stellar / Shizuku 兼容层，Root 与 ADB 不在引导中出现（完成页也不再列 Root，计数为 x / 6）；电池优化打开本应用系统「关于」页；轮询防抖减轻无障碍卡片闪烁。

## 3. 设备验证（单台手机）

- 设备：一加 PJD110（ColorOS 16 / Android 16），1440×3168、640dpi，宽 360dp，系统字体缩放 1.0。
- 连接：平板经 USB 主机模式连接该手机，平板上以 root 启动只绑定本机端口的 adb server，容器内用 `adb -P 5038` 访问。这只是本轮验收手段，不是 DSHA 的产品能力。
- 方式：本地构建 `assembleStandardDebug`（测试变体），测试证书签名后 `pm install -r` 覆盖安装；中途用户卸载测试包后重新安装，从引导第一步完整走到完成页。
- 经截图核对：启动页（运行中 / 停止中 / 启动中，日夜模式）、三段轨道卡片、悬浮胶囊与最后一行滚出、设置列表、数据与备份、安装页滑到底、插件页、终端、技能页、语言选择、悬浮条行数、屏幕操作分组、引导欢迎页摘要与检查详情弹窗、授权页进度条与 Stellar 设备通道卡、ColorOS「关于应用 → 耗电管理」跳转路径、完成页授权卡（6 项、`已开启 6 / 6`）。
- 用户手动操作并反馈：自动旋转关闭后的竖屏流程、停止后副标题、无障碍卡片不再闪烁。
- **未验证**：其他手机机型与系统版本、1.3 倍字体真机、十种语言中除中文外的实际显示、鸿蒙 / 荣耀 / Android 10 设备上的部署前检查实际表现（只有单测覆盖判定逻辑）、正式包覆盖安装。
