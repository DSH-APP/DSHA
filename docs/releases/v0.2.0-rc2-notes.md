# DSHA v0.2.0-rc2 正式版 · build170

由贡献者 [@ym2025szz](https://github.com/ym2025szz) 维护并发布，感谢原作者 [@qiannianhuanxiang](https://github.com/qiannianhuanxiang) 和其他贡献者。

本次为 **正式 Release / Latest**，GitHub 不标记为预发布。发布已验收的 **build170**；APK 版本为 `0.2.21-20261009.0750-dsh0.2.0-rc.2`，内置 DSH **0.2.0-rc.2**、移动 UI **3.0.5**，Ubuntu 基础环境编号仍为 **10**。沿用 `com.dsh.client` 和历史 E7E3 签名。

## 更新内容

- **DSH 与插件**：升级 DSH 0.2.0 rc2 和移动 UI 3.0.5，补齐手机焦点、弹窗及插件卡片交互；第三方插件解析检查后自动启用，支持依赖安装脚本。
- **附件与图片草稿**：文件直接进入系统文档选择器，保留多选及图片过滤；修复草稿残留引用导致保存失败，增加旧引用恢复提示和页面关闭后的图片恢复。
- **ADB 与 shell**：修复首次离线依赖准备的 `PARENT_LINK` / 冷目录问题，校验全部 15 个依赖；无线调试未开启时也可先准备离线依赖。修复聊天 shell 无法创建 `/tmp` 临时目录。
- **文件、虚拟屏和局域网**：网页支持调用原生分享与保存，补充虚拟屏开启步骤和启动诊断；LAN 失效链接、等待认证等错误提供明确指引，并整理日志显示。
- **备份与安装**：新导出统一为无需密码的 `.tar.gz`，保留旧加密备份读取；作品与文件导出、存储指南及技能集中到“数据与备份”，优化首次安装的并行解压和离线准备。
