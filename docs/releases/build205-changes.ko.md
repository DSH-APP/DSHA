# DSHA 0.2.1-rc.3-20261027.1312-dsh0.2.1-rc.3 / build205

- 터미널 붙여넣기는 크기가 제한된 FIFO 입력 대기열을 사용하며 대괄호 붙여넣기를 하나의 항목으로 보냅니다. 대기열이 가득 차면 후속 입력을 일시 중지하고 확인을 요청하며, 보내지 않은 내용은 자동으로 재시도하지 않습니다.
- 가상 화면 시작 결과를 알 수 없을 때 허용된 진단 코드를 유지합니다. 진단은 원격 종료를 증명하거나 알 수 없는 결과에 대한 보호를 해제하지 않습니다.
- 휴대전화 제어 동작을 가장 최근에 성공한 화면 관찰의 대상에 연결합니다. 대상이 바뀌거나 새 관찰이 시작되면 새로운 관찰이 필요하며, 오래된 관찰로 동작 권한을 복원할 수 없습니다.
- 기기 DNS를 사용할 수 있을 때 바이트 단위로 정확히 일치하는 이전 기본 DNS 설정만 기기 DNS로 이전합니다. 사용자가 수정한 설정과 기기 DNS를 사용할 수 없을 때의 이전 설정은 유지합니다.
- 세션과 작업 공간 스트림 복구, 다운로드 탐색 및 압축 응답의 회귀 테스트를 확장했습니다. 이 테스트는 휴대전화 또는 실제 서버 재시작 검증을 의미하지 않습니다.
- dsh-web-mobile 3.2.2, DSH rc.3, 로컬 및 LAN 접근과 10개 언어를 유지합니다. 휴대전화 검증은 계속 보류됩니다.
