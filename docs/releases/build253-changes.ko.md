# DSHA 0.2.1-rc.3-20261101.2200-dsh0.2.1-rc.5 / build253

- 터미널 화면 다듬기: 두 줄 보조 키의 키캡 사이에 간격을 두고, 기능 키는 한 단계 진한 색, 방향 키는 크게, ^C / ^D / ^Z와 기호 키는 고정폭 글꼴로 바꿨습니다. Ctrl·Alt 잠금은 아래쪽 표시줄로 보여 줍니다. 사용자 키 배치와 길게 눌러 편집하기는 그대로입니다.
- 사이드바 간소화: PTY와 간이 터미널 세션을 생성 순서대로 하나의 목록에 모으고, 세션 상태는 이름 뒤의 작은 점으로 표시합니다. 「모두 종료」는 세션이 없으면 숨겨지며 누르면 여전히 확인합니다.
- 새 세션은 카드 세 장(PTY 터미널, 간이 터미널, DSH CLI)으로, 설명 대화상자는 요점 네 가지와 상태 범례로 바꿨습니다.
- 검증 범위: 로컬 터미널 관련 단위 테스트와 정적 검사만 했습니다. 실기기 설치는 확인하지 않았고 UI 테스트와 Lint는 CI에 맡깁니다. versionCode를 253으로 올렸습니다(build252 기반). DSHA 리비전은 0.2.1-rc.3, 내장 DSH는 0.2.1-rc.5로 유지됩니다.
