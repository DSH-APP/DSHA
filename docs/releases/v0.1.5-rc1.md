## 上游更新与适配

[官方 rc.1](https://github.com/deepseek-ai/deepseek-harness/releases/tag/dsh-v0.1.5-rc.1) 发布于 2026-09-10。npm 锁定版本为 `0.1.5-rc.1`，APK 文件名使用 `rc1`。与 alpha.2 比较的主要变化包括默认 DeepSeek-V41-Flash、右栏引导页、预览布局与滚动、状态信息及代码块样式。官方发布说明汇总了更早版本的更新，不应把其中所有项目视为 alpha.2 之后新增。

- 新模型使用 `deepseek-flash`，仍提供 V4 Flash、V4 Pro 和 V4 Flash Vision Exp。原有显式配置在升级过程中保持原位。
- 更新 npm 精确锁文件、离线运行时、内置插件宿主版本声明和前端提示组件的精确补丁锚点。
- 输入框回车换行、网页拼接缓存、会话原子写入与旧会话迁移补丁均重新核对锁定源码；保留上游新增页面与 API。
- Ubuntu 版本仍为 10，相同基础环境只替换受管运行时。冷安装同时解压 Ubuntu 与 dsh，局部升级只读取独立的 dsh 包。
- 保留终端会话回收、Web PID 身份核验、60 秒后继续等待、独立安全 profile、启动错误诊断和 `NARB_DISABLE_NATIVE_CACHE=1` 首次加载修复。

## 覆盖更新与耗时

旧版 alpha.2 调试包保持原应用数据，再覆盖安装 rc1；由 MainActivity 的真实门禁进入 ExtractActivity 自动更新，耗时 **7446 ms**。更新前后的会话、设置、原 profile、插件源码、附件和工作区摘要一致。Ubuntu 的 Python 目标 inode 保持不变，未重建基础环境。

初始设备没有用户会话和附件，因此额外建立了隔离的历史消息、工作文件和第三方插件源码进行保留验证。界面验收前将历史测试日志调整为本机使用的 zstd 编码；独立存储回归同时验证两种编码。这一调整不属于产品升级逻辑。

| 测量 | 结果 |
|---|---|
| 自动 alpha.2 → rc1 局部升级 | 7.45 秒 |
| 隔离冷环境解压及离线工具安装 | 15.57 秒 |
| 冷环境完整验证，含首次原生加载器初始化 | 19.30 秒 |
| 连续六次启动至鉴权 | 3.425、3.660、3.662、3.660、3.560、3.659 秒 |

| Gecko 普通启动／页面随后就绪 | 4.007 秒／1.803 秒 |

这些数字来自当前设备和验收数据，不能当作其他手机、大型工作区或首次网络请求的固定时限。

## 自动检查与范围

- 标准版、兼容版各 330 项 JUnit：329 通过、1 跳过，无失败或错误；两版 Release Lint 无错误。
- 宿主 23 项网页兼容、草稿、鉴权、内置引导、活动状态与启动观察器检查通过；输入框 5 项、提示组件 8 项及真实拼接器缓存回归通过。
- Android Ubuntu 的 16 项会话存储、旧消息迁移、移动删除、排他发布与内置引导测试全部通过。Linux 原生模块相关检查实际运行在手机内，没有用 Windows 缺少原生依赖的结果代替。
- 已实际验证 Android 16 上的系统 WebView 和内置 Gecko；本轮没有 Android 6/7 实机，也没有真实 16 KB 页内核设备。API 23 和 ELF 静态检查不能替代这些设备上的运行验收。

Gecko 文件预览的辅助功能定位在初次提示、目录折叠和前台切换时不稳定，最终通过实际屏幕触摸及截图验收。该过程中的定位失败不作为产品通过依据。发布包不包含调试 Instrumentation。
