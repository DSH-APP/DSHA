# DSHA 0.2.1-rc.3-20261102.0700-dsh0.2.1-rc.5 / build264

- 업데이트 페이지 압축: 버전, 업데이트 채널, 상태를 하나의 기본 카드로 합쳤습니다. 기본 버튼 자체가 진행 막대라서 확인·다운로드·검증·설치가 버튼 크기와 위치 변화 없이 제자리에서 바뀝니다. 다운로드 취소는 여전히 알림에서 할 수 있습니다.

- 업데이트를 확인하는 중에도 채널을 바꿀 수 있으며, 바꾸면 새 채널로 다시 확인합니다. 다운로드와 설치 중에는 여전히 바꿀 수 없습니다.
- 검증 범위: 사용자가 테스트 패키지 실기기에서 확인 중 채널 전환, 진행 버튼 애니메이션, 태블릿 세로 화면을 확인했습니다. 짧은 화면, 1.3배 글꼴, 태블릿 가로 화면은 따로 확인하지 않았습니다. versionCode를 264로 올렸습니다(build263 기반). DSHA 리비전은 0.2.1-rc.3, 내장 DSH는 0.2.1-rc.5로 유지됩니다.
