# DSHA 0.2.1-rc.3-20261029.0741-dsh0.2.1-rc.3 / build208

- - スマホ操作が DSHA 自身のオーバーレイ（ステータスバー、アシスタント、確認ダイアログ）を対象の遮蔽と誤判定する問題を修正しました。未登録のフォーカス不能な自オーバーレイはパッケージ ID で窓全体を除外し、TARGET_WINDOW_OCCLUDED を返しません。除外領域を横切る座標軌跡は引き続き拒否され、全体を覆われた場合は操作可能領域なしと判定されます（#210）。
- - link() が拒否される端末で、旧 pnpm 内容リンクの実体化が全量コピー中に固定 120 秒のタイムアウトで中断されないようにしました。タイムアウトは実際のハング用の 15 分のバックストップに変わり、コピー中断によるトランザクション pending で次回起動が塞がるのを防ぎます（#209）。
- - dsh-web-mobile 3.2.2、DSH rc.3、ローカル・LAN 接続と10言語を維持します。実機検証は引き続き一時停止中です。
