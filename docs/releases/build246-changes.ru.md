# DSHA 0.2.1-rc.3-20261101.1600-dsh0.2.1-rc.5 / build246

- Исправлено: окно плавающего помощника не было изолировано от клавиатуры. Свёрнутый помощник находится внизу экрана, и при касании поля ввода в другом приложении он поднимался вместе с клавиатурой этого приложения и закрывал содержимое рядом с полем ввода.
- Плавающий помощник никогда не принимает ввод текста (редактирование выполняется на отдельной странице помощника). Теперь его окно учитывает только системные панели и не реагирует на клавиатуру других приложений, а область исключения, которую он регистрирует для наблюдения за экраном, больше не меняется при открытии и закрытии клавиатуры.
- Объём проверки: только локальные/CI модульные тесты; **на реальном устройстве не проверялось**. Исправление может не сработать на некоторых версиях Android или прошивках (помощник может по-прежнему подниматься с клавиатурой); нужна обратная связь пользователей. versionCode повышен до 246. Ревизия DSHA остаётся 0.2.1-rc.3, встроенный DSH — 0.2.1-rc.5.
