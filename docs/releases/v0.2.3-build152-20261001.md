## 日志报错与修复

用户提供的日志来自版本码 147、HUAWEI SGT-AL10 / Android 16。
失败在冷安装离线工具阶段：proroot 的嵌套 Bash 返回 EINVAL/126，回退 proot 后 mkdir 返回 ENOSYS。
日志没有 Web 运行输出，不能把这次失败归因于聊天页面，也不能当作 151 真机验收。

当前代码改为在独立临时目录探测嵌套 Bash、mkdir、普通文件读写及 Python hashlib/sqlite3/ssl，
按用户运行偏好最多检查 proroot、proot 和 proot 兼容方式。
兼容方式设置 PROOT_NO_SECCOMP=1，关闭的是 proot 的跟踪加速，仍使用 Android 应用沙箱；
依据 [Termux 固定修订源码](https://raw.githubusercontent.com/termux/proot/v5.1.107.92/src/tracee/event.c)。

能力检查通过后只安装一次冻结的软件包槽。真正的 dpkg 写入失败不会换通道重放；
进程组退出无法确认时保留任务保护及现场。安装前核对包槽摘要，保留正常 dpkg 与 curl/git/node/Python 后检查。
全部后检查和适配完成后，先持久化成功方式并更新当前调用快照，再发布就绪标记。
设置保存失败不发布就绪；没有增大 Ubuntu 基础版本或替换未知修订的原生库。
新策略与包槽校验代码也进入受管运行时指纹，避免后续策略变更沿用旧证明。

## 备份无密码

新手动、救援、重导出及自动副本的用户导出统一为真正的标准 `.tar.gz`，
界面和用户导出 API 删除新密码及加密选项，内层为带完整尾摘要的 DSHADATA。
新备份导入不显示密码输入。

内部自动副本仍由宿主密钥保护，导出时认证解密并生成新的无密码载荷。
旧手动加密备份只在读取旧原件时要求原密码，成功认证后可导出新无密码文件；旧密文保留。
缺少原密码、密钥不可读、错误密码或文件篡改会明确失败，不将加密载荷伪称无密码。
真实 scope、数据完整性等级、部分数据与插件警告保留，内外层摘要分别核对。
