# DSHA 0.1.5-rc2 · 构建 126

在[构建 125](v0.1.5-rc2-build125.md)上完善插件管理排序，并更新内置移动端插件。应用版本码 **126**，dsh 保持 **0.1.5-rc.2**，Ubuntu 基础环境保持 **10**。

## 插件管理

- 名称排序与检查更新改为两个同高、同圆角的描边按钮，具有按压反馈和禁用状态，适配中英文、日夜、短屏及 1.3 倍字体。
- 排序按钮打开单选菜单：**名称 A–Z、名称 Z–A、已启用优先、可更新优先**。按钮显示当前选项，选择后立即重排实际列表。
- 名称按字母、中文拼音和数字自然顺序排列，例如 `plugin2` 在 `plugin10` 前；状态优先模式的组内仍按名称排序。界面语言切换不会改变排序规则。
- 排序通过 ConfigStore 的 `plugin_sort_order` 保存，重新打开页面仍保留；兼容旧页面状态中的 `enabledFirst`。搜索与“只看自己装的”筛选可与排序组合使用。任务期间检查更新禁用，本地排序仍可使用。

## 内置 dsh-web-mobile

由 **2.4.0-dsha.7** 更新为 **2.4.1-dsha.1**，基于官方 npm 发布的 **2.4.1**。上游发布时间为 2026-09-11，包下载后核验 SHA-512 integrity、SHA-1 和 SHA-256。

- 合入拖动桌宠/悬浮物时让位于拖动操作的修复，避免误打开侧栏；支持组件声明的拖动标记与小型悬浮物识别。
- 合入触屏大平板横屏的会话删除菜单，宽屏确认弹窗居中限宽；鼠标设备仍不注入。
- 保留 DSHA 的 Host/Origin/鉴权检查、删除正文校验、键盘视口适配、明确会话打开事件、文件右侧面板、Agent 预设入口、输入框与语言适配。
- 浮动入口跟随上游调整为顶部 12px，继续保留 DSHA 的 44px 触摸区域。
- 保留 dsh 0.1.5-rc.2 的 peer 锁定和 MIT 许可。通过原有受管环境更新进入已有安装，不重建 Ubuntu、不重置用户插件配置。

来源：[上游 2.4.1 更新说明](https://github.com/mexiaosqwq/dsh-web-mobile/blob/7ae9bcbe006afbb04fb4e653e55e8771c1749518/README.md)、[npm 发布包](https://registry.npmjs.org/dsh-web-mobile/-/dsh-web-mobile-2.4.1.tgz)。
