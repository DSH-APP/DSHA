## 5. 与设计稿的有意差异

- 原生保留**六个**底部动作：设计稿只画四个，是因为浏览器原型没有真实剪贴板/输入焦点能力；原生把「粘贴文本 / 回到输入」作为独立一行保留，避免静默减能力。
- 设计稿的「显示模式」在原生仍叫「显示设置」，因为它同时承载字号、极简/工作台、球位置和快捷按键布局。
- 原生摘要使用真实会话数「N 个会话 · PTY X / 简易 Y」，不显示原型里「仅本页内存，刷新即丢失」这类不适用于进程级会话的模拟文案。
- 状态胶囊用短词（运行中/已退出/待核验/就绪…）；完整长状态保留在无障碍描述与结束确认框，避免窄侧栏被长文案挤爆。
- 原生会话行同时保留重命名与结束两个 48dp 图标；设计稿只画了关闭。窄侧栏下名称会省略号截断，功能不被裁掉。
- 抽屉宽度上限仍为既有策略 336dp，内联侧栏 240–296dp；没有照搬 HTML 的 344px，也没有按机型写死。
