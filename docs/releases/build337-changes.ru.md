# DSHA 0.2.1-rc.5-20261107.1900-dsh0.2.2-rc.1 / build337

- Исправлен 409 интерфейса телефонных задач (T115, `a9c718e2`): в production-пакете build336 окно задач физического экрана не создавалось — встроенный `dsh-status-overlay` продолжал вызывать удалённый в 0.2.2-rc.1 `SessionController.inspect`, из-за чего `sessions.status` бросал TypeError, мост отвечал 409, а Java видела только `ASSISTANT_TASK_CHANGED`. Теперь читаются `controller.state` и ограниченная страница `controller.events` (последние 16 событий сообщений обрезаются до 8 видимых реплик; `turnId` / `turnActive` берутся из проекции `turnBoundary` хоста), поля ответа совпадают с чтением Java; host-тест проходит 11/11. **Проверка на устройстве — после установки build337 пользователем.**
- Исправлен `pty.fork` веб-терминала (T116, `adab1698`): если `sharp` загружается раньше `node-pty` в том же процессе Node, экспорты `pty.node` регистрируются под ключами sharp/libvips и веб-терминал затем падает с `pty.fork is not a function` (повтор не помогает). Предзагрузка `startup-observer.cjs` теперь требует node-pty до загрузки плагинов; сбои тихие и не влияют на запуск. См. [аудит T116](../design/t116-pty-fork-20261107.md).
- Первая партия сокращения длинных текстов UI (T114, `c4c79941`): 12 длинных текстов P1 из §2.3 аудита заменены краткими 1–2-строчными сводками, полное описание остаётся в InfoHint / InfoSurface (новых ключей перевода нет, смысл безопасности/приватности не меняется); в `UiMotion` добавлены `crossFadeText` и `animateCounter`, опробованные на статусе страницы обслуживания, авторезервного копирования и заголовке запуска; добавлены UiMotionTest (9) и InfoHintTest (6), 53 класса / 449 тестов пакета ui проходят.
