# DSHA 0.2.1-rc.3-20261101.0053-dsh0.2.1-rc.5 / build220

- 휴대폰 작업 오른쪽 아래의 플로팅 제어 창과 화면 권한 사이의 경쟁 상태를 수정했습니다. 상태 창을 펼치면 화면 제어가 즉시 일시 중지되고 이전 권한이 취소되며, 이후 도착하는 `turn/end` 또는 `/app/ui/task-end`가 일시 중지된 제어 창을 무조건 닫지 않습니다.
- 사용자가 펼친 뒤 일시 중지한 동일 작업은 계속 연결됩니다. 명시적으로 계속하면 화면을 새로 관찰하고, 명시적으로 중지하면 작업을 정리합니다. 이전 권한이나 결과를 알 수 없는 동작을 자동 승인하거나 다시 실행하지 않습니다. 정상 완료 시에는 창과 서비스를 계속 종료합니다.
- 정리 과정에서 메인 스레드가 작업 소유권과 일시 중지 상태를 다시 확인합니다. 펼친 일시 중지 유지, 명시적 중지, 정상 완료에 대한 Android 회귀 테스트를 추가하고 장치 작업 안내를 갱신했습니다.
- 모바일 ScreenSense 인식/동작 성능 평가와 단계별 리팩터링 제안을 추가했습니다. OCR, 압축 프로토콜, 지연 예산은 설계 평가이며 이 빌드에 구현된 기능이 아닙니다.
- versionCode를 220으로 올렸습니다. DSHA 리비전은 0.2.1-rc.3, 내장 DSH는 0.2.1-rc.5로 유지됩니다. 전체 빌드, 테스트, 서명 및 실기기 검증 범위는 CI / Release 기록을 따릅니다.
