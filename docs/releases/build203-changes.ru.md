# DSHA 0.2.1-rc.3-20261027.0700-dsh0.2.1-rc.3 / build203

- Граница: сборка по-прежнему тестовая. TalkBack, масштаб шрифта и полная проверка поворота не выполнялись; файловый браузер, удалённое сопряжение/рабочие пространства и веб-предпросмотр используют текущую реализацию.
