# DSHA 0.2.1-rc.3-20261031.1800-dsh0.2.1-rc.5 / build218

- Первый запуск переработан в четыре шага (приветствие → назначение → разрешения → готово) вместо трёх страниц ViewPager2 и отдельной страницы подготовки. При `welcomed == false` по-прежнему открывается только знакомство; Main и восстановление запуска проверяют тот же контракт.
- Первое развёртывание теперь выполняется как фоновая задача обслуживания уровня приложения, а прогресс показывается капсулой развёртывания на экране знакомства и в верхней панели Main, без полноэкранного ожидания. Во время развёртывания экран остаётся включённым; экран готовности и один запуск Web появляются только после успеха. Если развёртывание внутри знакомства прервано в фоне, знакомство возвращается к своему предыдущему шагу (`welcomed` записывается только при выходе из знакомства в Main).
- Обновление поверх снова открывает полноэкранную страницу обслуживания среды выполнения в новом оформлении (полоса этапов, список этапов и нижние действия), а не ограниченный Main с диалогом. Если на диске есть незавершённая транзакция обслуживания или незакрытая площадка изолированной пробной проверки, страница обслуживания, панель и автозапуск сначала переходят к «восстановлению прерванного обслуживания» (убедиться, что старый процесс проверки завершён, и закрыть площадку), а не запускают обновление, обречённое на ошибку `TRIAL_RECOVERY_REQUIRED`. Автозапуск по-прежнему пробует один и тот же кандидат только один раз; ограниченный Main открывается только при явном выборе пользователя «Войти в ограниченный интерфейс» и не записывает признак готовности, поэтому терминал, Web и плагины проходят проверки среды.
- Добавлены карточки разрешений для семи возможностей устройства и ADB с рекомендацией по назначению и возможностью пропуска. Разрешение на уведомления запрашивается по нажатию в Android 13+; оптимизация батареи только читается, исключение не запрашивается; менеджер Stellar (`roro.stellar.manager`) распознаётся и открывается; текст настроек доступности приведён к реальному имени в системном списке.
- На планшетах от 600dp две колонки, в горизонтальной ориентации телефона шапка и подвал сжимаются, содержимое прокручивается при шрифте 1.3×. versionCode повышен до 218; ревизия DSHA остаётся 0.2.1-rc.3, встроенный DSH — 0.2.1-rc.5; в этом раунде установка поверх на реальном устройстве не проверялась, а объём сборки и приёмки определяется этим CI run и квитанцией Release.
