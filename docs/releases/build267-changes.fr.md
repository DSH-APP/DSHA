# DSHA 0.2.1-rc.3-20261102.0830-dsh0.2.1-rc.5 / build267

- Expérimental : correctif au mieux pour le conteneur qui perd Internet après le passage aux données mobiles. Le DNS du conteneur n'était écrit qu'au démarrage avec les serveurs du réseau du moment ; après le passage du Wi-Fi aux données mobiles, ces serveurs devenaient injoignables et toutes les résolutions expiraient jusqu'au retour du Wi-Fi. Le DNS du conteneur est désormais rafraîchi automatiquement après un changement de réseau ; si une résolution échoue encore, elle est refaite une fois via le résolveur système d'Android (résolution seule, sans renvoi de requête ni DNS public injecté). Ajoute le diagnostic en lecture seule /app/net.
- Ce correctif est expérimental et n'est pas garanti pour toutes les combinaisons d'appareil, de système, d'opérateur, de VPN ou de DNS privé ; si le conteneur n'a toujours pas Internet après un changement de réseau, signalez la sortie de /app/net.
- Portée de la vérification : tests unitaires et contrôles de source locaux uniquement ; le changement de réseau n'a pas été testé sur appareil. versionCode porté à 267 (basé sur build266). La révision DSHA reste 0.2.1-rc.3 et le DSH intégré reste 0.2.1-rc.5.
