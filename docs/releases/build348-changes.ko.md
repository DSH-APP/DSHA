# DSHA 0.2.1-rc.5-20261109.1100-dsh0.2.2-rc.1 / build348

- 하단 동작 서랍의 첫 화면 높이 상한을 사용 가능 높이의 0.72×로 축소(`450952c1e`): 플러그인 「추가 작업」 등 `BottomSheetCard` 진입 목록이 내용에 맞춰 늘어나면 화면 위쪽 절반까지 밀려올라갔다. 새 `SheetGeometry.bottomDrawerMaxHeight(heightDp, liftDp)`(사용 가능 높이 = 화면 높이 − 플로팅 캡슐 들어올림)를 추가해 `BottomSheetCard`가 이를 사용하고, 넘치는 내용은 서랍 안에서 스크롤되며 바닥글은 고정된다. `CardSheet`의 BOTTOM 모드는 0.9를 유지하며 상수를 공유하지 않는다(설명 / 선택 / 긴 양식은 호출 범위가 넓고 긴 양식은 본문 높이가 필요). `SheetGeometryTest` / `BottomSheetCardLayoutTest` / `CardSheetGeometryTest`가 새 비율과 짧은 화면(<480dp)의 불변 동작을 검증하고, 설계 문서 UI 기준선 §9에 절충을 기록.
- 플러그인 실행 증거가 Auto review 호환 셸의 버전 동등 검사를 건너뜀(`4a25d2562`): profile 기본값은 서명된 호환 셸 `dsh-auto-review@0.1.0`이고, 셸의 patch가 공식 패키지 `@deepseek-ai/dsh-experimental-auto-review@0.2.2-rc.1`을 삽입한다. 실행 스냅샷에는 profile 항목(셸 0.1.0)만 기록되고 카드 버전은 공식 패키지 0.2.2-rc.1에서 오므로, `PluginIdentity.legacyShim(cardName, observedName)`는 「canonical 카드 + alias 실행 행」이라는 과거 포장 경로만 인정하고 `PluginRuntimeProjection.apply()`는 호환 셸에서 버전 동등 검사를 생략한 뒤 로드 상태로 확인한다. 그 결과 「로드 상태 미확인 / Web 재시작 후 적용」 오표시가 계속되지 않는다. alias가 아닌 버전 불일치는 여전히 unknown + 재시작 대기가 되며 「구 모듈이 신 버전을 가장」 보호는 그대로다. `PluginRuntimeProjectionTest`에 실제 방향의 버전 불일치 사례와 canonical 행 보호를 추가.
- 플러그인 카드 상태를 의미색 배지로 변경(`df4fe653d`): 출처 / 버전 / 구성 / 현재 Web을 각각 독립 배지로 표시하고 배경과 글자색은 `shell_*` 의미 토큰에서 가져온다. 구성과 현재 Web의 어조 매핑은 `PluginCardState.configTone` / `runtimeTone` 순수 로직으로 분리해 단위 테스트를 추가했으며 표시만 바꾸고 상태 판정은 건드리지 않는다. 재시작 대기는 전체 줄 안내에서 경고 배지(`item_plugin_state_chip`)로 바꾸어 「업데이트 / 최근 작업 메시지」 두 안내 줄과 구분한다. 배지는 `PluginFlowRow`에 넣어 좁은 화면과 1.3배 글꼴에서 통째로 줄바꿈하며 핵심 상태어를 생략하지 않고, 상태 점은 구성 배지의 compound drawable로 합쳐 TalkBack 별도 포커스로 노출하지 않는다.
