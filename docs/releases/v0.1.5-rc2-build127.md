# DSHA 0.1.5-rc2 · 构建 127

在[构建 126](v0.1.5-rc2-build126.md)上调整日志阅读和关于弹窗。版本名、包名、发布签名及交付文件名不变；版本码递增到 **127**，可覆盖原版安装。dsh 保持 **0.1.5-rc.2**，内置 dsh-web-mobile 保持 **2.4.1-dsha.1**，Ubuntu 基础环境保持 **10**。

## 修改

- 修复安装与修复页检查日志的嵌套滚动：手指在日志框内上下滑动时优先滚动日志，到边缘后再让整页滚动。保留长按文字选择和完整日志复制。
- 新增日志只有在原本位于末尾、没有触摸操作时才自动跟随；正在阅读历史内容时不拉回底部，不抢外层页面的阅读位置。
- 诊断报告放入与日志一致的有界滚动框，随屏幕高度限制在 144—220 dp；完整报告保留，复制和导出继续使用完整数据，报告不再把页面无限撑长。
- 关于弹窗将 GitHub、QQ 群改为带图标、说明和箭头的入口卡片。底部移除重复的三个文字入口，只保留独立的全宽“关闭”按钮；内容过长时滚动，关闭按钮固定可用。仓库地址和 QQ 群号不变。

使用 Android 13 / Redmi M2012K10C / arm64 非调试插桩副本，正式 APK 不包含测试入口。
