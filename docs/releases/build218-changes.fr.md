# DSHA 0.2.1-rc.3-20261031.1800-dsh0.2.1-rc.5 / build218

- Le premier lancement est restructuré en quatre étapes (accueil → usage → autorisations → terminé), en remplacement des trois pages ViewPager2 et de la page de préparation séparée. Avec `welcomed == false`, seul le guide s'ouvre toujours ; Main et la récupération au démarrage vérifient le même contrat.
- Le premier déploiement devient une tâche de maintenance d'arrière-plan au niveau de l'application, et la progression s'affiche dans la capsule de déploiement du guide et dans la barre supérieure de Main, sans attente plein écran. L'écran reste allumé pendant le déploiement ; la page de fin et un démarrage Web n'apparaissent qu'après succès. Si le déploiement dans le guide est interrompu en arrière-plan, le guide revient à son étape précédente (`welcomed` n'est écrit qu'en quittant le guide pour Main).
- La mise à jour par-dessus revient à la page plein écran de maintenance de l'environnement d'exécution dans la nouvelle présentation (barre d'étapes, liste des étapes et actions en bas), au lieu d'un Main limité avec une boîte de dialogue. Si le disque contient une transaction de maintenance inachevée ou un site d'essai isolé non fermé, la page de maintenance, le panneau et le démarrage automatique passent d'abord par « reprendre la maintenance interrompue » (vérifier que l'ancien processus d'essai est terminé, puis fermer le site) au lieu de lancer une mise à jour vouée à l'échec avec `TRIAL_RECOVERY_REQUIRED`. Le démarrage automatique n'essaie toujours le même candidat qu'une seule fois ; le Main limité n'est ouvert que si l'utilisateur choisit explicitement « Entrer dans l'interface limitée », et il n'écrit aucun marqueur de disponibilité : le terminal, le Web et les plugins passent toujours les portes d'environnement.
- Ajout de cartes d'autorisation pour sept capacités de l'appareil plus ADB, recommandées selon l'usage et ignorables. La permission de notification est demandée au toucher sous Android 13+ ; l'optimisation de batterie est seulement lue, sans demande d'exemption ; le gestionnaire Stellar (`roro.stellar.manager`) est reconnu et peut être ouvert ; les textes d'accessibilité reprennent le nom réel de la liste système.
- Les tablettes à partir de 600dp utilisent deux colonnes, le mode paysage du téléphone compresse l'en-tête et le pied de page, et le contenu défile avec une police de 1,3×. Le versionCode passe à 218 ; la révision DSHA reste 0.2.1-rc.3 et le DSH intégré 0.2.1-rc.5 ; cette série n'a pas été vérifiée par une installation par-dessus sur appareil réel, et le périmètre de build et d'acceptation suit ce CI run et le reçu Release.
