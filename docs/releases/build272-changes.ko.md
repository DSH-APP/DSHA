# DSHA 0.2.1-rc.3-20261102.1100-dsh0.2.1-rc.5 / build272

- 실험적: 시작 로그 영역을 네이티브로 다시 만들었습니다. 개요는 단계별로 묶어 각 단계의 시작·완료·소요 시간을 보여 주며, 문제가 있는 단계는 위로 올라오고 자동으로 펼쳐져 긴 로그에서 찾을 필요가 없습니다.
- 원본 보기는 전체 로그를 유지하며 「문제만」「시간 숨기기」「줄 바꿈」을 전환할 수 있습니다. 위로 스크롤하는 동안 「새 로그 n개」 배지가 나타나고 한 번 누르면 최신으로 돌아갑니다. 복사와 다운로드는 여전히 전체 원문입니다.
- 실험적인 UI 업데이트로 아직 실기기에서 통합 시각 점검을 하지 않았습니다.
- 검증 범위: 로컬 단위 테스트, Lint와 소스 게이트만 했습니다. 실기기 렌더링은 확인하지 않았습니다. versionCode를 272로 올렸습니다(build271 기반). DSHA 리비전은 0.2.1-rc.3, 내장 DSH는 0.2.1-rc.5로 유지됩니다.
