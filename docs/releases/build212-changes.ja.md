# DSHA 0.2.1-rc.3-20261030.1506-dsh0.2.1-rc.3 / build212

- 初回復元を三状態判定に変更：元の Web が存活していれば再接続し、Web とランチャーの両方の終了を確認できた場合のみ旧記録を整理して起動を継続し、確認できない場合は保護を維持します。
- 終了確認時は暗号化インスタンス記録と旧 PID 記録を同時に退役させ、次回起動時に「確認待ち」で止まらないようにします。
- 旧インスタンスの確認中に起動を押すと今回の意図を記録し、完了後に一度だけ自動で継続します。停止・新しい世代・再接続済みの場合は重複起動しません。
- 身元は確認済みで認証が一時的に失敗する場合、最大 3 回まで再確認します（500ms/1500ms の有界待機）。それでも通らない場合のみ未確認状態を保持します。
- 起動ページは理由別に復元接続・ランチャー終了待ち・記録不読・認証一時不可などの状態と入口を表示し、確認中は起動ボタンを無効にしますが、再起動/セーフ起動の入口は引き続き押せて今回の起動意図を記録し、確認完了後に一度だけ自動で継続します。
- versionCode を 212 に引き上げました。ビルドと検証の範囲は本 run と Release の記録に従います。
