# DSHA 0.2.1-rc.3-20261027.1149-dsh0.2.1-rc.3 / build204

- 인터페이스: v5 인터랙션 프로토타입의 페이지 표현이 설정, 플러그인, 실행 구성, 설치 및 환경, 기기 권한, 데이터 및 백업, 업데이트, 진단, 환영/첫 실행, 정보, 환경 복구까지 확장되었습니다. 페이지 제목, 그룹 레이블, 카드, 입력, 버튼은 26sp 자릿수와 하나의 라이트/나이트 팔레트로 통일했습니다.
- 터미널: 사이드바의 "새 세션", "세션 종료", "입력으로 돌아가기"가 첫 탭에 반응합니다. 사이드바의 "시스템 / 라이트 / 다크" 테마 전환을 제거했고, 화면은 앱 테마를 따르며 전환 시 세션을 다시 만들거나 명령을 재생하지 않습니다.
- 마무리: ADB 페어링 화면의 중복 제목을 제거하고, 링크 설치 확인 화면을 26sp 자릿수에 맞추고, 실행 환경 유지보수(압축 해제) 화면을 v5 카드와 버튼으로 바꿨습니다.
- Sunset-3090-Q의 플러그인 관리 개선을 병합해 중복 새로 고침을 줄이고 확인된 작업 상태를 유지합니다.
- 전체 확인 설정을 변경한 뒤 화면 읽기가 계속 일시 중지되는 문제를 수정했습니다. 명시적 거부, 사용자 일시 중지 및 Android 권한은 유지됩니다.
- PC 작업 공간, QR 페어링, PC 연결 도구 및 릴레이를 제거했습니다. 휴대전화 제어와 로컬·LAN 접근은 유지됩니다.
- 네이티브 및 웹 상단 안전 영역의 중복 적용을 제거했습니다. 상태 표시줄, 10개 언어 및 시스템 언어 사용을 유지합니다.
- 가상 화면 실행은 선택적 generation을 받아 실행 전에 상태를 확인합니다. 네이티브 실행 요청에는 coreInstance와 package만 포함됩니다. 이 사전 상태 확인은 원자적인 세대 보호가 아닙니다.
- 이번 소스 통합에는 dsh-web-mobile 3.2.2와 DSH rc.3이 포함됩니다. 휴대전화 검증은 계속 중단되며, 이전 브랜치나 다른 패키지의 기기 결과는 이 빌드의 검증이 아닙니다.
