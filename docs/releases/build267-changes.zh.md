# DSHA 0.2.1-rc.3-20261102.0830-dsh0.2.1-rc.5 / build267

- 实验性：切到移动数据后容器无外网的争取性修复。以前容器的 DNS 只在启动时写入当时网络的地址，从 WiFi 切到移动数据后这个地址就不可用，所有域名解析超时，回到 WiFi 才恢复。现在切网后会自动刷新容器的 DNS；解析仍失败时，会经 Android 系统解析器再解析一次（只解析，不会重发请求，也不注入公共 DNS）。新增只读诊断 /app/net。
- 这是实验性修复，不保证在所有机型、系统、运营商、VPN 或私有 DNS 组合下都有效；如果切网后仍无外网，请反馈 /app/net 的输出。
- 验证范围：仅本机单测与源码门禁；未做切网真机验证。版本码提升为 267（基于 build266）；DSHA 修订号保持 0.2.1-rc.3，内置 DSH 为 0.2.1-rc.5。
