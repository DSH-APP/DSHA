# DSHA 0.2.1-rc.3-20261029.1500-dsh0.2.1-rc.3 / build207

- 新增 Root 命令三態攔截：嚴格（預設，僅白名單）、放寬（任意命令，但攔截格式化/刷機/重新啟動/清除資料等不可逆操作）、完全放寬（不按命令內容攔截）；設定 → 裝置能力授權可切換。
- 放寬與完全放寬只對 Root 通道生效；Shizuku/ADB 通用執行器仍按嚴格檔，簡訊讀取在三個檔位都需要原生授權。
- Root 原始命令經特權程序執行，保留逾時、256 KiB 輸出截斷與執行身分驗證；嚴格檔補充遞迴刪除儲存根和一級目錄的攔截。
- 本包為 SunsetRNE 測試身分（非 E7E3）並使用固定測試簽章；驗證範圍限於本機安裝與 Root 三檔行為，未涵蓋全部 ROM/機型。
