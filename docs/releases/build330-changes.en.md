# DSHA 0.2.1-rc.5-20261106.0230-dsh0.2.2-rc.1 / build330

- Refuses to launch the host itself onto the virtual screen (T76): `/app/vscreen/launch` no longer accepts DSHA's own package as the target. The system does not create a separate instance for a secondary display; it reuses the same running process, and the WebView already bound to the default display crashes with a `libmonochrome` null pointer on the secondary display (relay device evidence: display 4, main-thread Looper entering WebView, reused running process 14715). The bridge refuses before any authorization prompt, the Manager before claiming, and the Core before sending `am start`, all through the same check, returning `VSCREEN_SELF_LAUNCH_REFUSED` (`state=NOT_SENT`, no launch command is sent and there is no crash); the built-in plugin classifies this code as pre-dispatch, the native app picker no longer lists the host, and the result page shows a Chinese/English reason. This is a safety refusal, not support for secondary-display self-launch; supporting it later requires `createDisplayContext` with a separate WebView instance. The runtime descriptor is regenerated (runtimeId `35e3f499`); fixed inputs are not rebuilt.
- Managed gh APK asset fix (T79, T78 conclusion B): the official build328/329 APKs contain only `assets/gh-cli.tar` (38,727,680 B, STORED) and no `gh-cli.tar.gz` — AGP 9.1.1's asset merge automatically gunzips `.gz` files and drops the extension, so the managed install that opens `gh-cli.tar.gz` must fail (the wrapper bootstrap can still recover). The source fixed-input name and the `runtime-descriptor.json` pin stay unchanged and fixed inputs are not rebuilt; the APK packaging name becomes `gh-cli.bin`, `RuntimeTools` opens the packaged name and falls back to the source name, and the new `tools/verify-apk-managed-assets.py` release gate checks the actual member names, byte digests and the pinned gh member in the production and test-package build chains so a silent rename cannot recur. The runtimeId follows the managed-generator change and is now `35e3f499` (fixed inputs are not rebuilt).
- Verification scope: the full host contracts group, the whole-tree format check (JDK 17) and targeted unit tests (VirtualScreenPolicy, VirtualScreenManager ownership, update page); no device validation was performed locally. Raises versionCode to 330 (based on build329); the DSHA revision stays 0.2.1-rc.5 and the bundled DSH is 0.2.2-rc.1.
