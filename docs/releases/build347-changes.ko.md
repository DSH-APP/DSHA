# DSHA 0.2.1-rc.5-20261109.0900-dsh0.2.2-rc.1 / build347

- SAF 폴더 선택을 시스템 파일 선택기로 고정(`479302313`): 새 `ui/SystemDocumentPicker`가 트리 선택 인텐트를 `com.android.documentsui` / `com.google.android.documentsui`로 명시하고, 내보내지 않았거나 비활성·미설치면 기본 해석으로 되돌린다. OEM이 기본 처리기를 바꾼 경우 SD 카드 / USB 드라이브 등 마운트가 보이지 않을 수 있음을 먼저 설명하고 「시스템 파일 선택기 / 가로챈 앱 정보에서 기본 설정 지우기 / 기본 그대로 계속」 세 진입점을 제공한다. 권한 페이지, 워크스페이스 원탭 백업 디렉터리, 네이티브 데이터 프로젝트 백업 원본 세 곳의 트리 선택을 통일하고 매니페스트 `<queries>`에 두 시스템 패키지와 `OPEN_DOCUMENT_TREE`를 추가했다. `SystemDocumentPickerTest` 7건이 강제 시스템 진입·OEM 가로채기 판별·폴백을 검증한다.
- 기기 채널 상태 배지가 버튼과 스위치를 밀어내지 않음(`cfad29009`): Root / Shizuku / ADB / 외부 기기 네 행을 「왼쪽 열 제목 + 상태 배지」 가중치 배분으로 바꾸고, 행 내 확인 / 페어링 버튼과 스위치를 먼저 자체 너비로 측정하며 긴 상태는 왼쪽 열 안에서 줄바꿈한다. 새 `ShellChannelStatusPill`(최대 6행, 생략 없음, 줄 간격 2dp)을 추가하고 외부 기기 상태를 왼쪽 열에 합쳤다. `DeviceGrantsLayoutTest`에 긴 상태 / 중영 / 1.3배 글꼴에서 동작이 너비를 유지하고 화면 안에 남는 회귀를 추가했다.
- 「최근 작업에서 숨기기」에 콘텐츠 가드와 엄격 모드 추가(`76b3a44a6`): Android 13+ RecentTasks는 「최근 가시 작업」을 유지하므로 앱 안에서 바로 최근 작업으로 스와이프하면 현재 카드가 시스템에 남고, 공개 API만으로는 그 카드 하나만 UI 종료 없이 제거할 수 없다. 새 `ui/RecentsPrivacyGuard`(Application 수준 생명주기)를 추가해, 스위치가 켜지면 모든 화면에서 최근 작업 스크린샷 내용을 끈다(API 33+). 실험적 엄격 모드(기본 꺼짐)는 앱 전체가 백그라운드로 간 뒤 700ms 후 UI 작업을 끝내며, SAF 등 결과 대기 선택기가 진행 중이거나 화상 화면(PiP)·다중 창·회전 중에는 발동하지 않는다. 실패는 진단 로그에 남기고 크래시·재실행하지 않는다. `BrowserTasks`는 적용 후 작업 목록과 root Intent 플래그를 다시 읽어 빈 목록이나 플래그 불일치를 `RECENTS_HIDE_APPLY` / `RECENTS_HIDE_VERIFY` 실패로 처리해 거짓 성공을 없앴다. 설정 페이지에 엄격 모드 하위 행(상위 스위치 꺼짐 시 숨김)과 10개 언어 문구 `m9500`–`m9502`를 추가했다.
- 관리 런타임 업데이트: `DshaApp` / `ConfigStore` 변경으로 `runtimeId`를 `28dc573a`로 재계산. fixed-inputs는 고정된 20261105e를 유지하고 내장 `dsh-web-mobile`은 업스트림 3.3.1과 기본 활성을 유지한다.
