# DSHA 0.2.1-rc.3-20261101.1430-dsh0.2.1-rc.5 / build245

- «Восстановить прерванное обслуживание» теперь отличает ожидающие транзакции от нечитаемых записей. Если запись не читается, сообщается её тип, причина и следующий шаг вместо одного кода ошибки, и заведомо неудачное сканирование больше не повторяется.
- Если журналы транзакций плагинов не читаются, на странице обслуживания есть «Изолировать нечитаемые журналы плагинов». После нативного подтверждения перечисленные записи без изменений перемещаются в `plugin-install-quarantine` вместе с описью; ничего не удаляется и не воспроизводится, а при изменении записей после подтверждения действие отклоняется. Сеансы и настройки не затрагиваются; связанные плагины может понадобиться переустановить. То же действие есть на странице аварийного восстановления.
- Транзакции данных хоста, среды выполнения и пересборки среды могут быть применены частично, поэтому при ошибке чтения они не изолируются: сообщается точная причина и предлагается экспортировать диагностику для поддержки, чтобы не пропустить откат и не оставить личные данные в несогласованном состоянии.
- Исправлена взаимоблокировка при одновременном наличии старого и нового каталогов данных: все проверки не могли прочитать записи, а «Выбрать каталог данных» из-за этого отклонялось. Теперь выбор каталога данных этим состоянием не блокируется; другие ожидающие транзакции по-прежнему обрабатываются первыми.
- Объём проверки: локальные модульные тесты и Python-регрессии транзакций плагинов пройдены; на устройствах не проверялось. versionCode повышен до 245. Ревизия DSHA остаётся 0.2.1-rc.3, встроенный DSH — 0.2.1-rc.5.
