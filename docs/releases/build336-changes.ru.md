# DSHA 0.2.1-rc.5-20261107.0330-dsh0.2.2-rc.1 / build336

- Встроенный `dsh-web-mobile` синхронизирован с upstream 3.3.1 и снова включён по умолчанию (T101, `517078d2`): по выбранному пользователем плану C за основу взят upstream 3.3.1 (`4e71eb67`, адаптация к хосту 0.2.2) и **полностью следует upstream**, сохранён только минимальный набор хостовой интеграции. Upstream исправляет белую страницу целиком, обрезанные переключатели верхней панели, исчезнувшую клавишу файлов, наложение текста вкладок и перекрытие полосы вкладок файловой панели верхней панелью; фиксируется HEAD, а не теги v3.3.0 / v3.4.0 (в последних react по-прежнему обязательный peer). Дайджест `lib/client.js` — `7f82fac2…`; явное отключение пользователем по-прежнему важнее значения по умолчанию, а во встроенном реестре больше нет записи `defaultDisabled`.
- План C добавляет к чистому upstream только пять хостовых интеграций: ① геометрическая подгонка шестерёнки `DSHA_GEAR_FIT_V1` (upstream всё ещё опирается на наличие индикатора подключения, который 0.2.2 может не отрисовать при первом подключении; используем измеренную геометрию); ② обёртка переменных безопасной зоны `--dsha-safe-area-inset-*` (Android WebView не сообщает inset системных панелей; единственное место, уже обёрнутое upstream, пропускается без вложенности); ③ замена трёх серверных модулей (удаление сессии идёт через хостовую аутентификацию `connection.requestRejection`, сжатие действует только на текущий порт webServer, live-сессии удаляются через публичный AgentHandle); ④ нативная передача файлов (`lib/file-transfer.js` + `/api/dsha/files/{prepare,release}`: сохранить / поделиться / история загрузок / сохранить изображение, лимит 32 MiB с откатом); ⑤ мультиязычность и live-locale (8 дополнительных языков, чтобы подписи мобильной оболочки не откатывались на английский).
- Удалены устаревшие локальные патчи (upstream 3.3.1 их покрывает или они больше не применяются): `DSHA_SESSION_INPUT_V4` (переписывание нажатия на строку сессии / закрытия панели), строка поиска в оверлее горячих клавиш телефона и CSS видимой полосы, перенос строки семейства шрифтов `DSHA_FONT_FAMILY_ROW_V1`, подсветка нажатия фона `DSHA_BACKDROP_PRESS_V1`, правило сворачивания для широкоэкранного сенсора (upstream PR #257 его перенял); `test-mobile-backdrop-press.mjs` и `test-mobile-modal-behavior.mjs` уходят вместе с ними, host-tests manifest сокращается с 252 до 250 пунктов. Уже перенятые upstream пункты не восстанавливаются.
