## 行为变更

网页文件菜单接入原生下载记录及下载/保存到相册/另存为/分享入口，记录进度并支持暂停、继续、取消。取消为终态，需要从网页重新发起新任务；暂停状态仍可继续。移除记录不删除完成目标；分享选择器打开只说明进入系统分享流程，不代表对方收到。

单文件统一为十进制 **5 GB = 5,000,000,000字节**，不是5 GiB。上传摄取、网页二进制传输和原生下载采用一致边界；大图片上传保留原始File，模型图片能力与限制不变。续传结合持久任务、来源身份、HTTP Range/If-Range、长度与摘要核验，完成后才发布；旧片段或不匹配响应不能拼成成功文件。

空白首页采用键盘最小避让并保留主动输入。中间真机验证发现官方 **32 CSS px尾部padding**被误算为需避让内容，同样本多产生约 **100设备px**上移；据此收窄测量并补回归。最终键盘可确认结果仅取下方当前APK设备证据，不把中间观察写成最终修复完成。

搜索补入请求头和请求构造前置检查：对ByteString、控制字符、凭据格式与API版本提供字段/来源/字符位置等脱敏诊断，派发前失败明确未发送；不清空或替换凭据，不自动换账号重试。宿主受控响应与Java链通过不代表报告中的realme设备或真实转发搜索服务已恢复。
