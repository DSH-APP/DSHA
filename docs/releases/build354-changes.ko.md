# DSHA 0.2.1-rc.5-20261110.1300-dsh0.2.2-rc.1 / build354

- 테스트 패키지 피드백 내보내기 시스템 별칭 수정 (T142, `17b914f9d`): Android 16에서 `Context.getCacheDir()` / `getFilesDir()`가 `/data/user/0` 시스템 별칭을 반환하고 `AndroidBackupFileSystem`의 세그먼트별 NOFOLLOW 열기가 정상 별칭을 `PARENT_LINK`로 판정해 테스트 패키지의 "피드백 로그 내보내기(테스트 패키지)"가 실패하고 `dsh-home` 수집이 열화되었습니다. 이제 이 프로세스가 방금 만든 캐시 아카이브와 `getFilesDir()`만 `getCanonicalFile()`로 정규화한 뒤 읽으며(`core/TestPackageFeedbackExporter`), 사용자가 선택한 SAF 대상과 guest 경로의 탈출 방지 검사는 그대로 둡니다. 실기기 TB321FU(Android 16)에서 353 `.debug` 패치 패키지로 세 번 연속 내보내기에 성공했습니다(9개 항목, `dsh-home` 포함, `PARENT_LINK` 없음).
- 설정 및 플러그인 화면 간소화 (T143, `5e6e92aeb`): 설정 화면은 페이지 안의 "설정" 큰 제목을 숨기고 내용을 위로 올려 중복 여백을 없앴습니다. 플러그인 화면의 "로컬 플러그인" 카드는 위아래 두 줄에서 나란한 두 진입점(플러그인 가져오기 / 플러그인 내보내기)으로 바꾸고 부제목과 오른쪽 화살표를 없애 아이콘과 이름만 남깁니다. `ShellCard` / `ShellRow` 스타일과 테마 치수를 그대로 쓰며 세로/가로와 태블릿은 기존 레이아웃에 적응합니다. 표시만 바꾸고 클릭 동작과 문자열 리소스 키는 바꾸지 않습니다. 미사용 문구는 `check-ui-i18n` 규칙에 따라 처리했습니다(`newFindings=0`).
