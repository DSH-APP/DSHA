# DSHA 0.2.1-rc.5-20261109.1400-dsh0.2.2-rc.1 / build349

- Исправлена видимость фона статусных капсул «конфигурация / текущий Web» на карточках плагинов (`93af9944d`): фон маленькой капсулы брался из `shell_*_soft` (8% непрозрачности) и на белой карточке почти не был виден — казалось, что поменялся только цвет текста. Теперь используется заливка того же оттенка с 18% (`BADGE_FILL_ALPHA = 0x2E`, альфа составляется из `toneColor`), нейтральный по-прежнему `shell_raised`, а предупреждающая капсула «нужен перезапуск» затемнена так же. Меняется только отображение; сопоставление тонов и решение о состоянии не затронуты.
- Текст капсул на первом экране сокращён до ≤4 символов: в конфигурации остаётся только вывод (включён / отключён / можно включить / отсутствует / ошибка / временный / обработка), в текущем Web — только загружен / загружается / ошибка загрузки / ожидание службы / не загружен / не проверено; полное состояние и история загрузок перенесены в `contentDescription` для специальных возможностей и больше не занимают капсулу.
- Баннеры-подсказки больше не мигают: из подписи пересборки убран `System.identityHashCode`. Каждое обновление списка создаёт новые Item, старая подпись менялась и баннер пересобирался, из-за чего подсказки «доступно обновление / последняя операция» мигали рядом; теперь подпись строится только по содержимому подсказок, языку, версии и записям операций, и неизменный баннер не пересобирается.
- Описание управляемой среды не изменилось (по-прежнему `5fec6de5`): в этом выпуске изменены только слой отображения `PluginFragment` и `PluginFragmentRenderingTest`, launcherSources в `runtime-descriptor` те же; fixed-inputs заморожены на locked 20261105e, встроенный `dsh-web-mobile` остаётся upstream 3.3.1 и включённым по умолчанию.
- Версия и область: versionCode повышен до 349 (на основе выпущенного build348 / `2045b61d6`); ревизия DSHA остаётся `0.2.1-rc.5`, встроенный DSH — `0.2.2-rc.1`. Выпуск содержит только указанное исправление UI и не меняет решение о состоянии плагинов, белый список команд устройства и не ослабляет защиту времени выполнения. build348 уже выпущен как официальный пакет (tag `dsha-a-su-build348-20261109-110000`).
