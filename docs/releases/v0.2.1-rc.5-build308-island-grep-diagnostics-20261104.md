## 2. 改动

- 实验性（Ralsei1337）：多选「提交」经 `answerBase` 补带 `rowAction`，`AgentTaskAnswerReceiver` 能读取已选集合并回传；此前缺该字段读到空集合而直接返回。
- 实验性（Ralsei1337）：等待作答通知按系统 3 个动作槽位最多显示 2 个选项，第三个槽位放「提交」或「自己写」；选项超过 2 个时展开态提示点按通知进入对话。通知签名加入计时器开关；新模型显式写 `colorized=false`；释放已结束任务的多选集合；多选切换 PendingIntent 按选项序号区分。
- 调整（发布会话）：`canPostPromotedNotifications()` 自 API 36 存在，但 36.0 旧模型 ROM 按 colorized 提升，查询 false 不等于用户关闭；保留 build305 后设置页依赖的 `STATE_UNKNOWN`，判定在 `util/IslandPage.supportState`。动作槽位规划抽为 `util/IslandText.quickSlots`，单测穷举确认动作数不超过 3。
- 安全（#215）：`util/GrepReadPaths` 按受支持的 grep 参数收集真正读取的文件，`-f FILE`、`-nfFILE` 等模式文件与输入文件一并进入短信库路径与规范路径核验；无法识别的参数在严格档拒绝；`device-shell-policy.py` 同步。Root 放宽档走原始 shell，不经此解析。
- 诊断页（#213）：上游补丁基于 build252 前的旧页面，按当前结构等效移植。当前页已在忙碌时禁用复制/导出、无结果时禁用复制；补上 results 观察者重算反馈按钮，早期失败（维护未完成 / 任务门忙）的结果卡片到达后可复制。
- 实验性（启动目标插件，d80e2bd9）：`dsh-launch-target` 面板在容器宽度 ≤420px（无容器查询时视口 ≤599px）竖排时，标签与选择器改为按内容取高，去掉标签下约 180px 空白；分段控件加 `dshaLt_segments` 类显式撑满整行；宽屏横排不变。
- 未挑入：上游 #200（压缩补丁 writeHead 重入）已在 build194 由 `belongs()` 排除中间件接管的响应等效修复，现有 carrier 测试覆盖；其 `headersSent` 早退会吞掉所有重复 writeHead，不采用。
