# DSHA 0.2.1-rc.3-20261102.0830-dsh0.2.1-rc.5 / build267

- 実験的：モバイルデータに切り替えるとコンテナがインターネットに接続できなくなる問題への暫定修正です。これまでコンテナの DNS は起動時のネットワークのアドレスでのみ書き込まれていたため、Wi-Fi からモバイルデータに切り替えるとそのアドレスに届かなくなり、Wi-Fi に戻るまで名前解決がすべてタイムアウトしていました。今後はネットワーク切り替え後にコンテナの DNS を自動で更新し、それでも解決できない場合は Android のシステムリゾルバでもう一度解決します（解決のみで、リクエストの再送や公開 DNS の注入はしません）。読み取り専用の診断 /app/net を追加しました。
- この修正は実験的で、すべての端末・システム・通信事業者・VPN・プライベート DNS の組み合わせで有効とは限りません。切り替え後もインターネットに接続できない場合は /app/net の出力をお知らせください。
- 検証範囲：ローカルの単体テストとソースゲートのみ。ネットワーク切り替えは実機で確認していません。versionCode を 267 に引き上げ（build266 ベース）。DSHA リビジョンは 0.2.1-rc.3、同梱 DSH は 0.2.1-rc.5 のままです。
