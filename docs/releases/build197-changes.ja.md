# DSHA 0.2.1-rc.3-20261025.2000-dsh0.2.1-rc.3 / build197

- 「最近使ったアプリ」には DSHA のホームカードを 1 枚表示します。ホームから戻る操作でランチャーに戻り、既存のページとブラウザーインスタンスを再利用します。
- 「アクセスアドレス」には、LAN の状態、手動での有効化、権限の案内、有効な現在の接続リンクを常に表示します。
- 現在の会話内でスマートフォンを操作できます。明示的な要求には内蔵ツールを使用し、タスクの状態を表示します。操作対象を覆わないよう、画面を観測する前にアプリ自身のフローティングウィンドウを非表示にします。システム権限と現在の画面の識別情報の確認は引き続き行います。
- 簡体字中国語と英語に加え、繁体字中国語、ロシア語、日本語、韓国語、アラビア語、ポルトガル語、ラテン語、フランス語を追加しました。システム言語に合わせた選択と、アラビア語の右から左へのレイアウトに対応します。
- 内蔵の指示により、カスタム指示と既存の会話を保持しながら、選択した言語に合わせて応答します。
- 標準版は従来のパッケージ名と署名を維持し、上書き更新に対応します。ソースに同梱の build197 レポートには、ソフトウェアの確認、実際の実機受け入れ確認、未検証の範囲が記録されています。
