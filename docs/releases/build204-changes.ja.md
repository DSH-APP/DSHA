# DSHA 0.2.1-rc.3-20261027.1149-dsh0.2.1-rc.3 / build204

- インターフェース：v5 インタラクションプロトタイプのページ表現が、設定、プラグイン、実行設定、インストールと環境、デバイス権限、データとバックアップ、更新、診断、ようこそ／初回起動、このアプリについて、環境復元までをカバーします。ページタイトル、グループ見出し、カード、入力欄、ボタンは 26sp の字階と共通のライト／ナイト配色に統一しました。
- ターミナル：サイドバーの「新しいセッション」「セッションを終了」「入力に戻る」が最初のタップで反応します。サイドバーの「システム／ライト／ダーク」テーマ切り替えを削除し、外観はアプリのテーマに従います。切り替えでセッションを再作成せず、コマンドも再生しません。
- 仕上げ：ADB ペアリング画面の重複タイトルを削除し、リンクインストール確認画面を 26sp の字階に合わせ、実行環境メンテナンス（展開）画面を v5 のカードとボタンに置き換えました。
- Sunset-3090-Q のプラグイン管理改善を統合し、確認済み操作の状態を保持して重複更新を減らしました。
- 全体の確認設定を変更した後に画面読み取りが停止したままになる問題を修正しました。明示的な拒否、ユーザーの一時停止、Android の権限は引き続き有効です。
- PC ワークスペース、QR ペアリング、PC 接続ツール、中継を削除しました。スマートフォン操作とローカル・LAN アクセスは維持します。
- ネイティブと Web の上部安全領域を統一し、ステータスバーを表示します。10 言語とシステム言語への追従を維持します。
- 仮想画面のアプリ起動は任意の generation を受け付け、起動前に状態を確認します。ネイティブの起動要求には coreInstance と package だけを渡します。この事前確認は世代を原子的に保証するものではありません。
- 今回のソース統合には dsh-web-mobile 3.2.2 と DSH rc.3 が含まれます。実機受け入れは引き続き停止中で、以前のブランチや別パッケージの端末結果はこの版の検証になりません。
