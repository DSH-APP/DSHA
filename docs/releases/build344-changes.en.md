# DSHA 0.2.1-rc.5-20261108.1300-dsh0.2.2-rc.1 / build344

- proot run-root self-mirror bind (T123, `424b4a015`): proot execs / mmaps host paths, so `/proc/self/maps` contains the canonical path the kernel resolved, while the run root is usually passed through the `/data/user/0` alias and maps show `/data/data`. Without a bind, guest read-back through maps is translated into `<rootfs>/data/data/...` (a same-named skeleton inside the rootfs) and fails with ENOENT. `baseArgv()` now adds `-b <canonical rootfs>:<canonical rootfs>`, with canonical resolved by `getCanonicalFile()` (`/data/user/0` → `/data/data`) and a fallback to the passed path on failure; proroot v1.2.8 vendor already binds the canonical root resolved from `-r`, so the App does not bind twice (re-check when upgrading proroot). This touches a launcher source, so the managed runtime descriptor is recomputed from `2ae3f266` to **`f65796a2`** — a managed-runtime update; fixed inputs are not rebuilt and no managed runtime is added. The new `ContainerRuntimeSelfMirrorTest` covers alias→canonical and coexistence with the `.l2s` bind. **The proot device check is not done** (switching proot restarts the Web and interrupts the current session) and is left to the user.
- Swipe actions `SwipeAction` (T122 / F2, `df9d77263`): the trailing action strip stops open at a 45% threshold and damps at 30% past the strip width; LTR swipes left and RTL right (both direction and translation mirrored by pure `SwipeGesture` logic). Swiping only reveals actions, destructive actions only invoke the host's existing confirmation dialog (second confirmation) and the component never deletes directly; destructive actions without a confirmation callback are not clickable; lists conflicting with horizontal scrolling do not attach swiping; only one row is open per screen; a "show actions" custom action is provided to screen readers, and the strip is hidden from them when closed.
- Bottom sheet `BottomSheetCard` (T122 / G1, `df9d77263`): bottom, full width, drag handle (down 96 dp or tap closes), Back closes it first; short screens (<480 dp) fill the page with a scrolling body and a pinned footer; scrim taps only close and never execute actions; motion goes through `UiMotion` and lands on the end state without animation when system animations are off.
- Wiring and copy (T122): automatic backup records swipe for "re-check restore / export" and tap to open details / the action sheet; the plugin list swipes for "delete plugin" (still using the original confirmation dialog, disabled on tablet two-pane and for temporary plugins), and plugin "more" actions plus sort filters become bottom sheets; existing confirmation dialogs are not migrated. Eleven new strings across ten languages and `ids.swipe_action_open` are added with refreshed hygiene byte pins, and three new classes plus four test classes are registered in the format manifest.
