# DSHA 0.2.1-rc.3-20261030.1506-dsh0.2.1-rc.3 / build212

- أصبح الاسترداد الأولي حكمًا ثلاثي الحالات: إعادة الاتصال إذا كان Web الأصلي حيًا؛ وتنظيف السجلات القديمة ومتابعة الإقلاع فقط بعد تأكيد خروج Web ومشغّله معًا؛ وإبقاء الحماية عند تعذّر التأكيد.
- عند تأكيد الخروج يُسجَّل تقاعد سجل المثيل المشفّر وسجل PID القديم معًا، فلا يتوقف الفتح التالي عند «بانتظار التأكيد».
- الضغط على البدء أثناء فحص المثيل القديم يسجّل نية هذه الجولة ويُكمل تلقائيًا مرة واحدة بعد انتهائها؛ الإيقاف أو جيل جديد أو اتصال مُعاد لا يسبب بدءًا مكررًا.
- إذا تأكدت الهوية وفشل المصادقة مؤقتًا، يُعاد فحص الاتصال 3 مرات كحد أقصى (انتظار محدود 500ms/1500ms)؛ وبعدها فقط تُبقى الحالة غير المؤكدة.
- تعرض صفحة البدء الحالات والمداخل حسب السبب: استعادة الاتصال، والمشغّل ما زال يخرج، والسجل غير قابل للقراءة، والمصادقة غير متاحة مؤقتًا؛ ويبقى زر البدء معطّلًا أثناء الفحص، بينما تظل مداخل إعادة التشغيل/البدء الآمن قابلة للنقر وتسجّل نية البدء لهذه الجولة وتتابع تلقائيًا مرة واحدة بعد اكتمال الفحص.
- رُفع رمز الإصدار إلى 212؛ ونطاق البناء والقبول وفق هذا التشغيل وسجل Release.
