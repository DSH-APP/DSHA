# DSHA 0.2.1-rc.3-20261101.0306-dsh0.2.1-rc.5 / build242

- Merges UI v5 Scheme A: Settings and Plugins switch to list + detail at widths of 840dp or more, maintenance uses two columns, and the launch home follows the prototype. Settings sub-pages use flat groups; multi-sentence static hints keep only the first sentence, with the full text behind an ⓘ dialog.
- Device grants: turning on global permission, relaxing root blocking, or choosing Allow all for screen actions now shows a red confirmation that cannot be dismissed by tapping outside, with Cancel on the far right. Relaxing root also requires a 10-second wait and three acknowledgements. Root tiers and screen confirmation modes are risk-graded cards; screen actions gain an app picker, and the virtual screen has its own row.
- The launch activity bar becomes a wavy progress bar: while work runs, a wave segment travels along the track, and on completion it fills and flattens into a solid line. It reflects real state only and shows no percentage.
- The floating-status page is compacted into short rows and saves changes immediately. Interface language uses a Follow system tile plus a grid of native names. Skills moves into Settings and switches between a single column and side-by-side layout by page width.
- New interface text is translated into all ten languages. Robolectric layout regressions cover phone portrait (360dp) and wide layouts, plus a small-screen language picker case.
- Verification scope: the test package was overwrite-installed and inspected on a single Lenovo tablet (TB321FU), with screenshots in both landscape and portrait, but not every change was viewed on the device. Nothing was tested on a physical phone; phone portrait is covered only by Robolectric layout regressions, not real-device rendering.
- Raises versionCode to 242, counted from cumulative test-package overwrite installs (220 + 22); 221–241 were not released. The DSHA revision remains 0.2.1-rc.3 and bundled DSH remains 0.2.1-rc.5. Complete build, unit-test, signing and publication scope follows this CI / Release receipt.
