# DSHA 0.2.1-rc.3-20261025.2000-dsh0.2.1-rc.3 / build197

- 최근 앱에는 DSHA 홈 카드 하나가 표시됩니다. 홈에서 뒤로 가기를 누르면 런처로 돌아가며 기존 페이지와 브라우저 인스턴스를 다시 사용합니다.
- 접속 주소에는 항상 LAN 상태, 수동 활성화, 권한 안내 및 현재 유효한 연결 링크가 포함됩니다.
- 휴대전화 제어는 현재 대화에서 작동합니다. 명시적인 요청에는 내장 도구를 사용하고 작업 상태를 표시합니다. 대상이 가려지지 않도록 화면을 관찰하기 전에 앱 자체의 플로팅 창을 숨깁니다. 시스템 권한 및 현재 화면 신원 확인은 계속 적용됩니다.
- 기존 간체 중국어와 영어에 번체 중국어, 러시아어, 일본어, 한국어, 아랍어, 포르투갈어, 라틴어 및 프랑스어를 추가했습니다. 시스템 언어 일치와 아랍어의 오른쪽에서 왼쪽으로 쓰는 레이아웃을 지원합니다.
- 내장 지침은 사용자 지정 지침과 기존 대화를 유지하면서 선택한 언어에 맞춰 응답하도록 조정됩니다.
- 표준 버전은 기존 패키지 및 서명 신원을 유지하여 덮어쓰기 업데이트를 지원합니다. 소스와 함께 제공되는 build197 보고서에 소프트웨어 검사, 실제 기기 검수 및 미검증 범위가 기록되어 있습니다.
