# DSHA 0.2.1-rc.3-20261031.0300-dsh0.2.1-rc.5 / build215

- 설치 패키지 경량화: 독립 긴급 DSH를 0.2.1-rc.3에서 기본 환경과 같은 0.2.1-rc.5로 맞췄습니다. 두 런타임 아카이브가 바이트 단위로 같아져 APK에는 한 부만 담깁니다(약 127.7 MB 크기의 DSH 아카이브 하나가 줄어듭니다). 긴급 환경은 여전히 별도 디렉터리에 풀리며, 독립 잠금·식별 정보·세션·시작 절차는 그대로입니다.
- 독립 긴급 DSH를 처음 준비할 때 오버레이 입력 목록이 디스크립터와 맞지 않아 실패하던 문제(build193부터)를 고쳤습니다. 긴급 잠금 버전에 맞는 recipe를 읽도록 바꾸고 단위 테스트와 빌드 측 대조 검사를 추가했습니다.
- 앱이 전혀 불러오지 않는 BouncyCastle 리소스(Picnic 양자내성 상수 표와 인증서 경로 검토 메시지, 약 1.2 MB)를 제외했습니다. 백업 암호화에 쓰는 AES-GCM, SHA-256, PBKDF2는 영향을 받지 않습니다.
- versionCode를 215로 올렸습니다. DSHA 리비전은 0.2.1-rc.3을 유지하고 내장 DSH 접미사는 0.2.1-rc.5입니다. 빌드와 검수 범위는 이번 run과 Release 기록을 따릅니다.
