# DSHA 0.1.6-alpha1 · UI 重构 build 133

2026-09-17。纠正上一轮交付：build 132 的记录验证了功能与运行时，不能视为用户确认稿的 UI 已落地。用户指出主结构、内页与入口仍不符合确认稿；本轮按实际页面重新实现。

## 本轮改动

- 主界面固定品牌栏，启动状态卡、独立主按钮、实际端口/环境信息卡、快捷入口分组。
- 按用户最新反馈移除启动日志「展开」，恢复原有「下载日志」按钮。日志使用共用 LogScrollView，在框内滚动，滚动时不移动上方状态卡。
- 设置、插件市场/管理、安装与环境、接口与运行配置、数据与备份、设备授权、ADB、自检、更新重新组织为卡片页面。安装页显示实际环境版本，六组件状态来自真实检查。
- 关于 DSHA 改为独立卡片内页，含真实版本、包名、许可、仓库、反馈与使用引导。
- 悬浮条改为独立编辑页，含开关、预览、透明度、行数、停留时间、背景与行为设置；不再跳到配置页。沿用原有持久化键，保存才修改偏好。
- 运行方式、DNS、内核、备份范围和悬浮条选项使用底部选择卡片；保留真实适配器和原有保存逻辑。
- 导出与恢复各自进入对应操作页；保留原有密码、预检、确认及宿主事务流程。目录说明可单独查看。
- 三页首次介绍、安装前检查、真实环境维护、模型配置引导和准备完成串联。主要操作固定底部；模型使用真实 DSH 编辑器。
- 终端保留用户指定的原生 PTY/简易结构与会话行为。

- 两版各 543 项单测：542 通过、1 跳过，0 失败；两版 Release Lint 无 Error/Fatal。仍有 Warning（标准 418 / low 368），不把它们说成零警告。
