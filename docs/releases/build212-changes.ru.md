# DSHA 0.2.1-rc.3-20261030.1506-dsh0.2.1-rc.3 / build212

- Первичное восстановление теперь решает по трём состояниям: при живом исходном Web — переподключение; очистка старых записей и продолжение запуска только после подтверждённого выхода Web и его лаунчера; при невозможности подтвердить — сохранение защиты.
- При подтверждённом выходе одновременно снимаются зашифрованная запись экземпляра и старая запись PID, поэтому следующее открытие больше не останавливается на «ожидает подтверждения».
- Нажатие запуска во время проверки старого экземпляра записывает намерение этого раунда и автоматически продолжает один раз после завершения; остановка, новое поколение или уже восстановленное подключение не приводят к повторному запуску.
- Если личность подтверждена, а аутентификация кратковременно сбоит, соединение перепроверяется не более 3 раз (ограниченные ожидания 500ms/1500ms); только затем сохраняется неподтверждённое состояние.
- Страница запуска показывает состояния и входы по причине — восстановление соединения, лаунчер ещё завершается, запись нечитаема, аутентификация временно недоступна; во время проверки кнопка запуска отключена, а входы перезапуска/безопасного запуска остаются доступны и записывают намерение запуска этого раунда, автоматически продолжая один раз после завершения.
- Код версии повышен до 212; объём сборки и приёмки определяется этим run и квитанцией Release.
