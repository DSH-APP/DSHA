# DSHA 0.2.1-rc.5-20261107.1900-dsh0.2.2-rc.1 / build337

- 휴대폰 작업 인터페이스 409 수정 (T115, `a9c718e2`): build336 정식 패키지에서 실제 화면의 휴대폰 작업 창을 만들 수 없었다. 내장 `dsh-status-overlay` 가 0.2.2-rc.1 에서 제거된 `SessionController.inspect` 를 계속 호출해 `sessions.status` 가 TypeError 를 던졌고, 브리지는 일괄 409 를 반환했으며 Java 쪽에는 `ASSISTANT_TASK_CHANGED` 만 보였다. 이제 `controller.state` 와 `controller.events` 의 제한된 페이지를 읽는다(최근 16개 메시지 이벤트를 최근 8개 표시 대화로 자름, turnId / turnActive 는 Host 의 turnBoundary 투영 우선). 응답 필드는 Java 읽기와 일치하며 host 테스트 11/11 통과. **정식 패키지 실기기 검증은 사용자가 build337 을 설치한 뒤 진행한다.**
- Web 터미널 `pty.fork` 수정 (T116, `adab1698`): 같은 Node 프로세스에서 `sharp` 가 `node-pty` 보다 먼저 로드되면 `pty.node` 내보내기가 sharp/libvips 키로 등록되어 Web 터미널을 열 때 `pty.fork is not a function` 오류가 난다(재시도 무효). 시작 프리로드 `startup-observer.cjs` 가 플러그인 로드 전에 node-pty 를 require 한다. 실패는 조용히 처리되며 시작에 영향을 주지 않는다. 자세한 감사는 [T116 감사](../design/t116-pty-fork-20261107.md).
- UI 긴 텍스트 1차 정리 (T114, `c4c79941`): 감사 보고서 §2.3 의 P1 기본 노출 긴 텍스트 12곳을 1–2줄 요약으로 바꾸고 전체 설명은 기존 InfoHint / InfoSurface 시트로 옮긴다(새 번역 키 없음, 보안·개인정보 문구 의미 불변). `UiMotion` 에 `crossFadeText` 와 `animateCounter` 를 추가해 유지보수 페이지 상태, 자동 백업 상태, 시작 제목에 시험 적용. UiMotionTest(9)와 InfoHintTest(6) 추가, ui 패키지 53개 클래스 / 449개 통과.
- 백그라운드 숨김 최근 작업 재적용 (T111, `e809f72c`): `MainActivity.onCreate`, `WebPreviewActivity.onCreate`, `onResume` 에서 `BrowserTasks.applyRecentsPreference` 를 다시 실행해 프로세스 재시작·덮어쓰기 업데이트·시스템 작업 재구성 후 "새 작업이 기본 노출"되는 틈을 막는다. 매니페스트의 `excludeFromRecents` 는 작업 루트 Activity 에만 남긴다. 대상 단위 테스트 51개 통과. ColorOS 16 과 Lenovo 실기기 동작은 미검증이며 수정되었다고 주장하지 않는다.
- 문구 및 CI/문서 수정: T109 슬라이스 1 은 네이티브 UI 동의어/중복 15곳을 통합하고 용어를 통일하며 유일한 러시아어 초과 문자열을 고친다(`44e44119`). 시작 상태줄에 10개 언어 문구 추가(`c4fd2828`). Java 포맷 목록 보완(`ec532d9a`)과 번역 바이트 핀 6개 갱신(`6b573957`)으로 contracts / java-format 게이트를 복구. UI 기준선 v2–v5 와 T112 감사(51항목, P1 22)는 docs-only 기록.
