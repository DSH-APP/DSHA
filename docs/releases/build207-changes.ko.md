# DSHA 0.2.1-rc.3-20261029.1500-dsh0.2.1-rc.3 / build207

- Root 명령 3단계 차단을 추가했습니다. 엄격(기본, 허용 목록만), 완화(모든 명령을 허용하지만 포맷·플래시·재부팅·데이터 삭제 같은 되돌릴 수 없는 작업은 차단), 완전 완화(명령 내용을 검사하지 않음). 설정 → 기기 권한에서 전환할 수 있습니다.
- 완화와 완전 완화는 Root 채널에만 적용됩니다. Shizuku/ADB 범용 실행기는 계속 엄격하며, SMS 읽기는 세 단계 모두에서 네이티브 승인이 필요합니다.
- Root 원시 명령은 권한 프로세스에서 실행되며 시간 제한, 256 KiB 출력 자르기, 실행 ID 검증을 유지합니다. 엄격 모드는 저장소 루트와 1차 디렉터리의 재귀 삭제도 차단합니다.
- 이 패키지는 SunsetRNE 테스트 ID(E7E3 아님)와 고정 테스트 서명을 사용합니다. 검증 범위는 이 기기 설치와 Root 3단계 동작에 한정되며 모든 ROM/기기는 포함되지 않습니다.
