# DSHA 0.2.1-rc.3-20261101.0450-dsh0.2.1-rc.5 / build243

- Исправления для телефона в портретной ориентации: на узких экранах «Остановить» и «Перезапустить» стали двумя кнопками равной ширины с рамкой под основной кнопкой; длинные пояснения о восстановлении Web перенесены в подзаголовок, крупный заголовок показывает только короткое состояние. Три дорожки готовности (среда / рабочий стол / порт) сохранены как были.
- Страница обслуживания среды больше не встраивает окно журнала; причина уже указана в блоке ошибки, полный журнал открывается кнопкой просмотра записи. На широком экране карточка этапов занимает всю строку, если пояснения нет.
- У режима «Настроить по приложениям» больше нет пустой метки; число столбцов в выборе языка зависит от ширины и масштаба шрифта; варианты 1–6 строк плавающей панели делят одну строку поровну.
- Нижняя навигация телефона стала настоящей непрозрачной плавающей капсулой поверх содержимого; снизу оставлено место, чтобы последняя строка прокручивалась выше капсулы. На планшетах по-прежнему левая рейка.
- На телефоне проверка перед развёртыванием сворачивается в одну строку; нажатие открывает архитектуру, место и WebView. На планшетах по-прежнему полная сетка.
- Проверка перед развёртыванием показывает ядро браузера и вывод о поддержке: Android 10 и ниже или не-arm64 нельзя развернуть; HarmonyOS / WebView Honor-Huawei помечаются как высокий риск с просьбой сначала обновить System WebView. Страница сбоя обслуживания и диагностика используют ту же локальную сводку и умеют копировать её для поддержки. Ничего не отправляется в сеть.
- Полоса разрешений в мастере показывает только рекомендуемые пункты, без ряда пустых точек «всего x / 7». Канал команд рекомендует только Stellar (через слой совместимости Shizuku); если менеджер не установлен, основная кнопка открывает GitHub Release, а уже установленный Shizuku продолжает работать. Root и ADB остаются в настройках. Оптимизация батареи открывает системную страницу «О приложении» (в ColorOS нажмите «Расход батареи»); DSHA не запрашивает исключение.
- Опрос больше не перерисовывает всю страницу при колебаниях текста состояния Shizuku/Root, а спецвозможности остаются подключёнными при разрывах короче 1,5 с, что уменьшает мерцание карточек. Финальная страница перечисляет только 6 разрешений мастера, без Root, и считает их как «включено x / 6».
- Объём проверки: тестовый пакет установлен поверх и проверен на одном телефоне OnePlus PJD110 (360dp, портрет); результаты — в записи проверки этой сборки. Другие телефоны не проверялись.
- versionCode повышен до 243. Ревизия DSHA остаётся 0.2.1-rc.3, встроенный DSH — 0.2.1-rc.5.
