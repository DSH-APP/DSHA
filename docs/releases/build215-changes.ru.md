# DSHA 0.2.1-rc.3-20261031.0300-dsh0.2.1-rc.5 / build215

- Пакет стал меньше: независимая аварийная DSH переведена с 0.2.1-rc.3 на ту же 0.2.1-rc.5, что и основная среда. Архивы среды выполнения теперь побайтно совпадают, поэтому APK хранит одну копию (на один архив DSH размером около 127,7 МБ меньше); аварийная среда по-прежнему распаковывается в собственный каталог, со своими блокировкой, идентичностью, сеансами и порядком запуска.
- Исправлен сбой первой подготовки независимой аварийной DSH из-за расхождения списка входных файлов оверлея с дескриптором (начиная с build193): рецепты теперь читаются для версии аварийной блокировки; добавлены модульный тест и сверка на стороне сборки.
- Удалены ресурсы BouncyCastle, которые приложение никогда не загружает (таблицы констант постквантовой схемы Picnic и сообщения проверки цепочек сертификатов, около 1,2 МБ); AES-GCM, SHA-256 и PBKDF2 для шифрования резервных копий не затронуты.
- versionCode повышен до 215; ревизия DSHA остаётся 0.2.1-rc.3, суффикс встроенной DSH — 0.2.1-rc.5; объём сборки и приёмки определяется этим запуском и квитанцией Release.
