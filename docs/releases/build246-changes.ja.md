# DSHA 0.2.1-rc.3-20261101.1600-dsh0.2.1-rc.5 / build246

- フローティングアシスタントのウィンドウがキーボードから分離されていなかった問題を修正しました。折りたたんだアシスタントは画面下部にあり、以前は他のアプリで入力欄をタップしてキーボードが出ると一緒に上へ押し上げられ、入力欄付近の内容を隠していました。
- フローティングアシスタントは文字入力を受け付けません（編集は別のアシスタント画面で行います）。現在はシステムバーだけを避け、他のアプリのキーボードには反応しません。画面観察用に登録する除外領域も、キーボードの開閉で変わらなくなりました。
- 検証範囲：ローカル/CI の単体テストのみ。**実機ではテストしていません**。一部の Android バージョンや ROM では修正が効かない（アシスタントが引き続きキーボードと一緒に上がる）可能性があり、今後のフィードバックで確認が必要です。versionCode を 246 に引き上げ。DSHA リビジョンは 0.2.1-rc.3、同梱 DSH は 0.2.1-rc.5 のまま。
