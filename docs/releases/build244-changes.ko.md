# DSHA 0.2.1-rc.3-20261101.0910-dsh0.2.1-rc.5 / build244

- 「중단된 유지보수 복구」가 계속 실패하던 문제 수정: 이전 빌드는 플러그인 완료 기록을 플러그인 트랜잭션 디렉터리 안에 원자적으로 기록했고, 기록이 중단되면 `.previous`, `.tmp-*` 같은 파일이 남았습니다. 이후 모든 검사가 `PLUGIN_JOURNAL_ID`를 보고했고 복구는 「Web 중지 중」에서 멈췄으며, 다른 복구는 `REPAIR_RECOVER_PENDING_FIRST`로 거부되어 Web을 시작할 수 없었습니다.
- 완료 기록은 이제 트랜잭션 디렉터리 밖에 저장됩니다. 이전 잔여 파일과 그 디렉터리의 알 수 없는 항목은 그대로 보존되며, 더 이상 유지보수를 막지 않고 플러그인 작업으로 다시 실행되지도 않습니다. 이미 이 상태인 기기는 덮어 설치 후 검사를 통과할 것으로 예상됩니다.
- 이번 빌드는 플러그인 트랜잭션 스크립트를 갱신하므로, 덮어 설치 시 일반적인 관리 런타임 업데이트 절차로 관리 파일을 교체합니다. 개인 데이터는 그대로 유지됩니다.
- 검증 범위: 로컬 단위 테스트(backup 및 util 패키지 1689건)와 플러그인 트랜잭션 Python 회귀 테스트를 통과했습니다. 이 문제가 발생한 기기에서는 아직 실기 검증하지 않았습니다. versionCode를 244로 올립니다. DSHA 리비전은 0.2.1-rc.3, 내장 DSH는 0.2.1-rc.5로 유지됩니다.
