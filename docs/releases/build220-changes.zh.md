# DSHA 0.2.1-rc.3-20261101.0053-dsh0.2.1-rc.5 / build220

- 修复手机任务右下角悬浮控制窗与识屏授权的竞态：用户点开状态窗后，屏幕控制会立即暂停并撤销旧授权；随后到达的 `turn/end` 与 `/app/ui/task-end` 不再无条件关闭暂停控制窗。

- 清理路径在主线程再次核对任务归属和暂停状态，补充展开暂停保留、显式停止回收和正常完成回收的 Android 回归测试；同步更新设备操作指南。
- 补充手机端 ScreenSense 识屏/操作层性能评估与分阶段重构方案；OCR、紧凑协议和延迟预算仍是设计评估，不是本版已落地能力。
- 版本码提升为 220；DSHA 修订号保持 0.2.1-rc.3，内置 DSH 为 0.2.1-rc.5。完整构建、单测、签名和真机验收范围以本版 CI / Release 回执为准。
