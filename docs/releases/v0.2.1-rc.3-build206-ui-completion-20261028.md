# build206 UI v5 补全（2026-10-28）

身份：`0.2.1-rc.3-20261028.1200-dsh0.2.1-rc.3` / build206 / Standard / 测试包 `dsh.android.client.SunsetRNE` / 非调试 / CI 临时测试证书（非 E7E3）。
分支：`Sunset-3090-Q`。性质：同 build206 的 UI 补全轮，不改版本号、不改包名与签名身份。

## 1. 背景与基线

`<workspace>/reviews/ui-v5-gap-20261028.md` 的结论是：v5 原型只真正覆盖 6 个功能区，插件列表只换到卡片外壳，运行配置/设备授权仍停留在“旧结构 + 新配色”，启动遮罩与部分进度条未替换，终端侧栏缺少关闭动效。

本轮以 `deliveries/top4-interactive-20261028`（四入口 + 终端侧栏交互原型，对齐 [page-map](../design/ui-v5-20261026/page-map.md) 与 [page-kit](../design/ui-v5-20261026/page-kit.md)）为决策基线，只做视觉、信息层级与动效修正；不伪造状态、不改插件/终端/授权业务。

## 2. 改动

### 2.1 插件列表

- `item_plugin.xml`：卡片改为「34dp 图标块 + 名称/说明 + 多行真实状态 + 状态点/更多/展开/开关」；`pluginStatus` 仍是真实文本源，`pluginSwitch` 保持 `MaterialSwitch` 并改用 `ShellSwitch`。
- `plugin_list_header.xml`：分段控件换成轨道 + 选中滑块；已安装筛选整组收进一张 `ShellCard`（标题、检测插件、搜索、只看自己装的、计数、排序/检查更新）；`pluginBusy` 仍是 3dp 进度条。
- `plugin_list_footer.xml`：空状态改为居中虚线卡片。
- `PluginFragment.java`：分段切换 260ms 回弹；首屏列表逐项淡入；状态点跟随真实状态色。未改 Adapter、排序/筛选、DiffUtil 与无障碍语义。

### 2.2 设置二级页

- `fragment_config.xml`（运行配置）：分组改为「运行与网络 → 显示与启动 → 悬浮条 → 运行时兼容选项」，全部走 `ShellPageTitle / ShellSectionLabel / ShellCard / ShellInput / ShellSwitch / Shell*Button`；端口自动/固定仍由原 `config_automatic_port` 开关驱动，未加装饰性假分段。
- `fragment_device_grants.xml`：三通道卡、系统权限、敏感能力统一 `ShellCard` + `ShellSwitch`；状态框统一 `bg_shell_status`；按钮统一次级/文本按钮。保留 Root/Shizuku/ADB、短信二次确认与 `FullPermissionControls` 的注入位置。
- `activity_diagnostics.xml`：标题、分组、卡片、启动记录行与按钮统一 v5；结果列表仍由 `CardPage.entry` 动态填充。
- `dialog_about.xml`：两个入口合并为同一张卡内的两条 `ShellRow`，保留全部 id。

### 2.3 UI 动效

- `UiMotion`：统一 `cubic-bezier(.22, 1, .36, 1)`、系统动画开关判断、列表逐项入场、按钮按压缩放。
- 内页 Activity 统一走页面淡入上移（主题 `Animation.DSHA.Activity`）。
- 启动检查遮罩从裸 `LinearLayout + ProgressBar + Button` 换成 v5 卡片：品牌块、`ShellActivityTrack` 活动条、真实状态文案与诊断入口；检查结束后 160ms 淡出。
- 启动页状态点在启动/停止/进入/核对中做 1500ms 呼吸；已就绪/未运行保持静止。

### 2.4 弹窗动效

- 居中弹窗：220ms 上移 8dp + 0.94→1 缩放 + 淡入；退出 140ms 回缩淡出。
- 底部弹层：`CardSheet` 在首次 `show()` 前设置贴底与 `Animation.DSHA.Sheet`，260ms 滑入，220ms 收回；不再出现首帧居中再跳到底部。
- 动效在系统关闭动画时退回静态。

### 2.5 终端侧边栏

- 抽屉打开 300ms + 遮罩 200ms；关闭用面板位图快照完成 220ms 出屏 + 180ms 遮罩淡出，真身与焦点/无障碍按既有语义同步恢复（既有生命周期测试要求关闭后立即 GONE）。
- 行/分组/空态/底栏对齐原型：50dp 行、11dp 圆角、活动行 soft 底 + 描边、11.5sp 分组标题 + 计数 pill、虚线空态、2 列 10dp 圆角动作网格、软危险「结束全部」。
- 不改 `terminal_panel` / 工具栏颜色与遮罩色，不改会话操作与二次确认。

## 4. 已知边界

- 本轮没有重排 `NativeDataActivity` / `RetainedDataActivity` 等备份数据深页；它们仍使用 Java 内联手写结构。
- 运行配置的「自动/固定端口」保持开关语义，没有改成真正可点的分段控件，避免改变 `ConfigFragment` 的绑定。
- `DshaSelectView` 构造时硬编码 `bg_input`，XML 的 `bg_shell_input` 会被覆盖；两者当前 token 一致，视觉无差异。
- `FullPermissionControls` 与授权页部分动态按钮仍是 Java 内联旧样式。
- 终端侧栏旧 drawable（`bg_terminal_session` 等）已不再引用但保留，可能增加 unused-resource lint 警告。
- 结论来自源码与本地编译/资源编译，不能替代真机验收。
