# DSHA 0.2.1-rc.3-20261101.0450-dsh0.2.1-rc.5 / build243

- 휴대폰 세로 화면 수정: 좁은 화면에서 시작 페이지의 「중지 / 다시 시작」을 기본 버튼 아래 같은 너비의 테두리 버튼 두 개로 표시합니다. Web 복원 확인의 긴 설명은 부제목으로 옮겨 큰 제목에는 짧은 상태만 표시합니다. 세 개의 준비 상태 레일(실행 환경 / 작업대 / 포트)은 원래 디자인을 유지합니다.
- 실행 환경 유지 관리 페이지에 유지 관리 기록 로그 상자를 더 이상 넣지 않습니다. 실패 설명 상자에 원인이 포함되며 전체 기록은 하단의 기록 보기에서 엽니다. 넓은 화면에서 설명이 없으면 단계 카드가 한 줄 전체를 차지합니다.
- 「앱별 사용자 지정」에 빈 배지가 더 이상 표시되지 않습니다. 언어 격자의 열 수는 너비와 글꼴 배율로 정해지며 큰 글꼴 휴대폰에서는 2열이 됩니다. 플로팅 바 최대 줄 수 1–6은 한 줄에 균등 배치됩니다.
- 휴대폰 하단 탐색을 콘텐츠 위에 겹치는 불투명 플로팅 캡슐로 바꿉니다. 페이지 하단에 캡슐 높이를 남겨 마지막 줄이 캡슐 위로 스크롤됩니다. 태블릿은 기존 왼쪽 레일을 유지합니다.
- 휴대폰 환영 화면에서는 여섯 칸 검사를 한 줄 요약으로 접고, 누르면 아키텍처·공간·WebView를 봅니다. 태블릿은 기존처럼 전체 격자를 보여 줍니다.
- 첫 안내의 「배포 전 검사」에 웹 엔진과 지원 결론을 넣습니다. Android 10 이하 또는 비 arm64는 배포할 수 없습니다. 홍몽/아너 자체 WebView는 고위험으로 표시하고 먼저 System WebView 업데이트를 안내합니다. 유지 관리 실패 페이지와 자가 진단은 같은 기기 요약을 쓰며 지원용으로 복사할 수 있습니다. 네트워크로 보내지 않습니다.
- 안내 권한 진행 막대는 추천 항목만 표시하며 「전체 x / 7」 빈 점을 섞지 않습니다. 기기 명령 채널은 Stellar(Shizuku 호환 계층 사용)만 추천하고, 미설치 시 기본 버튼이 GitHub Release를 엽니다. 기존 Shizuku도 계속 사용할 수 있습니다. Root와 ADB는 설정 화면에만 둡니다. 배터리 최적화는 이 앱의 시스템 「앱 정보」를 열며(ColorOS에서는 「배터리 사용량」 탭), 예외를 자동 요청하지 않습니다.
- Shizuku/Root 상태 문구가 흔들려도 권한 페이지 전체를 다시 그리지 않고, 접근성의 1.5초 미만 연결 끊김은 연결됨으로 유지해 카드 깜빡임을 줄였습니다. 완료 페이지의 「권한」은 안내의 6개 항목만 표시하고 Root를 빼며 「x / 6 사용」으로 셉니다.
- 검증 범위: OnePlus PJD110 휴대폰 한 대(360dp 세로)에 테스트 패키지를 덮어 설치해 확인했으며 결과는 이번 빌드 검증 기록을 따릅니다. 다른 휴대폰은 테스트하지 않았습니다.
- versionCode를 243으로 올립니다. DSHA 리비전은 0.2.1-rc.3, 내장 DSH는 0.2.1-rc.5로 유지됩니다.
