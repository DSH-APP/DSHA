# DSHA 0.2.1-rc.3-20261102.1200-dsh0.2.1-rc.5 / build274

- Экспериментально: тема и оформление. В «Настройки › Опыт» появилась страница «Тема и оформление» с предпросмотром светлой, тёмной и системной темы; кнопка темы из верхней панели перенесена сюда.
- При смене темы можно выбрать круговое раскрытие, диагональную шторку, плавное затухание или без анимации. Добавлены пять палитр (Классический синий, Аврора, Сакура, Кибер, Янтарь) для светлого и тёмного режимов. При холодном запуске показывается анимация загрузки.
- Нативную светлую / тёмную тему можно синхронизировать с веб-интерфейсом (отключаемо); палитры не синхронизируются.
- Это экспериментальное обновление интерфейса без единой визуальной проверки на устройстве. Объём проверки: локальные целевые модульные тесты, Lint и проверки исходников. versionCode повышен до 274 (на основе build273). Ревизия DSHA остаётся 0.2.1-rc.3, встроенный DSH — 0.2.1-rc.5.
