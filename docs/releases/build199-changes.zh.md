# DSHA 0.2.1-rc.3-20261026.1356-dsh0.2.1-rc.3 / build199

- 修复 Android 原生插件页读取 Web 运行证据快照时的 `READ=PARENT_LINK`：Android 的 `/data/user/0` 是 `/data/data` 的系统别名，`currentSnapshot` 的逐段 NOFOLLOW 检查会把合法别名当作父级链接拒绝。现在读取前把运行根规范化为真实路径，再交给读取器对最终文件执行 NOFOLLOW 与大小上限检查；读不到快照时仍按原有规则保留待核验，不会伪造已加载。
- 保留 build198 的身份归一化、Auto review 版本证据、30 秒新鲜度窗口与原因码日志；本轮只改快照路径解析。
- 新增回归：运行根为符号链接时，快照路径必须解析到真实根；运行根缺失时返回明确错误。当前版本说明断言同步跟随 build199。
- 边界：DSHA 自启动到独立虚拟屏时触发的 WebView 原生崩溃不在本包修复范围；本轮由 CI 编译与单测验证，未做设备安装验收。

版本码提升到 199；包名、历史签名、常规文件名及内置 DSH rc.3 保持。本分支只跑 Standard。
