# DSHA 0.2.1-rc.3-20261101.1430-dsh0.2.1-rc.5 / build245

- 「중단된 유지보수 복구」가 복구 대기 트랜잭션과 읽을 수 없는 기록을 구분합니다. 기록을 읽을 수 없으면 어떤 기록인지, 원인과 다음 단계를 알려 주며, 원시 오류 코드만 보여 주거나 반드시 실패할 검사를 반복하지 않습니다.
- 플러그인 트랜잭션 기록을 읽을 수 없으면 유지보수 화면에 「읽을 수 없는 플러그인 기록 격리」가 나타납니다. 나열된 기록을 네이티브에서 확인하면 그대로 `plugin-install-quarantine`으로 옮기고 목록을 남깁니다. 삭제하거나 다시 실행하지 않으며, 확인 후 기록이 바뀌면 실행을 거부합니다. 세션과 설정에는 영향이 없고 관련 플러그인은 나중에 다시 설치해야 할 수 있습니다. 긴급 복구 화면에서도 같은 작업을 제공합니다.
- 호스트 데이터, 런타임, 환경 재구축 트랜잭션은 일부만 적용된 상태일 수 있으므로 읽을 수 없어도 자동 격리하지 않습니다. 정확한 원인을 알리고 진단을 내보내 지원팀에 문의하도록 안내해, 롤백을 건너뛰어 개인 데이터가 어긋나는 일을 막습니다.
- 이전·새 데이터 디렉터리가 함께 있을 때의 교착 상태를 수정했습니다. 이전에는 모든 검사가 기록을 읽지 못했고 그 때문에 「데이터 디렉터리 선택」도 거부되었습니다. 이제 이 상태에서도 데이터 디렉터리를 선택할 수 있으며, 다른 복구 대기 트랜잭션은 여전히 먼저 처리해야 합니다.
- 검증 범위: 로컬 단위 테스트와 플러그인 트랜잭션 Python 회귀 테스트를 통과했으며 기기 검증은 하지 않았습니다. versionCode를 245로 올립니다. DSHA 리비전은 0.2.1-rc.3, 내장 DSH는 0.2.1-rc.5로 유지됩니다.
