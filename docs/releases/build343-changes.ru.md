# DSHA 0.2.1-rc.5-20261108.1100-dsh0.2.2-rc.1 / build343

- Прогресс и скелетоны (E1 / E4): новый `DeterminateProgress` даёт определённый прогресс в виде полосы и кольца; реальный процент только растёт, `100` пишется только завершённым состоянием; отмена срабатывает один раз, после неё прогресс не принимается, а в терминальных состояниях завершения / ошибки / отмены анимации останавливаются и отмена скрывается; при неизвестном объёме используется неопределённое состояние без подделки прогресса. `FiniteSkeleton` — ограниченный скелетон на 1–2 с, останавливается при поступлении данных, скрывается по достижении предела и переходит к статической подсказке, без бесконечного shimmer.
- Списки и вкладки (F1 / F3 / F4): `StaggerList` смещает по времени только первые 8 элементов один раз, с дедупликацией по стабильному ключу, поэтому прокрутка / перерисовка / перелистывание не повторяют анимацию; `CardTabs` — вкладки внутри карточки с горизонтальной прокруткой, невыбранные панели `GONE`, выбранный ключ восстанавливается при повороте; `GroupedList` даёт липкие и сворачиваемые заголовки групп, меняя только `translationY`, а свёрнутое тело уходит из скринридера.
- Аккордеон и технические примечания (B2 / B3): `Accordion` построен на `DisclosureCard` с одиночным раскрытием и сохраняет строку последствий и семантику чтения при сворачивании; `TechNote` — примечание в подвале на основе `DisclosureCard`, пустые детали не сворачиваются.
