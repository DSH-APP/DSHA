## 2. 问题

- 团队反馈：引导第 3 步「按需授权」内容密度过高。build243 在一加 PJD110（360dp 竖屏）上，一张已开启的通知卡约占 1/3 屏，首屏只能完整看到 1 项。
- 原因：每张卡同时有说明、可解锁能力标签和状态框，三处重复同一件事；「推荐」在分组标签、逐卡一行与顶部圆点三处重复；已开启与未开启的卡同样高；分类标题与说明再占一层。

## 3. 改动

- `PermissionCard`：改为一行（图标 + 名称 + 副标题 + 行尾状态或主操作 + 箭头），详情只在展开时创建；`stateDescription` 与展开 / 收起动作，切换后归还读屏焦点。
- `PermissionCards` / `PermissionChannelCard`：每项提供行内主操作（短文案，读屏描述保留完整说法）与异常提示；与行内状态重复的状态说明删除，用途与跳转提示缩为一句。设备命令通道的主操作移到行内。
- `PermissionPanel`：去掉分类标题、分类说明、推荐标签与圆点，改为「推荐 x / y」+ 细进度条和单个列表；未推荐项收进「更多授权 · N 项」。
- `PermissionGoals`：分组接口改为 `cards()` / `recommendedCards()` / `otherCards()`。
- 新增 `util/PermissionExpansion`（纯逻辑，配单测）；删除不再使用的 `bg_onb_perm_rec`，新增 `bg_onb_row_ripple`。
- `OnboardingActivity`：页面说明与底部按钮文案各缩为一行。
- 交互稿：`docs/design/onboarding-20261031/permission-compact.html`（现状与新方案并排，可切换授权状态与用途）。
