# DSHA 0.2.1-rc.5-20261109.0900-dsh0.2.2-rc.1 / build347

- SAF のフォルダー選択をシステムのファイル選択画面に固定（`479302313`）：新規 `ui/SystemDocumentPicker` がツリー選択インテントを `com.android.documentsui` / `com.google.android.documentsui` へ明示し、未エクスポート・無効・未搭載の場合は既定の解決へ戻す。OEM が既定ハンドラーを差し替えている場合は SD カード / USB ドライブなどのマウントが見えない可能性を説明したうえで「システムのファイル選択画面 / 乗っ取ったアプリの情報で既定を解除 / 既定のまま続行」の 3 入口を提示。権限ページ、ワークスペースのワンタップバックアップ先、ネイティブデータのプロジェクトバックアップ元の 3 か所でツリー選択を統一し、マニフェストの `<queries>` に 2 パッケージと `OPEN_DOCUMENT_TREE` を追加。`SystemDocumentPickerTest` の 7 項目が強制システム入口・OEM 乗っ取り判定・フォールバックを覆う。
- デバイスチャネルのステータスピルがボタンとスイッチを押し出さない（`cfad29009`）：Root / Shizuku / ADB / 外部デバイスの 4 行を「左列タイトル + ステータスピル」の重み配分に変更し、行内の確認 / ペアリングボタンとスイッチを先に自身の幅で計測、長い状態は左列内で折り返す。新規 `ShellChannelStatusPill`（最大 6 行・省略なし・行間 2dp）を追加し、外部デバイスの状態を左列に統合。`DeviceGrantsLayoutTest` に長い状態 / 中英 / 1.3 倍フォントで動作が幅を保ち画面内に残る回帰を追加。
- 「最近のアプリに表示しない」にコンテンツガードと厳格モードを追加（`76b3a44a6`）：Android 13+ の RecentTasks は「直近の可視タスク」を保持するため、アプリ内から直接最近のアプリへスワイプすると現在のカードはシステムに残り、公開 API だけではその 1 枚を UI 終了なしに消せない。新規 `ui/RecentsPrivacyGuard`（Application レベルのライフサイクル）を追加し、スイッチ ON のとき全画面で最近のアプリのスクリーンショット内容を無効化（API 33+）。実験的な厳格モード（既定 OFF）はアプリ全体がバックグラウンドへ退いて 700ms 後に UI タスクを終了するが、SAF などの結果待ち選択画面が進行中、ピクチャーインピクチャー、マルチウィンドウ、回転時には発動しない。失敗は診断ログへ記録しクラッシュ・再実行しない。`BrowserTasks` は適用後にタスク一覧と root Intent フラグを読み直し、空タスクやフラグ不一致を `RECENTS_HIDE_APPLY` / `RECENTS_HIDE_VERIFY` として失敗扱いにし、偽の成功をやめた。設定ページに厳格モード子行（親スイッチ OFF 時は非表示）と十言語文案 `m9500`–`m9502` を追加。
