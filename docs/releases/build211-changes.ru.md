# DSHA 0.2.1-rc.3-20261030.1245-dsh0.2.1-rc.3 / build211

- Индикатор прогресса на странице плагинов переведён на схему F: дыхание в неопределённом состоянии, бегущий свет в определённом; прогресс следует только реальному percent.
- При успехе показывается зелёный 100% с задержкой 700 мс; при ошибке — красный на максимальном прогрессе задачи с задержкой 900 мс и последующим исчезновением.
- Длинное постоянное пояснение источника загрузки перенесено в окно круглой кнопки с восклицательным знаком; там же показывается последний результат задачи или ошибка.
- Результаты плагинов теперь имеют явное состояние успеха/ошибки: переполнение очереди, недоступность фонового исполнителя и ошибки выбора файла также видны в этом окне.
- Оба места выбора источника используют один индикатор; добавлены тёмные/светлые token, откат при уменьшении анимации и семантика прогресса TalkBack.
- Область сборки, модульных тестов и проверки на устройстве ограничена этим run и записью Release.
