## 二、上游差异与补丁复核

上游 37 个提交的用户可见变化：插件页图标与中英文标题描述、手机档「更多视图」入口、子代理 chip
让位、抽屉暗层收敛到 frame 伪元素、`overlay-backdrop-fab` 改名 `drawer-layer`、全屏手势按方向
定族（左右 45% 起点区退役）、hero 工作树行排版、插件页交还宿主排版、测试门禁空转加固。

| 项目 | 结论 |
|---|---|
| `lib/client.js` | 摘要 `8a17dd03b5de35f1aea52c93d6e3352fcd43c781de380639f60a93bf6040a26a`；全部 DSHA 补丁锚点命中，无需重定位 |
| `DSHA_GEAR_FIT_V1` | 上游仍保留旧的 `:has(> button[data-phase], > [role="status"])` 守卫，几何让位补丁照旧替换；未重新依赖宿主节点存在性 |
| 安全区 | 上游仍只有 frame 顶部使用 DSHA 变量，其余 `env()` 继续单层包装，无嵌套 `var` |
| 多语言 / live-locale | `--locale-sources` 锚点全部命中；上游删除 nav 文案 `backdrop`（抽屉暗层改名后不再有该文案），本地目录同步删除该键，其余键与插值占位符不变 |
| 服务端三模块 | `lib/{index,compress,delete-session}.js` 上游未改，DSHA 完整替换继续按固定摘要 + 唯一锚点核验 |
| 文件传输 | 上游仍无 `lib/file-transfer.js`，继续由 `tools/file-transfer/file-transfer.js` 生成为仅本地追加成员（含 source map） |

退役成员：`lib/types/client/effects/overlay-backdrop-fab.d.ts`、同名 `.d.ts.map`、
`src/client/effects/overlay-backdrop-fab.ts` 进入 `tools/mobile-plugin-upstream.lock.json#retiredFiles`，
`tools/prepare-mobile-plugin.py --write` 会删除旧产物；未复核的成员仍报错，不做通配清理。
