# DSHA 0.2.1-rc.5-20261110.1300-dsh0.2.2-rc.1 / build354

- Исправление системного псевдонима при экспорте отзыва тестового пакета (T142, `17b914f9d`): в Android 16 `Context.getCacheDir()` / `getFilesDir()` возвращают системный псевдоним `/data/user/0`, и посегментное открытие с NOFOLLOW в `AndroidBackupFileSystem` отвергало законный псевдоним как `PARENT_LINK`; из-за этого «Экспортировать журнал отзыва (тестовый пакет)» завершался ошибкой, а сбор `dsh-home` деградировал. Теперь только свежесозданный этим процессом кэш-архив и `getFilesDir()` нормализуются через `getCanonicalFile()` перед чтением (`core/TestPackageFeedbackExporter`); выбранное пользователем место SAF и проверки выхода путей guest не меняются. На устройстве TB321FU (Android 16) три последовательных экспорта с патч-пакетом 353 `.debug` прошли успешно (9 записей, включая `dsh-home`, без `PARENT_LINK`).
- Упрощение страниц настроек и плагинов (T143, `5e6e92aeb`): на странице настроек скрыт большой заголовок «Настройки», содержимое поднято вверх, лишний отступ убран; карточка «Локальные плагины» на странице плагинов превращена из двух строк в две расположенные рядом точки входа (Импорт плагина / Экспорт плагинов), без подзаголовка и стрелки, с иконками и названиями, в стилях `ShellCard` / `ShellRow` и с размерами темы, с адаптацией к портрету/ландшафту и планшетам. Изменено только представление; поведение нажатий и ключи строковых ресурсов не тронуты. Неиспользуемые строки обработаны по правилам `check-ui-i18n` (`newFindings=0`).
