# DSHA 0.2.1-rc.3-20261102.1030-dsh0.2.1-rc.5 / build271

- 實驗性：新增「外接裝置」能力，預設關閉。在「設定 → 裝置能力授權」的通道分組中單獨開啟後，可以經 USB 或無線偵錯控制另一台手機，確認後為它安裝 APK、APKS、XAPK 或模組；每次安裝都會先請你確認。
- 刷機只做唯讀預檢與模擬，不會真的寫入；此能力需要已授權的 root，且不沿用本機 ADB 或全域授權。
- 這是實驗性功能，尚未在實機上連接外接裝置驗證，可能無法正常運作。
- 驗證範圍：僅本機單元測試與原始碼門禁；未經實機驗收。版本碼提升為 271（基於 build270）；DSHA 修訂號維持 0.2.1-rc.3，內建 DSH 為 0.2.1-rc.5。
