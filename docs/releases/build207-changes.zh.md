# DSHA 0.2.1-rc.3-20261029.1500-dsh0.2.1-rc.3 / build207

- 新增 Root 命令三态拦截：严格（默认，仅白名单）、放宽（任意命令，但拦截格式化/刷机/重启/清数据等不可逆操作）、完全放宽（不按命令内容拦截）；设置 → 设备能力授权可切换。
- 放宽与完全放宽只对 Root 通道生效；Shizuku/ADB 通用执行器仍按严格档，短信读取在三个档位都需要原生授权。
- Root 原始命令经特权进程执行，保留超时、256 KiB 输出截断与执行身份校验；严格档补充递归删除存储根和一级目录的拦截。
- 本包为 SunsetRNE 测试身份（非 E7E3）并使用固定测试签名；验证范围限于本机安装与 Root 三档行为，未覆盖全部 ROM/机型。
