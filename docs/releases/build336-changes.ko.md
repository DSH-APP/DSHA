# DSHA 0.2.1-rc.5-20261107.0330-dsh0.2.2-rc.1 / build336

- 내장 `dsh-web-mobile`을 업스트림 3.3.1로 동기화하고 기본 활성화로 되돌립니다 (T101, `517078d2`): 사용자가 고른 C 안에 따라 업스트림 3.3.1(`4e71eb67`, 호스트 0.2.2 대응)을 기반으로 **업스트림을 완전히 따르고**, 호스트 통합에 필요한 최소 집합만 남깁니다. 업스트림은 전체 화면 흰 화면, 상단 바 토글 잘림, 파일 키 사라짐, 탭 글자 겹침, 파일 패널 탭 바가 상단 바에 가려지는 문제를 고칩니다. v3.3.0 / v3.4.0 태그 대신 HEAD를 고정합니다(후자는 여전히 react가 필수 peer). `lib/client.js` 다이제스트 `7f82fac2…`; 기본 활성화 후에도 사용자의 명시적 비활성화가 우선하며, 내장 레지스트리에 `defaultDisabled` 항목이 없습니다.
- C 안이 순수 업스트림보다 추가하는 것은 다섯 가지 호스트 통합뿐입니다: ① 기어 기하학적 자리 조정 `DSHA_GEAR_FIT_V1`(업스트림은 연결 표시등 존재 여부로 판단해 0.2.2 첫 연결에서 오판할 수 있으므로 실측 기하로 변경); ② 안전 영역 변수 래핑 `--dsha-safe-area-inset-*`(Android WebView는 시스템 바 inset을 보고하지 않으며, 업스트림이 이미 감싼 한 곳은 중첩하지 않고 건너뜀); ③ 서버 모듈 3개 교체(세션 삭제는 호스트 인증 `connection.requestRejection` 경유, 압축은 현재 webServer 포트에만 적용, live 세션은 공개 AgentHandle로 삭제); ④ 네이티브 파일 전송(`lib/file-transfer.js` + `/api/dsha/files/{prepare,release}`, 저장 / 공유 / 다운로드 기록 / 이미지 저장, 32 MiB 공유 제한과 실패 시 폴백); ⑤ 다국어와 live-locale(추가 8개 언어로 모바일 셸 라벨이 영어로 되돌아가지 않음).
- 오래된 로컬 패치를 삭제합니다(업스트림 3.3.1이 이미 포함하거나 더 이상 채택하지 않음): `DSHA_SESSION_INPUT_V4`(세션 행 터치 클릭 / 드로어 닫기 재작성), 휴대폰 단축키 오버레이 검색 행과 가시 영역 CSS, `DSHA_FONT_FAMILY_ROW_V1` 글꼴 패밀리 행 줄바꿈, `DSHA_BACKDROP_PRESS_V1` 배경 누름 색상, 와이드 화면 터치 접기 규칙(업스트림 PR #257이 인수). `test-mobile-backdrop-press.mjs`와 `test-mobile-modal-behavior.mjs`도 함께 은퇴하며 host-tests manifest는 252→250항목이 됩니다. 업스트림이 인수한 항목은 다시 적용하지 않습니다.
- 알려진 위험과 수용 항목(실기 검증 전에는 통과로 쓰지 않음): 335→336 최초 덮어쓰기 설치는 미검증입니다. 수용 항목은 메인 화면이 흰 화면이 되지 않음, 사이드바와 footer에 설정 진입점이 하나뿐임, `dsh-web-mobile` 기본 활성화, 파일 패널의 네이티브 저장 / 공유 / 다운로드 기록 사용 가능, 10개 언어 라벨 정상, 개인 데이터 무사. 업스트림 삭제 라우트 자체에는 호스트 인증 훅이 없고 압축은 프로세스 전역이며 삭제 수명 주기가 공개 핸들을 포착하지 않으므로 C 안은 호스트 측 서버 모듈 교체를 유지합니다(인증과 포트 제약 추가). 네이티브 파일 전송과 8개 추가 언어는 호스트 통합이며 업스트림 기능이 아닙니다. 업스트림을 따르며 수용하는 회귀: 휴대폰 단축키 오버레이에 검색 없음, 설정의 글꼴 패밀리 행이 좁아 보일 수 있음, 다크 테마에서 배경 누름이 밝게 번짐; 세션 행 클릭과 드로어 닫기는 업스트림 구현으로 돌아갑니다.
