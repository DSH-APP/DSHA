## 架构判断与残余

[架构评估](../audits/build155/architecture-assessment.md)将本项目定性为单 Android 模块中的宿主编排、独立 Linux 运行域及宿主事务。此次把 Web 生命周期状态收归应用范围拥有者，显式化宿主桥路由，拆出冷安装候选/解压/工具安装职责，并共用有界进程输出轮询；Low 的预览回退和 DNS 保留旧可用配置也有当前宿主测试证据。桥接动作本体仍在 `HttpShellService`，插件、维护和 PTY 入口仍使 `ProotBootstrap` 较密集；这些是真实的后续结构工作，不由格式化或行数变化自动消失。

历史归档读取、rc1 prepare/finalize 的启动调用以及最终源/归档完整性复核属于继续保留的兼容和保护契约，本轮没有声称删掉它们。702 项格式检查不包含两份机器生成类和受保护原件，也没有据此宣称技术债评分低于任何阈值。

本轮未完成同签名真机覆盖安装、Android 6/7 和 16 KiB 实机矩阵、Root/Shizuku 厂商兼容、真实虚拟屏/后台生命周期、VPN/private DNS、Android FUSE/掉电、全部外部模型服务、外部源码法律来源、线上 CI 或服务器部署。E7E3、包名和 `debuggable=false` 证明覆盖更新的软件前提，不证明用户设备上的迁移已实际完成。
