# DSHA 0.2.1-rc.3-20261102.0200-dsh0.2.1-rc.5 / build257

- proroot 文件锁修复：proroot 引擎的运行库把所有 fcntl 失败都报成「权限不足」（EPERM），文件被别的进程锁住时也一样，Gradle 等依赖跨进程文件锁的工具因此出错。兼容层现在返回正确的错误码，锁被占用时得到「稍后重试」。默认的 proot 引擎不受影响。
- 验证范围：测试包在一台 Android 16 平板上选 proroot 核对了锁探针和 Web 对话；正式包未在真机安装。版本码提升为 257（基于 build256）；DSHA 修订号保持 0.2.1-rc.3，内置 DSH 为 0.2.1-rc.5。
