# DSHA 0.2.1-rc.5-20261105.2310-dsh0.2.2-rc.1 / build327

- 덮어쓰기 업데이트 후 유지보수가 한 단계로 끝납니다. 유지보수 화면에서 「실행 환경 업데이트」를 누르면 출생 ID 검증 후 이전 웹 프로세스를 완전히 중지하고, 유지보수 배리어를 획득해 업데이트를 실행합니다. 제한된 메인 화면에 들어가 「중지」를 누르고 유지보수 화면으로 돌아올 필요가 없습니다.
- 내장 세로 화면 적응 플러그인(모바일 UI `dsh-web-mobile`)은 기본적으로 비활성화되며 덮어쓰기 업데이트 후에도 비활성 상태로 유지됩니다. 현재 버전 안에서 네이티브 플러그인 화면에서 명시적으로 활성화한 경우에만 적용되고, 다음 APK 덮어쓰기 업데이트에서 다시 비활성으로 수렴합니다. build324 이후의 새 화면과 새 로직에 적응하지 못한 코드가 많아 메인 화면 흰 화면과 사이드바 중복을 일으켰기 때문입니다. 기본 활성화로 되돌리려면 [docs/plugins.md](../en/plugins.md)의 하드 게이트를 충족하고 실기기 증거를 첨부해야 합니다.
- 검증 범위: 호스트 테스트, contracts 전체, 소스/설명자 게이트. 실기기 결론은 해당 시점에 실제로 확인한 기록에 따라 작성하며 통과를 미리 쓰지 않습니다. versionCode를 327으로 올렸습니다(build326 기반).
