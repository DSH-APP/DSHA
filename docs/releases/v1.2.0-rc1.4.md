# v1.2.0-rc1.4：备份恢复与使用体验修复

本版修复备份内容缺失、部分备份误标全量及导出验证问题，并完善下载、插件、运行恢复和内嵌网页。版本码 113，沿用历史 APK 签名、环境版本 9 与 dsh 0.1.2-rc.1。

本次由贡献者 [@ym2025szz](https://github.com/ym2025szz) 推进，感谢原作者 [@qiannianhuanxiang](https://github.com/qiannianhuanxiang) 及其他贡献者，以 **Pre-release（预览版）** 发布。[GitHub 发布页与双版本下载](https://github.com/DSH-APP/DSHA/releases/tag/v1.2.0-rc1.4)。

2026-09-08 同版本功能复查：六步检查合并探测，实测约 1.9 秒，增加持续脱敏输出与任务保留；补充“显示与运行”各项说明，修复配置/ADB 同步、超时与终端进程残留、维护并发、备份缓存保留规则及更新通道/进度状态。完成真实官方模型往返、App 无线配对、备份及双内核网页检查。当前文件、摘要与验证边界以[最新功能验收](../functional-audit-rc1.4.md)为准。

2026-09-07 同版本 UI 重整：按适度紧凑的方向统一标题、间距和操作层级，重排设置、配置、插件、更新、诊断及备份页面。配置保存固定在底部，子页统一顶部返回，保留右上角日夜切换。按钮、禁用态、大字体可读性及终端保留机制继续生效。版本名 rc1.4、版本码 113 均不变。见[本次排版验收](../ui-layout-rc1.4-verification.md)。

- 备份：四种范围分别保存；包含会话附件、公开目录实际数据及插件源码/依赖。导出后验证实际文件，恢复前完整预检并展示影响范围，提交失败或中断可恢复原状态。接通启动次数自动备份和最近备份入口。
- 更新：APK 下载由前台服务接管，关闭页面后继续，支持取消和断点续传；进程重建保留任务。下载及安装前校验大小、SHA-256、包名、版本与当前签名。
- 插件：兼容范围采用 npm SemVer；检查更新优先读取版本元数据。任务显示阶段、字节和进度，可在安全边界取消；旋转保留任务与结果。
- 运行：连续启动失败后暂停自动重试，显示失败阶段并提供安全启动、回退和诊断入口。增加持续运行/省电模式，按活动任务管理运行锁。
- 内嵌网页：系统 WebView 与 Gecko 均支持文件下载和系统保存位置；返回键先关闭弹层、抽屉及预览。保留页面、阅读位置和未发送图片；完善文件选择备用入口。修复旧 WebView 的 Promise.withResolvers 启动兼容问题。
- 官网：来源改变后撤下旧安装入口，同源重新生成保留摘要与版本；电脑端二维码携带完整安装信息。修正过时指南，完善 320px 菜单、搜索重置与复制回退。官网修复已上线。

标准版面向 Android 11+，兼容版面向 Android 6+，均为 arm64。两版共用包名和数据，选择适合设备的一版覆盖同签名旧版。

实测设备为 Android 13 / 4 KB 页 Redmi M2012K10C，使用同源码调试包完成备份、下载/取消/进程恢复、插件、运行恢复及双内核网页验收。旧 Android 和 16 KB 页设备仍有实机覆盖限制；正式发布包另作签名、API、架构和 ELF 检查。详细证据见[总验收清单](../optimization-implementation.md)。

GitHub 发布资产为标准版、兼容版 APK 及各自的 SHA-256，共四个文件；本地 `release` 继续保留同一批已验证安装包。官网公开下载和 App 更新清单使用独立网站发布流程，本次 GitHub 发布不改写该清单。
