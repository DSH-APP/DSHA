# DSHA 0.2.1-rc.5-20261106.0010-dsh0.2.2-rc.1 / build328

- Исправлена ошибка `gh` «managed GitHub CLI is unavailable» в среде 0.2.2: официальный GitHub CLI v2.103.3 (linux-arm64) добавлен как 12-й фиксированный вход `gh-cli.tar.gz` в управляемые ресурсы; при установке извлекается только закреплённый член, повторно проверяется SHA-256 и выполняется атомарная публикация в `/opt/gh/bin/gh`; при полной пересборке среды он внедряется как управляемый ресурс, а не как ручная установка пользователя.
- Если двоичный файл отсутствует или повреждён, обёртка gh загружает его по фиксированному URL и сверяет фиксированный SHA-256; любая ошибка завершает установку fail-closed и печатает готовую к копированию команду восстановления. Удалено вводящее в заблуждение утверждение, что двоичный файл «bundled».
- Добавлен явный контракт `util/MaintenanceToolPaths` и ограниченная предварительная проверка перед пересборкой: `/opt` сохраняется как каталог пользовательских инструментов, `/usr/local/bin` относится к системному дереву и не сохраняется, `usr/local/share/dsha` внедряется управляемо; при более чем 100 000 записей в `/opt` пересборка отклоняется до перемещения старого дерева.
- Объём проверки: хост-тесты, полная группа contracts и проверки исходников/дескриптора/сторонних уведомлений; локальная проверка на устройстве не выполнялась. Код версии повышен до 328 (на базе build327); APK увеличивается примерно на 13,0 МиБ из-за встроенного архива gh.
