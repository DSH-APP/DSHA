# DSHA 0.2.1-rc.3-20261101.1600-dsh0.2.1-rc.5 / build246

- 修复悬浮助手窗口未与输入法隔离：收起后的悬浮助手贴在屏幕底部，此前在其他应用里点输入框弹出键盘时，它会随键盘整体上弹，挡住输入区附近内容。
