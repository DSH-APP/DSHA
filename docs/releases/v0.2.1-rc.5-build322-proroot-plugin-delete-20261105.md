## 2. 改动

- 根因：proroot v1.2.8 预加载的 libc `renameat2` 忽略两个目录描述符，按当前目录解析名称，导致插件卸载的保留移动返回 ENOENT（或误改当前目录下同名对象）。
- `plugin-transactions.py` 的 `rename_noreplace` 直接发 `renameat2` 系统调用（arm64 276 / x86_64 316，RENAME_NOREPLACE），只接受单段名称；没有非原子 renameat 降级，不支持时拒绝执行并保留现场。
- `runtime-fs` 未受影响；proroot 兼容层未改，README 记录了该行为。
