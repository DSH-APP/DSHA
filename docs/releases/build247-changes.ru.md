# DSHA 0.2.1-rc.3-20261101.1630-dsh0.2.1-rc.5 / build247

- Шаг 3 первоначальной настройки «Разрешения по необходимости» теперь один список: без категорий, по строке на разрешение. Выданные показывают только статус; для невыданных в конце строки есть «Разрешить / Включить / Настройки» и подзаголовок в одну строку о том, что это даёт.
- Пояснения, подсказки о переходе и остальные кнопки скрыты в раскрываемой области и открываются касанием; после изменения разрешения строка снова сворачивается. Встроенная подсказка появляется только при проблемах: отказ, ограничение фоновой работы, ожидание подключения.
- Рекомендуемые пункты идут первыми, остальные свёрнуты в «Ещё разрешения»; вводный текст и нижняя кнопка — по одной строке. На телефоне 360dp в портретной ориентации все шесть рекомендуемых пунктов помещаются на один экран.
- Объём проверки: локальные модульные тесты; тестовый пакет установлен поверх на один OnePlus PJD110 (360dp, портрет), проверена страница разрешений. Другие устройства, языки, тёмная тема, короткие экраны и шрифт 1,3× не проверялись. versionCode повышен до 247. Ревизия DSHA остаётся 0.2.1-rc.3, встроенный DSH — 0.2.1-rc.5.
