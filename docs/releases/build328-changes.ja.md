# DSHA 0.2.1-rc.5-20261106.0010-dsh0.2.2-rc.1 / build328

- 0.2.2 環境で `gh` が「managed GitHub CLI is unavailable」となる問題を修正：公式 GitHub CLI v2.103.3（linux-arm64）を 12 番目の固定入力 `gh-cli.tar.gz` として管理対象資産に追加し、インストール時は固定メンバーのみを抽出して SHA-256 を再検証し、`/opt/gh/bin/gh` へ原子的に公開します。ツリー全体の再構築時も管理対象として注入され、ユーザーによる手動インストールに依存しません。
- バイナリが欠落または破損している場合、gh ラッパーは固定 URL と固定ダイジェストから自動導入し、いずれかの手順が失敗すれば fail-closed で停止してコピー可能な復旧コマンドを表示します。「bundled」と称していた誤った案内は削除しました。
- `util/MaintenanceToolPaths` の明示的な契約と、再構築前の有界な事前チェックを追加：`/opt` はユーザーツールとして保持し、`/usr/local/bin` はシステムツリーとして保持せず、`usr/local/share/dsha` は管理対象として注入します。`/opt` が 10 万項目を超える場合は、旧ツリーを移動する前に再構築を拒否します。
- 検証範囲：ホストテスト、contracts 全体、ソース/記述子/第三者通知のゲート。本機での実機検証は未実施です。バージョンコードを 328 に更新（build327 ベース）。APK は同梱する gh アーカイブにより約 13.0 MiB 増加します。
