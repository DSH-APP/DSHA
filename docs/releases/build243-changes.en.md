# DSHA 0.2.1-rc.3-20261101.0450-dsh0.2.1-rc.5 / build243

- Phone portrait fixes: on narrow screens, Stop and Restart on the launch page become two equal-width outlined buttons below the main action; long Web restore notes move to the subtitle so the title only shows a short state. The three readiness rails (runtime / workspace / port) keep their original design.
- The runtime maintenance page no longer embeds the maintenance log box; the failure box already includes the reason, and the full record still opens from View maintenance record. On wide screens the stage card fills the row when there is no note.
- Customize by app no longer shows an empty badge; the language grid picks its column count from width and font scale, dropping to two columns on phones with large fonts; floating-status Maximum lines 1–6 share one row evenly.
- The phone bottom navigation is a true floating opaque capsule over the content; pages keep a bottom inset so the last row can scroll above it. Tablets still use the left rail with the previous bottom inset.
- On phones, the welcome pre-check collapses to one summary row; tap it for architecture, space and WebView. Tablets still show the full grid.
- Pre-deployment check now shows the browser engine and a support verdict: Android 10 or older and non-arm64 cannot deploy; HarmonyOS / Honor-Huawei WebView is marked high-risk with a prompt to update System WebView first. The maintenance failure page and diagnostics reuse the same local summary and can copy it for support. Nothing is uploaded.
- The onboarding permission bar shows only recommended items, without an empty all-7 dot row. The device-command card recommends only Stellar (through the Shizuku compatibility layer); when no manager is installed the main button opens the GitHub Release, and an existing Shizuku still works. Root and ADB stay in Settings. Battery usage opens this app's system App info page (on ColorOS tap Battery usage); DSHA never requests an exemption.
- Onboarding polling no longer redraws the whole permission page when Shizuku/Root status text jitters, and accessibility stays connected through disconnects shorter than 1.5 seconds, reducing card flicker. The completion page lists only the 6 onboarding permissions, without Root, and counts them as x / 6 enabled.
- Verification scope: the test package is overwrite-installed and checked on one OnePlus PJD110 phone (360dp portrait); results follow this build's verification record. No other phones were tested.
- Raises versionCode to 243. The DSHA revision remains 0.2.1-rc.3 and bundled DSH remains 0.2.1-rc.5.
