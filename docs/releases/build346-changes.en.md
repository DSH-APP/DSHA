# DSHA 0.2.1-rc.5-20261109.0700-dsh0.2.2-rc.1 / build346

- Keep screen on and power saving are now hard-exclusive (`d540dfe9d`): new pure-logic `util/PowerModePolicy`; both default off, turning either on forces the other off and syncs persistence, the service and the window flag, while turning one off and repeated enabling never touch the other side; the Settings page uses a sync guard so programmatic `setChecked` cannot recurse, and shows a bilingual toast when it force-disables the other side; on startup a historical double-on state is normalized to Keep screen on and power saving off, quietly, and written back. `PowerModePolicyTest` / `ConfigStorePowerModeTest` cover defaults, non-interference and the startup branch.
- Physical-screen activity history M1 (`19d928f3c`): adds `ScreenActivityFeed` (in-memory ring of about 120 s / 64 events), `ScreenActivityEvent` / `ScreenActivityPolicy` / `ScreenActivityQuery` and `ScreenActivityRecorder`; it records target changes, user taps / scrolls, content changes and assistant actions only while a phone task is active; task end, pause and accessibility service disconnect or reconnect clear it immediately; nothing is written to disk, backups or diagnostics; sensitive apps keep only target changes, password fields only "already entered", and IME / own-overlay events are dropped.
- Results and tool: every `/app/ui/*` JSON result now carries `recentActivity` (at most 3 events since the previous result); a new `GET /app/ui/history?since=<seq>&limit=20` serves incremental reads (default 20, max 100, `since` continues from `nextSince`; M1 returns no images and `frames` is an empty array); the bundled `dsh-computer-use-android` adds the `android_history` tool and `/app/help` is synced. The accessibility config adds `typeViewClicked|typeViewScrolled`; the action executor records `ASSISTANT_ACTION` explicitly and uses a 1.5 s dispatch window to separate user from assistant; execution-time guard semantics (target comparison, credential TTL, confirmation policy) are unchanged.
- Managed-runtime update: changes to `DshaAccessibilityService` / `HttpShellService` / `screen/ScreenActionExecutor` / the new `screen/ScreenActivityRecorder` / the accessibility config and the bundled plugin `server.cjs` recompute `runtime-descriptor` to `7b1ca97d`; fixed inputs stay frozen at the locked 20261105e; the bundled `dsh-web-mobile` stays upstream 3.3.1 and default-enabled.
- Version and scope: versionCode raised to 346 (based on the released build345 / `917295a5a`); the DSHA revision stays `0.2.1-rc.5` with bundled DSH `0.2.2-rc.1`. This batch contains only the two lines above; it does not change the device shell allowlist and does not relax execution-time guards.
