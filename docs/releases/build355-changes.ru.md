# DSHA 0.2.1-rc.5-20261110.1500-dsh0.2.2-rc.1 / build355

- Быстрые действия стартовой страницы собраны в «+»-пузырь верхней панели (T145, `3d03cb12a`): стартовая страница больше не показывает всю карточку быстрых действий (терминал / проверка и обслуживание / адреса доступа); кнопка «+» в верхней панели раскрывает пузырь от якоря (`ui/QuickActionsBubble`). На стартовой странице в пузыре четыре пункта — история загрузок, о DSHA, среда выполнения · проверка и обслуживание, адреса доступа (с подзаголовком «показать локальные адреса и адреса LAN»); на остальных корневых страницах остаются только история загрузок и «о DSHA». Пузырь — это `PopupWindow` (закрывается нажатием снаружи / кнопкой «назад» / повторным нажатием «+», `INPUT_METHOD_NOT_NEEDED`); каждая строка имеет метку `contentDescription=`, фокусируема и использует `selectableItemBackground`, а видимые пункты и порядок задаёт чистая логика `util/QuickActions`. Четыре пункта стартовой страницы разделяют три линии `shell_line`; вне стартовой страницы остаются два пункта, поэтому сохраняется только первая линия. Журнал запуска, кнопки безопасного запуска и восстановления и их id не меняются; вход в терминал по-прежнему остаётся в нижней навигации.
- Страница разрешений устройства упрощена (T146, `e2d8006fc`): с главной страницы убраны четыре обзорные капсулы и фиксированный заголовок; каналы выполнения устройства / операции экрана стали двумя строками-входами, сводки состояния которых берутся из доступных только для чтения предикатов `GrantSummary` (каналы = уровень Root + состояние Shizuku; экран = доступность + пауза + режим подтверждения), а длинные переводы переносятся на строки вместо обрезки при 320dp / шрифте 1,3×. Содержимое прежних карточек перенесено на отдельные страницы `DeviceChannelsFragment` (Root / Shizuku·Stellar / ADB / внешние устройства и уровень перехвата root-команд) и `ScreenOperationFragment` (настройки доступности, режим распознавания экрана, пауза, режим подтверждения и передача конфиденциальных экранов, распознавание виртуального экрана); переключатели, проверка, сопряжение и двойные подтверждения не меняются. `SettingsPanes.open` поддерживает и одну колонку (стек возврата), и две панели (≥840dp продвигает панель подробностей с возможностью возврата); `MainActivity` добавляет заголовки подстраниц «Каналы выполнения устройства» и «Операции экрана»; `GrantsUi` выделен для общих сегментов и элементов раскрытия.
- Управляемая среда выполнения не изменилась: T145 / T146 — изменения интерфейса слоя app и не входят во входы `runtime-descriptor`; объединённое дерево проверяет через `tools/prepare-runtime-descriptor.py --check`, что **`8e54085c`** не меняется (205 входов). Фиксированные входы по-прежнему заморожены на `fixed-inputs-20261105e`, встроенный `dsh-web-mobile` 3.3.5 и его включение по умолчанию не меняются.
- Версия и объём: versionCode повышен до 355 (на основе опубликованного build354 / `cdb2ea51a`); ревизия DSHA остаётся `0.2.1-rc.5`, встроенный DSH — `0.2.2-rc.1`.
