# DSHA 0.2.1-rc.5-20261105.2200-dsh0.2.2-rc.1 / build326

- Исправлено решение об обслуживании после установки поверх: установка поверх, сохраняющая ту же версию DSH и заменяющая только встроенные управляемые патчи, теперь корректно открывает страницу обслуживания среды, а «обновить среду выполнения» снова становится основным действием; «войти в главный экран» больше не перекрывает обновление.
- Если после установки поверх обнаружена неподтверждённая старая веб-сессия, блокируется только «автоматический запуск обновления»; страница обслуживания по-прежнему отображается, и обновление можно запустить вручную одним нажатием — неизвестные экземпляры не воспроизводятся автоматически.
- Объём проверки: тесты хоста, полная группа contracts, 11 целевых тестовых классов и проверки исходников/дескрипторов; выводы на устройстве следуют фактически подтверждённой записи, и успех заранее не записан. versionCode повышен до 326 (на основе build325).
