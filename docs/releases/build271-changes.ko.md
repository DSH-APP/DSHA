# DSHA 0.2.1-rc.3-20261102.1030-dsh0.2.1-rc.5 / build271

- 실험적: 「외부 기기」 기능을 추가했습니다(기본값은 꺼짐). 「설정 → 기기 권한」의 채널 그룹에서 따로 켜면 USB나 무선 디버깅으로 다른 휴대폰을 제어하고, 확인 후 APK·APKS·XAPK·모듈을 설치할 수 있습니다. 설치할 때마다 먼저 확인합니다.
- 플래싱은 읽기 전용 사전 점검과 모의 실행만 하며 실제로 쓰지 않습니다. 이 기능은 허가된 root가 필요하고 이 기기의 ADB나 전역 권한을 물려받지 않습니다.
- 실험적인 기능으로 외부 기기를 연결한 실기기 검증을 아직 하지 않아 제대로 동작하지 않을 수 있습니다.
- 검증 범위: 로컬 단위 테스트와 소스 게이트만 했습니다. 실기기 검증은 하지 않았습니다.versionCode를 271으로 올렸습니다(build270 기반). DSHA 리비전은 0.2.1-rc.3, 내장 DSH는 0.2.1-rc.5로 유지됩니다.
