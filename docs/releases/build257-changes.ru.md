# DSHA 0.2.1-rc.3-20261102.0200-dsh0.2.1-rc.5 / build257

- Исправление файловых блокировок в proroot: среда выполнения движка proroot сообщала о любой ошибке fcntl как об EPERM (нет прав), даже когда блокировку просто держал другой процесс, поэтому инструменты, опирающиеся на межпроцессные блокировки файлов, например Gradle, завершались ошибкой. Слой совместимости теперь возвращает правильный код ошибки: занятая блокировка означает «повторите попытку». Движок proot по умолчанию не затронут.
- Объём проверки: тестовый пакет проверен на одном планшете с Android 16 в режиме proroot зондом блокировки и разговором в веб-интерфейсе; официальный пакет на устройство не устанавливался. versionCode повышен до 257 (на основе build256). Ревизия DSHA остаётся 0.2.1-rc.3, встроенный DSH — 0.2.1-rc.5.
