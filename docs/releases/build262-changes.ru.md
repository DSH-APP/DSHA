# DSHA 0.2.1-rc.3-20261102.0600-dsh0.2.1-rc.5 / build262

- Новый компактный предпросмотр экрана только для чтения: ИИ-ассистенты могут читать полную структуру текущего экрана через /app/sense/state, используя меньше текста, с теми же разрешениями и изоляцией задач, что и прежнее чтение экрана. Метки k*** в предпросмотре служат только для просмотра и не позволяют нажимать; нажатия по-прежнему выполняются через существующие действия с узлами.
- Список действий узла теперь читается один раз за наблюдение и перепроверяется перед выполнением, что уменьшает ошибочные действия после изменения экрана.
- build261 отдельно не публиковался: его Source checks и публикация не прошли, потому что три новых файла не были внесены в список форматирования; исправление вставки в терминал из build261 входит в эту версию.
- Объём проверки: проверка только для чтения на странице системных настроек на устройстве; локальные модульные тесты и проверки исходников пройдены. versionCode повышен до 262 (на основе build261). Ревизия DSHA остаётся 0.2.1-rc.3, встроенный DSH — 0.2.1-rc.5.
