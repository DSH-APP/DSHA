# DSHA 0.2.1-rc.5-20261110.0400-dsh0.2.2-rc.1 / build351

- Privileged physical-screen execution Phase A (T130, `4e8c80e0e`, experimental, off by default): the managed `app_process` privileged Core mirrors display 0 (`VIRTUAL_DISPLAY_FLAG_AUTO_MIRROR`) and captures frames through ImageReader with bounded `maxWidth` 320–1920 / `jpegQuality` 30–90 / `maxFps` 1–10 (defaults 1280 / 60 / 6; near-black frames are tagged `SECURE_OR_BLACK`; frames are never written to disk or logs), and injects the fixed verbs tap / swipe / key (3 / 4 / 66 / 67) — **the path never depends on accessibility**. New `/app/priv/{info,frame,config,tap,swipe,key,benchmark,close}` endpoints plus `PhysicalScreenManager` / `PhysicalScreenCore` / `PhysicalScreenDisplaySession` / `PhysicalScreenLauncher`; an action receipt returns a fresh frame and a fresh observation in one round trip, the credential lives 30 seconds, is single-use and bound to the generation and target package, `EXECUTION_UNKNOWN` is never replayed, and failures are fail-closed with no silent fallback to accessibility. Four gates apply: Settings → Device capability grants → Privileged execution (`privileged_execution_v1`, native grant, off by default, revocable, never restored from backup or environment, closing it drops the Core connection), the current phone-task identity (`taskSessionId` / `turnId` after `/app/ui/task-begin`), a verifiable target package (`PRIV_TARGET_UNVERIFIABLE`), sensitive-app rejection (`PRIV_SENSITIVE_TARGET_UNSUPPORTED`) plus `ScreenConfirmationPolicy.allows`; Phase A shows no per-action native confirmation, so ASK is always `NOT_SENT` (`SCREEN_CONFIRMATION_REQUIRED`) and only "allow all" or a per-app `ALLOW` passes. `/app/priv/benchmark` runs N full action chains and reports App-side `roundTripMs` and Core-side `inputMs` / `frameWaitMs` p50 / p95 / max (nearest rank, no interpolation) with `accessibilityRequired:false`; `waitMs` is 0–500, `n` is 1–20 and `n × (waitMs + 400) ≤ 8000`. Rotation / split screen / resolution changes rebuild the mirror and change `generation`, invalidating all old credentials; the black-frame check is a 48-pixel sampling heuristic for the caller, not content recognition. See `docs/privileged-screen-core.md`; 27 new unit tests cover policy / routes / launcher / manager.
