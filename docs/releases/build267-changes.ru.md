# DSHA 0.2.1-rc.3-20261102.0830-dsh0.2.1-rc.5 / build267

- Экспериментально: исправление «по возможности» для потери интернета в контейнере после переключения на мобильные данные. DNS контейнера записывался только при запуске с серверами текущей сети, поэтому после перехода с Wi-Fi на мобильные данные эти серверы становились недоступны и все запросы имён завершались по тайм-ауту до возврата Wi-Fi. Теперь DNS контейнера обновляется автоматически после смены сети; если разрешение имени всё равно не удаётся, оно выполняется ещё раз через системный резолвер Android (только разрешение, без повторной отправки запросов и без подстановки публичного DNS). Добавлена диагностика только для чтения /app/net.
- Это экспериментальное исправление, и оно не гарантированно работает для всех сочетаний устройства, системы, оператора, VPN или частного DNS; если после смены сети в контейнере всё ещё нет интернета, пришлите вывод /app/net.
- Объём проверки: только локальные модульные тесты и проверки исходников; смена сети на устройстве не проверялась. versionCode повышен до 267 (на основе build266). Ревизия DSHA остаётся 0.2.1-rc.3, встроенный DSH — 0.2.1-rc.5.
