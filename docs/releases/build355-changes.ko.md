# DSHA 0.2.1-rc.5-20261110.1500-dsh0.2.2-rc.1 / build355

- 시작 페이지 빠른 실행을 상단 바「+」버블로 모음(T145, `3d03cb12a`): 시작 페이지는 더 이상 빠른 실행 카드 전체(터미널 / 점검 및 유지보수 / 접속 주소)를 표시하지 않고, 상단 바 오른쪽에「+」버튼을 추가했습니다. 누르면 앵커에서 버블이 펼쳐집니다(`ui/QuickActionsBubble`). 시작 페이지 버블에는 네 항목—다운로드 기록, DSHA 정보, 실행 환경 · 점검 및 유지보수, 접속 주소(「본체 및 LAN 주소 보기」부제 포함)—이 있고, 다른 루트 페이지에는 다운로드 기록과 DSHA 정보만 남깁니다. 버블은 `PopupWindow`이며(바깥 탭 / 뒤로 가기 / 「+」재탭으로 닫힘, `INPUT_METHOD_NOT_NEEDED`), 각 행은 `contentDescription=` 레이블을 가지고 포커스 가능하며 `selectableItemBackground`를 재사용합니다. 표시 항목과 순서는 순수 로직 `util/QuickActions`가 결정합니다. 네 항목 사이에는 `shell_line` 구분선 세 개가 있고, 시작 페이지가 아닐 때는 두 항목뿐이라 첫 번째만 남깁니다. 시작 로그, 안전 시작, 복구 버튼과 해당 id는 그대로이며, 터미널 진입점은 계속 하단 내비게이션이 담당합니다.
- 기기 권한 페이지 간소화(T146, `e2d8006fc`): 홈에서 상단의 네 개 요약 캡슐과 고정 헤더를 제거하고, 기기 실행 채널 / 화면 조작을 두 줄 진입점으로 바꿨습니다. 상태 요약은 읽기 전용 `GrantSummary` 판정(채널 = Root 단계 + Shizuku 상태, 화면 = 접근성 + 일시정지 + 확인 방식)에서 오며, 긴 번역은 320dp / 1.3배 글꼴에서도 말줄임 없이 줄바꿈됩니다. 기존 카드 내용은 독립 페이지 `DeviceChannelsFragment`(Root / Shizuku·Stellar / ADB / 외부 기기 및 root 명령 차단 단계)와 `ScreenOperationFragment`(접근성 설정, 화면 인식 모드, 일시정지, 확인 방식과 민감 화면 인계, 가상 화면 인식)로 옮겼습니다. 스위치, 검증, 페어링, 이중 확인 흐름은 그대로입니다. `SettingsPanes.open`은 단일 컬럼(뒤로 가기 스택)과 이중 창(≥840dp에서 상세 창으로 이동하고 뒤로 가능)을 모두 지원하고, `MainActivity` 상단 바에「기기 실행 채널」「화면 조작」하위 페이지 제목을 추가했으며, 공용 세그먼트와 접기 구성 요소를 `GrantsUi`로 추출했습니다.
- 관리 런타임 불변: T145 / T146은 모두 app 계층 UI 변경이며 `runtime-descriptor` 입력이 아닙니다. 병합 트리는 `tools/prepare-runtime-descriptor.py --check`로 **`8e54085c`**가 변하지 않았음을 검증합니다(205개 입력). fixed-inputs는 고정된 `fixed-inputs-20261105e`를 그대로 사용하며, 번들 `dsh-web-mobile` 3.3.5와 기본 활성화도 그대로입니다.
