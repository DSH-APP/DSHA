# DSHA 0.1.5-rc2 · 构建 122 修订

修复英文启动日志遗漏和环境维护横幅误报，增加不依赖 Web 的原生启动恢复页。dsh 保持 **0.1.5-rc.2**，Ubuntu 基础环境保持 **10**，版本码由 121 升至 **122**；两个 APK 名称保持用户指定的 rc2 名称。

## 修复原因与行为

- **维护横幅**：原实现将 `EnvironmentTaskGate` 的任何占用都显示为“环境维护进行中”。启动 Web、读取插件清单、启动终端也会使用该锁。现在只显示真实数据维护任务，显示实际任务名称；等待确认恢复备份有独立提示。执行门禁和运行进程保护继续保留。
- **英文日志与阶段**：原日志在产生时已拼成中文，页面切换语言没有重新渲染；容器观察器的配置检查和加载阶段也未接入语言。现在区分应用事件和原始输出，应用事件按当前语言显示，历史记录保留中英文版本。进程退出码、配置检查、插件加载和等待鉴权均已覆盖；命令输出、第三方异常和用户内容保持原文。
- **自动启动恢复**：明确的配置/插件启动错误、启动进程退出或连续故障会进入原生恢复页。鉴权等待时间长仍继续等待，不因超时自动终止或更改配置。恢复按钮可手动进入；WebView 和 Gecko 的明确启动失败也可转入原生恢复。

## 恢复能力

- 最近 **五次启动记录**：时间、阶段、耗时、状态和脱敏输出；失败证据不被后续成功重试覆盖，并包含在日志导出中。
- 最近 **三份健康启动配置快照**及 **三份修复前快照**：仅捕获 Web profile 的 `package.json`、`cordis.patch.yml`、`pnpm-workspace.yaml`、`pnpm-lock.yaml`，以及 DSH home 的 `settings.yaml`、`cordis.patch.yml`。每个文件上限 4 MiB；固定路径有界读取，不遍历工作区、会话或依赖树，不复制 `.env` 或凭据文件。
- 健康快照先在启动前捕获，完整界面就绪后核对代次和配置内容仍一致再保存；安全启动不替换普通配置快照。用户按具体快照与编号恢复，恢复后的下一次健康启动跳过轮换一次。
- 可新建 Web 基础启动配置、共享设置或共享补丁。先保存原文件，再写入默认内容。插件、会话和原生 API Key 保持原位。
- 无须启动 Host 即可查看并卸载第三方插件；使用现有插件管理器核验结果，官方核心和内置插件不能从此卸载。
- 修复和卸载通过应用级 `BackupTask`，先停止 Web、关闭所有终端、核验进程并取得 `RuntimeTasks` 维护屏障。快照有摘要校验；配置写入有修复前副本与中断日志，失败回退，未确认完成时阻止启动。恢复配置不会自动下载已卸载的插件。

参考 [DSH Desktop 的配置快照设计](https://github.com/anywhere-labs/dsh-desktop/blob/63e160ab4387988db894adef766865eab897cf80/dsh-plugin-desktop/src/profile-checkpoint.ts)及[恢复控制器](https://github.com/anywhere-labs/dsh-desktop/blob/63e160ab4387988db894adef766865eab897cf80/dsh-plugin-desktop/src/startup-recovery-controller.ts)的独立恢复入口、健康快照轮换和用户选择后修复思路；按照安卓现有离线插件管理器和进程维护契约实现。

## 验收

- 标准版和兼容版均在 Android 13 / Redmi M2012K10C / arm64 的**非调试插桩包**上通过 **52 项检查**。覆盖真实启动后切换英文、旧日志无应用中文残留、普通任务锁不显示维护横幅、WebView 116 / Gecko 143 完整界面就绪后保存快照、损坏配置自动进入恢复、精确快照恢复、新建设置、恢复页真实卸载测试插件、修复后英文启动成功及失败记录保留。测试配置逐文件还原，测试记录与插件清理；未发送模型推理请求。
- 配置快照 Python **7 项**通过：固定槽位轮换、未纳入用户数据、摘要和过期快照拒绝、文件原先不存在的恢复语义、中断日志回退、注入写入失败回退、配置与启动代次一致性。
- Android Ubuntu 内额外验证：拒绝软链接和 FIFO、SHA 恢复、私有文件权限、中断回退及凭据文件保留。
- 启动观察器回归通过：中英文配置清单和加载阶段、真实缺失导入和异常、只执行一次、浏览器加载错误与就绪事件。观察/翻译错误不改变 Loader 的执行结果。
- 两版各 **360 项单测：359 通过、1 跳过、0 失败**；Lint 无错误。发布签名、122 版本码、arm64 架构、16 KiB ZIP 对齐和恢复资源核验通过，无调试插桩入口；Ubuntu 基础包及宿主原生库与既有版本一致。
- 新恢复页与英文日志已在真机截图核对。本轮未使用 Android 6/7 实机或真实 16 KiB 页内核。测试机副本沿用其原签名保留数据，交付 APK 使用既有发布证书。

本修订保留 Agent 预设真实切换与顶部对齐、多终端和中英文设置；此前功能验收见[构建 121 记录](v0.1.5-rc2-build121.md)。
