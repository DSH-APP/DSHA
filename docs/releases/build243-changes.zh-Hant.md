# DSHA 0.2.1-rc.3-20261101.0450-dsh0.2.1-rc.5 / build243

- 手機直向修訂：啟動頁「停止 / 重新啟動」在窄螢幕改為主按鈕下方兩枚等寬描邊按鈕；Web 恢復核對的長說明移到副標題，大標題只顯示短狀態。三段就緒軌道（執行環境 / 工作台 / 實際連接埠）維持原設計。
- 執行環境維護頁不再內嵌「本次維護記錄」日誌框，失敗說明框已含原因，完整記錄仍從底欄「查看本次維護記錄」開啟；寬螢幕無說明時階段卡佔滿整行。
- 螢幕操作「按應用自訂」不再顯示空白標籤；介面語言網格依寬度與字型縮放決定欄數，大字型手機退為兩欄；懸浮條「最多顯示行數」1–6 在一行內等分。
- 手機底部導航改為真正疊在內容上的不透明懸浮膠囊；頁面底部留出膠囊高度，最後一行可滾出膠囊上方。平板仍用左側導航，頁底餘量不變。
- 手機歡迎頁把六格檢查收成一行摘要，點開看架構、空間與網頁核心；平板仍顯示完整格子。
- 首次引導「部署前檢查」增加網頁核心與支援結論：Android 10 及以下或非 arm64 無法部署；鴻蒙/榮耀自研 WebView 標高風險並提示先更新系統 WebView；維護失敗頁和自檢复用同一段本機摘要，可複製給支援。不聯網上報。
- 引導授權頁進度條只顯示推薦項，不再混入「全部 x / 7」空心點；裝置命令通道在引導裡只推薦 Stellar（走 Shizuku 相容層），未安裝時主按鈕開啟 GitHub Release，已有 Shizuku 仍可用；Root 與 ADB 只放在設定頁。電池最佳化入口改為開啟本應用系統「關於」頁（ColorOS 上再點「耗電管理」），不自動申請豁免。
- 引導授權頁輪詢不再因 Shizuku/Root 文案抖動整頁重繪，無障礙短暫斷線 1.5 秒內維持已連線，減輕卡片閃爍；完成頁「授權」只列引導裡的 6 項，不再顯示 Root，計數改為「已開啟 x / 6」。
- 驗證範圍：在一台 OnePlus PJD110 手機（360dp 直向）上覆蓋安裝測試包驗收，結果以本版驗證記錄為準；未在其他手機上測試。
- 版本碼提升為 243；DSHA 修訂號維持 0.2.1-rc.3，內建 DSH 為 0.2.1-rc.5。
