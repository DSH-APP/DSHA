修复新连接平板的旧环境升级失败，同时完善平板宽屏下的预设与文件入口。版本码 **128**；dsh **0.1.5-rc.2**，Ubuntu 基础环境仍为 **10**，内置移动插件为 **2.4.1-dsha.2**。沿用原发布签名、包名和交付文件名。

## 平板升级失败

实机：Xiaomi M367FC，Android 17 / API 37，arm64，4 KiB 内存页。

平板安装了构建 127，但保留着基础环境 9。升级到基础环境 10 的个人文件保护阶段失败，记录显示：

```text
Permission denied:
/run/dsha-maintenance-root/data/user/0/com.dsh.client/files/linux/ubuntu/.l2s
```

该路径是 proot 为宿主绝对路径映射创建的运行时挂载占位，并非个人文件。旧逻辑把它纳入 `/data` 遍历，触发权限拒绝；快速迁移探针只检查了 `/root` 是否存在，无法证明完整遍历可用。失败发生在切换环境前，原数据与已生成的安全备份均保留。

本次修复：

- 在读取/遍历前精确排除运行时 `.l2s` 占位，覆盖 `/data/data`、不同 Android 用户的 `/data/user` 路径；不粗略排除整个 `/data`，真实个人文件权限错误仍会中止迁移。
- 模拟硬链接按独立 rootfs 与 guest 路径解析，把有效文件内容写入归档；兼容旧宿主绝对路径、映射路径和相对路径，并拒绝循环、越界及外部挂载。
- 个人文件迁移预先选择 proot，和其他 Python 维护脚本保持一致，不在数据读写结果未知后自动切换通道重放。Web 的运行方式仍保留用户配置。
- 重新打开维护页时显示上次失败原因，不再只给出通用说明；已就绪环境不会因此重新迁移。

已在这台平板完成实际基础环境 **9 → 10** 升级，恢复与校验个人目录、工作区、配置、会话及第三方插件，环境身份为 `128:10:0.1.5-rc.2`。普通启动成功，旧会话能够打开。升级安全备份保留在应用私有目录：

```text
files/maintenance/03cd80c0-0673-4c1a-bc89-0ddeaf441772/safety.tar.gz
```

## 平板顶栏

之前的按钮修饰和布局调整只覆盖 ≤1023px 的窄屏。平板横屏下，原标签改成按钮后露出浏览器默认边框，预设仍靠左；移动插件的桌面隐藏规则同时隐藏了文件夹入口。

- 预设模块自身加载基础按钮样式，清除默认边框，保留键盘操作的可见焦点提示；不依赖移动插件是否处于窄屏模式。
- 触屏会话顶栏将操作区推到右侧。宽屏触控下，预设与文件夹按钮相邻，文件按钮保留 44px 触摸区域。
- 文件按钮调用原有 `sidebarRight.openTab('files')`，实际打开文件面板。保留上游其他顶栏入口和鼠标桌面的移动控件隐藏规则。
- 预设仍通过锁定 Host 确认，不修改既有切换/新建会话规则。
