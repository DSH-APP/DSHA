# DSHA 0.2.1-rc.3-20261102.0400-dsh0.2.1-rc.5 / build258

- 부팅 로딩 화면과 앱 아이콘에서 Web으로 바로 이동: 「설정 → 실행 구성」 또는 Web 플러그인 상세의 내장 플러그인 dsh-launch-target에서 앱 아이콘으로 실행할 때 메인 화면과 Web 중 무엇을 열지 고를 수 있습니다(기본값은 메인 화면). Web을 고르면 먼저 부팅 로딩 화면이 나타나고 환경이 준비되면 Web이 열립니다. Web에서 계속 뒤로 가면 홈 화면으로 돌아갑니다.
- 유지 관리, 시작 복구, 처리 대기 중인 플러그인 링크가 있을 때는 여전히 메인 화면을 먼저 열며, 알림이나 작업 카드에서 돌아올 때는 Web으로 바로 가지 않습니다. 이 선택은 이 기기에만 저장되고 백업되지 않습니다.
