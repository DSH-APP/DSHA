## 2. 本版内容

来自分支 `ui-v5-scheme-a`（22 个提交，基于 `fa9b505`）并合入 build220（`84db710`）后快进到 `main`。逐条说明见 [build242 更新说明](build242-changes.zh.md)。主要包括：

- 设置 / 插件 ≥840dp 左列表右详情，维护页两列，启动主页按原型重排，设置子页平铺分组，多句静态说明收进 ⓘ。
- 设备能力授权：全局权限、放宽 root、屏幕操作「全部允许」前的红色确认（点空白不关闭、「取消」在最右）；放宽 root 另需 10 秒等待与三项知情勾选；风险分级卡片；屏幕操作应用选择器；虚拟屏单独成行。
- 启动活动条改为 M3 形态波浪进度条（就绪时压平为实线，不显示百分比）。
- 悬浮条页紧凑化并即改即存；界面语言「跟随系统」+ 母语名网格；技能页由独立 Activity 改为设置子页 `SkillsFragment`，按页面宽度单列 / 并排。
- 新增约 70 条界面文案并补齐十语目录（`uiv5a001`–`uiv5a072`，部分已撤销）。

## 3. 设备验证（仅平板）

- 设备：联想平板 TB321FU（单台）。横屏内容宽度约 1024dp，竖屏约 640dp。
- 方式：本地构建 `assembleStandardDebug`（测试变体），测试证书签名后 `pm install -r` 覆盖安装到 `io.github.sunsetrne.dsha.test`；未卸载、未清数据。未安装正式包 `io.github.sunsetrne.dsha`。
- 横屏：助手经截图核对了设置 / 插件双栏、维护页两列、启动主页、ⓘ 弹窗、详情内返回、插件搜索联动、Root 档位卡片。
- 竖屏：由用户截图反馈并据此修正了全局权限确认框、屏幕操作板块、波浪活动条（含重影修复）、悬浮条页、语言选择（含 Français 被截断修复）。
- **未在设备上看过**：技能页新布局与底部弹层、屏幕操作应用选择器的搜索与编辑流程、Root 档位从「下一步」接入第二步确认的完整路径、十种语言中除中文外的实际显示。
- **未在手机真机上测试**。手机竖屏仅有下面第 4 节的 Robolectric 布局回归，不代表真机渲染、触控或系统字体缩放下的表现。

## 5. 已知限制

- 「取消」放在最右是高危确认框的专用规则，与 App 内普通确认框的按钮顺序相反。
- 三项知情勾选只是产品层面的风险确认，不构成法律意义上的免责条款。
- 拉丁语在部分系统上缺少语言显示名，语言选择格的副标题可能为空。
- 设备授权页依赖较多系统服务，未纳入手机竖屏布局回归。
