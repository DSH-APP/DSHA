# DSHA 0.2.1-rc.3-20261031.2130-dsh0.2.1-rc.5 / build219

- build218 の初回ガイド再構成を完了：4 ステップ（ようこそ → 用途 → 権限 → 完了）、バックグラウンド配備カプセル、全画面の実行環境メンテナンスページ。初回配備と上書き更新は同じメンテナンス入口を使います。
- 実機フィードバックの修正：ガイド内のバックグラウンド配備がシステムに回収された場合は元のステップに戻る。「用途」の選択が推奨項目を実際に決める。バッテリーカードはシステムの「バックグラウンド使用を許可」状態で判定する。Stellar の分身構成では実際のマネージャーの権限カードを表示する。
- Stellar マネージャーを検出したとき、端末権限ページとガイドカードは実際のマネージャー名を統一して使い、旧名を固定表示しない。
- バッテリー最適化の入口はこのアプリのバッテリーページを直接開く。カードとボタンの文言は「バックグラウンド使用を許可」の意味に合わせる。
- 上書き更新は全画面メンテナンスページに戻る。ディスクに未完了の隔離トライアルまたはメンテナンストランザクションがある場合は、先に古いトライアルプロセスの終了を確認して現場を閉じ、それからメンテナンス/更新に入る。失敗が確定した更新は開始しない。
- 幅広タッチ（タブレット横向き / CSS ≥1024px）のセッション行は、アーカイブ/ピン留めを ⋯ メニューに収納する。280px サイドバーでタイトルが約 55px まで圧縮される問題を修正し、行内は「時刻 + ⋯」だけにする。同梱の dsh-web-mobile にはローカル先行パッチがあり、上流 PR #256 のマージ後に外す。
- versionCode は 219 に、DSHA リビジョンは 0.2.1-rc.3、同梱 DSH は 0.2.1-rc.5 のまま。ビルドと受け入れはこの CI run と Release 受領書に従い、今回の実機上書きインストール受け入れは主張しない。
