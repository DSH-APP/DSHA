# DSHA 0.2.1-rc.3-20261031.2130-dsh0.2.1-rc.5 / build219

- build218의 첫 실행 안내 재구성을 마무리: 4단계(환영 → 용도 → 권한 → 완료), 백그라운드 배포 캡슐, 전체 화면 실행 환경 유지보수 페이지. 첫 배포와 덮어쓰기 업데이트는 같은 유지보수 진입점을 사용합니다.
- 실기기 피드백 수정: 안내 내 백그라운드 배포가 시스템에 회수되면 원래 단계로 돌아감. '용도' 선택이 추천 항목을 실제로 결정. 배터리 카드는 시스템의 '백그라운드 사용 허용' 상태로 판정. Stellar 복제 구성은 실제 관리자 기준 권한 카드를 표시.
- Stellar 관리자가 감지되면 기기 권한 페이지와 안내 카드가 실제 관리자 이름을 사용하며, 예전 이름을 고정 표기하지 않음.
- 배터리 최적화 진입점은 이 앱의 배터리 페이지를 바로 엶. 카드와 버튼 문구는 '백그라운드 사용 허용' 의미로 변경.
- 덮어쓰기 업데이트는 전체 화면 유지보수 페이지로 복귀. 디스크에 미완료 격리 시험 또는 유지보수 트랜잭션이 있으면 먼저 이전 시험 프로세스 종료를 확인하고 현장을 닫은 뒤 유지보수/업데이트로 진입하며, 실패가 확정된 업데이트를 시작하지 않음.
- 넓은 터치(태블릿 가로 / CSS ≥1024px) 세션 행은 보관/고정을 ⋯ 메뉴로 접음. 280px 사이드바에서 제목이 약 55px로 눌리는 문제를 수정하고 행 안에는 '시간 + ⋯'만 남김. 내장 dsh-web-mobile에는 로컬 선행 패치가 있으며 업스트림 PR #256 병합 후 제거.
- versionCode는 219로, DSHA 개정은 0.2.1-rc.3, 내장 DSH는 0.2.1-rc.5로 유지. 빌드와 수용은 이번 CI run과 Release 영수증을 따르며 이번 라운드는 실기기 덮어쓰기 설치 수용을 주장하지 않음.
