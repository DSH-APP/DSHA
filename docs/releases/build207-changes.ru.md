# DSHA 0.2.1-rc.3-20261029.1500-dsh0.2.1-rc.3 / build207

- Добавлены три режима перехвата root-команд: строгий (по умолчанию, только белый список), мягкий (любые команды, но необратимые операции — форматирование, прошивка, перезагрузка, очистка данных — блокируются) и полный (без проверки содержимого команд); переключение в «Настройки → Разрешения устройства».
- Мягкий и полный режимы действуют только для канала root. Общий исполнитель Shizuku/ADB остаётся строгим, а чтение SMS требует нативного разрешения во всех трёх режимах.
- Исходные root-команды выполняются в привилегированном процессе с тайм-аутом, ограничением вывода 256 КиБ и проверкой идентичности исполнения. В строгом режиме также блокируется рекурсивное удаление корней хранилища и каталогов первого уровня.
- Это тестовая идентичность SunsetRNE (не E7E3) с фиксированной тестовой подписью. Проверка охватывает только установку на этом телефоне и три режима root; все ROM и модели устройств не покрыты.
