# DSHA 0.2.1-rc.3-20261030.1900-dsh0.2.1-rc.5 / build213

- 내장 DSH를 업스트림 dsh-v0.2.1-rc.5로 업그레이드했습니다. 대화 thinking 표시가 업스트림 변경을 따릅니다. 런타임 아카이브는 rc.5 기준으로 재빌드했고(127,674,426 B, SHA-256 `91aa4685721ce569e32953295dc6b01b63fe2ac5e1eac8173440656896acdcb2`), 패치 체인과 31개 data/storage 읽기 패키지를 확인했습니다. 증거는 [rc.5 데이터 읽기 증거](../runtime-data-compatibility-rc5.md)에 있습니다.
- 터미널에 DSH CLI 진입점을 추가했습니다. 워크스페이스 상단 바 버튼과 "새 세션" 선택기에서 고정 시작 안내가 있는 PTY 세션을 바로 열 수 있습니다(dsh 버전을 미리 확인하고, 대화형 TUI가 없다는 점, headless의 자격 증명/권한 차이, 터미널에서 Web을 시작하지 말아야 한다는 점을 설명합니다). 세션 유형은 추가하지 않으며 세션 종료, 실행 보호, 유지 보수 장벽의 의미는 그대로입니다.
- 휴대폰 세로/좁은 창(< 600dp)에서 터미널 세션 드로어의 최대 너비를 336dp에서 224dp(약 1/3)로 줄였고, 태블릿/넓은 창(≥ 600dp)은 336dp를 유지합니다. 스크림/뒤로 가기 제스처 영역은 최소 32dp를 그대로 두며, 인라인 사이드바 너비는 바뀌지 않습니다.
- 224dp 드로어에서는 세션 행이 기존 좁은 창 규칙대로 상태를 세로로 쌓고 하단 작업은 두 열을 유지합니다. 낮은 창/가로 모드 압축 규칙은 그대로입니다.
- versionCode를 213으로 올렸습니다. DSHA 리비전은 0.2.1-rc.3이며 내장 DSH 접미사는 0.2.1-rc.5입니다. 빌드와 검증 범위는 이번 run과 Release 기록을 따릅니다.
