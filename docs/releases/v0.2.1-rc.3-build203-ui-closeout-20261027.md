- **物理屏语义滚动被遮挡判定拒绝（新发现，建议修）**：`/app/ui/node?action=scroll_forward` 稳定返回 `NODE_SCROLL_REGION_UNAVAILABLE`，`/app/ui/screenshot` 返回 `TARGET_WINDOW_OCCLUDED`。原因是 `MainScreenWindowPolicy.region()` 把整窗标成 `obscured`：ZUI Taskbar 的窗口是 `125..1475 × 2530..2560`（居中、非全宽，过不了 `edgeChrome` 的全宽条件），加上 `com.zui.game.service` 的 75×160 边缘浮层 `(0,1771)-(75,1931)`。`ScreenWindowRegion.hasUnexcludedArea()` 见 `obscured` 直接返回 false，于是任何整窗应用的语义滚动都会失败。建议把遮挡判定落到目标节点矩形（并与实际遮挡区求差），或让居中的系统栏也按 edge chrome 裁切。
