- 플러그인 카드의 「설정 / 현재 Web」 상태 캡슐 배경 표시 문제 수정(`93af9944d`): 작은 캡슐 배경이 기존 `shell_*_soft`(8% 불투명)라 흰 카드에서 캡슐이 거의 보이지 않고 글자색만 바뀐 것처럼 보였다. 같은 색상 계열의 18% 채움(`BADGE_FILL_ALPHA = 0x2E`, `toneColor`에서 alpha 합성)으로 바꾸고, 중립은 `shell_raised`를 유지하며 재시작 대기 경고 캡슐도 함께 진하게 했다. 표시만 바꾸며 캡슐 톤 매핑과 상태 판정은 바꾸지 않는다.
- 캡슐 문구를 첫 화면에서 ≤4자로 축약: 설정 쪽은 「사용 중 / 사용 안 함 / 켜기 가능 / 누락 / 오류 / 임시 / 처리 중」 등 결론 단어만, 현재 Web 쪽은 「로드됨 / 로드 중 / 로드 실패 / 서비스 대기 / 로드 안 됨 / 미확인」만 표시한다. 전체 상태와 로드 이력은 `contentDescription`으로 옮겨 접근성에 제공하고 캡슐에는 넣지 않는다.
