# DSHA 0.2.1-rc.3-20261030.1506-dsh0.2.1-rc.3 / build212

- 최초 복구를 3상태 판정으로 변경: 원래 Web이 살아 있으면 다시 연결하고, Web과 런처가 모두 종료된 것이 확인된 경우에만 이전 기록을 정리하고 시작을 계속하며, 확인할 수 없으면 보호를 유지합니다.
- 종료가 확인되면 암호화된 인스턴스 기록과 이전 PID 기록을 함께 폐기해 다음 실행이 "확인 대기"에서 멈추지 않습니다.
- 이전 인스턴스를 확인하는 동안 시작을 누르면 이번 의도를 기록하고 완료 후 한 번만 자동으로 이어갑니다. 중지, 새 세대, 이미 다시 연결된 경우에는 중복 시작하지 않습니다.
- 신원이 확인되었고 인증이 일시적으로 실패하면 최대 3회 재확인합니다(500ms/1500ms 유한 대기). 그래도 통과하지 못할 때만 미확인 상태를 유지합니다.
- 시작 페이지는 이유별로 복구 연결, 런처 종료 중, 기록 읽기 불가, 인증 일시 불가 등의 상태와 진입점을 표시하며, 확인 중에는 시작 버튼이 비활성화되지만 재시작/안전 시작 진입점은 계속 눌러 이번 시작 의도를 기록하고 확인 완료 후 한 번 자동으로 이어갑니다.
- versionCode를 212로 올렸습니다. 빌드와 검증 범위는 이번 run과 Release 기록을 따릅니다.
