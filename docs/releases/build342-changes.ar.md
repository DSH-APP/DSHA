# DSHA 0.2.1-rc.5-20261108.0900-dsh0.2.2-rc.1 / build342

- ثلاثة أشكال لردّ اللمس (A1 / C1 / C2، `99c971d6c`): الصفوف القابلة للنقر تحصل على طبقة حالة فقط (المحتوى والتخطيط بلا تغيير)، والأزرار الرئيسية تتقلص إلى 0.985 عند الضغط، والبطاقات الكبيرة تُحوّل زاوية الحافة من 18 إلى 22dp؛ وعند إيقاف حركات النظام يصبح كل شيء ثابتًا، ولا تدخل الأزرار المعطلة في إيماءة التصغير. يضيف `UiMotion` تدوير الأرقام وتحويل الحافة وتلاشي المناطق. تم توصيل 25 شاشة: الأزرار والصفوف المشتركة في `OnboardingKit` / `CardPage` وتذييل `CardSheet` و`attachButtons` على جذور 25 شاشة (البدء / الإعدادات / أذونات الجهاز / النسخ الاحتياطي / التثبيت والصيانة / التحديث / التشخيص / الإضافات / الشاشة الافتراضية / الطوارئ / الاستعادة / الملفات وغيرها؛ وتُستثنى منطقة اللمس المخصصة للطرفية وWebView).
- أزرار تحميل مضمّنة `LoadingAction` (A2، `2d261ff4f`): يظهر دوّار حقيقي 16dp يسار الزر، ويُثبَّت العرض المقيس أثناء الانشغال وتُعطَّل النقرات ويُكتب `stateDescription`، وعند الانتهاء يعود النص والعرض الأصليان. يُرفض `start` المتكرر، ويعيد `run()` المتزامن الحالة حتى عند الاستثناء، وتظهر قوس ثابتة عند إيقاف حركات النظام. النسخ الاحتياطي بنقرة واحدة يعرض الدوّار المضمّن ويثبّت العرض عند بدء المهمة الحقيقية؛ أزرار النشر/الصيانة تكون مخفية أصلًا أثناء الانشغال ولها منطقة تقدّم مستقلة، فلا تُضاف حالة تحميل زائفة.
- تدوير الأرقام وتلاشي الحالات (E5 / G4، `3bbae9e68`): يتذكر `RollingNumber` القيمة السابقة ويتدحرج إلى الجديدة، وتبقى الوحدة مع formatter، وتُثبَّت القيمة مباشرة عند إيقاف الحركات؛ ويكتب `FadeSwap` النص أولًا ثم يجعله يظهر، ويتلاشى محتوى المنطقة 90ms ثم يُعاد بناؤه ويظهر 150ms، ويُحتفظ فقط بآخر تحديث متتالٍ. يتدحرج إجمالي صفحة التخزين من القيمة السابقة؛ وتُبدَّل حالات مساحة العمل والنسخ التلقائي وترويسة الصيانة عبر FadeSwap.
- مستويات البطاقات وشارات الحالة (H1 / H2، `055b400c4`): ثلاثة مستويات — elevated رئيسية (surface + حافة رقيقة + رفع 1dp)، filled للمجموعات (خلفية صلبة بلا حدود)، outlined ثانوية؛ وتُوحَّد المجموعات على filled، ويتيح `CardPage.card(Tier)` للصفحة اختيار المستوى صراحة. الشارات (>99 تظهر 99+) ونقاط الحالة تستخدم رموز `shell_*` فقط ويمكن تغيير لونها في العنصر نفسه؛ بطاقة حالة مساحة العمل elevated، ونقطة النسخ التلقائي تتغير بلون المفتاح، وشريط التحديد المتعدد يستخدم شارة عدد. بطاقات التحديد وشريط التحديد المتعدد (D1 / D2 / H3، `708206da3`): `SelectableCard` للتحديد المفرد حافة 2dp + صبغة + علامة، وللمتعدد مربع اختيار؛ وتخفي الخلايا المدمجة العلامة لمنع الاقتطاع، ويعلن قارئ الشاشة `radio` / `checkbox` checked. يعرض `SelectionActionBar` شارة العدد والإجراءات، ويطوي العدد عند صفر عناصر دون إزاحة الشريط. وُصلت خلايا اللغة ودرجة معاينة الشاشة الافتراضية (تحديد داخل البطاقة بدل حوار الاختيار) وبطاقات نطاق التصدير؛ وانتقلت النسخ المحفوظة والبيئات القديمة إلى شريط سفلي متعدد التحديد (العدد + تحقق + تحديث / إلغاء).
