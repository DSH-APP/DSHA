# DSHA 0.2.1-rc.3-20261101.0306-dsh0.2.1-rc.5 / build242

- UI v5 방안 A를 통합했습니다. 설정과 플러그인은 너비 840dp 이상에서 왼쪽 목록·오른쪽 상세로 바뀌고, 유지 관리 화면은 2열, 시작 홈은 프로토타입대로 다시 배치했습니다. 설정 하위 페이지는 평면 그룹으로 바꾸고, 여러 문장의 고정 설명은 첫 문장만 남기고 전체 내용은 ⓘ 대화상자로 옮겼습니다.
- 기기 권한: 전역 권한 켜기, root 차단 완화, 화면 조작 '모두 허용' 전에 빨간 확인 창을 띄웁니다. 바깥을 눌러도 닫히지 않고 '취소'는 맨 오른쪽에 있습니다. root 완화에는 10초 대기와 세 가지 확인 체크가 추가로 필요합니다. root 단계와 화면 확인 방식은 위험도별 카드로 바뀌었고, 화면 조작에 앱 선택기를 추가했으며 가상 화면은 별도 행으로 분리했습니다.
- 시작 활동 막대를 물결 진행 막대로 바꿨습니다. 진행 중에는 물결 구간이 트랙을 따라 움직이고, 완료되면 끝까지 채워지며 직선이 됩니다. 실제 상태만 표시하고 백분율은 보여 주지 않습니다.
- 플로팅 바 설정은 간결한 행으로 줄이고 변경 즉시 저장합니다. 화면 언어는 '시스템 따르기'와 언어 이름 그리드로 바꿨습니다. 스킬은 설정 하위 페이지가 되었고 페이지 너비에 따라 한 열과 좌우 배치를 전환합니다.
- 새 화면 문구를 10개 언어로 모두 번역했습니다. 휴대폰 세로(360dp)와 넓은 화면의 Robolectric 레이아웃 회귀 테스트, 언어 선택 작은 화면 사례를 추가했습니다.
- 검증 범위: 테스트 패키지는 Lenovo 태블릿(TB321FU) 한 대에서만 덮어 설치하고 확인했으며, 가로·세로 모두 스크린샷으로 확인했지만 모든 변경을 기기에서 본 것은 아닙니다. 실제 휴대폰에서는 전혀 테스트하지 않았습니다. 휴대폰 세로는 Robolectric 레이아웃 회귀만 있으며 실제 기기 렌더링을 보장하지 않습니다.
- versionCode를 242로 올렸습니다. 테스트 패키지 누적 덮어 설치 횟수(220 + 22)를 기준으로 했고 221–241은 따로 출시하지 않았습니다. DSHA 리비전은 0.2.1-rc.3, 내장 DSH는 0.2.1-rc.5입니다. 전체 빌드, 단위 테스트, 서명, 게시 범위는 이번 CI / Release 기록을 따릅니다.
