## 2. 改动

- 实验性：root helper 并发上限为 3；超时、App 退出和覆盖安装时自动回收，超出槽位返回 `ROOT_BUSY`；ADB 探活不再把 Root/Shizuku 服务误判为 ADB；覆盖安装快照在广播内及时写入，并记录 root-busy 与 package-replaced 证据。
- 安全修复：备份与导出排除 `.dsh/adbkeys`；恢复 build303 及以前的旧归档时不落地其中的 ADB 配对密钥；本机环境重建保留当前设备配对。
- 实验性：设备命令与虚拟屏共用 `DeviceChannelOrder`（Root → Shizuku → ADB，Android 17 上 ADB 已验证连接时先于 Shizuku）；设备命令分严格与已授权两档各选一次，执行失败不换通道重放；ADB 路径新增局域网授权前提。
- 修复：Web 页并入 Main 同一任务（singleTop + REORDER_TO_FRONT），桌面/自由窗口下不再出现两个窗口；已有存活宿主时转交请求。
- 实验性：签名内置临时修复插件 `dsh-fs-search-scope`：glob 剪掉 `.agents/worktrees` 与已登记链接工作树，策略校验顺序不变，停用即恢复上游；`dsh-runtime.bin` 按锁重建，固定构建输入切到 `fixed-inputs-20261103c`。
- 文档：T42 ADB 通道原生化设计稿补充 Q1–Q9 决定与 E1–E4 只读取证结论；原生 ADB 客户端实现仍未开始。
