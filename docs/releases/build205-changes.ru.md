# DSHA 0.2.1-rc.3-20261027.1312-dsh0.2.1-rc.3 / build205

- Вставка в терминал использует ограниченную очередь ввода FIFO; вставка с маркерами поступает одной записью. При заполнении очереди последующий ввод приостанавливается до подтверждения; неотправленные данные автоматически не повторяются.
- При неизвестном результате запуска виртуального экрана сохраняются разрешённые коды диагностики. Диагностика не доказывает завершение удалённого процесса и не снимает защиту для неизвестного результата.
- Действия управления телефоном привязаны к цели последнего успешного наблюдения экрана. При смене цели или начале нового наблюдения нужны свежие данные; устаревшее наблюдение не восстанавливает разрешение на действие.
- Если DNS устройства доступен, переносится только прежняя стандартная конфигурация DNS, точно совпадающая побайтно. Изменённые пользователем настройки и прежняя конфигурация при недоступности DNS устройства сохраняются.
- Расширены регрессионные сценарии восстановления потоков сеанса и рабочего пространства, проверки загрузки и сжатых ответов. Эти сценарии не подтверждают проверку на телефоне или перезапуск реального сервера.
- Сохранены dsh-web-mobile 3.2.2, DSH rc.3, локальный доступ и доступ по LAN, а также десять языков. Проверка на телефоне остаётся приостановленной.
