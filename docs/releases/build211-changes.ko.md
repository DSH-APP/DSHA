# DSHA 0.2.1-rc.3-20261030.1245-dsh0.2.1-rc.3 / build211

- 플러그인 페이지 진행 표시줄을 F 안으로 변경: 불확정 상태는 호흡, 확정 상태는 흐르는 빛이며 진행률은 실제 percent만 따릅니다.
- 성공하면 초록색 100%를 700ms 유지하고, 실패하면 이번 작업에서 본 최대 진행률 위치에 빨간색으로 900ms 유지한 뒤 사라집니다.
- 다운로드 소스의 상시 긴 설명을 오른쪽 원형 느낌표 버튼 팝업으로 옮기고, 최근 작업 결과나 오류도 함께 표시합니다.
- 플러그인 결과에 명시적 성공/실패 상태를 추가해 대기열 가득 참, 백그라운드 실행기 사용 불가, 파일 선택 오류 등 투입 전 실패도 팝업에서 확인할 수 있습니다.
- 두 다운로드 소스 위치가 같은 진행 표시줄을 공유하며, 다크/라이트 token, 동작 줄이기 대체, TalkBack 진행 의미를 보완했습니다.
- 빌드, 단위 테스트, 실기기 검증 범위는 이번 run과 Release 기록으로 한정합니다.
