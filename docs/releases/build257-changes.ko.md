# DSHA 0.2.1-rc.3-20261102.0200-dsh0.2.1-rc.5 / build257

- proroot 파일 잠금 수정: proroot 엔진의 런타임은 다른 프로세스가 잠금을 잡고 있을 때조차 모든 fcntl 실패를 EPERM(권한 없음)으로 보고해, Gradle처럼 프로세스 간 파일 잠금에 기대는 도구가 실패했습니다. 이제 호환 계층이 올바른 오류 코드를 돌려주므로 잠금이 잡혀 있으면 '다시 시도'가 됩니다. 기본 proot 엔진은 영향을 받지 않습니다.
- 검증 범위: 테스트 패키지를 Android 16 태블릿 한 대에서 proroot로 두고 잠금 프로브와 웹 대화를 확인했습니다. 정식 패키지는 실기기에 설치하지 않았습니다. versionCode를 257로 올렸습니다(build256 기반). DSHA 리비전은 0.2.1-rc.3, 내장 DSH는 0.2.1-rc.5로 유지됩니다.
