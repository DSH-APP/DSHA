# DSHA v0.1.5-rc2.1 / build 130

2026-09-13 本地交付。包名 `com.dsh.client`；标准版 Android 11+、兼容版 Android 6+，均为 arm64。dsh 仍锁定 `0.1.5-rc.2`，Ubuntu 基础环境版本仍为 10。两版共享数据和包名，沿用历史签名；不需卸载旧版。本轮没有上传 GitHub、修改历史 Release 或覆盖手机原安装。

## 本版修改

- **#67**：插件观察器采用锁定加载器的实际查找顺序，修复全局插件误报。persona 兼容旧 `text` 字段，保留原提示词和现代 `prefix`。维护成功后仍核对环境就绪，同一候选失败不反复自动重启。终端 exec 窗口的暂时不可读进程信息不再被当作已退出。
- **#65 与启动保护**：核对实际 Bash 和加载器；旧环境不可执行时可进入原生救援。普通同基础环境覆盖只更新受管运行时，不打包 Ubuntu；需要重建时保护个人数据并保留原件。修复冷安装依赖、候选局域网补丁和附件原子发布。
- **数据导出与恢复**：宿主读取、加密和校验；错误密码或归档预检失败不修改活跃数据。按范围恢复、项目目的地选择、配置重置和固定配置检查点接入原有维护屏障。已验证的私有加密副本可重新导出，仍使用原密码。部分救援或目标无法读回会明确提示。
- **更新与回退保护**：新运行时通过实际端口、鉴权、存储写后重开、网页握手及进程退出确认后提交。旧副本轮换前重新核对逐根摘要和清单外文件；未知或修改过的原件保留。已取消的按启动次数自动备份不会重新启用。

## 验收

最终 Gradle 命令：

```text
:app:testStandardDebugUnitTest :app:testLowDebugUnitTest
:app:lintStandardRelease :app:lintLowRelease
:app:assembleStandardRelease :app:assembleLowRelease
```

两版各 **491 项单测，490 通过、1 原有跳过、0 失败/错误**。两版 Release Lint 通过，仍有既有警告。新增三项清理回归覆盖：原件被修改、较新副本已损坏、保留目录含未知文件时不误删。

`tools/verify-dsh-upgrade-apk.py` 核对实际 APK 的基础环境和 dsh 包摘要、486 个共享依赖别名、28 个 Ubuntu 离线软件包及官方功能模块；两版通过。`tools/audit-standard-apk.py` 两版 arm64 ELF、16 KB 段对齐与 RELRO 静态检查通过。

真机为 Redmi M2012K10C，Android 13 / API 33、4 KiB 页、WebView 116。使用同生产代码的独立非调试 `com.dsh.client.rc21audit`，覆盖 WebView / Gecko 实际启动、无 Bash 数据导出恢复、真实进程强杀、Keystore、SAF 阻塞取消、双语短屏与旋转以及 #67。逐项报告见[专项验收记录](../backup-upgrade-acceptance.md)与[#67 修复记录](../issue67-recovery.md)。

## 验收边界

本轮按用户要求收尾并交付当前已验证修复，不能视为完整专项所有扩展矩阵已完成。批量保留副本管理和旧树救援来源、隔离插件的完整审阅启用流程、跨运行时数据格式代次关联仍有未完成项；这些能力不作为自动删除原件的依据。未接入的清理原型不包含在 APK 中。

历史 v1–v4 验证以合成样本为主。Android 6/7、最低标准 API 30、反馈中的 Android 16 平板及真实 16 KiB 页设备未在本轮实测；不能从本手机或静态 ELF 检查推断通过。进程强杀不是断电验证，测试 Provider 也不代表所有云盘。proroot 在本机触发 glibc 断言时，验证的是确认退出后的单次 proot 回退。
