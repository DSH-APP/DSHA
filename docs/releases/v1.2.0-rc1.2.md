# DSHA v1.2.0-rc1.2（重构版 · 预览版）

这是用于收集反馈的 **Pre-release**，包含高安卓标准版和低安卓兼容版，版本码均为 **111**。
本次由贡献者 [@SunsetRNE](https://github.com/SunsetRNE) 维护并发布，延续 1.2 系列的重构与适配工作；感谢原作者 [@qiannianhuanxiang](https://github.com/qiannianhuanxiang) 及其他贡献者。

## 与此前已发布预览版的区别

此前 GitHub 上的 1.2 预览版为 [alpha.2](https://github.com/qiannianhuanxiang/DSHA/releases/tag/v1.2.0-alpha.2) 和 [rc1](https://github.com/qiannianhuanxiang/DSHA/releases/tag/v1.2.0-rc1)。本次汇总 rc1 之后的修复，包括此前本地分发的 rc1.1；并非只包含全屏这一项更新。

| 项目 | alpha.2 / rc1 | rc1.2 |
|---|---|---|
| dsh 运行时 | alpha.2 使用 0.1.2-alpha.2；rc1 升至 0.1.2-rc.1 | 延续 rc1 的 0.1.2-rc.1，重点完善 Android 适配与插件功能 |
| 插件市场 | rc1 为占位入口，主要管理内置插件 | 接回链接安装、本地导入、多选导出、第三方插件删除，并可跳转 dsha.cc 选插件 |
| 安卓版本 | 单一 APK；rc1 的旧系统兼容仍待完善 | 标准版最低 API 30，兼容版最低 API 23，针对旧系统提供 Gecko 与重编原生运行时 |
| 包体积 | 已发布 rc1 APK 为 414.37 MiB | 标准版 212.39 MiB，减少约 48.7%；兼容版 289.46 MiB，减少约 30.1% |

| 安装与终端 | 部分安装步骤和运行时入口待完善 | 补齐基础工具第 2 步、离线 pnpm、npm/npx 及 npm 插件登记入口 |

包体积对比使用各 Release APK 的实际字节数；仍完整内置 Ubuntu、Node、pnpm 和 dsh，首次解压无需额外下载这些环境。

## 主要更新

### 插件安装与管理

- 支持 GitHub 仓库、分支/子目录、Release 附件和 HTTPS 压缩包直链，也能从分享文字识别链接。
- 修复缺少根证书导致的 `CERTIFICATE_VERIFY_FAILED`；随包提供 CA，GitHub 归档使用官方 codeload 下载，继续验证 TLS 证书。
- 导入支持 ZIP、TAR、TAR.GZ、TGZ；优先系统文件选择器，增加备用入口，处理旧文件管理器无返回、权限和空选择问题。
- 支持多选导出、第三方插件删除、启用/禁用、搜索和排序；卡片重新排版，解决控件挤压重叠。
- 插件市场增加「前往 dsha.cc 选插件」按钮。在网站选择后，将下载链接粘贴回 App，或下载插件包后导入。安装、删除或切换启用状态后，重启 Web 生效。

### 全屏对话与启动

- 删除顶部「返回 / DSHA 对话 / 浏览器打开」工具栏，系统 WebView 与 Gecko 都使用全屏页面。
- 保留系统返回手势，边缘滑动可临时唤出系统栏；键盘弹出时缩小网页可用区域。
- 完善异步 Cookie 鉴权、附件选择、加载失败重试及渲染进程恢复；修复启动/停止竞争及停止后被看门狗重新拉起的问题。

### 安装与 npm

- 补齐安装模块第 2 步的基础工具安装与结果检查，修复 proot 硬链接映射导致 apt/dpkg 报文件不存在的问题。
- 两版终端均可使用 `npm install 包名` 安装普通 npm 依赖。
- 对 npm 发布的 dsh 插件，使用 `dsha-plugin install 包名@版本` 下载、校验并登记到插件配置；普通 npm 安装不会自动登记为 dsh 插件。
- 修复部分 Android 13 手机终端原生库加载时的 RELRO / Out of memory 错误，保留 16 KB 对齐。

## 覆盖安装与兼容范围

- 沿用此前 rc1 / rc1.1 的发布签名，版本码升到 111，可直接覆盖同签名旧版；从这些预览版升级无需先卸载。
- 环境版本保持 9，本次更新不会仅因包体积调整而触发清空重装；已有配置、插件和会话继续使用。
- 编译/目标 SDK 为 API 37（Android 17）。这表示已完成相应编译适配，不代表所有 Android 17 设备都已真机验收。
- 兼容版面向 Android 6—12，但旧内核、厂商 ROM 和第三方文件管理器仍需更多设备反馈；32 位设备不支持。无线调试配对码等系统功能仍受 Android 版本限制。
- 本版仍为预览版，不承诺已经恢复 1.1.10 全部历史能力；独立插件网站的内容审核、投稿和下载服务不在此次 APK 验收范围内。

## 已完成的验证

- 两版 Release 构建和 Android Lint 检查通过；签名、版本、架构与校验文件已核验。
- Android 13 真机验证两版插件链接下载、文件导入、PTY/npm，以及 rc1.2 的系统 WebView / Gecko 全屏、返回和键盘避让。
- 前序 Android 16 真机验证了启动、模型回复、插件导入导出/删除和终端；rc1.2 未重复发送模型请求。
- Android 6—12、Android 17 和 16 KB 页设备仍需补充真机验收。静态 ELF 对齐检查不能代替设备验证。
