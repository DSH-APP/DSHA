# DSHA 0.2.1-rc.5-20261105.2310-dsh0.2.2-rc.1 / build327

- Обслуживание после обновления поверх теперь выполняется за один шаг: на странице обслуживания «обновить среду выполнения» полностью останавливает старый веб-процесс после проверки идентичности рождения, затем берёт барьер обслуживания и выполняет обновление; больше не нужно входить в ограниченный главный экран, нажимать «остановить» и возвращаться на страницу обслуживания.
- Встроенный плагин адаптации под портрет (`dsh-web-mobile`) по умолчанию отключён и остаётся отключённым после обновления поверх; он действует, только если пользователь явно включит его на нативной странице плагинов в текущей версии, а следующее обновление APK поверх снова отключает его. Его код не адаптирован к новым страницам и логике с build324, что вызывало белый главный экран и дублирование боковой панели; чтобы вернуть включение по умолчанию, нужно выполнить жёсткий критерий из [docs/plugins.md](../en/plugins.md) и приложить доказательства с устройства.
- Объём проверки: тесты хоста, полная группа contracts и проверки исходников/дескрипторов; выводы на устройстве следуют фактически подтверждённой записи, и успех заранее не записан. versionCode повышен до 327 (на основе build326).
