# 2026-09-09 按钮、对话交互与错误日志修订

本次仍使用 1.5-alpha.1、版本码 114、环境版本 10 和历史发布签名，覆盖更新保留现有环境与数据。

## 可见变化

- 插件页把原先 48dp 刷新图标位中的四字文字移出，改为独立的横向图文按钮。检测入口带刷新图标和明确文案，最小触摸高度 48dp；小屏、大字体均保持单行。
- 对话页的图标说明区分输入方式：触摸点击不弹悬停气泡；真实鼠标悬停和键盘焦点仍显示说明。点击按钮、点空白、滚动、Escape、切换窗口会关闭提示，并取消尚未显示的延迟提示。
- 发送按钮切换为暂停等状态时，共用的 Tooltip 不会因为旧悬停/焦点继续显示新文字。保留原按钮事件、菜单动作、输入焦点和草稿；不会强制清空输入或移除 React 的节点。
- 新增“错误日志”卡片，默认下载为 `Download/DSHA/DSHA-error-log-时间.txt`。保存后可点路径查看，也可“另存为”选择位置。

下载入口：启动页“运行日志”右侧的“下载日志”；设置 →“诊断与日志”；网页加载失败时的“下载错误日志”。

日志包括版本与设备信息、最近失败阶段、应用操作/崩溃/页面错误，以及最多 256 KiB 的最新 Web 输出。
不依赖环境诊断或 Web 启动成功。导出时统一隐藏常见密钥字段；截断时丢弃不完整首行，避免仅剩密钥值片段。
日志保存后校验实际内容，文本使用 `text/plain`，可以交给文本查看器打开；记录最后保存的 URI，重开后仍能查看。
未读取配置全文、对话文件和终端历史，也没有自动上传日志。取消“另存为”不会改动已有下载文件。

## 实现与覆盖更新

上游 Tooltip 使用 `onMouseEnter` 和焦点共同保持显示，触摸产生的兼容鼠标事件与按钮焦点会造成残留。
本次替换锁定前端中的该组件，用 pointer 类型区分触摸，并统一管理显示、延迟计时和关闭事件。
修订在 `RuntimeTools` 准备环境时应用；入口增加缓存修订参数，旧安装也会取得新组件。WebView / Gecko 共用同一份前端修订。
未重新打包 Ubuntu rootfs，没有递增环境身份，不触发已有用户的环境重建。
