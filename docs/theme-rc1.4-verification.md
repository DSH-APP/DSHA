# rc1.4 同版本主题修复验收

此页记录最初带设置主题卡片的修复。按用户后续要求，该卡片及选择弹窗已移除，仅保留右上角日夜切换；当前安装包与摘要见[最新调整记录](theme-toolbar-only-rc1.4.md)。本页文件已保留到 `release/history/rc1.4-before-toolbar-only-20260907`。

用户反馈的截图是 rc1.3 更新页，默认按钮呈现黑底深色文字。本次将修复并入 rc1.4，版本名、版本码 113、签名及环境版本 9 均保持不变。

## 修复内容

- 默认按钮明确指定背景与文字状态，修复关闭 Material 着色后未提供默认背景造成的黑色按钮。主操作、次操作、危险操作和禁用状态分别匹配可读文字。
- 顶部提供白天/黑夜快捷切换；设置提供跟随系统、白天、黑夜，记住选择。偏好进入设置备份，并保持旧备份缺少该字段时的兼容行为。
- 日夜主题共用控件规则；提高弱提示、状态色和选中/按压状态的对比度。ADB 配对页面使用 AppCompat 主题并跟随日夜配色。
- 将固定高度按钮改为最小高度加内容自适应，避免大字体时裁切。配对页面增加滚动，旧系统的系统栏和强制变暗通过 API 检查处理。
- 主页面引用随前台页面更新；主题/旋转重建不执行终端退出清理，保留正在运行的 PTY 和简易 Shell。

## 验证结果

- 20 个原生布局 × 白天/黑夜 × 1.3 倍字体，连同实际更新页，检查 520 项真实控件文字状态；最低对比度约 5.03:1，没有文字省略或高度裁切。涵盖默认、主操作、危险和禁用按钮、输入提示、单选框和勾选框。
- 实际设置页和主题弹窗另检查 84 项文字状态，最低约 7.16:1。设置选择、顶部切换及页面保持均通过。
- 色板测试覆盖 76 组正文、辅助文字、状态色、按钮、选中及按压组合，最低约 4.69:1。对比度按 [WCAG 文字对比度算法](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)计算，全部以至少 4.5:1 验收，禁用标签也保持可读。
- Android 13 / Redmi M2012K10C：新进程恢复已保存主题；切换两次保持同一运行中 PTY；独立原生设置的主题备份、恢复、失败回滚及旧数据兼容通过。测试未发送终端业务命令或模型请求，最后恢复跟随系统。
- 110 项 Java 单测通过；标准/兼容 Release 构建通过。两版 Lint 无错误，分别有 403/361 个警告，未声称清理全库警告。
- 主题切换采用 [Android DayNight/AppCompat 机制](https://developer.android.com/develop/ui/views/theming/darktheme)。旧 Android 尚未新增实机覆盖；低版本 API 由编译和 Lint 验证。终端输出区保留原有深色底，以保持默认 ANSI 白字可读。

验收入口：`ThemeInstrumentation`（完整布局、`lifecycle`、`probe` 三种模式）、`UiThemePreferenceTest`、`tools/test-ui-colors.py`。截图与原始报告保存在本地 `app/build/theme-evidence`，没有上传到第三方。
