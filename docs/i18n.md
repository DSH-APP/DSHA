# 界面语言、系统语言锁存与网页同步

核验日期：2026-10-25，build197 源码。下列数量来自固定目录和宿主检查，设备范围另以当前交付回执为准。

## 用户选择与生效时机

“设置 → 界面语言”提供“跟随系统”及十种固定语言，默认保存意图为 `system`。旧版明确保存过的 `zh/en` 继续保留，设置摘要显示当前生效语言。[UiLanguagePreference](../app/src/main/java/com/deepseekharness/app/util/UiLanguagePreference.java) 接受下表十种 canonical tag 和 `system`；无效旧偏好归一为跟随系统。

| 偏好 | 实际界面语言 |
|---|---|
| `zh` | 简体中文 |
| `zh-Hant` | 繁體中文 |
| `en` | English |
| `ru` | Русский |
| `ja` | 日本語 |
| `ko` | 한국어 |
| `ar` | العربية |
| `pt` | Português |
| `la` | Latina |
| `fr` | Français |
| `system` | 按锁存的系统语言解析，不覆盖用户保存的跟随系统意图 |

显式十语偏好不随系统变化。系统标签按完整语言/script/region 解析：明确 `Hans` 优先映射简体，明确 `Hant` 优先映射繁体；没有明确 script 时，`TW/HK/MO` 映射繁体，其他中文地区映射简体。已支持的其他主语言使用对应固定 tag；未知有效主语言使用英语，`null/und` 或非法标签保留中文回退。网页桥只接收十种解析后的固定 tag，区域标签和 `system` 不直接通过网页桥。

[SettingsFragment](../app/src/main/java/com/deepseekharness/app/ui/SettingsFragment.java) 在选项对话框关闭后调用 [LanguageController.select](../app/src/main/java/com/deepseekharness/app/ui/LanguageController.java)，保存偏好并立即更新资源。Activity 可因语言切换重建；终端、Web 服务与应用级业务任务由各自所有者保留，语言变更不应重放命令或重新启动 DSH。

## 为什么在进程启动时锁存系统语言

[DshaApp](../app/src/main/java/com/deepseekharness/app/DshaApp.java) 先调用 `SystemLanguage.initialize(this)`，再应用界面语言。应用会调用 `Locale.setDefault`；若后续直接把默认 Locale 当系统语言读取，“跟随系统”可能读到刚应用的界面语言而锁死。

[SystemLanguage](../app/src/main/java/com/deepseekharness/app/util/SystemLanguage.java) 因而在进程最早时刻锁存真实系统首选语言，之后不受本进程 `Locale.setDefault` 影响。Android13+ 优先读 `LocaleManager.getSystemLocales()`，避免持久应用语言污染资源；不可用时按系统资源 LocaleList、旧 `Configuration.locale`、JVM默认值回退。初始化只发布一次，提前读到的临时值允许最早的正式初始化替换。

这是一份进程级锁存，源码没有承诺系统语言在当前长寿命进程中变化时立刻重新采样。改变系统语言后，新应用进程会按新系统来源解析；当次进程的“跟随系统”仍使用已锁存值。不要用停止 DSH、清数据或重建环境来刷新语言。

[AppLocaleDispatch](../app/src/main/java/com/deepseekharness/app/util/AppLocaleDispatch.java) 在 API33+ 使用平台 application locales，在较低版本使用 AppCompat；Application 资源同时更新，供通知、悬浮界面与后台任务使用。独立远程网页进程读取平台或应用所有者提供的当前语言，不自行写入全包 locale。原生固定目录为 4,706 条，包含 472 个动态格式模板和 6 个 Android indexed 格式项；十语 Java 字典按类和方法分块生成，XML 使用对应资源限定符。单独修改 XML 不能覆盖动态文字。

Android 的 `plugin_count` 复数和 Standard 版说明由独立的 [android-resources.json](../tools/i18n/android-resources.json) 定义十语内容，由 `localize-android-ui.py --resources-only` 生成并精确检查；阿拉伯语保留 zero/one/two/few/many/other 六种数量形式。欢迎页数字计数与版本/build 拼接模板不含可翻译文字，明确标记为不可翻译。该资源目录不增加运行时文案字典的 4,706 条计数。

## 动态状态与网页

[UiStateText](../app/src/main/java/com/deepseekharness/app/util/UiStateText.java) 只在显示边界重译已登记的完整文案或模板，参数保留原文；不对用户消息、命令、日志任意子串替换。原始状态与业务数据不能因界面语言切换被改写。动态翻译源为 [messages.json](../tools/i18n/messages.json) 与 [messages-extra.json](../tools/i18n/messages-extra.json)，新增语言内容在 [translations](../tools/i18n/translations/) 与 [translations-extra](../tools/i18n/translations-extra/)。

[WebPageScripts](../app/src/main/java/com/deepseekharness/app/ui/WebPageScripts.java) 注入 `window.__DSHA_LANGUAGE__` 并派发 `dsha-language`；WebView 语言消息监听只接受当前本机、同源、顶层页面。网页明确选择任一固定 tag 可以通过受限消息桥保存宿主显式偏好；普通外部站点无此权限。Gecko 使用相应扩展通道，应急通道限于自身精确 `localhost` authority，不借用正式 `127.0.0.1` 的设备或插件桥。

固定 0.2.2-rc.1 的 `LocaleRuntime.addLanguage/register` 承担网页翻译。上游自带 zh/en/ja/es/fr/de/ru/pt，并在每个 namespace 注册这些字典；同一 namespace 重复注册同一语言会抛错，所以 DSHA 只补上游没有的 zh-Hant/ko/ar/la，ja/fr/ru/pt 改用上游文案（DSHA 原有这四种网页译文已删除）。网页选择器为上游 8 种加 DSHA 4 种，共 12 种，不重复。Web 目录包含 74 个 namespace 的 3,860 个键，来源为锁文件约束的官方字典及当前签名生产补丁；四份 DSHA 语言目录覆盖完整相同键集，其中 `dsh-experimental-*` 包（forge、liveshare、stats 等）新增键统一写 `null`，按语言声明的回退链显示（zh-Hant→zh，ko/ar/la→en），稳定包不允许 `null`。DSHA 补丁新增、上游没有对应译文的键记为 `upstreamMissing`，这些键在上游语言中显示英文。桥对单个语言或 namespace 的失败只跳过该项并经页面错误事件报告，不回滚其余注册。移动插件语言内容由随包 `dsh-web-mobile` 3.3.5 的上游 bundle 与其既有 DSHA 补丁提供；本分支试点移除旧版移动插件 locale 补丁脚本，不把 `tools/mobile-locales.*` 的行文键数当作当前覆盖。网页选择及原生切换均通过真实 locale 服务发布快照；阿拉伯语设置 `<html dir="rtl">`，切回其他语言恢复 `ltr`。对话、文件、命令、模型生成内容、错误原文及第三方插件自有内容不作 DOM 全文翻译。

`onboardingArtworkLocale` 保留官方现有 `zh/en` 插图选择码，避免请求不存在的图片。`time.locale` 使用各语言有效的 BCP-47 tag；日期/月名等格式仍取决于 WebView/Gecko 内置 `Intl` 数据，尤其不是所有引擎都提供拉丁语日期数据。

正式运行时和独立应急运行时都使用签名语言配方。`previousPatches` 只允许完整匹配旧三项替换时在内存撤回并应用新版；部分旧形态先走既有受管 canonical 恢复，缺失或不符的 canonical 拒绝发布。此过程只处理受管模块，不读取或改写用户对话、插件配置和文件。独立应急 overlay 支持从旧锁定归档升级语言，也能幂等处理已经带完整新版的归档；归档是否共用必须依据最终 SHA 相等，不能靠映射跳过独立锁。

## 核验与维护

原生检查入口：[UiLanguagePreferenceTest](../app/src/test/java/com/deepseekharness/app/util/UiLanguagePreferenceTest.java)、[AppLocaleDispatchTest](../app/src/test/java/com/deepseekharness/app/util/AppLocaleDispatchTest.java)、[UiStateTextTest](../app/src/test/java/com/deepseekharness/app/util/UiStateTextTest.java)。网页与补丁检查包括：

- `python tools/prepare-web-languages.py --check`：完整核验锁定 raw fixture，并检查源目录和生成输出。
- `python tools/prepare-web-languages.py --catalog-only --check`：离线构建校验固定目录、插值、生成 helper、正式配方与同版本应急配方的一致性，不宣称重读了上游 fixture。
- `tools/test-ui-language.mjs`：真实 rc3 locale 对十语全部 29,320 个键查找、双向选择、旧 Host 偏好、RTL 清除、无用户正文改写及监听清理。
- `tools/test-language-patch-chain.py`：真实 Java17/Python 受管补丁、旧完整形式、新形式、canonical 修复及部分/重复/未知输入拒绝。

实际设备仍需按当前 APK 核对首次启动、保存语言、跟随系统、旋转、通知和网页同步。历史不同 APK/ROM 的结果不能移作本轮实测。
