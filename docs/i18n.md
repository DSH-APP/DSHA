# 界面语言、系统语言锁存与网页同步

核验日期：2026-10-21。参考基线：已发布 F10 `087724c`，并对照本轮工作树源码。本页是实现说明，没有新增设备语言切换验收。

## 用户选择与生效时机

“设置 → 界面语言”提供“跟随系统 / 简体中文 / English”。默认保存意图为 `system`；旧版明确保存过的 `zh/en` 继续保留。设置摘要同时显示当前生效语言。[UiLanguagePreference](../app/src/main/java/com/deepseekharness/app/util/UiLanguagePreference.java) 只接受这三个值，其余旧值归一为跟随系统。

| 偏好 | 实际界面语言 |
|---|---|
| `zh` | 简体中文，不随系统变动 |
| `en` | English，不随系统变动 |
| `system` | 中文系统标签映射中文；其他有效语言映射英文；无法识别时回退中文 |

[SettingsFragment](../app/src/main/java/com/deepseekharness/app/ui/SettingsFragment.java) 在选项对话框关闭后调用 [LanguageController.select](../app/src/main/java/com/deepseekharness/app/ui/LanguageController.java)，保存偏好并立即更新资源。Activity 可因语言切换重建；终端、Web 服务与应用级业务任务由各自所有者保留，语言变更不应重放命令或重新启动 DSH。

## 为什么在进程启动时锁存系统语言

[DshaApp](../app/src/main/java/com/deepseekharness/app/DshaApp.java) 先调用 `SystemLanguage.initialize(this)`，再应用界面语言。应用会调用 `Locale.setDefault`；若后续直接把默认 Locale 当系统语言读取，“跟随系统”可能读到刚应用的界面语言而锁死。

[SystemLanguage](../app/src/main/java/com/deepseekharness/app/util/SystemLanguage.java) 因而在进程最早时刻锁存真实系统首选语言，之后不受本进程 `Locale.setDefault` 影响。Android13+ 优先读 `LocaleManager.getSystemLocales()`，避免持久应用语言污染资源；不可用时按系统资源 LocaleList、旧 `Configuration.locale`、JVM默认值回退。初始化只发布一次，提前读到的临时值允许最早的正式初始化替换。

这是一份进程级锁存，源码没有承诺系统语言在当前长寿命进程中变化时立刻重新采样。改变系统语言后，新应用进程会按新系统来源解析；当次进程的“跟随系统”仍使用已锁存值。不要用停止 DSH、清数据或重建环境来刷新语言。

[AppLocaleDispatch](../app/src/main/java/com/deepseekharness/app/util/AppLocaleDispatch.java) 在 API33+ 使用平台 application locales，在较低版本使用 AppCompat；Application 资源同时更新，供通知、悬浮界面与后台任务使用。构建资源必须同时覆盖中文与英文，单独修改 XML 不能覆盖全部动态文字。

## 动态状态与网页

[UiStateText](../app/src/main/java/com/deepseekharness/app/util/UiStateText.java) 只在显示边界重译已登记的完整文案或模板，参数保留原文；不对用户消息、命令、日志任意子串替换。原始状态与业务数据不能因界面语言切换被改写。动态翻译表来源见 [messages.json](../tools/i18n/messages.json)。

[WebPageScripts](../app/src/main/java/com/deepseekharness/app/ui/WebPageScripts.java) 注入 `window.__DSHA_LANGUAGE__` 并派发 `dsha-language`；WebView 的语言消息监听只接受当前本机同源顶层页面。网页明确选择 `zh/en` 可经过受限消息桥更新宿主偏好；普通外部站点无此权限。Low Gecko 通过自己的扩展消息通道同步；应急网页仅注入语言与兼容，不注册正式设备/插件桥。语言同步不意味着模型回答、用户插件内容或外部页面都被翻译。
