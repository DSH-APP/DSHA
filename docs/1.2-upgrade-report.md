## 已实施

1. 新增独立 `runtime_id`，保留历史 `use_rc6`、`workdir`、`api_key` 等偏好键；Alpha 只接受固定 runtime manifest 和生产 dsh 包。
2. `restore-merge.py` 使用独立 stage，候选 `.dsh` 先校验，再原子换位；rename、校验或中断失败时保留旧数据及失败 stage。
3. `ProotBootstrap.extractOfflineBundle()` 使用 stage、校验、同父目录原子切换、成功 marker 和失败回滚；失败不删除旧 rootfs、旧 marker 或旧用户数据。保留用户数据时，目录读取失败、未知条目或不能原样重建的软链都会 fail-closed，阻止切换而不是静默丢项或跟随复制。
4. Alpha 启动固定为 `dsh web --no-open --host 127.0.0.1 --port 3080`。只接受新版明确打印的严格 BrowserAuth URL，认证交换成功后才判定 Web 就绪；启动信息仅内存保存并按 generation 清理。
5. WebView/GeckoView 直接加载本轮 `authUrl`；移除 Alpha 路径中的 `dsha_t`、`X-Dsha-Token` 注入、裸 `uiUrl()` 探测及旧 WebView/auth/lan patch、自愈和会话格式改写。
6. LAN 默认关闭，由 DSHA 代理监听 `0.0.0.0:3081`；LAN token、3090 bridge token、dsh BrowserAuth cookie 独立。代理做 303 清 token、HttpOnly/SameSite=Strict LAN Cookie、loopback Host/Origin/Sec-Fetch-Site 重写、后端 Cookie/CORS 清理和 WebSocket 透传，并在认证失效时 fail-closed。
   BrowserAuth 交换兼容多个 `Set-Cookie` 响应头及合法的合并头，只提取本轮 `dsh-auth-*` Cookie，其余后端 Cookie 不会进入 LAN 代理。
7. Alpha 不自动注入旧插件、bundle、cordis patch、插件市场或会话迁移；旧 web profile 和 patch 在覆盖升级时隔离保存，session/settings/credentials 透明保留。
8. 日志、异常和 Web 输出增加敏感信息脱敏；活动日志、Android `/proc` 进程诊断和停止/复活诊断也在写盘或写 Logcat 前统一脱敏，不会把启动命令里的 API key、BrowserAuth token 或 Cookie 落盘。
9. `SensitiveData` 统一覆盖 query、header、Cookie、Bearer、异常文本及 JSON 引号字段（混合大小写），`LaunchFragment`、`DownloadSink`、PTY/终端、活动日志和 Web 日志均在展示或落盘边界脱敏；真实 HTTP 请求仍使用原始认证值。
10. Alpha 固定读取 APK 内置脚本资产，禁用 runtime-overlay、远端脚本检查和手动脚本更新入口；旧 runtime 的增量更新路径保留。
11. `scripts/ci-make-offline-bundle.sh` 每次都从全新的同父目录 rootfs stage 构建，不复用旧 `ci-rootfs`；只有产物通过结构和固定 runtime metadata 校验后才清理该 stage，失败现场保留供排查。
12. 便携式 Windows x64 工具链已落地到 `<TOOLCHAIN_ROOT>`（Temurin 17.0.20.1、Gradle 8.5、SDK 34/build-tools 34.0.0/NDK 26.3.11579264、platform-tools），未改系统 PATH、注册表或全局 `JAVA_HOME`；Windows 侧 Java/资源编译、lint、完整 APK 打包均成功（Gradle unit test 为 `NO-SOURCE`）。本阶段额外使用历史 APK debug keystore 重签并通过证书核对；固定 dsh 的 production closure 仍必须在原生 Linux arm64 构建，未把 Windows x64 结果冒充 upstream arm64 构建。
13. 本阶段修复 HMR 单次自愈、PTY 弱生命周期 listener/下一帧刷新、Alpha 插件市场与 HMR 黑名单/安装回滚、四种透明备份范围（含 settings）和脱敏启动分段计时。
