# 运行恢复与省电验收（2026-09-07）

连续三次失败后暂停自动重启，按启动代次去重；持续健康两分钟才清零。恢复状态保存在原生设置，手动启动重置失败预算。启动页展示失败阶段和原因，提供已有安全启动、插件回退与诊断入口。停止仍只写哨兵、处理 Web PID。

持续运行是默认模式。省电模式在熄屏、无局域网访问、无原生任务且运行状态连续已知空闲一分钟后释放 Web 锁，不主动停止 Web。内置适配读取 dsh 的 Agent、收件箱、后台作业和定时任务状态；缺少接口、未知状态或状态文件过期时保持保活。原生任务独立持锁，终端、桥接请求、插件和备份等命令不会随 Web 空闲锁释放而失去保活。锁有超时并由活跃任务/服务续期。

验证结果：

- `RestartBudgetTest` 验证三次失败、重复回调去重、旧代次失效、短暂/间歇健康不清零、持续健康清零、持久计数和手动重试。
- `PowerPolicyTest` 验证熄屏连续空闲等待、任务开始恢复、局域网/启动/前台保持及停止释放。
- `node --test tools/test-app-activity.mjs` 两项测试覆盖生成、排队、运行/停止中的后台作业、定时任务、已结束任务、缺少接口和未知枚举。
- 全部 StandardDebug Java 单测以及 LowDebug/Test APK 构建通过。
- Android 13 / Redmi M2012K10C：`RecoveryInstrumentation` 在独立目录注入进程创建失败，验证三次失败暂停、阶段保存、恢复器重建后仍暂停和手动重试。
- 同一设备真实启动已有 dsh：将启动计数预置为阈值减一，验证自动备份成功且 Web 鉴权就绪；保留有效备份 `Download/DSHA/DSHA-backup-20260907-142625-743c77d7.tar.gz`，没有恢复用户数据。原始计数和省电偏好已还原。
- 同一设备实际熄屏，确认空闲后 Web WakeLock 释放；原生任务开始立即取得独立锁并恢复 Web 保活；任务结束释放，Web PID 仍然运行。测试结束停止测试期间启动的 Web，并唤醒屏幕。

当前证据覆盖 Android 13 的实际锁和进程行为，以及独立故障场景；没有宣称验证所有厂商的后台回收策略、Android 6/7 或真实生成任务的长期耗电。省电任务判定兼容当前随包 dsh 0.1.2-rc.1，后续接口变化将保守保持运行。
