进度条变种（同步播放当前状态）

所有变种跟随上方「动态状态 / 播放」同步；点卡片即应用到右侧新方案的状态条。A–F 来自 build243 进度方案，W1 是启动页 ShellActivityTrack 原样移植，W2–W4 是在它基础上的曲线变速版本。

改了什么

  • 标题与「市场 / 管理」分段并成一行；分段改为紧凑胶囊，管理页签带插件数徽标（检测中脉冲、未确认、刷新失败三种形态）。
  • 市场：「社区插件生态」整行卡片收为卡片标题右侧的链接；「粘贴链接」进入输入框尾部图标；下载源与「解析安装」共用一行。
  • 管理：标题行去掉，搜索与「检测插件」同行；「只看自己装的」、排序、下载源成为一行筛选胶囊；「检查更新」改为状态条空闲时的动作。
  • 下载源说明（圆形感叹号）并入下载源选择弹窗顶部，不再单独占一个 44dp 按钮。
  • 进度条、状态文字、取消按钮、安全模式恢复合并为一条固定高度的状态条：图标 + 主语 + 说明 + 百分比 + 单个动作。进度条有十个变种可切换：平条贴底边 4px，波浪 / 数值用文字下方 12px 固定车道。
  • 已采用 W3：启动页 ShellActivityTrack 的波浪几何（波长 26 / 振幅 3.4 / 线宽 4）加曲线变速与弹性追赶，落地为 PluginWaveProgress，数学在 util/WaveMotion。
  • 空闲与忙碌高度一致，取消按钮不再出现 / 消失顶动列表。

收束时长沿用 PluginTaskProgress（成功 700ms / 失败 900ms / 淡出 240ms）。波浪变种另有 520–600ms 的「铺满压平」过渡，从当前段位置出发，不跳帧。

W2 曲线变速：不确定态头 cubic-bezier(.2,0,.1,1)、尾 (.6,0,.25,1)，1.75s 一周期，段长 8%–60% 伸缩，波纹速度跟随头部速度；确定态填充 (.34,1.36,.64,1) 520ms 轻回弹（100% 处截断不越界），振幅随进度按三次方收到 45%。W3 在此基础上把填充换成 (.3,1.7,.55,1) 680ms 强回弹（峰值约越过目标 14%，只影响显示，读屏报真实值），波纹速度随最近一次跳变幅度加速、1.2s 无新数据后放缓到 0.55。
