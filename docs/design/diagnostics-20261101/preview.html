改了什么
  1. 去掉重复大标题：顶栏已写「自检与诊断」，状态卡直接说结论。
  2. 状态卡带结论：图标 + 一句话（正常 / 几项问题 / 未完成），主按钮唯一。
  3. 结果按严重度排：问题置顶并标色，正常项折叠成一行「N 项正常」。不再每行同一个盒子图标。
  4. 空状态：未检查时说明检查范围，替换现在那条空细卡。
  5. 6 个分组 → 3 个：检查结果 / 反馈 / 工具。
  6. 导出合并为一个弹层：故障包或文本报告 + 下载或另存为；「补充复现步骤」移进弹层，不再常驻页底。
  7. 所有既有能力保留：复制、导出 txt、日志下载/另存为、上次文件、启动记录、故障处理、修复工具、插件管理。
