插件卡片重构交互原型 · 非 App 资源

状态实验台

选中一张卡片后直接改字段，模拟真实仓库返回的状态组合。卡片上的开关、更新、删除也会跑完整的排队 → 执行 → 提交流程。

结构与数据来源

槽位数据相对当前的变化
glyphbuiltin / official / runtimeProvided / runtimeLocated / dynamic按来源换图标，不再全部是拼图
name · badge · versionname、来源分类、version版本从状态文本移到标题下；来源分类成为徽标，说明为空时不再拿分类顶替
switchrow.checked() / toggleEnabled()移到右上角，与标题同一行；语义与无障碍描述不变
descdescriptionText默认两行截断，展开 / 详情窗格显示全文
status配置态 + loadState多行状态块拆成「一行主状态」+ 下方提示条
progressoperation.phase / percent百分比文本变成进度条；未知百分比显示不定进度
notesavailable / restartRequired / updateAvailable / detected / 失败信息每条一个语气色 + 可选动作（重新导入、更新、查看详情）
foot展开态、itemActions「展开插件详情 / 更多」两个胶囊变成文字按钮 + 图标按钮，带 aria-expanded
detailsversion / location / source纯文本模板变成属性表，路径可复制；删除收进展开区底部
