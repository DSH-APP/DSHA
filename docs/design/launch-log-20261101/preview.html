压缩规则

  1. 行按阶段折叠：「正在 X…」与「完成「X」，耗时 n」合并为一行：状态图标 · 阶段名 · 耗时 · 占比条。21 行原文 → 6 行阶段。
  2. 计时行降级：STARTUP_PREP_TIMING / CAS_TIMING 不再占主视图，归入所属阶段的明细，只显示 phase + 毫秒 + 小比例条。
  3. 问题上浮：失败 / 跳过行让阶段变色、自动展开，并在标题行与「原始」标签上计数；概览里直接给出原句。
  4. 时间前缀改为时间槽：[0.7s] 变成左侧等宽灰色列，正文对齐、不再被前缀挤换行；复制仍是带前缀原文。
  5. 按钮收进标题行：复制 / 下载改 40dp 图标钮（保留无障碍名称）；「跟随最新」「查看最新」合并为框内一个浮标，暂停时才显示并带未读数。
  6. 原始视图工具条：全部 / 隐藏计时 / 仅问题 / 换行，筛选只影响显示。
