      原型说明 / 仅模拟

      DSHA 四入口交互预览。启动、插件和设置按 build197 Java/XML 的功能层级填充；终端沿用上一轮极简与悬浮球方案。不是当前手机的截图或运行状态，也不是生产 WebView 替换方案。

      本轮新增的三个主页面

      启动页演示准备、鉴权、就绪、停止和失败；停止 Web 不关闭终端。插件页提供市场/管理、源码样例、搜索、筛选、排序、详情、模拟安装启停与删除。设置页包括原有工作台、使用体验、支持三组，运行配置和数据备份有可返回子页，草稿只存当前文档。

      安装、备份、电脑配对、设备授权、更新和诊断均是流程说明或页面内模拟；不联网、不申请权限、不读写文件、不生成下载。语言只保存选择摘要，不翻译整页。插件链接识别是简化演示，不替代生产解析器。

      主 Tab 间保留筛选、草稿和滚动是本次设计增强，不是现有 Android 全部已具备。测试台在未准备/维护场景仍允许浏览静态主 Tab，便于评审；生产的首次准备门禁更严格，实际实施必须沿用原门禁。首页终端概览、测试台和设置中的终端显示快捷入口均为提案新增。

      悬浮球入口

      终端内的圆球是普通页面控件，不是跨应用悬浮窗，不需要系统悬浮窗权限。点击打开会话与返回菜单；拖动超过8px后视为移动，松手吸附左右边缘，不误触菜单。闲置2.5秒降低透明度，鼠标悬停或键盘聚焦时恢复清晰。聚焦圆球后方向键可调整位置，Enter/空格开菜单；不向终端发送这些移动按键。

      圆球始终完整留在当前可用区域，布局变化时重新约束，避免附加键和模拟输入行；只能减轻遮挡，不能保证不遮住任何输出字符。极短窗口以保留可点击入口为底线。位置仅本页内存保存，返回再进保留，刷新恢复默认；真实 Android IME/手势区避让仍需原生验收。

      三向态外观

      顶部外观按钮与会话侧栏底部的「系统 / 白天 / 黑夜」只切换本页颜色：系统=跟随浏览器 prefers-color-scheme，白天=浅蓝+白，黑夜=浅蓝+黑。侧栏、菜单、对话框和工作台顶栏随外观变化；终端输出区固定黑底，贴近原生 terminal_surface 的合同。选择只在本页内存，刷新后回到跟随系统，不写入应用设置。

      有限命令白名单

      helppwdlswhoamiecho 文本clearjobsdemo startdemo stopexit

      全是页面内固定响应。echo 只逐字显示文字，不展开变量或语法；管道、重定向、脚本、任意其他命令都不会执行。显示的路径和文件名均为虚构。

      会话与返回边界

      PTY / simple 各自维护递增 ID；显示编号复用本组最小空缺。切换与返回保留草稿、输出和计数，关闭仅移除目标会话。全部关闭后保持空状态，不偷偷新建。

      仅当前页面内存；刷新、关闭页面或浏览器返回离开页面会丢失。计数根据页面内经过时间模拟；不代表真实进程、系统后台保活或任务执行。浏览器挂起与休眠不在本原型的保证范围内。

      输入、可达性与范围

      附加键仅模拟：Tab 补全白名单，↑ / ↓ 查当前会话历史，← / → 移动输入光标，CTRL 再按 C 或 ^C 暂停计数，ALT 只反馈组合键。Esc 优先关闭对话框，其次收起模拟键盘，再返回主界面。网页按钮无法承诺真实系统 IME 的唤起、隐藏或动画。

      最多 12 个会话，每会话保留最近 240 行输出与 50 条历史；命令最多 512 个字符。无外部资源、网络、真实 shell、设备调用、剪贴板 API、用户文件读取或持久化存储。不应输入真实密钥或私密内容。

      这个表单只模拟命令；生产 PTY 仍使用 com.termux.view.TerminalView 原生输入，不由 HTML 表单替换。本页 Esc 返回、exit 确认都是演示行为；真实 PTY 的 Esc 应发送给终端，shell 的 exit 不应被 UI 拦截。生产 simple 中止会重启 shell，本页暂停计数不代表该流程。

      使用现代浏览器的原生 dialog、焦点返回和键盘环绕；支持减少动态效果偏好。没有模拟异步关闭失败／结果未知、FGS 前台服务；不验证 Android 原生手势、IME、PTY 生命周期或无障碍实现，后端未改动。
