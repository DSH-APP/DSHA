未保存的改动

    模拟条件

    v2 再压了什么

    • 页面说明并入第一个分组标签行，不再单占一行。
    • 行高 56 → 48dp（触控仍 ≥48dp），分组标签、卡片内边距、保存条同步收紧。
    • 五组卡片 → 两张：“高级”并入运行与网络末行；悬浮条并入显示与启动，“外观与行为”变行尾按钮。
    • 网页内核只有一项，改成桌面布局行的副文案。
    • 数据与备份、恢复旧端口草稿、项目主页改成卡片下方一行链接按钮。
    • 副文案压成一行（画中画只显示状态；局域网未设密码的后果移到开启后的提示里）。
    • 保存条状态改单行。

    v1 压缩了什么

    • 去掉与顶栏重复的大标题和图标块；说明压成一行 + ⓘ。
    • 整宽下拉 → “标签 + 当前值”行（运行方式）；内核只有一项，改只读；DNS 改分段控件。
    • 自动端口开启时，首选端口作副文案；关闭后在行下展开固定端口输入。
    • 局域网：开关、密码状态、设密码合成一行；开启后才显示 HTTP 未加密提示。
    • 画中画开关与系统状态合并，“系统设置”成行尾按钮。
    • 静态加载器 / seccomp 收进可折叠“高级”，摘要显示当前值，非默认值标“已改”。
    • 恢复旧端口草稿、数据与备份移到“更多”。
    • 保存条显示未保存项数与撤销；详情区 ≥720dp 两列，保存按钮不再整宽。

    不变的约束

    • 既有 id、ConfigStore 键、保存时机与 EnvironmentTaskGate 不变；画中画、局域网密码仍即时生效。
    • 端口校验仍用 ConfigInput.port（1–65535，3081/3082/3090–3099 保留）。
    • 无改动时保存仍可点（保存会重新套用局域网与悬浮条状态）。

    待确认

    • 新增短文案（“自动 / IPv4 / 原生”、画中画短状态、“更多”、未保存提示等）需进 messages.json 并过长度政策。
    • 静态加载器是否只对 proroot 生效：源码只见冷启动选择处引用，未确认，暂不按运行方式隐藏。
    • 手机从启动页推进到配置页时是否显示底部导航，未在真机核对。
    • 两列阈值取 720dp（详情窗格宽度，非屏幕宽度）。
