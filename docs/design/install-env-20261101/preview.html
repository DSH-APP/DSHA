状态场景

「检查全部」「按需修复」「重新检查单步」都会实际模拟逐步推进；场景「第 4 步失败」会在 pnpm 处失败并给出修复入口。

主页改了什么

  • 四行版本表 → 状态卡：一句结论 + 版本胶囊（点按复制完整版本，长版本不再折行）。
  • 「首次安装测速」从标题下的独立大按钮移到「维护与工具」组，诊断工具不再占首屏。
  • 「检查全部」「按需修复」并排进状态卡；运行时卡内显示 6 段进度、阶段耗时与取消。原「按需修复组件」行删除。
  • 六个步骤：同一图标 → 序号徽标 + 状态色；行高 64→52dp；点按在行内展开详情与「重新检查 / 按需修复」，不再弹窗。
  • 「备份并重建环境」从全宽危险按钮改为组内红色行，确认改为底部弹层并要求勾选知情。
  • 日志默认收起成一行（含行数与复制），运行或失败时自动展开。
  • 中断维护 / 环境未就绪：状态卡上方给出唯一下一步横幅，其余按钮按门禁置灰。

首屏（手机 360、1.0×）可见内容：当前实现到第 1 步为止；新方案能完整看到状态卡和全部六步。
