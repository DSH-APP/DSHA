## 统一视觉验收（待做）

与同期其他页面原型一起按同一标准核对后再选定方案：

- 颜色、圆角、卡片 / 主按钮 / 徽标与 `shell_ui.xml` 主题资源及现有 CardPage 一致，不引入独立配色。
- 日夜、短屏、1.3 倍字体、中英文（英文文案更长）下无截断或溢出；触控目标 ≥ 48dp。
- 平板横竖屏布局（A 双列、B 主从、C 表格）与其他页面的平板策略统一。
- 新增短状态文案（如「已提交」「需恢复」）进入 i18n 并符合[文案长度政策](../../i18n-length-policy.md)。
