问题（用户反馈 2026-11-02）：更新卡在维护页，失败说明写着“也可进入受限主界面导出可读副本”，进去后找不到按钮。原因有两层：受限主界面要点 4 层（设置 → 数据与备份 → 环境修复与数据救援 → 只读救援导出）；而且维护未完成时「数据与备份」把「环境修复与数据救援」整行置灰（WorkspaceFragment.refreshBackupStatus），实际点不进去。后端 NativeBackupJobs.exportInternal 只在非 rescue 时拦截待恢复状态，救援导出本来可用。

改法：

  1. 维护页：失败 / 待恢复 / 就绪未通过时，在阶段卡与说明之间加一个「导出可读副本」次按钮（放说明下方时手机首屏看不到），直接打开救援确认（1 次点击）。底栏三列不变，大字体下不再挤。更新进行中不显示。
  2. 数据与备份：待恢复时卡片副按钮由置灰的「从备份恢复」改为可点的「导出可读副本」；说明文案改为指出这条出路；「环境修复与数据救援」行不再置灰（里面的恢复中断提交、回退运行时本来就是给这个状态用的）。「自定义导出」「重置配置」仍置灰。
  3. 救援确认：NativeDataActivity 新增 data_mode=rescue，首次打开即弹出现有「救援导出」确认框，后续流程（系统保存位置、tar.gz、尽力救援标注）完全复用。
  4. 失败说明文案改为“也可先点‘导出可读副本’保存数据”，中英文同步进 i18n。

不改门禁与后端：救援导出不停止写入、不写就绪标记、不进入受限主界面。
