状态实验台

直接跳到某个状态，或者在屏幕里点按钮跑完整流程：检查 → 下载 → 校验 → 安装。切换通道会自动重新检查，与 UpdateEngine.setChannel 一致。版本号与更新记录是示例数据。

平板交互（沿用插件页的双栏逻辑）

  • 横屏（≥ 840dp）：左栏放主卡、候选摘要和管理列表，右栏显示“候选版本 / 本版本”的更新记录。点左栏的候选摘要或“本版本更新记录”，只切换右栏，选中行带强调边。
  • 竖屏（600–839dp）：单栏，内容最宽 640dp 并居中；弹层改成居中对话框。
  • 手机：单栏，弹层从底部升起。“查看完整记录”沿用 CardSheet。
  • 受管运行时、兼容回退在三种尺寸下都沿用现有弹层和 RuntimeRecoveryUi。
