# App 内网页优化验收（2026-09-07）

本阶段补齐网页导出、返回顺序、状态恢复和文件选择。设备为 Redmi M2012K10C / Android 13 / 4 KB 页：覆盖安装标准调试版测试系统 WebView 116.0.5845.92，再回装兼容调试版测试 Gecko 143。应用数据保留，未发送消息或调用模型。

## 实现

- `WebDownloadModel` 共用下载和 SAF 保存逻辑：进度、取消、完整长度检查、SHA-256 回读验证、失败保留完整缓存以便更换位置；普通 HTTP 仅允许当前本机服务及同源跳转。
- Gecko 直接消费浏览器已鉴权的响应流；WebView 使用当前 Cookie 下载。WebView 的 Blob / data 文件通过顶层同源 MessagePort 分块传输，不暴露通用 JavaScriptInterface。
- 返回先交给网页已有的 Escape 处理；抽屉和详情面板沿用现有组件或 layout 服务，再处理浏览历史及退出。Gecko 使用内置 WebExtension，校验会话、顶层页面和来源。
- 配置变化时保留浏览会话，切换 Activity 上下文和代理；保存浏览历史，使用客户端适配记录当前会话和阅读位置。
- 图片草稿保存在本机 IndexedDB，恢复图片原始字节；同步修订号防止发送/删除后、数据库尚未提交时复活旧图片。已有文字草稿机制保持不变。加载期间新选的图片优先。
- 两种内核共用内容 URI 复制、20 个文件/合计 256 MiB 上限、文件名规范化和清理。文件选择失败时在 OPEN_DOCUMENT / GET_CONTENT 间回退，复制过程持有原生任务锁。
- 真实页面验收发现 WebView 116 缺少 `Promise.withResolvers`，导致 dsh HTML 启动信号报错。现通过文档起始注入补丁，在页面脚本之前补齐；AndroidX WebKit 固定为仍支持 API 23 的 1.15.0。[官方版本说明](https://developer.android.com/jetpack/androidx/releases/webkit?hl=en)

`WebInstrumentation` 使用独立 HTTP 页面、独立浏览器源和样本数据。导出操作实际打开系统 DocumentsUI 保存并回读，完成后删除测试输出；上传选择器由测试监视器返回明确授权的独立 PNG URI，后续内核回调和读取链路真实执行。

`RealWebInstrumentation` 在真实 dsh 0.1.2-rc.1 页面确认：HTML 启动 Promise 已完成、页面布局已渲染、`dsh-app-integration` 客户端服务装配成功。该测试结束后停止其启动的服务并恢复自动备份计数。

Java 回归测试及两种调试版本构建通过。Node 测试覆盖图片恢复竞态、修订号、容量/类型限制，以及启动 Promise 的解析、拒绝、子类和保留原生实现。

## 覆盖边界

Android 6/7、11/12 和 16 KB 设备尚未真机覆盖。草稿验证包含真实 Activity 和浏览会话重建；下载缓存验证包含新模型及 Bundle 恢复，不能据此宣称已覆盖所有厂商的系统强杀行为。云文档提供方、完全不可用的系统选择器、超大附件和长时间后台传输没有完整设备矩阵实测。

本阶段不改变离线环境版本，也未清空用户主应用。合法用户备份继续保留。
